# 单批经验跨多门槛：H03 后续训练裁定

日期：2026-10-16。处理范围为目前运营适配器支持的普通单一核心职业；不是多职业、双职业或 Bard 的 XP 分配规则。

## 问题与证据边界

历史视角 H03 已复现：一级战士一次收到 5000 XP，完成二级课程后 XP 仍为 5000，但评价清空；直接开启三级候选需要评价，补录 0 XP 冒险又被已达门槛的经验停止规则拒绝。问题是已被系统接受的状态没有继续处理的出口，不是应当自动连升两级。

原书依据沿用本轮已核 DMG 印刷 86 / PDF 87 的完整页证据（来源 `dmg:86:gaining-levels`，原件哈希及复核方法见 `character-training-stage-evidence.md`）。该页要求评价按冒险等权、达标后停止后续经验、完成训练才授级；但页面示例没有唯一规定一批已接受 XP 同时越过多个阈值时，下一课程评价如何消费。现有整批入账采用解释不能反过来被冒称成所有溢出细节均已原书封口。

## 决策：显式、有界的采用解释

新增可选操作 `adopt-overrun-basis`，解释标识为 `reuse-recorded-adventure-ratings`。不默认执行，不自动修复导入文件；DM 必须明确确认、记录理由并核对引用的真实历史评价。只在完成实际授级、没有未消费评价、没有已开启课程，而且现有 XP 仍满足下一候选时允许。

本操作复用上一已完成课程的**完整**评价集合。每个 ID 必须唯一对应真实 `experience.awarded` 历史事实；无法新填一个更优评级、不能挑掉较差冒险、不能引用未知或重复 ID。若上一课程已经采用过本解释，则沿用该课程原已记录的完整依据，不凭空生成新冒险。

结果仅恢复后续训练的评价依据，XP 与等级不变。随后仍需单独开启候选、处理职业/等级上限门槛、制定计划、支付真实费用、记录占用时间并授予一个等级。记录带有 `ruleStatus=campaign-adoption-not-unique-raw`，公开档案和重放均保留该标记。

不采纳静默截 XP、把经验压到下一阈值减一、伪造 0 XP 冒险、免费复用旧课程付款/时间、一次训练授予多个等级，或把本解释作为唯一 RAW 默认值。它是一项逐课程的显式采用记录，尚不是完整战役配置文件中的持久可复用政策或所有溢出处理变体。

## 交互和旧档

发现对应待处理状态时，运营页展开采用解释说明，暂停普通“开启候选”按钮，列出上一课程实际评价。须完整选择、勾选明确确认并说明理由。依据缺失/不唯一时停用自动复用并提示保全原档，不因该辅助列表失败而中断其他角色数据显示。

旧行动输出结构不变；新操作是追加事件。旧档在完成一次授级后仍有足量 XP 的状态可走此入口，不必删除过去行动或改写快照。异常/歧义历史没有自动猜测迁移。本次不解决固定规则实现版本重放、全部旧文件升级或完整房规管理。

## 验证范围

专项用两个真实评价 E/S、总计 14000 XP，逐次完成 1→2→3→4，平均 1.5 周保持不变；每次单独付款和训练，XP 恒为 14000。测试缺失确认理由、未知解释、空/重复/不存在引用、挑选较好评价、重复采用、缺少实际授级和后续 XP 不足的拒绝；失败不修改原状态。没有虚构额外经验事件。

完整创建生命周期分支从真实已准入战士出发，单次 14000 XP，加独立实际资金入账，完成三次付款和三段日历占用，最终四级、14000 XP、钱包实际扣除 9000 gp。档案 JSON 重开重放一致；篡改采用引用必须拒绝。专项与集成测试不替代该新分支的浏览器点击、所有职业、扩展、多/双职业、配额或全系统发布验收。

H03 的有界显式继续路径已实现；尚未确定原书唯一溢出解释。H04 无日历授级、H05 冲突后果和 H06 时点/地点连续性仍单独待处理。
