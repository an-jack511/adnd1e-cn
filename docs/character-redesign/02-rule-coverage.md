# 规则覆盖矩阵与证据缺口

## 口径

定位均为**印刷页**，除特别注明不推断PDF页。原件位于项目父目录 `__RESOURCES/CORE 3` 与 `__RESOURCES/Extensions`。扫描映射必须逐项登记，DMG后部不能统一+1；本轮新核 DMG74→PDF75、79→80，PHB11→12、36→37。MM“4th Edition August1979”是该书印次标识，不是D&D4e。

证据：S=沿用署名共享证据与规则包页图核验，不是本轮重新阅读；N=本轮主任务查看原页图；U=仍待研究。实现：D=规则数据/计算存在，W=局部工作流，I=生产整合，P=仅本轮合成原型，U=未知/待补。一个D不能当作整个系统I。下列测试文件位于 `scripts/`；存在和通过计算测试不代表原书全部正确或UI已通过。

每行是功能簇，不是“每条原书规则全收录”。后续需要继续拆成原子条目（ruleId、原书版本/哈希、原文定位、适用/例外、决议、黄金输入输出）。本表不报告覆盖率百分比。
