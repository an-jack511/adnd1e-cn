## 三个真正可操作的原型流程

### A 创建一级魔法师

路径：创建 → 确认演示战役 → 使用示例实体骰记录 → 分配/检查 → 固定人类魔法师资格 → 输入姓名 → 初始授予说明 → d4 HP及2d4财富/采购 → 最终缺项 → 确认替换演示 → 人物卡。

浏览器实际输入 `原型验收·伊莱恩`，使用示例原骰的10/16/11/12/14/10，d4=4、资金3+3，采购866cp，余11134cp即55.67gp。卡显示1级、4/4HP、通常无甲AC10。生成前明确列出未完成的年龄/语言/熟练/准入等，不伪称完整RAW创建。各个DMG方法的算法另由单测覆盖；本轮浏览器只贯穿示例方法I，没有逐种方法全浏览器测完。

### B 一次冒险

实际操作：攻击目标AC−4 → 矩阵20；打开伤害2预览 → 取消 → HP保持4/4；重新预览确认 →2/4；实际恢复1 →3/4；团桌确认施法前提 →睡眠术准备副本消耗；使用火把 →6变5。切换视图保留同一人物。

额外负例：伤害恰到0时显示范围外原因，应用前阻止，HP与事件不变。准备耗尽后没有一键补满或因课程经过七天而恢复。当前原型只核基础矩阵，不处理武器/情境修正、战斗轮次、法术实际命中伤害、材料库存或零HP正式流程。

### C 经验、训练与长期意向

实际结算2501XP与1600gp，确认演示DM评级E；等级仍为1。预览导师路线，1周/1500gp，第1→8日；确认付款。到时间线明确登记七日实际课程（演示前提连续/同地/无冲突），仍未授级。成长输入d4=3，预览等级1→2、最大HP+3，当前HP保留3。应用后人物卡为2级、3/7HP、2501XP，法术仍耗尽。钱包余155.67gp。

提出研究计划仅新增意向，金币/日期/HP/书内法术不变，没有秘密成功检查或收益。上述“七日实际发生”是明确的合成前提，不是生产日历/地点/后果守卫已通过；完整非合成A/B/C仍列为阶段B–D门槛。

4. 生命周期：正式A/B/C、全部职业1→2、名号阶段前后、死亡/复活/永久变化、随从/研究/制造及中断/后补冲突；不能只测提交成功。
5. 迁移：所有旧格式→候选→回导原件字节相同；真正可运营适配逐步投影等价；未知字段/版本/事件尾部保全只读；公开投影不能逆造私档。
6. 存储：多标签CAS、保存中继续操作、延迟文件读取、并行打开/保存、配额、损坏、升级受阻和关闭数据库；成功生成的输出必须能重读/保存，行动/文件大小上限要对称。
7. UI：360/768/1280、320窄屏、200%缩放、仅键盘、模态Esc/焦点返回、屏幕阅读器与状态反馈、打印全部分区；新旧正式入口不矛盾。原型局部验证不替代它们。
8. 隐私：DM秘密标记不得存在玩家DOM/脚本载荷/IDB公开视图/导出/错误信息；本地模式不声称认证。
9. 发布：规则包封版摘要、全链接/静态资产、既有功能回归、可恢复部署版本及明确迁移说明；通过后才切换正式入口与远端发布。
