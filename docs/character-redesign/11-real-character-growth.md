# 正式角色成长接入

日期：2026-10-17。增量验收，不是整个角色系统完成声明。

## 产品与数据

`/character/growth/` 不再是单纯的演示或巨型事件表单。它与 `/character/sheet/` 共用 CharacterWorkspace、正式档案、Action 预览/提交、现有 IndexedDB 角色库及并发版本检查。导航携带角色与分支；刷新按精确槽位恢复，不悄悄改用另一角色。尚未保存时禁止直接切换。

界面展示已取得等级、下一经验门槛、训练阶段、当前下一任务、候升豁免与攻击表对照。普通操作不暴露事件ID、来源ID、原始JSON或底层裁定结构。创建和战役记录仍明确标为过渡入口，没有另建第二个角色库。

成长 Actions 覆盖最终经验结算、独立钱币入账、资格候选、训练方案、实付、明确日历、实际开课、连续训练分段、正式授级、实际当前HP结算、严重中断与重新开课，以及明确的资格例外和跨门槛评定采用。

主要模块：application/campaign-growth、actions/growth-actions、ui/campaign-growth-panel；复用原有 core-advancement、core-training、dated-training、calendar 与 campaign-runtime，而不重写另一套升级规则。

## 核验规则与边界

- DMG 印刷86 / 本项目PDF87，完整页图复核：经验足够不直接授级；冒险评定等权平均，保留分数；名号前按当前等级×1500gp/周；同职业同专业的实际导师与可用性不能由程序假定；合格自修的时间和总费用加倍；实际达到名号后才切换阶段。
- 名号后四个印刷收费族单独处理；原书未明确列出的职业不默认套战士族，需注明采用理由。对应名号等级仍使用已有PHB数据，本轮未重新逐页核验十职业所有高等级表。
- 经验输入为DM已经确认的最终奖励，不再乘属性奖励；实际金币收入不再自动授XP。跨多个门槛仍逐级训练，复用上一课程完整评定须明确战役解释，不能冒称唯一RAW。
- 训练费用与时长保留精确分数，不默认舍入。gp输入按200cp/gp精确解析；不足整cp拒绝。实际付款可部分预付；自动选择仅用钱包已有面额，不暗中换币、找零或挪款。付清前不能开课。
- 课程使用明确采用的战役日历、真实连续时段与地点；不随电脑时钟完成。已有日期、活动后果与位置连续性检查沿用既有策略。
- 生命骰按职业/等级与已记录体质处理。授级改变最大HP后，当前HP待实际结算，不自动治疗，不自动增加已准备法术或制造法术书条目。
- 超出明确数字等级上限的处理只能标为战役例外；旧无分类历史保留原状，不追溯伪称普通事实确认。

刺客数据仍存在 PHB 上限表与职业等级/行会规则的待解释冲突。测试fixture显式采用本战役例外，不构成解决该冲突的普遍规则，也不意味着普通低级刺客RAW必需这一例外。多职业、双职业、吟游诗人路径、UA/OA及完整高等级特殊条件未由本页全部验收。
