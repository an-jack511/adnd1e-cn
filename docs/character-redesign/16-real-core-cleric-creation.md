# 核心创建实跑记录：一级牧师

本记录是本地开发站点上一次完整浏览器验收，不是静态页面截图，也不是规则完整性宣称。

## 实际流程

- 站点：`http://127.0.0.1:4321/character/create/`
- 属性方法：DMG 方法 I；真实生成并分配为 STR 17、INT 15、WIS 17、DEX 10、CON 12、CHA 7。
- 身份：人类男性、守序善良、单职业牧师；核心资格检查通过。
- 一级生命值：浏览器实际掷得 1d8 = 3，记录为最大 HP 3。
- 起始金钱：手工记录 3d6 = 1、2、3，按 PHB p.35 记录为 60 gp。
- 语言：记录 4 项智力额外语言，并逐项记录 DM 对战役可用性与取得方式的确认。
- 武器熟练：木棒、战锤；通过牧师武器许可检查，保留 PHB p.37 与 p.19–20 的来源。
- 装备：钉头锤，按 1600 cp 的实际价格采购，支付 8 gp，余额为 52 gp；系统拒绝了第一次不守恒的输入，修正后才接受。
- 初始神术：选择“本次未授予／暂不准备”，记录 DM 确认、战役时点与 0 个准备副本。没有执行 Chance to Know，也没有把 PHB 神术表当成已知法术书。
- 灵能：战役配置明确 disabled。
- DM 审核：确认装备、未授予神术及入场约定，记录准入并保存进入正式人物卡。

## 正式人物卡可见结果

正式档案 ID：`7335c4de-c36e-46cc-8091-9ef4d58b62b8`（仅为本地验收档案）。

- 人类／牧师 1 级
- 当前 HP 待确认／最大 HP 3
- AC 待确认；系统没有从背包自动推断实际穿戴
- XP 0
- 法术：一环容量 3，当前准备副本 0；页面明确显示没有可用准备副本
- 装备与财富：钉头锤 1，账面财富 52 gp

## 验收结论

这条流程证明核心单职业神术角色可以在不伪造授予结果的前提下进入正式人物卡，并可随后通过战役中的祈祷／准备流程请求神术。它不代表牧师的所有长期运营、据点、随从、研究和复活规则已经完成；那些仍属于核心后续阶段。
