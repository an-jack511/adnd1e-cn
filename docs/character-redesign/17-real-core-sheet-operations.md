# 核心人物卡实跑记录：生命、穿戴与资源动作

基于本地浏览器中的正式人物档案 `牧师核心验收`，验证创建之后的常用团桌动作。

## 实际通过的操作

- 从“待确认”记录团桌实际当前 HP 3/3；确认框明确要求这不是治疗或重置。
- 确认实际无甲无盾；人物卡计算 AC 10，并保留“背包库存不等于已穿戴”的边界。
- 记录 1 点伤害，选择“严格零 HP”作为同一击进入负 HP 的战役处理，HP 从 3 变为 2。
- 记录 1 点实际治疗，HP 从 2 恢复至 3；恢复不超过最大 HP，也不替代零 HP、复活或休养规则。
- 每个动作均先显示预览，再由“确认应用”追加正式事件；取消不会改变档案。
- 最近活动时间线显示当前生命、穿戴、伤害和治疗事件；页面提示档案已保存到本机。

## 重要边界

人物卡不会从背包自动推断穿戴、AC、手部占用或穿脱时间；不会把“治疗”当成复活、苏醒或解除休养禁令。攻击查表仍显示职业原表目标，力量、熟练、距离、魔法与情境修正留给相应规则动作或 DM 裁定。

这证明的是核心人物卡的常用运行链路，不等于完整生命状态、战斗修正、法术恢复、升级训练和长期活动已经全部完成。
