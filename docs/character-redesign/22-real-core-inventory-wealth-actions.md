# 核心人物卡：财富与装备操作实测

## 范围

正式人物卡现在把已核验库存账本投影到玩家工作区，提供四类常用操作：

- 记录财富入账；
- 记录实际财富支出；
- 记录物品位置变化；
- 拆分原书明确标记为 `dozen`／`score` 的同质整包。

这些操作都走人物档案的预览—提交—重放路径，不直接修改派生总值，也不让玩家编辑底层事件 ID。

## 规则边界

财富入账只改变明确指定钱包中的钱币数量，不自动授予经验、生成战利品来源或把参考价格当成交价。支出要求“交付 − 找零 = 支出总额”，并保留每种面额。

物品移动只记录位置事实；程序不把位置变化解释成负重合法、可及或移动率结论。负重只显示已知重量下界，未知重量、体积、力量修正和实际移动率仍留给 DM。

拆包只允许规则数据明确给出同质计数单位的物品；混合包和内容未知的包不会被程序猜测。

## 浏览器验收

在既有牧师核心档案上打开“我的角色 → 装备与财富 → 记录财富支出”，输入 1 gp 交付、200 cp 总额后，预览显示：

> 账面财富：52 → 51 gp；钱币重量与具体钱包均保留在档案中。

随后取消预览，人物仍显示 52 gp，证明预览没有写入状态。正式人物卡同时显示物品数量、位置、已知重量下界，以及“使用／损失”“移动”“拆包”入口。
