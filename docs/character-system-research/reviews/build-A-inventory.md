# Build A：核心装备、货币与负重账本（仓库摘要）

日期：2026-10-14。详细研究原件保存在工作区研究目录；本摘要随实现进入仓库，作为发布门禁的可追溯证据。

核验范围为本地 PHB 印刷 p.35–38、101–102。实现录入 p.35–36 的 165 个价目项，以 `200cp=20sp=2ep=1gp=1/5pp` 的整数铜币价值记账；钱币负重按枚数而非面值。原表价只作参考，实际成交必须保存 DM 供货决定、议定价、付款、找零、实例 ID、数量和位置，并在一个修订中满足价值守恒。

物品是有稳定 ID 的实例，容器/穿戴/人物/坐骑/仓库是位置节点，拒绝包含循环。只为 PHB p.37 能明确对应的武器保存近似重量；范围、套装不一致及未列重量保持 unknown。负重输出只给已知重量下限和 12/9/6/3–4 寸参考档，最终结果始终要求体积、力量和 DM 裁定。

`scripts/test-core-inventory.ts` 覆盖 165 条唯一 ID、代表价格、币值与钱币重量、原子采购守恒、供货/余额/revision 拒绝、实例位置、未知重量下限和 3–4 寸范围。未覆盖职业/种族装备许可、护甲与战斗数据、多数重量/容量、消耗/转移/债务、持久化与 UI；因此发布门禁保持 partial。
