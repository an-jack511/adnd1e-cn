# H06：连续训练的地点边界核对

日期：2026-10-16。仅处理连续课程内部相接片段的地点变化，不声称已经完成全人物的世界位置/时钟。依据沿用已核 DMG37 的活动和 whereabouts 记录、DMG86 的连续训练及旅行限制，不新增原书未核的移动速度或魔法效果规则。

## 问题与决策

此前两段课程只须游戏时间首尾相接，地点可以从城 A 变成遥远城 B，而没有任何移动或地点认定事实。不能默认瞬移，也不能由此改成“所有课程片段必须同地点”的额外 1e 限制。

新 `locationPolicy=v1` 要求检查每对相接课程片段。地点标识相同时无需新记录；标识不同时，必须有对应人物、精确片段对、原/目标地点、同一时间边界、DM 理由与实际证据的 `locationTransitions` 事实。不能仅写一段无对象的普通理由。

支持两个有界情形：

- `same-physical-place`：DM 核实两个标识实际指同一物理地点，不全局替换旧地点 ID。
- `instantaneous-movement`：DM 确认有实际依据的瞬时移动，并明确课程没有因此中断。不自动施放法术、不扣组件、不赋予角色任何新能力，也不认证任意法术的具体效果。

这些是事实裁定，不是原书列举的两种统一移动规则。普通旅行不能把 method 字符串改成上述情形就合法化；仍需实际来源和 DM 明确确认。记录没有改变任何活动时间或训练进度，也不能豁免另外登记的实际旅行/冒险冲突；后果检查仍独立执行。

## 兼容

新日期授级要求明确 `locationPolicy=v1`；旧无标记授级保留此前重放结果，只能作为历史读取，不能由新写入口提交。该策略独立于 `consequencePolicy=v2`：一个描述地点边界检查，一个描述活动后果检查，不以“版本升级”覆盖全部旧算法。

新策略行动才在日期授级元数据中写入地点策略标识，旧快照没有凭空新增字段。过旧或缺标记的完成历史在界面提示未被当前全部检查认证。完整固定规则版本重放和历史修复仍不是本次交付范围。

## UI 和验证

课程训练区列出待核对的相接地点边界，选择实际情形、填理由/事实来源、明确确认连续性后追加记录。未解决时新授级停用/拒绝。时间断缝仍先由原日期覆盖检查处理；不能通过地点记录补掉一段旅行时间。

专项验证同地点、不同地点、实际瞬移及同一物理地点认定；缺确认/缺来源、普通旅行方法、错误人物/时间、重复边界、时间断缝均拒绝。输出保留原活动与进度。

完整创建生命周期分支以两段历史课程对账到不同地点：新授级拒绝，旧无地点策略的合成历史仍可原样重放，但新写入口拒绝；明确实际外部位移后才可授级，钱包不额外变化，JSON 重放一致。另验证记录实际位移后，若期间还有真实旅行活动，原后果冲突仍阻止授级。

这是有界课程地点核对，不是全世界旅行系统或自动魔法模拟。尚未解决首次课程与此前冒险的地点连接、人物“当前游戏时点”、所有活动的跨地点轨迹、事后回填与能力生效时点的完整联系，以及本新分支的浏览器验收。H06 不能据此整体标记完成。
