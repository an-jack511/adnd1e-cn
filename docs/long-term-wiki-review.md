## 审查顺序

对每一册、每一页/页组和跨页连接，按以下顺序处理：

1. **3R**：先核对原书页码、章节顺序、标题层级、表格结构、插图位置和跨页关系，确认内容确实属于该页/该书。
2. **5E**：核对英文原文、术语、专名、规则数字、单位、缩写、表格列和链接目标，保证英文内容有对应中文；允许保留格式必需的英文缩写、中英对照、英语副标题、专名原文和版权页英文。
3. **5R**：按现代中文阅读习惯重写不流畅、机械直译、过度简略或语义不完整的中文；不得为了顺口改变规则数字、条件、例外、概率、范围、持续时间或行动顺序。

术语核对优先参考灰机 Wiki 与 5e.tools 中文站／镜像中已经核对的中英名称，并与站内术语表交叉比对。统一译名必须同时满足：原书语义准确、符合 3R→5E→5R 的核对顺序、符合现代中文翻译惯例，并能在相同规则语境下跨页跨书稳定复用；旧版 AD&D 专名与新版译名冲突时，保留版本差异并在术语对照表中记录，不机械套用。外部资料只作为术语与专名参考，不复制其规则正文，不把不同版本名称混用；无法直接访问的来源须标明“未直接读取”，不得假称已逐页核验。

## 翻译与术语要求

### 已确定的固定译名

- `Magic-User` 统一译为“魔法师”；`magic-using creature(s)` 在表示具有施法能力的生物时统一译为“施法生物”，不使用生硬的“魔法使用者生物”。
- `proficiency` 泛指通过训练或实践获得的熟练程度时译为“熟练”；指可计数、可取得的规则单位时译为“熟练项”。具体术语包括“武器熟练项”“非武器熟练项”“角色熟练项”“荒野熟练项”“地城熟练项”“工匠熟练项”“蛮族熟练项”“通用熟练项”“宫廷熟练项”“骑乘熟练项”“划船熟练项”“空中骑乘熟练项”“植物学熟练项”“文化熟练项”“动物处理熟练项”“陆地骑乘熟练项”“龙骑乘熟练项”“绳索使用熟练项”“熟练项检定”“熟练项栏位”等。
- `proficiency` 只有在明确表示专业领域、专长领域或一般特长时才译为“专长”；不能把规则熟练项机械改成“专长”。“专长”可作为旧译别名保留在中英术语表中，但不作为正文主译名。
- 核心规则名词按语境固定区分：战斗时间 `turn` = “回合”、`round` = “轮”、`segment` = “段”；`spell level` = “法术环级”、`spell slot` = “法术环位”、`caster level` = “施法者等级”。法术书容量、费用、经验值或学习时间按法术级别计算时用“环级／每环”，不得误写为施法者的“环位”。
- 六项属性统一为 `Strength / STR`“力量”、`Intelligence / INT`“智力”、`Wisdom / WIS`“感知”、`Dexterity / DEX`“敏捷”、`Constitution / CON`“体质”、`Charisma / CHA`“魅力”；`Wisdom score` 译为“感知值”。只有明确指属性时才将 `Wisdom` 译为“感知”，普通语义仍依上下文译为“智慧”等，不得盲目全局替换。
- `THAC0` 等规则缩写、属性代码和骰式按规则惯例保留；具有实际语义的法术、物品、装备、职业、种族、人物、地理、怪物、规则动词和设定名词仍须使用中文主译名。
- AD&D 1E 的 `Breath Weapon` 统一译为“喷吐武器”，豁免类别译为“对喷吐武器豁免”；“吐息武器”作为新版语境的译法记录为版本别名，不混入 1E 正文。
- 标题中的中英对照不加括号；中文为主标题，英文为辅助标题。正文替换英文后，清除仅为中英混排留下的中文间空格。

- 逐页检查：大标题、中文段落、表格标题、表头、表格单元格、脚注、图注和交叉引用中的英文均须有中文对应。
- 审查时先区分英文的功能，不把所有英文都当作漏译：THAC0、AC、HP、HD、STR、DEX 等规则缩写/属性代码，骰式、单位代码、来源代码、书目代码和格式必需的英文可保留；这类保留不计为翻译缺失。
- 必须翻译具有语义的名称和规则词：法术名、魔法物品名、武器与装备名、职业与子职业、种族、角色/人物、地理、怪物、其余规则名词与动词，以及战役设定名词等。英文原文可在首次出现、表格双语列、英语副标题或专名需要时作为辅助保留。
- 中文标题和中文正文中的语义专名必须使用中文译名作为主要显示形式：人物、神祇、组织、种族、地理、城市、国家、怪物、法术、物品、装备及其他设定名称不得只保留英文，也不得出现“Southern 艾尔戈斯”这类中英混排。英文可在英语副标题、原书标题、双语对照表、来源核对位置或首次出现的括注中作为辅助信息，但不能替代中文正文中的译名。
- 对已确认译名的专名，跨页、跨书统一使用同一中文形式；存在不同版本译名时，在站内“中英术语对照表”或审查记录中保留英文、中文及核对状态，供后续复核。
- 中文译名替换英文后，须删除原先为英文与中文混排而保留的多余空格；中文与中文之间不得留空格。只有英文原名、缩写、代码、数字单位或确需分隔的中英对照仍保留空格。
- 首次出现的必要英文术语可采用“中文（English）”；同一书内及跨书相同规则概念必须统一中文名，除非来源明确要求区分。
- 规则缩写可保留，但正文首次使用时应有中文释义，或上下文已明确其含义；不能用缩写掩盖应翻译的完整规则名称。
- 英语副标题、版权页、出版信息、专名原文、咒语/誓言等格式或内容上必须保留的英文不强行翻译；这类保留不等于漏译。
- 同一英文词不得在相同规则语境中随意切换译法；若确实存在版本、职业、世界观或规则层级差异，须在术语表或审查记录中说明。
- 发现翻译不完整时，优先补齐原意，再做中文润色；不得用概括代替规则细节。

## 排版、分页与图片要求

- 同一书、同一类页面的标题层级、中文/英文副标题格式、表格对齐、来源行、页码行、列表和图注保持一致。
- 书籍阅读模式按内容连续阅读；不要把原书因分页产生的“（续）”“（再续）”“（续完）”“Continued”等标记继续作为 wiki 分节标题。可保留真实文章名称中的“继续”“未完待续”等含义，但不能把单纯分页标记当作新的章节。
- 跨页内容应合并到同一语境下，保留必要的原书页码来源标记；页码标记不能破坏标题层级或制造重复章节。
- 深色模式下检查正文、英文副标题、来源行、表头、链接、选中状态、边框和输入控件的对比度；禁止使用仅在浅色背景可读的硬编码深色文字。
- 删除重复图片、裁剪不周图片、模糊或无必要的原书文字扫描图；保留裁剪良好、清晰度尚可且确实有规则/叙事价值的插图、地图、图表或版式示例。
- 发现无法安全自动修正的图片问题，记录文件、页面、问题类型和建议，不用猜测替换素材。

## AI 痕迹与编辑说明

- 除首页允许保留的翻译声明和版权声明外，公开页面正文、章节标题、表格、图注、来源说明和页脚不得出现“AI”“GPT”“人工智能生成/翻译”“按原书概括”“不能简单套用”等工作过程说明。
- 如果内容与原书不同：优先按原书补全并忠实翻译；确需概括、节选或删改时，只使用简明、事实性的编辑说明，例如“按原书概括”“未采用 XX 规则”“节选自原书”“较原书有删改”，并放在明确的编辑说明位置。
- 不把尚未核对、来源不完整或仅为建议的内容写成“原书规则”；不把本项目的实现限制写成玩家规则。
- 修订机械、过短、缺主语、中文逻辑不自然或明显由英文逐词映射而来的句子；以忠实、清楚、可检索为优先。

## 工作方法

1. 先做只读盘点：工作树、站点构建状态、目录/章节清单、术语报告、已有审查文档和当前线上页面。
2. 按书籍和页面顺序建立审查记录；自动检查只用于发现候选，最终修改必须回看上下文和跨页关系。
3. 修改源 Markdown、术语表或样式后，重新生成其明确派生数据；不要手工只改搜索索引而留下源数据不一致。
4. 至少运行与改动相关的验证：数据校验、链接检查、阅读布局测试、术语检查和生产构建；涉及排版时检查浅色与深色模式截图。
5. 每批修订在审查记录中登记：文件、页码/章节、问题类别、修改内容、来源依据、是否影响跨页语境，以及修订计数。

## 修订计数与推送节点

- “修订 1 处”按一个独立可复核的内容改动计数：一个术语统一、一个漏译补全、一个句子修订、一个标题/分页标记清理、一个排版规则修正或一个图片处理决定均可计 1 处；纯生成文件同步不重复计数。
- 使用 `docs/long-term-wiki-review-ledger.md` 登记累计数、批次、文件范围、验证结果和提交哈希。
- 生产构建约每累计 500 处内容修订集中执行一次；以台账中的“最近一次成功构建累计数”为基准。两次构建之间先专注实质修改和必要的数据校验，不因小批修订反复构建；若改动风险或发布验证需要，可提前构建并记录原因。
- 每累计达到 200 处修订：先完成当前安全验证，再执行一次 `git commit`，随后执行一次 `git push origin main` 作版本留档；推送不需要另行等待或重复检查远端状态。
- 未达到 200 处时保留本地工作树与审查记录，不为了凑数制造改动。
- 提交只包含本任务已明确审查的文件；用户原有的无关改动不得一并提交。

## 工作批次与汇报节奏

- 工作批次按完整一本书或半本书划分；完成一个批次后再做阶段总结，避免按零散页面频繁汇报。
- 对微校格式、表格密集或版式复杂的书，优先按半本书集中处理；若一本书内容较短，则按整本书完成后总结。
- 批次总结应概括该书或半书的翻译、术语、排版、续页标记、深色模式、图片和 AI 痕迹审查结果，并同时报告本周期修订累计数。

## 当前优先级

1. 优先修订实质内容：漏译、误译、术语和专名不统一、规则细节缺失、语句过度简略或不符合现代中文习惯。
2. 在实质内容完成后，再集中处理空格、括号、英文辅助显示及其他混排格式问题。
3. 清理书内和跨页阅读模式中的分页型“（续）”标题，并同步目录、搜索和阅读数据。
4. 修复已能确认的深色模式低对比度样式和同类页面排版不一致。
5. 对 PHB、DMG、MM 及当前已公开的扩展书按目录顺序做翻译完整性与术语一致性审查；再处理图片冗余、裁剪、清晰度和跨书重复资源。
6. 每一批完成后更新审查台账，记录未解决问题和下一批入口。

### 后置专项：DLA 中英混排

DLA 中英混杂严重：既有应译英文散落在中文标题、正文和表格中，也有中文译文夹在英文句子或名称内部，导致阅读混乱。此项明确后置：在主要规则书与主要规则拓展中的规则名词完成梳理、校准纳入术语库，并完成跨书译名一致性核校之前，不开始 DLA 混排专项，也不因 DLA 问题转移当前规则校订重心。上述规则阶段完成后，再集中清理 DLA 的漏译、半译、中英交错和标题/正文不一致。清理时逐项结合原文语境判断，不做盲目的全局替换；英文副标题、必要的原文对照、来源代码和格式必需缩写仍按前述保留规则处理。
