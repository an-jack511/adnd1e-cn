4.0 士气、纪律与指挥 Morale, Discipline and Command

士气值反映部队整体的斗志与热情。指挥官能发令、重整部队；旅和军队另有上级指挥官。部队的士气、智力和阵营共同决定纪律，也就是服从命令、有效作战的能力。

A. 士气 Morale

[4.1] 确定基础士气 Determining Base Morale

所有部队的初始士气都是 11，按表 3 修正，得到基础士气 ML，写入军队名册。战斗中的当前士气会因情境变化，须随时记录。

有些特殊怪物从不作士气检定，或有特别加值；须在开战前明确定义并记录。不检定士气的部队，如狂战士和喋喋怪，不会溃逃，但仍须计算士气值，因为某些与溃逃无关的情况也要求士气检定。

D&D 规则中的人类和怪物士气，是为角色扮演的小队行动设计，不适用于大战；忽略原值，按本节重算。

表 3：基础士气修正 Morale Modifiers

AD&D 的特殊、超常能力按 DMG 定义，两项加值可以同时取得。D&D 则按生命骰后每两个星号给予基础士气 +1，向下取整。

例。十二个 10:1、1 HD 兽人模型组成正规部队，穿皮甲、持长剑 +1：11 +1（魔法装备）−1（AC 8）+1（正规）=12。六个 5:1 山丘巨人模型组成散兵，各有隐形药水：11 +2（9 HD）+1（魔法装备）−2（只有六个模型）+1（AC 4）=13。

例。基础士气 12 的兽人，由魅力 17 的战士指挥，以密集队形行进，被火球杀死 30%：12 +1（密集）+2（指挥官 CB）−1（魔法移除模型）=14。基础士气 13 的山丘巨人，已损失超过一半，又遭幽魂从后攻击：13 −2（伤亡）−2（后袭）−3（吸取等级）=6。

[4.3] 士气检定 How to Check Morale

所属玩家掷 2d10。结果不高于当前士气则成功，否则失败。

[4.4] 何时检定士气 When to Check Morale

表 5：士气检定时机 When to Check Morale

  • 首次损失初始模型的 25% 后，立即检定。
  • 首次损失初始模型的 50% 后，立即检定。
  • 已损失 50% 后，每再损失一个模型时检定。
  • 每次因魔法移除模型时检定。
  • 部队指挥官被杀时检定。
  • 近战阶段结束时，与不死生物或吸取等级的生物底座相接。
  • 近战阶段结束时，接触本部队无法伤害的生物，例如只能被魔法武器伤害的生物。
  • 散兵模型的基本地面移动距离内，有友方部队或模型溃逃。
  • 其他规则或战役规定的时机。

同一次攻击触发多项条件，只检定一次。例如一次火球使伤亡超过 50%，只作一次检定；若先中火球，再遭另一部队齐射、使总伤亡超过 50%，则是两次不同攻击，须检定两次。

同轮不同阶段分别触发条件，仍须各自检定。原书示例为：射击与魔法阶段被火球移走一个模型；移动阶段穿越射击使伤亡超过 50%；近战阶段指挥官遭隐形刺客杀死；阶段结束仍接触不死生物，共四次检定。此例保留原书列举顺序，实际阶段顺序仍按 [1.0]。

[4.5] 士气检定的结果 Effects of Morale Checks

成功没有不利效果。密集队形失败，立即散为疏开队形；并非实际移动，只把模型分开。不能借此增加正面模型数，但可以减少。

疏开、散兵或乌合队形失败则溃逃，立即背离敌军移动自己的移动率，再加该移动率的 ⅓，结束时背朝敌军，另见 [7.15] 和 [6.0]。

C. 指挥 Command

[4.7] 指挥的定义 Definition of Command

所有正规部队都必须有部队指挥官，乌合之众与散兵有时也有。旅、军队指挥官统辖多个部队，并直接指挥没有部队指挥官的乌合之众和散兵。

当全体模型均在部队指挥官的指挥半径内，且部队未因纪律失败失控、也未溃逃，便处于受指挥状态 In Command；否则为失去指挥 Out of Command。

正规部队必须受指挥，才能进入密集队形、以密集队形移动、且战且退，或采用 [11.6、11.7] 的特殊队形。受指挥的正规部队获得战斗与士气加值。失去指挥的正规部队或散兵仍能移动和作战，但不获相应加值。乌合之众无论指挥状态如何，始终受失去指挥的处罚。指挥官还能重整溃逃部队。

[4.8] 指挥半径 Command Radius

每名指挥官都有指挥半径 CR。人类或类人生物指挥官的 CR =（魅力 + 等级）÷2；战士及其子职业，如游侠、圣武士，再加 3 英寸。类人怪物或怪物指挥官的 CR 为其移动率的 ⅔。

指挥官必须能与部队交流。即使在 CR 内，魔法沉默或黑暗也可能令部队失去指挥。谁能指挥何种部队没有绝对限制，但应考虑阵营、种族仇恨、语言等。以常识选择指挥官。心灵感应等特殊能力的指挥效果，由战役或裁判事先规定；允许例外前应仔细考虑，并在开战前明确全部必要条件。

[4.10] 指挥层级 Command Hierarchy

部队指挥官只指挥自己的部队，不能使其他部队成员受益。

旅指挥官统辖 4–8 支部队，可以在部队指挥官阵亡后接管，重整溃逃部队而不论原指挥官是否存活，使超出原部队指挥官 CR 的模型重新受指挥，也能向乌合之众发令。只有一方超过七支部队，而且能组成至少两个各含 4–8 支部队的旅，才设置旅指挥官。

军队指挥官是战场最高军官，每方至多一名。军队足够大时下辖旅指挥官，否则直接统辖部队指挥官。能执行旅指挥官全部职能，作用对象可为本军任何部队。

有些战役指定特殊指挥结构；有些怪物，如魔冢，另有自己的层级。所有例外，须在开战前取得裁判同意；没有裁判则须其他玩家同意。
