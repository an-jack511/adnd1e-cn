特殊能力说明 · Notes Regarding Special Abilities

每项特殊能力以一个大写字母标示。

  1. 从3级起，武僧可以像德鲁伊一样与动物交谈。
  2. 从4级起，武僧可以遮蔽心智，使超感知觉（ESP）只有30%的成功概率。此后每升一级，ESP探知其思想的成功概率降低2%；即对5级武僧为28%，对6级为26%，依此类推。
  3. 达到5级后，武僧不再感染任何疾病，也永远不受加速术或缓慢术影响。
  4. 达到6级后，武僧可令自己进入强直昏厥状态，看上去如同死亡。武僧能降低体温与心率，因此伪装毫无破绽。该状态可维持的轮数，等于其等级的两倍（每轮10分钟）：6级为12轮，7级为14轮，依此类推。
  1. 达到7级后，武僧每天可治疗自己一次，恢复2—5点生命值（d4＋1）。此后每升一级，恢复量增加1点：8级为3—6点，9级为4—7点，依此类推。
  2. 达到8级后，武僧可以像德鲁伊一样与植物交谈。
  3. 迷惑、魅惑、催眠与暗示类法术对9级武僧只有50%的生效概率，也就是武僧对这类魔法有50%的抗性。此后每升一级，抗性提高5%，因此生效概率在10级为45%、11级为40%，依此类推。若抗性未能抵挡，仍可作豁免检定。
  4. 由于严格的心智训练，10级及以上武僧遭受心灵感应或心灵震爆攻击时，视为智力18（见《高级龙与地下城：怪物图鉴》“夺心魔”）。
  1. 达到11级后，武僧不受任何毒素影响。
  2. 达到12级后，指使术与使命术对武僧无效。
  3. 武僧最后获得、也可能最为可怕的能力，是传说中的“震颤掌”。武僧只须触碰受害者，便能在其体内引发致命震动，并可控制这些震动；一旦令震动停止，受害者便会死亡。目标几乎可以是任何生物，但这项能力受以下限制：
  1. 每周只能尝试一次；武僧必须在3个近战轮内触及目标，否则这项能力会耗尽，一周后方可再用。
  2. 对不死生物，或只能被魔法武器命中的生物无效。
  3. 目标的生命骰不得多于武僧；无论如何，目标的总生命值若超过武僧生命值的三倍（即高出超过200%），能力也不会生效。
  4. 武僧必须在规定时限内发出死亡命令（即停止震动），否则震动会自行消退，完全不造成伤害。时限按武僧使用能力时的经验等级计算，每级一天。

武僧必须遵守若干严格限制，分别涉及：1）护甲与武器；2）财宝；3）可用魔法物品；4）力量属性调整；5）随从；6）等级提升。具体如下：

  1. 如前所述，武僧不能穿戴护甲。可用武器列于角色职业表 II；未列出的武器不能使用。
  2. 武僧与圣武士相似，只能保留所得财宝中的很小一部分。任何时候，武僧最多可拥有两件魔法武器和三件其他魔法物品（见下文第3项）。武僧可保留足够维持简朴生活及供养随从（见下文第5项）的钱财；其余财宝和超额魔法物品必须赠予（非玩家）宗教机构。（另见后文“追随者”。）
  3. 武僧可使用所列武器的各种魔法版本（受禁止者除外）、戒指，以及盗贼可用的杂项魔法物品。除此之外，不能使用任何其他魔法物品。
  4. 武僧不会因力量属性而获得提高命中概率或增加伤害生命值的任何加值。
  1. 达到“师父”位阶以前，武僧完全不能拥有受雇者或随从。达到6级后，可短期雇人，但只限一次冒险的期间；此时还可拥有至多两名随从。随从可以是战士（但不能是圣武士或巡林客）、盗贼或刺客。此后每超过6级一级，可再增加一名随从，直至达到魅力值规定的上限。武僧达到8级后会获得追随者，详见后文。
  2. 7级（高阶师父）以上的武僧人数有限：8级（龙之宗师）共有三位，更高各级都只能有一位。玩家武僧取得足以升至8级的经验值时，只能暂时获得相应能力；他必须找到三位8级武僧——白、绿、红三位之一——并在不用武器或魔法物品的徒手单挑战斗中击败对方。升至9级及以上时也必须如此。败者会失去足够经验值，降至新等级下一级所需的最低经验值。武僧知道更高等级者所在之处，并须立即前去挑战；若不去，也会失去同等数量的经验值，降到本应挑战者之下一级的最低经验值。以上述情形为例，玩家角色会降回7级，必须重新向上提升。
