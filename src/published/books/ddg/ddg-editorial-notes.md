## 编者导言 Editor’s Introduction

《神祇与半神》表面上像《怪物图鉴》：有图片，也有成组的统计数据；但它不是为玩家角色准备的敌人目录，而是给地下城主用来建立、加强和扩展战役的工具。没有神祇、没有影响凡人命运的强大存在，奇幻世界就不完整。

侍奉神祇也是 AD&D 的重要部分。所有玩家角色都应有自己的守护神；当阵营与信仰相连时，阵营行为会变得更加具体。牧师尤其需要这些材料：他们是社会中的仪式主持者和知识保管者，常与民众和地方领袖保持联系，也因此拥有比普通战士、隐居的魔法师或盗贼更大的社会影响力。

神祇过多可能让地下城主一时难以选择。应先考虑战役气质：中世纪、古代、东方，还是完全不同的世界？可只使用一个万神殿，也可让不同神系在不同地区并存。本书的一切都是给主持人的指南，不是必须遵守的规则；使用前请先阅读所选神话的背景。

## 说明 Explanatory Notes

以下字段沿用本书神祇与英雄统计块的含义。

| 字段 | 含义 |
| --- | --- |
| <strong>出现频率 Frequency</strong> | 在可能出现的地域遇到该生物的概率：极罕见 4%，罕见 11%，不常见 20%，常见 65%；独一无二表示世上只有一个。 |
| <strong>出现数量 Number Appearing</strong> | 合理的平均数量；范围只是指引，不应机械地用来填充地下城人口。 |
| <strong>护甲等级 Armor Class</strong> | 受击难度，包含护甲、天生结构、魔法性质、速度与反应能力。 |
| <strong>移动 Move</strong> | 持续移动速度；括号或前缀可表示飞行、游泳、掘进或蛛网移动。无限表示可无误差地瞬间移动。 |
| <strong>生命值 Hit Points</strong> | 承受伤害的能力；对神祇而言，归零通常只是暂时驱逐回其本位面。 |
| <strong>生命骰 Hit Dice</strong> | 计算生命值和无职业生物攻击能力的骰数；除非另有说明，使用八面骰。 |
| <strong>巢穴概率 % in Lair</strong> | 在原初物质位面自己的巢穴中遇到它的概率；不在巢穴时通常没有巢穴宝藏。 |
| <strong>宝藏类型 Treasure Type</strong> | 参照《怪物图鉴》的宝藏类型表。 |
| <strong>攻击次数／每次伤害</strong> | 一轮内的物理攻击次数及其造成的伤害；魔法武器加值不计入伤害。 |
| <strong>特殊攻击／特殊防御</strong> | 统计块只列职业能力之外的特殊方式，完整说明见后文。 |
| <strong>魔法抗性 Magic Resistance</strong> | 法术完全失效的百分比，以 11 级施法者为基准；施法者每低一级增加 5%，每高一级减少 5%。 |
| <strong>智力 Intelligence</strong> | 约略对应人类智力；19–20 为超凡至超凡之上，21+ 为神祇般的智力。 |
| <strong>体型 Size</strong> | S 小于人类，M 约人类大小，L 明显大于人类。 |
| <strong>阵营 Alignment</strong> | 生物的行为倾向；神祇未必始终受自己的阵营约束。 |
| <strong>崇拜者阵营 Worshipers’ Alignment</strong> | 侍奉该神祇者的大致阵营；牧师必须与 patron 神祇一致。 |
| <strong>象征 Symbol</strong> | 神祇和信徒使用的标志，常刻在圣物上。 |
| <strong>位面 Plane</strong> | 神祇的本位面；通常与其阵营相符，但元素神或原初位面神祇可能例外。 |

神祇的职业栏分别表示其牧师／德鲁伊、战士（含圣武士或游侠）、魔法师／幻术师、盗贼／刺客、武僧／吟游诗人能力。神祇可以同时拥有看似不一致的职业。灵能等级 I–VI 则按书中统一表格解释；VI 表示没有灵能且不受灵能攻击影响。
