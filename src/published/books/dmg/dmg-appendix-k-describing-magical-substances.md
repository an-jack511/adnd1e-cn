有些地下城主不易描述药水瓶、魔法灵药及类似液体的内容物。以下列表提供液体的外观、颜色、味道与气味。无论是单独使用，还是结合附录 I“地下城布置”中的内容，都能帮助地下城主准备区域说明，或在临场发挥时快速描绘。

| 描述词 | 译法 |
|---|---|
| Bubbling | 起泡的 |
| Cloudy | 混浊的 |
| Effervescent | 冒泡的 |
| Fuming | 冒烟的 |
| Oily | 油状的 |
| Smoky | 烟雾状的 |
| Syrupy | 糖浆状的 |
| Vaporous | 蒸气状的 |
| Viscous | 黏稠的 |
| Watery | 水状的、稀薄的 |

| Luminous | 发光（透明度另行决定） |
| Opaline | 蛋白石般发光 |
| Phosphorescent | 磷光（透明度另行决定） |

| Translucent | 半透明 |
| Variegated | 斑驳多色（颜色另行决定） |
