本术语表汇集《地下城主指南》与《高级龙与地下城玩家手册》中的常用规则术语。

| 术语 | 释义 |
|---|---|
| 属性值 Ability Scores | 角色六项属性的数值评级，范围为 3–18：力量、智力、感知、体质、敏捷与魅力。 |
| AD&D | 《高级龙与地下城》（Advanced Dungeons & Dragons）。 |
| 阵营 Alignment | 对角色行为与伦理倾向的概述，由守序、中立或混乱，与善良、中立或邪恶组合而成。 |
| 护甲等级 Armor Class | 表示角色受到伤害时的防护程度，综合护甲类型、敏捷加值或减值、魔法防护等因素。 |
| 圣物 Artifact | 在遥远过去打造、拥有巨大力量的魔法物品。 |
| 星界 Astral | 与星界位面有关或位于其中；参见《玩家手册》第 120 页。与以太位面不同。 |
| 弩矢 Bolt | 1. 弩发射的弹矢。2. 用于闩门的横木。3. 闪电。4. 逃跑。 |
| 吐息武器 Breath Weapon | 某些生物（如龙、奇美拉）拥有的特殊攻击，可产生多种效果。用于豁免检定时，“吐息武器”不包括石化与变形效果，它们各有独立类别。 |
| 战役 Campaign | 泛指同一地下城主主持的所有冒险，而非某一次冒险；一系列基于既定世界持续进行的游戏。 |
| 比较 Cf. | 比较、参见。 |
| 魅惑 Charm | 一种轻微的心灵控制魔法。 |
| 职业 Class | 冒险者的职业，如战士、牧师、盗贼等。 |
| 铜币 c.p.（亦作 cp） | 铜币，价值为金币的 1/200。 |
| 伤害 Damage | 对生物或结构造成的生命值或结构点数损失。 |
| 死亡 Death | 生物生命值降至 0（或可选规则中的 −10）时死亡。多数死者可被复活，但尸体遭毁坏等情况会妨碍复活。 |
| 死亡魔法 Death Magic | 死亡射线、死亡之指等魔法；未通过豁免的目标会死亡。 |
| 神祇 Deities | 地下城主希望纳入战役的神话或传说中的神性存在。 |
| 类人种 Demi-humans | 通常指可作为玩家角色的类人且一般不敌视人类的生物，如精灵、矮人、半身人等。 |
| DM | 地下城主（Dungeon Master），即 AD&D 的裁判。 |
| 地下城 Dungeon | 泛指任何城堡、地点或遗迹，只要它可作为地下冒险的场所。 |
| 魔力 Dweomer | 源自古英语 dweomercraeft，意为魔法之术。 |
| e.g. | 例如。 |
| 遭遇 Encounter | 与怪物、另一支队伍等意外相遇。 |
| 负重 Encumbrance | 冒险者所携物品（护甲、武器、装备等）的重量与体积。 |
| 银币 e.p.（亦作 ep） | 琥珀金币，由自然形成的银金合金制成，价值为金币的一半。 |
| et al. | 以及其他人／事物。 |
| 以太位面 Ethereal | 与以太位面有关或位于其中；参见《玩家手册》第 120 页。与星界不同。 |
| 特殊力量 Exceptional Strength | 超过 18 的力量，通常记作 18／x，其中 x 为 01–00（100）。 |
| 经验 Experience | 击败怪物、获得财宝、扮演角色等带来的奖励，以经验值（XP）表示。经验越丰富，战斗能力、豁免等越强。 |
| 尺 Feet | “尺”或符号 ′（如 30 尺或 30′）通常指角色尺度下的实际英尺距离。另见“寸”及《玩家手册》第 39 页。 |
| 追随者 Followers | 角色达到特定等级后获得的一群忠诚同伴。 |
| 金币 g.p.（亦作 gp） | 标准货币单位；10 金币重 1 磅，每枚约重 1.6 常衡盎司。也用作重量／负重单位。 |
| 随从 Henchman | 等级较低、忠于队伍中某一成员而非整个队伍的非玩家角色。 |
| 受雇者 Hireling | 受雇陪同队伍冒险或临时承担其他工作的非玩家角色。 |
| 生命骰 Hit Dice | 用于掷骰决定生物生命值的骰子数。 |
| 生命值 Hit Points | 生物死亡（或可选规则中的昏迷）前可承受的伤害点数，反映体能、战斗经验、技巧或运气。 |
| 圣水／邪水 Holy/Unholy Water | 由牧师特别制备的水，可用于攻击不死生物或减缓毒素效果。 |
| 类人生物 Humanoid | 指类人且通常敌视人类的生物，如兽人、地精、大地精、狗头人等。 |
| i.e. | 即、也就是。 |
| 寸 Inches | 地下城尺度中 1 寸＝10 尺；户外尺度中 1 寸＝10 码（参见《玩家手册》第 39 页）。 |
| 先攻 Initiative | 决定敌对个人或群体行动顺序的方法；用于确定战斗中的攻击先后，也适用于其他行动。 |
| 隐形 Invisibility | 一种避开正常视觉观察的方法，但不会使对象无声无味。 |
| 联盟 League | 游戏中 1 联盟约等于 3 英里。 |
| 等级 Level | 1. 地下城楼层的深度或难度。2. 法术的难度与力量。3. 角色职业熟练度与经验程度。4. 怪物的强弱尺度。 |
| 兽化人 Lycanthrope | 传说中能够变形的人兽，如狼人、虎人等。 |
| 魔法 Magic | 无法用该世界科学解释的事物。任何带有 +1、+2 等加值的武器或物品均视为魔法物品。 |
| 魔法抗力 Magic Resistance | 怪物使法术完全失效的概率。其基准为 11 级魔法师施法；施法者每低于 11 级，抗力提高 5%；每高于 11 级，抗力降低 5%。例如，95% 魔法抗力意味着 10 级魔法师无法影响该怪物，而 12 级魔法师有 10% 概率成功。即使法术生效，怪物仍可照常进行豁免检定。 |
| 近战 Melee | 两名以上生物使用手持武器进行的战斗；不同于两名对手之间的决斗，也不同于远距离投射或发射武器的远程战斗。 |
| 梅佐恶魔 Mezzodaemon | 出现于 AD&D 模组 D3《卓尔地底城堡》的怪物；若无法查到其数据，可忽略。 |
| 世界设定 Milieu | 独特的游戏背景，其中含有构建世界时的多种变量，即冒险发生的“世界”。 |
