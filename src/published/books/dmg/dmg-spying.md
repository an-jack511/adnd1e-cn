大多数间谍可能都是受雇的刺客，不过玩家角色有时也可能雇用普通间谍。侦察任务大致分为以下几类：

**简单 SIMPLE：**获取某项活动的大致情况、防御状况、部队人数或准备情况。简单任务只要求间谍在非关键岗位上观察，例如混在当地人群中活动。

**困难 DIFFICULT：**获取计划、文件、地图等秘密信息。困难任务要求间谍进入某个地点，或取得某人的信任，因此必须积极而出色地扮演自己的身份。

**特别困难 EXTRAORDINARY：**耗时漫长、结构复杂且危险的任务，要求间谍打入某个组织或行动，并持续传递详细情报。这类任务需要间谍长期与被监视对象接触，不断收集高度详细且机密的一般与特定信息。

简单任务被发现的风险较低，困难任务风险更高，特别困难任务则风险很大。玩家角色参与时，侦察任务由玩家通过 DM 与目标互动，具体按玩家的行动、DM 掌握的情势以及被监视对象的反应裁定。由 NPC 执行时，则使用下表检定成功率。

**完成任务所需时间 Time Required to Accomplish Mission**

前往侦察地点所需的旅程时间，由 DM 根据具体情况决定。抵达后，间谍将根据任务难度花费以下时间来完成任务（或以失败告终）：

| 任务难度 | 所需时间 |
|:---:|:---:|
| 简单 | 1—8 天 |
| 困难 | 5—40 天 |
| 特别困难 | 视需要而定 |

特别困难任务所需时间要根据情形决定。例如，间谍若要加入一个秘密社团，可能需花一个月弄清其招募要求，再花一到数月达到入会资格，最后才能打入该团体。此后，他或她可按上述时间要求获取简单或困难情报；只有随着成员身份提升、持续参与并作出看似卓越的贡献，才能取得特别机密的情报。

**被发现概率 Chance of Discovery**

无论任务多简单，间谍总有被发现的可能。基础被发现概率为侦察期间**每天累积增加 1%**，最高累积至 **10%**，再减去间谍等级；即使结果为负，也至少有 **1%** 的概率。目标采取的反侦察措施会改变这一概率：

| 目标采取的措施 | 被发现概率 |
|:---:|:---:|
| 不采取措施 | 每周 1% |
| 最低限度的措施 | 每周检定一次，按修正后的 1%—10% 概率减半 |
| 中等措施 | 每周按修正后的概率检定两次 |
| 严密措施 | 每周以修正后概率的两倍检定两次 |

最低限度的措施包括偶尔检查人员及其行动，并留意重要情报。中等措施是在此基础上更频繁地检查，并更谨慎地询问行为可疑者。严密措施则包括多重人员与情报安全检查，以及派出反间谍人员查明可疑活动。

若间谍实际上成为某个团体的首领，被发现的概率就会降至“不采取措施”的类别，因为此人被视为“不会引起怀疑”；只有嫉妒心强或特别敏锐的行动者仍会调查他或她。

若一名间谍被抓，而另一名间谍仍在活动，则在此后 **20—50 天**内，后者被发现的概率会提高 **10 倍**。

按任务所用时间掷百分骰，确定间谍是否被发现。如果任务只持续该时间的一部分，再掷第三颗百分骰，以精确到十分之一百分比。例如，每周 **1%** 相当于每天 **0.14%**；若任务只进行一天，掷出 **99.9%** 表示间谍被发现。间谍一旦被发现，查阅下方的**间谍失败表**。

**间谍失败 Spy Failure**

间谍耗尽任务所需时间后若检定失败，可能出现多种结果，见下表。该表也用于间谍被发现时，需采用相应修正。

| d100 | 结果 |
|:---:|:---:|
| 01—35 | 可以继续尝试完成任务，但必须重新确定所需时间 |
| 36—60 | 再次侦察有 90% 概率导致失败、暴露并被监禁 |
| 61—80 | 间谍因可疑行为被捕并监禁；此后没有进一步消息* |
| 81—95 | 间谍被抓获，且有明确证据证明其从事侦察；他或她会遭受酷刑（掷 d6：1—2 死亡，3—4 全盘供出，5—6 叛变）* |
| 96—00 | 间谍被杀；若有反间谍人员，则可能叛变 |

\* 若有反间谍人员，他们会向间谍提供假情报，并跟踪他或她，以查明其来自何处、由谁派来。

**狂热间谍 Fanatical Spies**

绝对忠于主人或事业的间谍通常不会是受雇执行侦察的刺客，不过也可能存在这类刺客。他们绝不会成为双重间谍；掷骰总值超过 **60** 时，他们会直接自尽。

（非玩家角色间谍的费用，参见“专家受雇者”。）
