| 术语 | 释义 |
|---|---|
| 微缩模型 Miniature | 用作视觉辅助的小型铅制或塑料人偶。 |
| 投射武器 Missile | 向目标投掷或发射的武器，包括箭、长矛、投石机石块、投石索弹丸，以及掷向目标的其他物品（如油瓶、圣水瓶等）。 |
| 怪物 Monster | 游戏中指可能构成威胁的生物，包括人类或野兽。 |
| 蒙蒂·豪尔 Monty Haul | 奖励过量财宝／经验值的战役，或主持这种战役的地下城主。 |
| MU（亦作 M-U） | 魔法师（Magic-User）。 |
| 自然 20 Natural 20 | 掷 20 面骰出现“20”。这不同于总结果为 20；后者可能是较低骰值加上属性或魔法加值。 |
| N.B. | 请注意。 |
| NPC（亦作 N-PC） | 非玩家角色。 |
| 尼卡恶魔 Nycadaemon | 出现于 AD&D 模组 D3《卓尔地底城堡》的怪物；若无法查到其数据，可忽略。 |
| 队伍 Party | 一群冒险者。 |
| PC | 玩家角色。 |
| 角色 Persona | 玩家所扮演角色的身份。 |
| 石化 Petrification | 通过魔法使某物或生物迅速变成石头，例如蛇发怪的凝视。 |
| 灵药 Philter | 魔法饮剂或药水。 |
| 圣匣 Phylactery | 用于存放宗教文字的臂缠盒，因此也属于护符或符咒。 |
| 命匣 Phylactery | 巫妖用于储存生命力与灵魂的魔法容器；与宗教意义上的圣匣不是同一概念。 |
| 熟练项 Proficiency | 角色通过训练获得、并可按规则进行检定或使用的能力类别；规则语境统一译为“熟练项”。 |
| 武器熟练项 Weapon Proficiency | 角色掌握特定武器的训练项。 |
| 非武器熟练项 Nonweapon Proficiency | 不属于武器使用的训练项，例如动物知识、追踪或生存能力。 |
| 荒野熟练项 Wilderness Proficiency | 面向荒野环境的熟练项类别。 |
| 地城熟练项 Dungeon Proficiency | 面向地下城探索与行动的熟练项类别。 |
| 巡林客 Ranger | 战士子职业；统一译为“巡林客”，不使用“游侠”。 |
| 角色熟练项 Character Proficiencies | 角色可选择和使用的熟练项总称。 |
| 工匠熟练项 Artisan Proficiency | 与工艺、制作和修理有关的熟练项类别。 |
| 蛮族熟练项 Barbarian Proficiency | 野蛮人文化与荒野生活相关的熟练项类别；不是“蛮族”职业名的替代译法。 |
| 通用熟练项 General Proficiency | 不限于特定职业、环境或社会类别的熟练项。 |
| 宫廷熟练项 Court Proficiency | 与宫廷礼仪、社交和贵族生活有关的熟练项类别。 |
| 骑乘熟练项 Riding Proficiency | 与骑乘和控制陆地坐骑有关的熟练项；不译为“骑术专长”。 |
| 划船熟练项 Boating Proficiency | 与操纵船只、独木舟和其他水上载具有关的熟练项。 |
| 空中骑乘熟练项 Airborne Riding Proficiency | 与骑乘飞行坐骑有关的熟练项；龙骑乘熟练项另行计算。 |
| 植物学熟练项 Herbalism Proficiency | 与辨认和利用药用植物有关的熟练项。 |
| 文化熟练项 Cultural Proficiency | 与特定文化、习俗和社会背景有关的熟练项。 |
| 动物处理熟练项 Animal Handling Proficiency | 与安抚、照料和控制动物有关的熟练项。 |
| 陆地骑乘熟练项 Land-Based Riding Proficiency | 与骑乘陆地坐骑有关的熟练项。 |
| 龙骑乘熟练项 Dragon Riding Proficiency | 专门用于骑乘和操控龙的熟练项，不并入一般空中骑乘熟练项。 |
| 忍者装束 Shinobi Shozoku | 忍者常服，通常包括轻便上衣、兜帽、裤子和足袋靴。 |
| 攀爬爪 Te-kagi | 用于攀墙的爪形忍具；与猫手并列使用。 |
| 忍者攀爬耙 Shinobi Kumade | 带抓钩的伸缩竹制攀爬工具。 |
| 多用途苦无 Tobi-kunai | 可挖掘、撬动、钻孔、切割和楔入的多用途忍具。 |
| 撬门叉 Tsuba-giri | 用于撬门的重型叉状忍具。 |
| 水蜘蛛 Mizugumo | 可让使用者在水面直立行走的忍具。 |
| 影伴 Tween | 难以看见的生物；在赞扎洛竖琴的显现效果下会显出蓝色轮廓。 |
| 德拉姆 Dram | 原刊使用的小容量体积单位；按原文数值保留。 |
| 施法生物 Magic-Using Creature | 能够施展法术或使用魔法能力的生物；不译为“魔法使用者生物”。 |
| 埃尔里克 Elric | 《神祇与半神》中梅尔尼博内条目的黑暗精灵王；正文统一使用“埃尔里克”作为中文主显示。 |
| 法弗赫德 Fafhrd | 《神祇与半神》尼赫旺条目的北方野蛮人英雄；正文统一使用“法弗赫德”作为中文主显示。 |
| 水族 WaterFolk | 《地下城主设计工具箱》示例冒险中的元素水位面种族；正文使用“水族”作为中文主显示。 |
| 利林 Llirryn | 《地下城主设计工具箱》示例冒险中的水族领袖；正文使用“利林”作为中文主显示。 |
| 银盾 Silvershield | 《地下城主设计工具箱》示例冒险中的水生石像鬼样生物；正文使用“银盾”作为中文主显示。 |
| 泰亚 Tyaa | 尼赫旺神话中的邪恶鸟类之神；正文统一使用“泰亚”，与“泰亚之鸟”保持一致。 |
| 沃提沙尔 Votishal | 尼赫旺神话中的守序善良盗贼之神；采用音译“沃提沙尔”作为正文主显示。 |
| 位面 | 存在的其他领域，其中一些与主要物质位面相连；参见《玩家手册》第 120 页。 |
| 毒素 Poison | 既指人工制成的有毒物质，也指毒性生物的毒液。 |
| 长柄武器 Pole Arm | 长度至少 5 尺、带长柄且非长矛或手杖的武器。 |
| 变形 Polymorph | 通过魔法改变生物的外形。 |
| 白金币 p.p.（亦作 铂金币） | 白金货币单位，每枚价值 5 枚金币。 |
| 灵能 Psionics | 仅非常聪明的生物与部分怪物能够进行的心灵战斗；也包括心灵遥控等特殊心智能力。参见《玩家手册》附录 I。 |
| Q.E.D. | 证毕。 |
| q.v.（亦作 q.q.v.） | 参见；指另有交叉引用的条目。 |
| 随机生成 Random Generation | 通常通过掷骰，从多种可能性中随机决定某项内容。 |
| 圣遗物 Relic | 通常年代久远、拥有强大力量的神圣魔法物品。 |
| 研究 Research | 除通常含义外，也指魔法师或炼金术士准备新法术、附魔物品等工作。 |
| 复生术 Resurrection | 通过魔法使死去的角色恢复生命。 |
| 轮（亦称近战轮） Round | AD&D 的时间单位，等于 1 分钟；每轮由 10 个分段组成，10 轮为一个回合。 |
| 豁免检定 Saving Throw | 在不利情形下掷骰，判断法术效果、生物是否跌入坑中、是否避开龙息等。 |
| 侦测 Scrying | 通过神秘手段观察某个人或物品。 |
| 分段 Segment | AD&D 中最小的时间单位，每段 6 秒；10 段组成一轮。 |
| 银币 s.p. | 银币单位；20 枚银币等于 1 枚金币。 |
| 结构点数 Structural Points | 建筑或结构在崩塌前可承受的伤害量。 |
| 突袭 Surprise | 遭遇双方均需检定是否被突袭，这可能导致失去先攻。 |
| 命中 To Hit | 20 面骰掷出达到或超过的数值，才能对对手造成伤害。 |
| 陷阱 Trap | 冒险者可能触发的机械或魔法装置，通常会对一名或多名角色造成伤害，如坑洞、尖刺坑洞、宝箱上的毒针陷阱等。 |
| 财宝 Treasure | 冒险中可能获得的任何有价值物品的统称。 |
| 诡计 Trick | 更可能靠机智而非武力解决的装置或机关；不一定会造成身体伤害，例如旋转或下降的房间、会随机行动的雕像、暗中将队伍带到更深楼层的倾斜通道等。 |
| 回合 Turn | AD&D 的时间单位，等于 10 分钟；每回合包含 10 轮，每轮又由 10 个分段组成。 |
| 驱散不死生物 Turning Undead | 牧师运用神圣力量迫退、影响、摧毁或诅咒遭遇到的不死生物的过程。 |
| 不死生物 Undead | 一类邪恶、无灵魂、既非真正死亡也非真正存活的怪物，包括骷髅、吸血鬼、鬼魂、僵尸、食尸鬼等。 |
| vis-à-vis（相对于） | 面对面；相比之下。 |
| viz.（即） | 即；也就是说。 |
| 游荡怪物 Wandering Monster | 地下城主未预先标注的遭遇的统称；通常指在地下城中定期检查是否出现怪物。 |
| x.p. | 经验值。 |
