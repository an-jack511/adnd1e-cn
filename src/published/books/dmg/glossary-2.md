| 通用熟练项 General Proficiency | 不限于特定职业、环境或社会类别的熟练项。 |

| 骑乘熟练项 Riding Proficiency | 与骑乘和控制陆地坐骑有关的熟练项；不译为“骑术专长”。 |
| 划船熟练项 Boating Proficiency | 与操纵船只、独木舟和其他水上载具有关的熟练项。 |
| 空中骑乘熟练项 Airborne Riding Proficiency | 与骑乘飞行坐骑有关的熟练项；龙骑乘熟练项另行计算。 |
| 植物学熟练项 Herbalism Proficiency | 与辨认和利用药用植物有关的熟练项。 |
| 文化熟练项 Cultural Proficiency | 与特定文化、习俗和社会背景有关的熟练项。 |
| 动物处理熟练项 Animal Handling Proficiency | 与安抚、照料和控制动物有关的熟练项。 |
| 陆地骑乘熟练项 Land-Based Riding Proficiency | 与骑乘陆地坐骑有关的熟练项。 |
| 龙骑乘熟练项 Dragon Riding Proficiency | 专门用于骑乘和操控龙的熟练项，不并入一般空中骑乘熟练项。 |

| 类法术能力 Spell-Like Ability | 生物能够使用、但不一定属于职业法术表的魔法能力；正文统一译为“类法术能力”。 |

| 轮 Round | AD&D 的时间单位，等于 1 分钟；每轮由 10 段组成，10 轮为一个回合。战斗语境也可称“近战轮”，但不另设译名。 |
| 近战轮 Melee Round／战斗轮 Combat Round | Round 在战斗语境中的修饰性称呼；统一按规则时间单位译为“轮”，不得另立为独立时间层级。 |
| 护甲等级 Armor Class（AC） | 防护数值；数值越低通常越难被命中。正文、怪物数据栏和装备规则统一译为“护甲等级”，不把 AC 语境译成“防护等级”。 |
| 作用区域 Area of Effect（AOE） | 法术、吐息或其他能力实际影响的空间范围；与射程 Range、目标 Target 不混用。 |
| 攻击次数 Attacks | 生物或角色在一个适用时间单位内可发动的攻击数量；表格中的 3/2 表示每两轮攻击三次，不改写成“每回合三次”。 |
| 持续时间 Duration | 法术、能力或状态保持有效的时间；须保留原文使用的回合、轮、段、小时或其他单位。 |
| 经验值 Experience Points（XP） | 角色或生物因冒险、战斗、任务等获得的经验数值；统一译为“经验值”，不与经验等级混用。 |
| 经验等级 Experience Level | 角色依据经验值取得的总体等级；在单职业语境下通常等同于职业等级，涉及多职业或能力来源时须按上下文区分。 |
| 职业等级 Class Level | 角色在某一具体职业中的等级；不把多职业角色的单一职业等级机械当作总体经验等级。 |
| 生命骰 Hit Dice（HD） | 决定生物生命值、攻击能力和豁免等数据的骰子数量；统一译为“生命骰”，不译为“生命骰子数”作为字段名。 |
| 生命值 Hit Points（HP） | 生物当前或最大生命状态的数值；正文和字段统一译为“生命值”，不使用“命中点”“生命点数”或“生命值点数”。 |
| 命中所需数值 To-Hit Number | 攻击掷骰达到或超过的目标数值；与生命值 Hit Points 不同，不译为“命中点数”。 |
| 先攻 Initiative | 决定一轮内行动先后的规则；不与“先射判定”或单纯的“攻击顺序”混为一谈。 |
| 移动率 Movement Rate | 生物、角色或载具的规则移动速度；按语境译为“移动率”或“移动”，不把户外旅行距离与战斗移动率混作同一字段。 |
| 士气 Morale | 对 NPC、雇佣兵、怪物等是否继续战斗或撤退的检定；统一译为“士气”，不与反应检定混用。 |
| 法术环级 Spell Level | 法术在法术表与职业规则中的等级；统一译为“法术环级”或“几环法术”，不与角色等级、施法者等级混用。 |
| 法术环位 Spell Slot | 角色能够准备或记忆的某一环法术容量；与法术环级（Spell Level）不同，统一译为“法术环位”。 |
| 施法者等级 Caster Level | 施法者施展法术时用于确定范围、持续时间、效果或伤害的等级；与角色等级、法术环级分开处理。 |
| 角色等级 Character Level | 角色的职业等级或综合等级；不把它与施法者等级、生命骰或法术环级混用。 |
| 射程 Range | 攻击、法术或能力能够作用到目标的距离；与作用区域 Area of Effect、持续时间 Duration 分开处理。 |
| 反应检定 Reaction Roll | 遭遇或交涉时判断对方初始态度的检定；统一译为“反应检定”，不与豁免检定或士气检定混用。 |
| 阵营 Alignment | 描述角色、生物或组织伦理与宇宙立场的规则属性；统一译为“阵营”，不在规则语境中改译为“立场”或“道德倾向”。 |
| 豁免检定 Saving Throw | 在不利情形下掷骰，判断法术效果、生物是否跌入坑中、是否避开龙息等。 |
| 侦测 Scrying | 通过神秘手段观察某个人或物品。 |
| 段 Segment | AD&D 中最小的规则时间单位，每段 6 秒；10 段组成一轮。统一使用“段”，不使用“分段”“轮段”或“节”指代这一时间单位。 |
| 银币 s.p. | 银币单位；20 枚银币等于 1 枚金币。 |
| 结构点数 Structural Points | 建筑或结构在崩塌前可承受的伤害量。 |
| 突袭 Surprise | 遭遇双方均需检定是否被突袭，这可能导致失去先攻。 |
| THAC0 | “命中护甲等级 0 所需数值”的缩写；保留原缩写 THAC0，在中文说明中可补出释义，不强行改写缩写本身。 |
| 命中 To Hit | 20 面骰掷出达到或超过的数值，才能对对手造成伤害。 |
| 陷阱 Trap | 冒险者可能触发的机械或魔法装置，通常会对一名或多名角色造成伤害，如坑洞、尖刺坑洞、宝箱上的毒针陷阱等。 |
| 财宝 Treasure | 冒险中可能获得的任何有价值物品的统称。 |
| 诡计 Trick | 更可能靠机智而非武力解决的装置或机关；不一定会造成身体伤害，例如旋转或下降的房间、会随机行动的雕像、暗中将队伍带到更深楼层的倾斜通道等。 |
| 回合 Turn | AD&D 的时间单位，等于 10 分钟；每回合包含 10 轮，每轮又由 10 段组成。与“轮”“段”严格区分。 |
| 时间单位 Time Unit | 原文的泛称；须依据上下文核对其实际所指。若原文明确指 AD&D 的战斗计时层级，按“回合（turn）—轮（round）—段（segment）”顺序译为对应术语，不把泛称机械替换成固定单位。 |
| 驱散不死生物 Turning Undead | 牧师运用神圣力量迫退、影响、摧毁或诅咒遭遇到的不死生物的过程。 |
| 不死生物 Undead | 一类邪恶、无灵魂、既非真正死亡也非真正存活的怪物，包括骷髅、吸血鬼、鬼魂、僵尸、食尸鬼等。 |
