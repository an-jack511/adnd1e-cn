| 术语 | 释义 |
|---|---|
| 微缩模型 Miniature | 用作视觉辅助的小型铅制或塑料人偶。 |
| 投射武器 Missile | 向目标投掷或发射的武器，包括箭、长矛、投石机石块、投石索弹丸，以及掷向目标的其他物品（如油瓶、圣水瓶等）。 |
| 怪物 Monster | 游戏中指可能构成威胁的生物，包括人类或野兽。 |
| 蒙蒂·豪尔 Monty Haul | 奖励过量财宝／经验值的战役，或主持这种战役的地下城主。 |
| MU（亦作 M-U） | 魔法师（Magic-User）。 |
| 自然 20 Natural 20 | 掷 20 面骰出现“20”。这不同于总结果为 20；后者可能是较低骰值加上属性或魔法加值。 |
| N.B. | 请注意。 |
| NPC（亦作 N-PC） | 非玩家角色。 |
| 尼卡恶魔 Nycadaemon | 出现于 AD&D 模组 D3《卓尔地底城堡》的怪物；若无法查到其数据，可忽略。 |
| 队伍 Party | 一群冒险者。 |
| PC | 玩家角色。 |
| 角色 Persona | 玩家所扮演角色的身份。 |
| 石化 Petrification | 通过魔法使某物或生物迅速变成石头，例如蛇发怪的凝视。 |
| 灵药 Philter | 魔法饮剂或药水。 |
| 圣匣 Phylactery | 用于存放宗教文字的臂缠盒，因此也属于护符或符咒。 |
| 位面 Planes | 存在的其他领域，其中一些与主要物质位面相连；参见《玩家手册》第 120 页。 |
| 毒素 Poison | 既指人工制成的有毒物质，也指毒性生物的毒液。 |
| 长柄武器 Pole Arm | 长度至少 5 尺、带长柄且非长矛或手杖的武器。 |
| 变形 Polymorph | 通过魔法改变生物的外形。 |
| 白金币 p.p.（亦作 pp） | 白金货币单位，每枚价值 5 枚金币。 |
| 灵能 Psionics | 仅非常聪明的生物与部分怪物能够进行的心灵战斗；也包括心灵遥控等特殊心智能力。参见《玩家手册》附录 I。 |
| Q.E.D. | 证毕。 |
| q.v.（亦作 q.q.v.） | 参见；指另有交叉引用的条目。 |
| 随机生成 Random Generation | 通常通过掷骰，从多种可能性中随机决定某项内容。 |
| 圣遗物 Relic | 通常年代久远、拥有强大力量的神圣魔法物品。 |
| 研究 Research | 除通常含义外，也指魔法师或炼金术士准备新法术、附魔物品等工作。 |
| 复活 Resurrection | 通过魔法使死去的角色恢复生命。 |
| 轮（亦称近战轮） Round | AD&D 的时间单位，等于 1 分钟；每轮由 10 个分段组成，10 轮为一个回合。 |
| 豁免检定 Saving Throw | 在不利情形下掷骰，判断法术效果、生物是否跌入坑中、是否避开龙息等。 |
| 侦测 Scrying | 通过神秘手段观察某个人或物品。 |
| 分段 Segment | AD&D 中最小的时间单位，每段 6 秒；10 段组成一轮。 |
| 银币 s.p.（亦作 sp） | 银币单位；20 枚银币等于 1 枚金币。 |
| 结构点数 Structural Points | 建筑或结构在崩塌前可承受的伤害量。 |
| 突袭 Surprise | 遭遇双方均需检定是否被突袭，这可能导致失去先攻。 |
| 命中 To Hit | 20 面骰掷出达到或超过的数值，才能对对手造成伤害。 |
| 陷阱 Trap | 冒险者可能触发的机械或魔法装置，通常会对一名或多名角色造成伤害，如坑洞、尖刺坑洞、宝箱上的毒针陷阱等。 |
| 财宝 Treasure | 冒险中可能获得的任何有价值物品的统称。 |
| 诡计 Trick | 更可能靠机智而非武力解决的装置或机关；不一定会造成身体伤害，例如旋转或下降的房间、会随机行动的雕像、暗中将队伍带到更深楼层的倾斜通道等。 |
| 回合 Turn | AD&D 的时间单位，等于 10 分钟；每回合包含 10 轮，每轮又由 10 个分段组成。 |
| 驱散不死生物 Turning Undead | 牧师运用神圣力量迫退、影响、摧毁或诅咒遭遇到的不死生物的过程。 |
| 不死生物 Undead | 一类邪恶、无灵魂、既非真正死亡也非真正存活的怪物，包括骷髅、吸血鬼、鬼魂、僵尸、食尸鬼等。 |
| vis-à-vis | 面对面；相比之下。 |
| viz. | 即；也就是说。 |
| 游荡怪物 Wandering Monster | 地下城主未预先标注的遭遇的统称；通常指在地下城中定期检查是否出现怪物。 |
| x.p. | 经验值。 |
