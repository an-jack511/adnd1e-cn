这种可怕的不死生物主要存在于星界；不过，在发动“攻击”时，它可以像护甲等级为 0 一样被魔法武器或银质武器命中。幻灵按幽魂处理驱散。它不愿接近镜子或任何由银制成的东西。

幻灵拥有一种情绪型 ESP 能力，可以感知 100 英尺以内的潜在受害者。由于它会从墙壁、地板或天花板中出现，这种不可思议的外表使它能以 1–5（d6）掷骰结果突袭一个队伍或个体，并利用突袭形成的优势缩短与受害者之间的距离。被看见时，它呈现为穿着薄白长袍的无实体骷髅生物。

实际上，幻灵没有进行物理攻击的能力。然而，它选定的受害者会感觉有骨爪般的手指掐住自己的喉咙；即使穿着护甲，也能感受到这种效果。

即使受害者知道幻灵实际上无法伤害自己，这种暗示仍然极其强烈。受害者必须掷 3d6；若总数低于受害者的智力，说明暗示无效，受害者免疫这一只幻灵（但只对这一只幻灵免疫）。然而，若总数等于或高于受害者的智力，受害者就会陷入恐怖，并必须再次掷 3d6。将这次结果与受害者的体质比较：如果总数低于体质，受害者会惊慌逃跑 1–4 个近战轮（并且在此过程中可能再次遭到攻击）；如果总数等于或高于体质，受害者会遭受剧烈心脏痉挛并立即死亡。

死亡的受害者可以被复活；但如果尸体被遗弃，或一小时内没有尝试复活，尸体会在 2–8 小时后化为一只幻灵。

能够在星界移动和战斗的角色可以在星界上“正常”攻击幻灵；但幻灵每次攻击一个受害者时，只会在主物质位面停留一个近战轮，并且只有在这段时间里，它才能被非星界手段攻击。

要完成它的“攻击”，幻灵不需要按通常方式取得命中，因此无需进行“命中”掷骰。

## 刺客虫 Assassin Bug

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 罕见 |
| 出现数量 No. Appearing | 2 |
| 护甲等级 Armour Class | 5 |
| 移动 Move | 6"／18" |
| 生命骰 Hit Dice | 1+1 |
| 巢穴概率 % in Lair | 50% |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–4 |
| 特殊攻击 Special Attacks | 麻痹 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 动物 |
| 阵营 Alignment | 中立 |
| 体型 Size | S（最长 2 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | II／65 + 每点生命值 2 |

刺客虫像长着四肢的巨型绿头苍蝇——一对微型手臂和一对微型腿。除了交配季节之外，很少能看见刺客虫；交配季节每两个月出现一天，在此期间可能遇到一只雄虫和一只雌虫飞行寻找宿主，以便让后代寄生。它们的自然宿主是人类，但已知它们也会把卵产在半人类身上，偶尔也会产在人形生物身上。

雄虫总是首先攻击，以咬击受害者并造成 1–4 点伤害；雌虫在附近飞行，尽可能靠近目标，同时避免冒险遭到攻击。如果雄虫攻击成功，除非受害者以 +2 的修正通过豁免，否则雄虫的唾液会使受影响的身体部位麻痹。雄虫会持续攻击，直到被摧毁。就空战而言，它们的机动等级为 C。

一旦雄虫的一次攻击达成所需的麻痹效果，雌虫（能够闻到雄虫唾液的气味）就会“攻击”受影响的部位。如果成功，雌虫会把自己的卵植入受害者体内。卵植入后，雌虫立即死亡。

卵在植入 13–24 小时后孵化，产生 7–12 只幼虫。在这段时间内，只有非常强大的法术，例如有限祈愿术或疗愈术，才能移除或杀死虫卵。幼虫孵化后，每一只都会在吞食宿主内部器官的同时，每小时对宿主造成 1 点伤害。两周后，幼虫会离开宿主；它们会从最初植入虫卵的部位钻出，并在钻出时每只额外造成 5–8 点伤害。离开身体后，它们会蜕变为完全成长的刺客虫。

幼虫仍在宿主体内时，可以通过对宿主施放下列法术杀死：

- <strong>治疗重伤 Cure serious wounds</strong>：施法者超过 6 级后，每高于 6 级一层，可以杀死一只幼虫。
- <strong>治疗致命伤 Cure critical wounds</strong>：杀死所有幼虫。
- <strong>疗愈 Heal</strong>：杀死所有幼虫，并恢复受害者除 5–8 点之外的全部生命值。

在此期间，有限祈愿术或类似法术也能发挥作用。

巨魔、豺狼人和熊地精把刺客虫的卵视为珍贵美食。虫卵本身长 4–5 英寸，呈卵形，深蓝色。

<strong>描述：</strong>刺客虫通常是绿头苍蝇的颜色，但雌虫往往比雄虫颜色更浅。四肢是人类皮肤的颜色。翅膀几乎透明，但带有淡淡的银色光泽。
