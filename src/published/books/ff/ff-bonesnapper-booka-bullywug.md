Bonesnapper 是一种早已灭绝的食肉恐龙的矮小后裔，既愚蠢又好斗。它的大颚中长满锋利的牙齿，用来在近战中造成 1–8 点伤害；与此同时，尾巴会扫向同一个受害者，再造成 1–4 点伤害。它的攻击性使它总是战斗至死。

虽然没有智力，Bonesnapper 却继承了一种原始本能：收集人类骨骼，尤其是颌骨，用来装饰自己的地下巢穴。在巢穴中发现的这类骨骼数量，能很好地显示出其主人在同类中的地位。

<strong>描述：</strong>Bonesnapper 呈灰绿色，夹杂深灰色斑点与斑块。它有细小的猩红色眼睛，以及黄白色的牙齿。

## Booka

Booka 是精灵般的生物，喜欢住在阁楼、屋檐和阳光充足的屋顶上。它们厌恶寒冷；在这类气候中，它们总会待在室内，靠近烟囱。晴朗的早晨，它们会打扫自己居所的楼梯或门廊，而且总是在没有人在旁观察时这么做。如果在进行这些工作时受到打扰，它们就会生气，并立即搬到新家。

Booka 移动得非常快，也能够飞行。它们可以随意隐形，即使正在奔跑或飞行时也能做到。它们憎恨邪恶生物；只要有机会，就会对它们恶作剧：藏起贵重物品，把绳子、头发、衣服之类的东西缠在一起，并总的来说制造麻烦。

如果一只 Booka 被捕获，或以任何方式受到伤害，那么得知此事的其他同类必定会召来几十只 Booka，持续制造恶作剧与麻烦，直到冒犯者释放俘虏，或通过赠送贵重礼物（例如一袋金币、珠宝，甚至魔法物品）来补偿伤害：把礼物放在屋顶上，然后离开一天。未能安抚愤怒的 Booka，最终会导致某种致命事故，因为这些生物会为冒犯者设置套索与陷阱。

Booka 只有约 1 英尺高。雄性和雌性通常都有夸张的面部特征与纤细的身体。充其量只能说它们“长得不讨喜”。就空战而言，它们的机动等级为 A；不过，只要有可能，它们会借助隐形来避免战斗，无论是这种战斗还是任何其他形式的战斗。

## Bullywug

| 特殊防御 Special Defences | 伪装 |
| 魔法抗性 Magic Resistance | 标准 |

| 体型 Size | S 至 M |

| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 普通：I／18 + 每点生命值 1；首领：II／36 + 每点生命值 2；萨满或大酋长：III／80 + 每点生命值 3 |

Bullywug 是一种两足的蛙类怪物，栖息在潮湿的地方：多雨的森林、沼泽、潮湿的洞穴，或者任何阴凉或黑暗且附近有水的地方，因为 Bullywug 需要不时湿润自己的皮肤。

这些生物中有些种类比其他种类更聪明。聪明的群体往往住在洞穴或废弃的人类住所中，通常拥有盔甲、盾牌和各种武器（武器与盔甲可使用人类强盗的示例）。较不先进的 Bullywug 憎恨那些更聪明的同类，并会与它们交战。

只要没有被盔甲和盾牌负重拖累，Bullywug 就能快速游泳。即使有这些负重，Bullywug 仍能以 9" 的速度游泳。同样，无论是否穿戴装备，Bullywug 都可以向前跳 3"，或向上跳 1½"。进行这种跳跃时，该生物的“命中”骰或骰组获得 +1 修正。如果它使用刺入武器，成功的跳跃攻击会造成双倍伤害。

跳跃攻击是它们通常的近战方式。然而，没有武器可用或被缴械的 Bullywug 仍然会跳着发动攻击；此时它们使用两只爪子（每只造成 1–2 点伤害）和一次咬击（造成 2–5 点伤害）。

Bullywug 拥有类似变色龙的能力；它们的皮肤颜色可以是灰色、绿色或棕色，并且可以呈浅色或深色。因此，如果 Bullywug 静止不动，且所在区域允许它使用伪装能力，那么有 75% 的可能不会被发现（这同样适用于红外视觉，因为颜色改变也会改变体温）。在伪装条件下从未被察觉的位置发动攻击时，Bullywug 有 3/6 的机会使受害者措手不及；如果是跳跃攻击，则为 5/6。

这些生物的主要弱点是：除非它们使用长武器，否则它们的攻击总是在对手之后进行，因为它们移动缓慢，或在跳跃时暴露出破绽。注意，武器可以像对付冲锋一样对准跳跃进行预备攻击（实际上，跳跃就是一种冲锋）。

Bullywug 会组成有组织的群体，并且总由一只拥有完整 8 点生命值的大型个体带领。如果遇到 30 只或更多 Bullywug，至少会有 5 只大型个体，以及一名拥有 10–13 点生命值的首领（实际上是双骰怪物）；首领的所有攻击伤害 +1。使用盔甲等装备的群体中，每十只生物有 10% 的机会拥有一名部落萨满，萨满拥有 11–14 点生命值。人数达到 60 只或更多的群体会有一名拥有 16–19 点生命值的大酋长；大酋长的所有攻击伤害 +2。

这些生物很愿意为混乱邪恶的主人效劳，无论主人是人类还是其他生物。据说 Bullywug 与人类的混血后代可以存活；还据说某些堕落的人类与这些怪物生活在混合社群中，为来自地底深处洞穴的、未被指名的事物效劳。

Bullywug 有自己的、相当原始的语言；较聪明的个体可以结结巴巴地说通用语，不过词汇相当有限。它们受到沙华鱼人的鄙视；沙华鱼人偶尔会出于取乐或纯粹的恶意袭击 Bullywug 巢穴，并把俘虏活活吃掉。蜥蜴人很少与 Bullywug 来往，但双方之间没有公开的敌意。
