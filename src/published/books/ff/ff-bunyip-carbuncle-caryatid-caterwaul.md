| --- | --- |

本耶普水兽是一种水生野兽，外形类似覆盖着厚厚黑毛的海豹，长着黑色鬃毛和异常有力的颚。它栖息在湖泊、沼泽和流速缓慢的河流中。

这是一种顽皮而爱玩的野兽，但体型和力量足以掀翻小船。它还能察觉人类接近，并且可能（50% 的概率）短暂地浮出水面，对附近的一队冒险者咆哮；队伍中所有低于第 4 级的成员都必须以 -2 修正进行对魔杖豁免，否则会惊慌逃跑。

如果某个小型生物（例如矮人）正在水中挣扎，本耶普水兽通常会（80% 的概率）咬下并吞掉一条肢体；不过，除非是自卫，或受害者已经在流血，否则它不会攻击比矮人更大的东西。本耶普水兽强力的颚成功咬中时造成 1–6 点伤害。如果它的攻击骰掷出 20，受害者的一条肢体会被咬断（随机决定，或根据攻击情境决定）。

## 红宝兽 · Carbuncle

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 罕见 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动 | 3" |
| 生命骰 | 1 |
| 巢穴概率 | 10% |
| 宝藏类型 | 无（但见下文） |
| 攻击次数 | 无 |
| 每次伤害 | 无 |
| 特殊攻击 | 无 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 低至平均 |
| 阵营 | 中立，但有混乱倾向 |
| 体型 | S（长 3 英尺） |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | I／14 + 每点生命值 1 |

这种小型生物类似犰狳，身体上表面覆盖着由坚韧的皮革状皮肤形成的、彼此交错的小型“甲片”。它专门以树叶和小型昆虫为食，除非是在有大量食物的林地、沼泽等区域，否则很少能发现它。

它的上部甲片呈棕色，并有吸引人的图案；腹部则是浅灰色，点缀着小型绿色斑块。

它的头部、双眼正上方嵌着一颗大红宝石。这其实是动物身体的一部分；如果野兽死亡，红宝石就会碎成毫无价值的粉尘。不过，巫师（或具有同等地位的人）可以使用魅惑怪物或魅惑动物的能力，诱使它交出红宝石。这颗宝石通常价值 500金币（70%）；罕见个体拥有价值 1,000金币的宝石（25%），而红宝兽拥有价值 5,000金币宝石的概率为 5%。如果宝石被成功取出，红宝兽会以每月 100金币价值的速度重新长出宝石。每次重新长成时，宝石的价值都可能改变。

这种生物拥有共情和心灵感应能力，通过后者进行交流；它还拥有关于近期未来的微弱预言能力。它的共情能力使它能够理解自己遇到的每个人的性格，并知道那个人知道的事情，不过它的智力不允许它形成超出非常基本概念的想法。

如果遭到攻击，它不会抵抗，很容易被捕获。不过，它可以使自己意志性地死去：它没有恐惧，也没有死亡概念；如果受到胁迫，它会献出自己的生命。它通常会主动接近一队冒险者，并通过交流告诉他们自己宝石的价值，寻求加入队伍。然而，当这个目标已经达成，并且它取得了队伍的信任后，它的恶意本性会使它试图在队伍内部制造破坏，利用选择性的心灵感应和真假参半的预言，在队员之间播下敌意、猜疑，甚至引发争斗。

另一种选择（但很少发生）是，它会秘密地与附近的怪物交流，激怒它们，使它们攻击队伍。它散播这种不和的动机并不完全清楚，但一些贤者认为，红宝兽无法理解死亡，因此对战斗、尤其是死亡着迷，以至于会竭尽全力促成这类事件。

达到目的后，红宝兽会带着病态的着迷观察事态发展，然后选择一个合适的时机，悄悄离开。

## 女像柱 · Caryatid Column

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1–12 |
| 护甲等级 | 5 |
| 移动 | 6" |
| 生命骰 | 22 点生命值 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 2–8 |
| 特殊攻击 | 无 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 所有豁免检定 +4 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | M（高 7 英尺） |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | V／280 |

女像柱与石魔像非常相似（见《高级龙与地下城怪物图鉴》中的“石魔像”），它们通过魔法书，或由一名 16 级或更高等级的魔法师创造；创造者必须使用创造石魔像所需的同一组法术。不过，创造成本略高，所需时间也因制作过程复杂而翻倍。

最终形成的是一根约 7 英尺高、纤细而具有装饰性的石柱。随意一瞥只能看出一件装饰性的石制品，它可能与一根一模一样的石柱并排立在房间、礼拜堂或王座室的入口两侧。仔细检查会发现，这根柱子并不像预期那样围绕纵轴呈径向对称；它具有一名人类女性的、非常纤细的外形。一旦观察者辨认出这一细节，就会发现女性的一只“手”贴在身侧，手中握着一柄纤细的剑；这把剑与其他石头融为一体，平滑得几乎看不出来。

女像柱总是拥有特定的防御功能（绝不会作为游荡怪物遇到）。它可能被安排看守一只宝箱，阻止入侵某个区域，或执行其他类似任务。这个任务由创造者设定；如果柱子开始活动时创造者就在附近，创造者可以用简单的口头命令控制它。更常见的是，柱子执行任务时创造者并不在场，于是它会遵循创造者预先决定的简单行动路线。

一旦有人做出任务明确禁止的行为，女像柱就会“启动”——例如，潜在的窃贼接近它被安排看守的财宝，或者有人闯入“禁区”等。活动后，女像柱会呈现肉体的外观，身高缩减到约 5½ 英尺，形体略微膨胀，看起来像一名漂亮的年轻少女。原本由石头构成的剑会变成钢剑；如果有必要，这就是它在近战中使用的武器。它作为一只 5 生命骰的生物进行攻击，造成 2–8 点伤害。

不过，女像柱不一定会进入战斗；它的主要任务是守护财宝、防止闯入某个区域，或执行其他类似任务。如果它能够不通过战斗完成任务，就会尝试这么做。它的行为很大程度上取决于情势与创造者下达的指示；例如，它可能会转移入侵冒险者的注意力，把他们引到某个会被困住、遭怪物攻击，或遭受创造者施放法术攻击的地点。

然而，如果战斗不可避免，女像柱就会主动发起战斗。普通武器对它只造成一半伤害，魔法武器则造成完整伤害，但不计入魔法加值。如果一件武器，无论魔法与否，击中女像柱，它有 25% 的概率折断（此概率不累积）；魔法武器的每一个“加值”都会使折断概率降低 5%（因此，一柄 +4 剑的折断概率为 5%）；没有“加值”的魔法武器按 +1 处理。

女像柱的任务完成后——例如入侵者已被杀死，财宝不再容易遭受侵害——它会回到原来的位置，恢复原本的石头形态，剑也会重新变成石头。如果柱子被杀死，它会当场恢复石头形态，剑也一样。

夜嚎兽是一种独居、凶恶的猫科两足捕食者，长着短短的午夜蓝色皮毛、黄色眼睛和一条长尾巴。它的巢穴通常是一座铺满树枝与草叶的洞穴，宝藏只包括闪亮的物品；它尤其喜欢宝石。洞穴墙壁上会布满抓痕，那是夜嚎兽磨利爪子留下的痕迹。

这种野兽拥有一种不可思议的天生敏捷性，而且不同个体之间有所变化。遇到一只夜嚎兽时，用百分骰在下表中掷骰：

护甲等级调整也适用于闪避能力，以及针对火球术、闪电束等法术的豁免检定。

每轮攻击次数表的使用方式，与战士、巡林客和圣武士的多重攻击表完全相同。

夜嚎兽可以用两条腿迅速移动；当它降为四足奔跑时，可以在短时间内达到最高速度（移动率 24"）。它几乎能够攀爬任何表面（基础滑落概率为 5%），能够无声移动（75%），并能躲入阴影（75%）；因此，它偏好的攻击方式是潜伏在高处，然后从上方跃下，扑向毫无戒备的猎物。它听觉敏锐，嗅觉异常出色，因此很难让它措手不及（只有 10% 的概率能使它措手不及）。

它的第一次攻击（也只有这一次攻击）总会伴随着高亢、哀鸣般的尖啸。这种尖啸的频率会对 60 英尺内所有能听到的生物造成 1–8 点伤害（通过对吐息武器豁免检定者不受伤害）。

夜嚎兽每轮用两只爪子攻击（每只造成 1–4 点伤害），再用一次咬击（造成 1–6 点伤害）；或者按照上表所示，更频繁地发动攻击。
