Cifal——这个名称是“群体昆虫形成的人工生命”（colonial insect-formed artificial life）的首字母缩略词——是数个昆虫群的聚合体（每个昆虫群包含数十万只昆虫）。这些昆虫聚合成一个约有人类大小的单一无定形生物。

整体虫群拥有 8 个生命骰；另外还有 2 个生命骰用于提供维持各个虫群锁定在同一身体中的核心能量。最初受到的伤害会从这后面的 2 个生命骰的生命值中扣除；如果这些生命值耗尽，整体就会分裂为各自独立的昆虫。此时昆虫会以 24" 的速度飞走；它们只有在整体形态下才会攻击和防御。不过，结合力的生命值可以从整体其余部分的生命值中补回，速度为每个近战轮 2 点生命值。

Cifal 通过无数细小的叮咬进行攻击，这些叮咬合计造成 1–12 点伤害。

无论使用何种刃器，也无论武器是否为魔法武器，刃器对 Cifal 只造成 1 点伤害。钝器则造成完整的正常伤害。

严格地说，这种生物并不会飞；上面给出的移动率指的是它沿地面的移动速度，只不过这个结果相当于受到维持形状一致性的限制后的虫群飞行速度。Cifal 没有空中机动等级，但组成它的昆虫属于 A 类机动。

这些生物是鸵鸟的变异形态，长着坚硬的骨质喙，可以造成 1–8 点伤害。它们也用两只爪子战斗，每只爪子都造成 1–8 点伤害。

它们偶尔会爆发出高速，每五个近战轮中有一个近战轮可以达到 24" 的移动率。

Clubnek 的颜色是深浅不同的绿色，喙为黄色。除非受到威胁，否则它们通常并不具有攻击性，但行为相当反复无常、不可预测。它们通常是食草动物，很少在地下被发现；它们更喜欢在草地和树林中漫游。

这些属于亡灵类别的污秽生物，通常出现在搁浅的葬船上，或者出现在尸体未能回归其创造者的其他情形中。Coffer Corpse 虽然类似僵尸，但在牧师／亡灵表中按幽灵处理。

普通武器看起来似乎能对它造成伤害；如果 Coffer Corpse 在单个近战轮中受到普通武器造成的超过 6 点伤害，它会倒在地上，看起来像是已经被解决了。然而，普通武器实际上并没有对这种生物造成任何伤害；如果它某一轮倒在地上，下一轮就会站起来，继续进行近战——此时，所有正在与这只野兽近战的人都必须进行恐惧豁免，否则会惊慌逃跑。

Coffer Corpse 偶尔（25%）会带着一件武器，并在战斗中使用它；在其他情况下，它会用赤手攻击（视为一次攻击，造成 1–6 点伤害）。如果它赤手攻击，命中表示 Coffer Corpse 已经锁住双手，扼住了受害者的喉咙。此后每一轮，它都会自动对受害者造成 1–6 点伤害（不需要“命中”掷骰），直到它被杀死或受害者死亡。一旦 Coffer Corpse 锁住双手，任何东西都无法迫使它松开抓握。

睡眠、魅惑以及其他影响心智的法术对这些生物不起作用。魔法武器可以按通常的魔法加值对它们造成伤害。

Crabman 是两栖生物，通常出现在海岸洞穴中。它们外形像人形生物，但拥有坚硬的红褐色外骨骼。它们没有手，取而代之的是两只钳子，并用钳子战斗；每只钳子对受害者造成 1–4 点伤害。

Crabman 非常看重白银，会不惜一切代价取得白银，甚至会攻击怀疑携带任何白银制品的角色。不过在正常情况下，它们是相当和平的生物；只是偶尔有某种本能驱使它们离开海岸居所，向内陆发动野蛮的袭击。它们会成群结队地游荡，群体可达 30 或 40 只，沿途掠夺所有财物，也不会犹豫攻击那些试图保护财物的人。

Crabman 经常遭到沙华鱼人的袭击，因为沙华鱼人认为它们是美味佳肴。不过，沙华鱼人惯用的撒网战术对 Crabman 无效，因为 Crabman 的天生武器能非常迅速地割破渔网。

## Crypt Thing

| --- | --- |

| 出现数量 No. Appearing | 1 |

| 移动 Move | 12" |
| 生命骰 Hit Dice | 6 |
| 巢穴概率 % in Lair | 100% |
| 宝藏类型 Treasure Type | Z |

| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 很高 |

| 等级／经验值 Level/X.P. Value | V／275 + 每点生命值 6 |

Crypt Thing 是一种苍白、孤独的骷髅生物，总是穿着棕色兜帽长袍。它永久待在自己的巢穴中（至少，没有任何 Crypt Thing 曾在其他地方被遇到过），只要不去打扰它，它就不会攻击。

它的特殊力量是能够毫不失败地对一队人施放一种改良的传送法术（每遇到一队冒险者只能施放一次）。未能通过豁免检定的人，会根据下表的百分骰结果立即被传送：

| 百分骰结果 | 距离与方向 |
| --- | --- |
| 01–20 | 向北 100–1,000 英尺 |
| 21–40 | 向南 100–1,000 英尺 |
| 41–60 | 向东 100–1,000 英尺 |
| 61–80 | 向西 100–1,000 英尺 |
| 81–90 | 向上一个地下城层级 |
| 91–00 | 向下一个地下城层级 |

距离与方向会针对每一个被传送者分别决定。被传送者绝不会抵达实体材料内部；如果目标地点是实体，他们会抵达最靠近目标点的开放空间。不过，被传送者不一定会抵达地面高度。

通过豁免检定的人可以攻击 Crypt Thing，但只有魔法武器能够击中它。Crypt Thing 会反击，使用双手抓挠的动作，造成 1–8 点伤害。

Crypt Thing 能够用中立语交流；不过，如果有人询问队伍中某些成员失踪的情况，它不会透露自己的力量，反而会坚持声称那些成员已经被解离术分解了。

据说世上存在异常的 Crypt Thing：它们不会传送受害者，而是使受害者麻痹，并同时令其隐形。不过，这一类型与更常见的类型都不以受害者为食；它们的目的似乎纯粹是通过制造混乱与不和来获得乐趣。
