Denzelian 是一种和平的食岩生物。它非常纤薄，但表面积很大（约 10 英尺 × 10 英尺 × 3 英尺）；它在固体岩石中挖掘隧道，以每周 1 英尺的速度缓慢磨蚀岩石。通常会有一只雄性和一只雌性在彼此靠近的地方挖掘。它们会避开金属，即便只有很小的矿藏也会绕行；因此 Denzelian 隧道往往呈蜿蜒曲折的路线。

由于它们看起来像石头，散发令人厌恶的气味，而且无法消化，Denzelian 很少受到食肉者的打扰。

Denzelian 的寿命为 1,000 年；雌性一生只排卵一次。如果附近有雄性（通常确实会有），产下的卵群包含 3–8 枚卵，并在 100 年后孵化。卵看起来像没有特征的、拳头大小的石头。在一片有 Denzelian 雌性出没的区域内，找到一枚卵的概率为千分之一，因为它们不会把卵集中产在一起。某些富有的矿主愿意为一枚卵支付 1,000 枚金币或更多。

## Devil

《高级龙与地下城怪物图鉴》给出了 Devil 的完整资料；这里重印适用于 Styx Devil 的编辑后资料。

Devil 遵循明确的秩序与指挥链，因为害怕魔鬼大公而不敢破坏这套秩序。不过，不同位面的 Devil 之间以及不同魔鬼大公之间，仍存在激烈的竞争，甚至公开的敌对。

所有 Devil 都能够在地狱诸位面之间移动（公爵除外，它们未经许可不敢这样做）。它们可以随意移动到 Gehenna、Hades 和 Acheron，也能够穿过星界位面，虽然很少这样做。除非完成正确的仪式、打开传送门，或说出（并被听见）某个 Devil 的正确名字，否则没有 Devil 能够进入其他位面。

可以摧毁强大 Devil 或地狱公爵的物质形体，但除非是在地狱或邻近的下层位面遇到并与之战斗，否则不能真正杀死这些生物。Devil 永远无法被驯服。较弱的 Devil 总会战斗至被摧毁；较强的 Devil 在受到严重威胁时会谈判。如果受到正确命令，Devil 会服从，但这是一件危险的事，因为错误的命令会破坏约束它服务的法律。（此外，命令者通常必须为其灵魂签订契约。）其他不是守序邪恶的人也可能召唤或以其他方式与 Devil 打交道，不过，与这类怪物共餐时，最好使用人们常说的那把长勺。

如果正确地刻画（对于较强大 Devil 和魔鬼大公，还必须刻上符号），魔法阵可以把 Devil 拦在外面一段时间。神圣（善良）的神器或遗物会驱逐 Devil。

所有 Devil 都能在条件允许时把攻击指向两名或更多对手。如果一名强大 Devil 的物质形体被摧毁，它会被迫成为 Lemure，承受九十年的折磨，之后才能恢复原来的地位（见《高级龙与地下城怪物图鉴》中的“魔鬼，Lemure”）。

所有 Devil 都拥有或能够执行以下能力：

- 魅惑人类
- 暗示
- 幻术
- 红外视觉
- 传送（无误差）
- 知晓阵营
- 造成恐惧（效果各异）
- 动画死尸

Devil 能够召唤同类，召唤方式类似怪物召唤法术。

由于拥有特殊形式的心灵感应，Devil 能够理解并与任何有智力的生物交谈。

Devil 会受到下列攻击形式的影响：

| 攻击 | 最大伤害 |
| --- | --- |
| 酸 | 完整 |
| 寒冷 | 一半 |
| 电击（闪电） | 完整 |
| 火焰（龙息、魔法） | 无 |
| 气体（毒性等） | 一半 |
| 铁制武器 | 无* |
| 魔法飞弹 | 完整 |
| 毒素 | 完整 |
| 白银武器 | 完整 |

\*除非受到普通武器影响；在这种情况下，伤害依武器类型而定。

### Devil 的护符

强大 Devil 拥有一种特殊的铭文组合，可以把它们束缚于持有者。使用任何 Devil 护符都需要极大的谨慎。邪恶生物使用护符时需要人类献祭。仅仅观看这些护符，如果没有受到法术或魔法圆环的适当保护，就是危险的；研究护符上的咒语有 10% 的概率召唤出护符所属的种类或特定 Devil。说出护符上的名字，则总会召来所属的种类或特定 Devil。

Styx Devil 居住在地狱第五层。它们是类人生物，但头部比例异常巨大而丑陋，翅膀为黑色并饰有银色边缘。它们的主要任务是搜寻灵魂，将其带回 Geryon；不过，它们有时也会带着毁灭遇到的所有人类的意图巡视物质界。

Styx Devil 不受普通武器伤害，但会受到白银武器以及加值至少为 +1 的魔法武器伤害。

它的接触造成 2–8 点伤害，并有 50% 的概率对受害者施加监禁术（不允许豁免检定）。按 22 级魔法使用者施放处理，并将 Styx Devil 视为完全了解受害者的名字与背景。

要驱散 Styx Devil，必须说出圣言。

就空战而言，Styx Devil 的机动等级为 C。

Devil Dog 是毛色雪白、眼睛蓝色的猎犬，生活在寒冷地区；在积雪或覆霜的区域遇到它们时，30 英尺以外看不见它们。它们成群游荡，不断寻找食物；它们总会攻击人类队伍，而且狡猾得足以把保护色利用到极致。

Devil Dog 使用凶猛的咬击，并总是扑向咽喉。正常伤害为 2–8 点；不过，如果“命中”骰比所需命中数高出 4 点或更多，或者在任何情况下掷出自然 20，则命中咽喉。受害者受到双倍伤害，昏迷 2–8 轮，并且必须在昏迷期间接受轻伤治疗术（或同类更强的治疗），才能避免在昏迷期结束时死亡。当然，最初的伤害也可能直接杀死受害者。

攻击或追逐时——而 Devil Dog 的速度确实非常快——这些生物会发出强烈的吠叫。除非第 3 级或更低等级的角色以 -4 修正通过针对魔法的豁免，否则会因吠叫而恐惧。它们能够以极高的 30" 移动率持续三轮；之后必须“休息”三轮，在此期间最大移动率为 12"。

这个地下种族由巨大的黑色两足鸟组成，其中有凶猛的战士，永远不需要进行士气检定。很久以前，Dire Corby 失去了飞行能力；不过，它们以巨大的力量与凶猛弥补了这一点，总会发动攻击并战斗至死。

曾经的翅膀如今已经发展成两条强壮的手臂，末端长着锋利、坚硬如岩石的爪子。它们用这些爪子战斗，每只爪子都能对受害者造成 1–6 点伤害。

它们成群狩猎，追赶无助的受害者，同时发出可怕的尖叫。它们拥有一种粗略的语言（熟悉这种语言的人可以把它们的攻击叫声辨认成“毁灭！毁灭！”）。

Dire Corby 生活在巨大的地下洞穴中；过去，它们与巨型蝙蝠之间曾经公开交战，但如今已经形成一种不稳定的休战。
