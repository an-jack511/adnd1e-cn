| 出现数量 | 1 |

| 攻击次数 | 2 |

| 特殊防御 | 无 |

包裹怪本质上是一团可塑的肉，呈粗圆柱形，高 8 英尺，周长 3 英尺。它可以随意重新塑造身体适当部位，形成最多五个附肢；当它出现在人类或类人类面前时，会采取近似人形的外观（附肢分别成为头、手臂和腿）。它的智力基本属于动物水平，阵营中立，拥有标准魔法抗性，没有灵能能力。

近战中，包裹怪用两只“拳头”攻击，每只都能造成 1–8 点伤害。

如果包裹怪杀死了一个受害者——无论是怪物还是角色——它的第一件事就是扑到尸体上；尸体会在一轮内被完全吞食，只留下衣服、武器等物品。再经过三轮的延迟后（在这段时间内，野兽可以照常战斗；它不能在吞食轮攻击），包裹怪可以使用受害者的任何能力。例如，它会获得受害者的经验与知识，能够用受害者的声音说话，能够施放受害者已经记忆的法术，等等。受害者每拥有一个生命骰，包裹怪就获得 1–3 点生命值；无论它获得多少额外生命值，它的攻击概率仍按原本的数值处理。

随着包裹怪吞食更多受害者，它会获得更多能力与力量。如果属性或能力发生相互冲突（例如阵营冲突），就会随机丢弃其中一项，直到冲突消除。野兽会趋向于最近一次吞食的受害者的阵营，阵营语言也会相应变化。

包裹怪会随着年龄获得生命骰，每次增加 2 个生命骰；理论上，年老的包裹怪所能拥有的生命骰或生命值没有上限。

## 伊特怪 Ettercap

| 生命骰 | 5 |

| 特殊攻击 | 毒素 |

| 魔法抗性 | 标准 |

伊特怪是一种大致与人类同高的两足生物，手臂极长，腹部突出，双腿短，皮肤多毛；它的双手长着爪子，嘴巴两侧各有一颗突出的毒牙。伊特怪残酷、狡猾而奸诈。

伊特怪用爪子攻击，每只造成 1–3 点伤害；同时还会进行毒咬，造成 1–8 点伤害。

这种生物拥有类似蜘蛛的丝腺，位于肛门附近。腺体分泌出细而极其坚韧的银色丝线，野兽用它制造各种武器和装置——套索、网、绞索、绊线等。每只伊特怪都有偏好的武器与陷阱装置，因此遭遇时会因伊特怪的偏好而不同；不过，只要有时间，它们总会设置陷阱并准备伏击。

伊特怪与所有形式的蜘蛛都相处良好。

## 杀目兽 · Eye Killer

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 或 2–8 |
| 护甲等级 | 5 |
| 移动 | 9" |
| 生命骰 | 4 |
| 巢穴概率 | 25% |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 1–6 |
| 特殊攻击 | 死亡凝视 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 混乱邪恶 |
| 体型 | M |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | III／150 + 每点生命值 4 |

杀目兽出生时没有四肢，形状几乎是球形；后来，它会在一条大蛇的身体上长出蝙蝠般的上半身。它的退化翅膀无法支持飞行。身体上部为深灰绿色，下部为中绿色，并点缀暗黄色斑纹。它的眼睛比例异常巨大，而且似乎没有眼睑。

这种生物讨厌白昼，也憎恨明亮的裸焰。它生活在地下的黑暗区域；那里还可能发现 2–8 只杀目兽（概率 10%）。

这种生物的行为几乎完全取决于照明。如果依靠红外视觉或低等级自然环境光的生物接近并攻击它，杀目兽只会用身体缠绕，挤压受害者，造成 1–6 点伤害（命中表示它已经成功用身体缠住受害者；之后每轮，它都会自动造成 1–6 点挤压伤害，不需要“命中”掷骰）。

不过，如果接近的队伍携带提灯或火把，杀目兽就能使用可怕的死亡凝视，射程可达 50 英尺。它的眼睛会收集照射到自身的光，把光放大到极强的程度，再以一道强烈而狭窄的光线投射回持光者。光线命中目标时，视目标护甲等级为 10；受害者必须进行对死亡射线的豁免检定，否则立即死亡。通过豁免者受到 3–18 点伤害。

凝视可以被反射，不过不会伤害杀目兽——它只会收集光线，将其进一步放大，并在同一轮把光线投射到另一名受害者身上。幸运的是，死亡凝视每天只能使用一次。

如果火把或提灯的持有者接近杀目兽，它不会正面对着光，并会在照明变得强烈时试图逃跑（相当于距离 10 英尺处三支火把的强度）。如果照明不足以迫使它逃跑，它就会按前述方式用身体缠绕攻击。

## 火惧之眼 Eye of Fear and Flame

火惧之眼是一个戴着兜帽、身高与人类相当的身影；它的脸总是不可见，兜帽内部看起来像一块不透明的黑色屏幕。它不断在地下世界中游荡，寻找守序或守序中立的队伍或个体。它会命令某个个体，或某支队伍中的成员，去做邪恶的事（它拥有永久性的侦测阵营能力，会说所有阵营语言，因此会使用适合被命令者的阵营语言）。要求的行为各不相同，但无一例外都属于邪恶行为。

如果 Eye 遭到攻击，或命令没有被服从，它会向后掀开兜帽，露出一颗裸露的头骨；一个眼窝中有红宝石，另一个眼窝中有黑宝石。

红宝石每三轮释放一次 12 骰火球术；黑宝石每轮都像恐惧魔杖一样起效。每颗宝石价值 1,000–2,000 枚金币，不过从头骨中取出宝石，或生物被杀死时，宝石会失去这些性质。

如果近战形势对这种生物不利，它拥有转移到以太位面的能力；转移需要两轮，在此期间它会试图逃走。它没有徒手战斗的手段。

如果对 Eye 施放失明术或强力词语：失明术，法术会以完整威力反射回施法者。

据说火惧之眼要么是混乱邪恶的神祇创造出来、用于毁灭守序者，要么是守序／中立神祇创造出来、用于考验守序者。真相隐藏在迷雾中。据传世上只有约二十个这种生物。
