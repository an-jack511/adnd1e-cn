与其他同类汇编一样，《恶魔宝典》中的“怪物”一词有两种不同含义。第一种，也是更重要的一种，是指任何遇到的生物，无论敌对与否，无论是人类、人形生物还是野兽。因此，这个词作为遭遇对象的通称使用；在冒险队确认自己遇到了什么之前，它就是一个“怪物”。第二种用法更为传统，指某种邪恶或可怕的生物。更具体地说，如果队伍遇到的怪物后来被证明是邪恶法师，那么后者很可能同时也是第二种意义上的怪物；然而，如果遭遇的是一只没有恶意的和平生物，第二种意义就不适用。ADVANCED DUNGEONS & DRAGONS 玩家几乎肯定已经熟悉这个词的两种用法；新玩家起初可能会有些困惑，但经验很快会决定具体语境应当使用哪一种。

注意，尽管有上述术语，人类以及近人类在作为怪物遭遇时，攻击仍然使用人类攻击矩阵。换句话说，矮人、精灵、侏儒、半精灵、半身人、半兽人和人类，无论是“怪物”还是“玩家角色”，始终使用人类攻击矩阵。

每一种《恶魔宝典》怪物都会在后文获得完整描述；此外，每一种怪物还会被赋予若干参数的数值，这些参数共同概括其行为、战斗方式等。以下解释这些参数。

## 出现频率 Frequency

指出在某个地区或区域中、于该生物可能居住的地方遇到它的可能性，也就是该怪物在此类区域中的稀有程度。“极罕见”表示出现机会为 4%；“罕见”为 11%；“不常见”为 20%；“常见”为 65%。这些概率经过必要的小幅近似，反映在怪物等级表中，这些近似完全处于统计变动允许的范围之内。每个类别内部仍有差异，例如，同属“极罕见”的某些生物事实上会比其他同类更罕见。

## 出现数量 Number Appearing

表示一次遭遇中合理的平均数量。一般而言，如果在巢穴内或巢穴附近遇到某种生物，可以预期数量会落在此范围；离开巢穴更远时，遇到的数量会较少。同样存在例外：为特定袭击或惩罚任务组成战团的聪明、有组织怪物，可能在远离巢穴很远的地方以大批数量出现；而在它们巢穴附近的遭遇，反而可能碰到少量“斥候”或“外围守卫”。因此，所给数量范围只能作为指引，应按具体冒险的情形调整。

更严格地说，所给数量范围不一定是地下（地城）遭遇的推荐数量。由于许多冒险发生在地城中，本书在“遭遇列表”之后另有一节，说明在这类地点可能遇到的各类怪物数量。

## 护甲等级 Armour Class

描述人类、近人类或人形怪物所穿防护的大致类型，也包括怪物因身体结构和／或魔法性质而固有的防护，以及因速度、反应等因素导致的受击难度。所有这些因素合并为单一护甲等级数值。裁判无需因为高敏捷而调整这一数值；如果在特定情况下需要调整 AC，怪物个体描述中会列出相应改变。

## 移动 Move

表示怪物持续移动时的相对速度。极短时间内可能达到更高速度。通过相应调整地面比例，可以把生物的移动率换算到所需的任何时间尺度。在某些情况下，这一栏会给出多个数字，表示怪物可以在两种或更多介质或模式中移动：

- `X"`：怪物在正常介质中的移动率。
- `/X"`：除正常移动模式外，怪物的飞行速度。
- `//X"`：除正常移动模式外，怪物的游泳速度。
- `(X")`：除正常移动模式外，怪物的掘进速度。
- `*X"`：怪物在蛛网中的移动速度。

如果只给出一个数字，不自动表示怪物只能在地面移动（尽管大多数情况下确实如此）；必须查阅正文才能确定其含义。因此，一只唯一的移动方式是飞行的怪物，也只会有一个数字，而这里的数字就是飞行速度。

## 生命骰 Hit Dice

说明如何计算怪物死亡前能够承受的生命值。除非另有说明，生命骰使用八面骰。掷出所示数量的骰子，把结果相加，得到怪物的总生命值。

有些怪物的生命值低于完整 d8 的 1–8 范围，这会以生命值范围表示；例如，如果某生物有 1–4 点生命值，就掷四面骰决定其生命值。

另一些怪物的生命值会在生命骰产生的数值之外再增加若干点，这会以加号后跟数字表示。例如，若怪物的生命骰为“5+3”，就掷五个八面骰，将结果相加后再加 3；该怪物的生命值范围就是 5–40 点再加 3 点，即 8–43 点。

## 巢穴概率 % in Lair

表示在该怪物居住并储存宝藏（若有宝藏）的地方遇到它的机会。有些怪物永远不会在巢穴中发现：可能因为巢穴无法进入或无人知晓，也可能因为怪物没有固定巢穴，是真正的游荡怪物。

某些怪物的巢穴位于主物质位面以外；如果遭遇发生在主物质位面，或发生在不是该怪物居住位面的其他位面，显然不可能在它的巢穴中遇到它。然而，某些通常把巢穴设在主物质位面以外的怪物，可能为了追求特定目的或执行特定任务，暂时在那里建立巢穴。

## 宝藏类型 Treasure Type

指向本书末尾的表格。该表显示宝藏类型、宝藏各组成部分的数量，以及宝藏包含某组成部分的概率。例如，宝藏类型 J 表示每个遭遇个体始终有 3–24 枚铜币，但绝不会有银币、电子币、金币、铂金币、宝石、珠宝、地图或魔法物品。相反，宝藏类型 P 只可能有银币和／或电子币：银币出现概率为 30%，电子币为 25%，所以完全没有宝藏也是可能的。

如果指定的是个体宝藏，则每个该类怪物都将拥有或可能拥有所示宝藏；否则，宝藏只会出现在怪物巢穴中（通常怪物也会在巢穴中守卫宝藏）。不过，即使在拥有某种宝藏类型的怪物巢穴中发生遭遇，也不自动意味着冒险者击败怪物后就能得到宝藏。如果掷骰结果表明某一宝藏组成部分不在巢穴中，那么它就是不存在；因此，即使击败了巢穴中的怪物，也完全可能什么宝藏都得不到。

宝藏类型以该类怪物的平均数量为基础，平均数量由“出现数量”栏指定。若遭遇数量少于或多于该数，宝藏价值应相应减少或增加。给定类型的更大宝藏用括号中的倍数表示，例如 `(x2)`；不要把这种倍数与宝藏类型 X 混淆。

## 攻击次数 Number of Attacks

表示怪物在一个特定近战轮中可以发动的基本攻击次数，不包括特殊攻击。这个数字可能受到加速、迟缓等法术的改变，但不包括不寻常或特殊的攻击形式。多次攻击通常表示同一近战轮内使用了几种攻击方式；例如，一只用两只爪撕抓并在同一近战轮咬人的怪物，会记为 3 次攻击。

## 每次攻击伤害 Damage per Attack

表示某次攻击命中时对受害者造成的伤害点数，以伤害范围表示。如果怪物使用武器攻击，则不会列出伤害，因为伤害会随所用武器类型变化。更详细的攻击方式和每种攻击可能造成的伤害，必须查阅怪物正文。

## 特殊攻击 Special Attacks

详细列出龙息、魔法使用等特殊攻击方式。关于这些攻击的完整说明，包括发动方式和频率，见怪物正文。

## 特殊防御 Special Defences

含义基本不言自明，并在正文中以与特殊攻击相同的方式详细说明。内容包括防御魔法、伪装能力等。

## 魔法抗性 Magic Resistance

表示法术施放在该怪物身上或以其为目标时，法术绝对失效的百分比。该数值以 11 级魔法师施法为基础；施法者每低于 11 级一层，数值上调 5%；每高于 11 级一层，数值下调 5%。因此，拥有 95% 魔法抗性的怪物不会受 10 级或更低等级魔法师施放的法术影响，而 12 级魔法师有 10% 的机会影响它。

注意，即使法术“克服了魔法抗性”，怪物仍然可以进行正常豁免。

## 智力 Intelligence

表示基本上相当于人类智商的等级（至少概念上如此，即使智商本身如今似乎已经声名狼藉）。某些怪物在遭遇时凭本能而狡猾或特别诡计多端；如果是这种情况，正文会说明。智力等级大致对应以下角色智力分数：

| 数值 | 智力 |
| --- | --- |
| 0 | 无智力，或智力无法评定 |
| 1 | 动物智力 |
| 2–4 | 半智能 |
| 5–7 | 低 |
| 8–10 | 平均（人类） |
| 11–12 | 很高 |
| 13–14 | 高度聪明 |
| 15–16 | 非凡聪明 |
| 17–18 | 天才级 |
| 19–20 | 超天才级 |
| 21+ | 神祇级 |

## 阵营 Alignment

表示怪物倾向于守序、混乱、善良、邪恶或中立行为的基本性情，也可能受善恶意图修正。怪物的阵营会显著影响它遭遇时的行为、对某些情形的反应等。

## 体型 Size

缩写如下：`S` 小于典型人类；`M` 约人类大小（身高 5–7 英尺，体格大致与人类相当）；`L` 以某种方式大于人类，通常质量也比人类更大。除此之外，怪物的体型还会决定特定武器命中它时造成的伤害。

## 灵能能力与攻击／防御模式 Psionic Ability and Attack/Defence Modes

表示怪物可能具有的总体灵能能力。有些怪物只是被怀疑拥有灵能而非得到确认；若属此类，正文会说明。

## 等级与经验值 Level and Experience Point Value

按照《ADVANCED DUNGEONS & DRAGONS 地下城主指南》中说明的方法决定。如果怪物拥有不同生命骰和／或不同“经验等级”，则会分别列出各项数值。

上述字段和数值说明怪物的一般参数；每个条目后面都会接着给出怪物的详细描述，包括行为、通常栖息地、攻防方式、特殊特征等。必要时还会附上该类生物的典型图示。

正文中能够飞行的怪物还会出现“空中机动等级”（Aerial Manoeuvrability Class）。这是一种从 A 到 E 的总体评级，表示怪物在空中的机动能力：A 级位于一端，飞行迅速且机动性极强，难以命中，也能迅速而根本地改变方向；E 级位于另一端，飞行缓慢而笨重，相对容易成为目标，无法急转弯，除了极小幅度的方向改变外，需要很大空间才能完成动作。
