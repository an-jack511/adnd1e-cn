Fire Snake 的颜色从血红色到橙色不等，而且总是出现在火焰中。一些大型的永久性火焰中会有 1–6 条，但较小的半永久性火焰（例如火坑和油碗）中可能只有一条。蛇的下方会有它们积攒的宝石。

由于颜色与周围环境非常相称，它们有 60% 的概率发动突袭。它们的咬击造成 1–4 点伤害，并注入一种温和毒素；除非受害者通过针对毒素的豁免，否则会麻痹 2–8 轮。

有人推测 Fire Snake 是 Salamander 的幼体。

| 智力 Intelligence | 低 |

| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | IV／165 + 每点生命值 5 |

Firetoad 是一种约 4 英尺高、覆盖紫色疣状突起的大型红色蟾蜍。向它投掷液体或油会使它逃跑，不过在逃跑时，它会在同一个近战轮内把两次火球攻击集中到做出该行为的人身上。

Firetoad 可以随意喷吐小型火球，射程 30"，爆炸半径 5 英尺。这是它唯一的攻击方式；火球造成的伤害等于 Firetoad 当前剩余的生命值。对这次攻击可以进行正常豁免，成功则伤害减半。

Firetoad 很少（20% 的概率）主动攻击，除非受到威胁、骚扰，或是在防御自己的宝藏。

## Flail Snail

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 4 |
| 移动 Move | 3" |
| 生命骰 Hit Dice | 4–6 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 每条触手 1 次 |
| 每次伤害 Damage/Attack | 每条触手 1–8 |
| 特殊攻击 Special Attacks | 无 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 见下文 |
| 智力 Intelligence | 低 |
| 阵营 Alignment | 中立 |
| 体型 Size | L |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 4 HD：III／150 + 每点生命值 4；5 HD：IV／205 + 每点生命值 5；6 HD：V／350 + 每点生命值 6 |

这种以硅为基础的软体动物，外壳顶部平均高 8 英尺；它有 4–8 条棍棒状触手，并不停挥动，抽打路径上的一切目标。在战斗中，每条触手都有自己的生命值；触手“死亡”后就不再攻击。所有触手被杀死后，野兽会把头部和身体其余部分缩进壳里；它会在 1–3 轮内死亡，并发出可怜的哀鸣，每轮有 50% 的概率吸引游荡怪物。

这种生物的身体也有生命值，但它能以极高速度把身体缩进壳里，因此按 AC -8 处理。不过，身体一旦被击中，无论是否还有触手存活，都会立即杀死它。

近战中，每条触手造成 1–8 点伤害。每条触手代表这种生物的 1 个生命骰，因此拥有 5 条触手的蜗牛有 5 个生命骰。

Flail Snail 免疫火焰（普通或魔法）和毒素，但对明亮照明极度敏感，因此总是在夜间或地下被遇到。

颜色鲜艳的外壳为它提供部分魔法防护，作用类似一件闪耀色彩长袍。每当它受到魔法攻击时，效果是可变的：40% 的概率法术失常，30% 的概率正常生效，20% 的概率完全不起作用，10% 的概率反射回施法者。如果法术失常，其效果会发生改变（完全由裁判决定，但裁判不会允许超过轻微的改变），而改变后的效果会从蜗牛偏转到最近的人或生物。

外壳重 250 磅（2,500 枚金币的重量），在其居住者死亡后 1–6 个月内仍保留魔法性质。外壳最多可以卖到 5,000 枚金币。
