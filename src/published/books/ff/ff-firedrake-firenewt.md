这种小型龙兽仅在岩石地区被发现，长约 4 英尺；外形像微型红龙，但性情并不像龙。如果即使在和平意图下受到打扰，它也有 50% 的概率发动攻击。它不使用爪子战斗，但咬击会造成 2–8 点伤害。

Firedrake 还拥有喷吐武器，每天可使用五次。这是一道长 60 英尺、根部直径 10 英尺的火焰锥，造成 2–16 点伤害（成功通过豁免时减半）。

与体型更大的亲族龙相比，Firedrake 的寿命很短；龙族随年龄增加生命值的阶段规则不适用于它。

这种龙兽的血液在空气中会猛烈燃烧（喷吐武器实际上就是血液喷流），但如果血液保存在水下容器中，就会失去活性。把剑浸入这种血液后，剑会立即变成火焰剑，持续 3–6 个近战轮；不过，在此期间每次用剑击打时，都有累积 2% 的概率使剑折断。如果剑“熬过”这 3–6 轮，它停止燃烧后会恢复原本的力量。

就空战而言，Firedrake 的机动等级为 C。

## Firenewt

| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 依武器类型而定 |
| 特殊攻击 Special Attacks | 喷吐火焰 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 低 |

| 体型 Size | M |

| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 普通：III／90 + 每点生命值 3；精英：III／125 + 每点生命值 4；祭司：IV／190 + 每点生命值 4；霸主：IV／165 + 每点生命值 5 |

这些蜥蜴人的远亲生活在晒热的岩石丘陵、火山地区，或其他炎热、干燥、有时带硫磺气味的地点，无论是在地表还是地下。它们有时也被称为 Salamander。

Firenewt 战士（最常见的类型）通常穿着链甲，携带普通武器：长矛与剑（45%）、仅剑（25%）、长矛与手斧（20%），或战斧（10%）。

每遇到 10 名战士，就会有一名精英战士，拥有 3+3 个生命骰，以及 AC 3（链甲加敏捷修正）。每遇到 30 名，除了三名精英战士外，还会有一名“祭司”，拥有 3+3 个生命骰、AC 5，并拥有以下德鲁伊能力，每项每天可使用一次：动物友谊、妖火、预测天气、制造火焰、金属加热和烟火术。精英战士总是携带战斧，而祭司在近战中使用钉头锤。

在地表遇到的 Firenewt 中有 33% 会骑乘巨型高跷鸟（精英战士中有 90%，祭司全部如此）；这些野兽由祭司训练，即使 Firenewt 的“主人”下马，它们在近战中也非常娴熟。

所有 Firenewt 都拥有有限的喷吐武器。每轮一次，它们可以对正前方、5 英尺范围内的敌人喷火，造成 1–6 点伤害（成功豁免表示伤害减半）。

Firenewt 对火焰攻击有很高的抗性，进行豁免时获得 +3。此外，影响它们的所有火焰攻击，每个攻击伤害骰减去 1 点。相反，Firenewt 针对寒冷攻击的豁免为 -3，而此类攻击对它们造成的伤害每个攻击骰增加 1 点。

Firenewt 是残酷的掠夺者；遇到它们时，它们通常会组成狩猎队。它们喜欢把受害者活活折磨、烤熟，然后享用。

在 Firenewt 巢穴中，除了正常成员外，还会有额外 70% 的雌性和 150% 的幼体，以及一处秘密且严密守卫的孵化场，其中有 200% 的卵。孵化场由祭司控制，并由 1–3 只幼年火蜥蜴守卫（见《高级龙与地下城怪物图鉴》中的“火蜥蜴”）。巢穴由一名拥有 4+4 个生命骰、AC 3 的 Firenewt 霸主统治；霸主身边有四名精英战士组成的亲卫队。

<strong>描述：</strong>典型 Firenewt 呈斑驳的棕褐色，脊柱沿线颜色最深，向腹部逐渐变为接近白色。光滑的皮肤与特征像鳗鱼，尽管皮肤是干燥的。眼睛为深红色。雌性略短于雄性（约高 5½ 英尺），颜色更暗淡、更偏棕色。幼体颜色较浅，接近成熟时逐渐变深。
