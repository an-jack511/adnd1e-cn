Fog Giant 是云巨人的亲族；如果极其罕见地遇到多达 6 只 Fog Giant，它们总会伴有一只云巨人。

Fog Giant 听觉极敏锐，嗅觉高度发达。因此，只有掷出 1（d6）时才会被突袭。它们还能融入雾中，从而获得使对手措手不及的能力（概率 80%）。它们栖息在有雾的区域，例如沼泽、湿地、茂密森林和海岸附近。

Fog Giant 的皮肤乳白，头发银白，眼睛黑色而锐利。它们喜欢巨大华丽的剑，更偏好用镶银的白龙皮制成的盔甲。近战中，它们会用喜爱的剑或拳头战斗，两者都对受害者造成 4–24 点伤害。如果穿着盔甲，盔甲不影响护甲等级；它们的护甲等级始终按 1 处理。

成年 Fog Giant 像云巨人亲族一样，能够从 1"–24" 的距离投掷岩石，命中造成 2–20 点伤害。它们有 45% 的概率接住类似投射物。

Fog Giant 会说自己的方言和阵营语言；除云巨人外，其他巨人都听不懂这种方言。

| 魔法抗性 Magic Resistance | 标准 |

Mountain Giant 很少在巢穴外被遇到；巢穴是从岩山中心凿出的巨大洞穴。除了自己的语言外，它们还都能说食人魔语。

与它们的丘陵巨人亲族一样，它们能从 1"–20" 的距离投掷岩石，命中造成 2–16 点伤害。它们接住类似投射物的概率为 30%。近战中，它们用巨大棍棒攻击，造成 4–40 点伤害。

Mountain Giant 可以召唤并控制其他怪物，通常（70%）是 6–15 个食人魔，但有时（20%）是 4–9 个巨魔，或（10%）是 1–4 个丘陵巨人。如果在其巢穴中遇到 Mountain Giant，有 75% 的概率这些生物会在场，担任仆人和守卫。

巨人女性和幼年 Mountain Giant 很少被遇到；如果在巢穴中遇到四只 Mountain Giant，还会额外有一名女性和一名幼年巨人（各有 8+1–2 个生命骰，并进行一次攻击，造成 2–16 点伤害）；否则，遇到的 Mountain Giant 总是成年雄性。

Mountain Giant 的皮肤为浅棕至浅红棕色，像丘陵巨人一样穿着粗糙的兽皮或皮革。

## Giant Strider

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 罕见 |
| 出现数量 No. Appearing | 1–6 |
| 护甲等级 Armour Class | 4 |
| 移动 Move | 15" |
| 生命骰 Hit Dice | 2 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 2 |
| 每次伤害 Damage/Attack | 1–8／1–10 |
| 特殊攻击 Special Attacks | 火球 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准；豁免 +2，免疫魔法火焰 |
| 智力 Intelligence | 动物 |
| 阵营 Alignment | 中立邪恶 |
| 体型 Size | L（肩高 6–7 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／73 + 每点生命值 2 |

这些大型不会飞、没有羽毛的鸟看起来像沉重的鸵鸟。每只暗红色、微微发光的眼睛旁都有一根小管，野兽可以从管中投射造成 1–6 点伤害的小型火球。它们每小时可以投射两枚火球（每根管子一枚），准确度相当于 +4 长弓，最大射程 50 英尺，爆发半径 10 英尺。

此外，Giant Strider 可以向前方或侧方咬击，造成 1–8 点伤害，或向后踢击，造成 1–10 点伤害。不过，它不能在同一近战轮同时协调两种攻击，通常会朝最近一次被击中的方向发动攻击。

这些鸟免疫火焰，无论普通或魔法火焰；它们的身体已经适应了从温暖中获取营养，因此最适合生活在沙漠和火山地区。强烈热量、火焰、火球等，每三轮一次会像轻伤治疗术一样治疗它们。因此，人们经常能看到 Giant Strider 在熔岩床中涉水，或站在森林火灾的火焰里（凤凰传说可能就源自这种景象）。

相反，寒冷法术等会额外造成 2–7 点伤害，而水（如果饮下）对它们是毒药。即使把冷液体泼到它们身上，也会造成一些伤害（由裁判根据情势决定，但通常为 1–2 点）。

Firenewt 会把这些生物当作坐骑使用。它们通常无所畏惧，从不进行士气检定。
