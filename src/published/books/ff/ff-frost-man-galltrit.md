由于这些生物的致命天赋，本地部族非常害怕它们，并称它们为“冰魔”；不过，Frost Man 在大多数方面都很像普通人类，而且可以拥有战士、牧师、盗贼，甚至魔法使用者的能力。它们会携带与职业相称的武器。

Frost Man 还拥有每天三次从一只眼睛放射冻结的冰雾锥的能力；冰雾锥长 35"，根部直径 10 英尺（不用时，通常会用眼罩遮住这只眼睛）。另一只眼睛会进行聚焦，因此不会因单眼视觉而降低命中概率。

被雾锥捕获的生物受到 3–18 点伤害（通过针对龙息的豁免后减半）。

到目前为止，这些生物只被单独遇到过；它们的巢穴位置、巢穴类型和生活模式都未知。有人认为，寒冷地区的山脉深处洞穴中有 Frost Man 村庄，其中住着雌性和儿童，但还没有人能够证实这些传闻。

Frost Man 外形像普通的人类男性。不过，它们会散发寒气，最远 30 英尺外就能清楚察觉，但寒气强度不足以造成伤害。它们穿着宽松的兽皮，并把个人宝藏装在皮袋中。

根据目前有限的证据，Frost Man 中大多数（75%）属于战士，15% 是盗贼，约 8% 是牧师，只有 2% 是魔法使用者。与人类相比，牧师和魔法使用者似乎都只能把施法能力发展到第 2 级。

## Galltrit

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1–4 |
| 护甲等级 Armour Class | 2 |
| 移动 Move | 3"／18" |
| 生命骰 Hit Dice | 2 点生命值 |
| 巢穴概率 % in Lair | 20% |
| 宝藏类型 Treasure Type | 1–3 颗宝石 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–2 |
| 特殊攻击 Special Attacks | 麻醉唾液；抗凝血剂 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 混乱邪恶 |
| 体型 Size | S（高 ½ 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | II／32 |

Galltrit 是一种身高约半英尺、性情恶劣的有翼小妖精。它呈石灰色，加上体型很小，因此很难被发现；人类和大多数半人类发现它的概率为八分之一，精灵为六分之一。

Galltrit 会出现在有粪便、腐肉或内脏的区域。如果受到打扰（例如被噪音惊动），它会发动攻击：飞到受害者身上，最好是在未被察觉的情况下，咬击造成 1–2 点伤害，并把牙齿锁进受害者的皮肤。如果 Galltrit 在攻击前取得突袭，它的初始攻击获得 +3 命中概率。就空战而言，它的机动等级为 B。

Galltrit 的唾液具有麻醉作用，会使咬伤附近的神经和皮肤麻木一整轮；在此期间，Galltrit 每个近战轮吸取 1 点生命值的血液。每四个近战轮，唾液中的抗凝血剂会使受害者的体质降低 1 点；降低持续的天数等于已经吸取的生命值点数。例如，经过 10 个近战轮，Galltrit 吸取了 10 点血，受害者失去 2 点体质，而这 2 点体质会在 10 天后恢复。

即使没有被发现，Galltrit 也很少会与受害者保持接触超过一整轮；一旦自己的存在被察觉，它会试图逃走。注意，如果这种生物在初始攻击时未被发现，那么由于麻醉作用，受害者之后也不会注意到它；受害者过一段时间会察觉自己正在失血，并感到体质逐渐衰弱，但只有到足够清醒、能够考虑寻找攻击原因时，才会意识到攻击的来源。

如果受害者暂时失去 3 点体质，他就会倒下；此时 Galltrit 几乎必定会暴露。倒下后，受害者需要两个完整回合才能恢复，并需要 12 天才能恢复失去的体质。
