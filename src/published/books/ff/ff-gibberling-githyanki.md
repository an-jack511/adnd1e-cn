Gibberling 是面色苍白、弯腰驼背、四肢短小而手臂很长的裸体类人生物，通常出现在荒凉森林或地下黑暗洞穴中。地下型 Gibberling 厌恶明亮的光，尤其害怕火焰。

Gibberling 会以庞大数量发动攻击，发出令人毛骨悚然的嚎叫和疯狂的喋喋声；这会使即使最勇敢的雇佣兵每轮都必须检定士气，不过不会影响玩家角色。它们用普通剑等武器攻击；使用这些武器的技巧很高，因此获得 +1 命中概率。无论任何情形，它们都会战斗至死，依靠数量优势击败敌人——也就是说，几乎任何敢于进入它们领地的生物，因为 Gibberling 极具攻击性。

虽然它们显然有一种用于彼此交流的原始方式，却没有能被辨认出的语言。奇怪的是，按理说会以如此庞大数量攻击的生物应当有首领来控制它们并决定策略，但至今没有遇到过这种首领类型。似乎也没有战士职业以外的 Gibberling。

## Githyanki

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1–4 |
| 护甲等级 Armour Class | 可变 |
| 移动 Move | 依速度而定 |
| 生命骰 Hit Dice | 可变（上限 11） |
| 巢穴概率 % in Lair | 40% |
| 宝藏类型 Treasure Type | 个体：N；巢穴：A、Z（×2） |
| 攻击次数 No. of Attacks | 可变（如人类） |
| 每次伤害 Damage/Attack | 依武器类型而定 |
| 特殊攻击 Special Attacks | 无 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 非凡或天才 |
| 阵营 Alignment | 可变，但总是邪恶 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 250–250 |
| 攻击／防御模式 Attack/Defence Modes | All／all，但有例外 |
| 等级／经验值 Level/X.P. Value | IV 级及以上／可变 |

数千年前，夺心魔（见《高级龙与地下城怪物图鉴》中的“夺心魔”）征服了一个邪恶人类种族，使其为自己服务，通常把他们当作奴隶，但有时会挑选特别优质的受害者作为食物。人类怀恨了几个世纪，却无法积聚足够力量摆脱夺心魔的控制。后来，他们秘密地逐渐发展力量与能力。在最高领袖 Gith 的领导下，他们反抗奴役者；经过漫长而残酷的斗争，他们终于取得自治。从那一刻起，这个种族被称为 Githyanki，并迅速以强大的灵能者和凭本能战斗的致命战士闻名。

如今 Githyanki 居住在星界位面，不过有时会把自己投射到物质主位面（如今全种族成员都拥有这种天赋能力），并在地下建立临时避难所，以此为基地袭击人类和夺心魔。（如果 Githyanki 同时遇到人类和夺心魔，它们会先消灭夺心魔，可能看起来像在与人类合作；但夺心魔一死，Githyanki 就会转而攻击人类，并试图将其消灭。）

Githyanki 崇拜一位巫妖女王，据说她拥有相当于 24 级甚至更高等级魔法使用者的力量。

Githyanki 可以作为战士、魔法使用者或战士／魔法使用者发展；没有游侠、僧侣、德鲁伊或刺客职业，幻术师也很少见（5%）；它们还有一种反圣武士职业，即骑士。它们从未发展到 11 级以上，很少超过 9 级；据推测，巫妖女王会消灭任何强大到足以挑战她至高地位的 Githyanki。

Githyanki 住在星界位面的巨大城堡中，每座城堡由一名最高领袖统治；最高领袖是 10／8 级或 11／9 级的战士／魔法使用者。最高领袖对统治范围内的所有人拥有生杀大权。每座城堡还会有 40 名骑士（9 级反圣武士），作为最高领袖的精锐支援部队和私人卫队；城堡中最多还会有 1,000 名较低阶的 Githyanki。

它们像人类一样使用盔甲和武器，不过设计的华丽程度通常很有辨识度。进行战争远征时，它们穿着 +4 甲片甲（AC 0），但不携带盾牌。5 级及以上的战士和战士／魔法使用者通常（50%）携带 +1 加值的双手剑，否则使用普通双手剑。7 级及以上的 Githyanki 战士通常（60%）携带 +2 或 +3 长剑；7 级及以上的骑士必定（100%）拥有一把银剑——一把 +3 双手剑，在星界使用时，每个近战轮有 20% 的概率切断银色灵魂线（对有心灵屏障的受害者无效）。最高领袖会使用一把特殊银剑，+5、完全锋锐，并且能够影响有心灵屏障的受害者。

银剑没有阵营，但智力为 8 或更高，并拥有相应能力。Githyanki 会不惜一切代价防止这些银剑落入人类手中；一把特殊银剑遗失后，会立即组织一支极其强大的 Githyanki 袭击队，任务是找回银剑；任务失败也不会减轻行动。

离开物质主位面巢穴后，Githyanki 很少以超过 4 人的队伍出现。典型队伍包括：三种职业各一名 1–3 级学徒、一个 4–6 级战士，以及一名 7／6 级战士／魔法使用者首领。很少情况下（10%），遇到的 Githyanki 队伍会执行特殊任务；此时只有一名学徒，队伍由一名 8 级骑士率领。

如果发现巢穴，其中会有 21–30 名 Githyanki，通常分配如下：

- 1 名最高领袖：11 级战士／9 级魔法使用者。
- 2 名队长：8 级战士，以及 7／6 级战士／魔法使用者。
- 1 名骑士：8 级反圣武士。
- 2 名术士：4–7 级魔法使用者。
- 3 名军士：4–7 级战士。
- 2 名“gish”：4／4 级战士／魔法使用者。
- 10–19 名低阶成员：在三种可能职业之间平均分配，经验等级为 1–3 级。

Githyanki 队伍中超过 4 人的情况非常罕见（概率 5%）。这类队伍执行的是特别明确的任务（但不会是寻找遗失的银剑——那项活动会促成一支更大、更强的队伍），并且比普通队伍更强；预计有 5–10 名成员，由巢穴的最高领袖带队，并由一名队长、一名骑士和 2–7 名“低阶成员”支援，成员在这些类别间平均分配。无论在巢穴中还是在大型队伍里，都有 5% 的概率用一名 6 级幻术师替代一名低阶成员。

除剑以外，Githyanki 拥有魔法物品的概率与人类相同。

一处位于物质主位面的巢穴会有 5–10 件魔法物品，选择这些物品时会特别考虑任务的适用性。在小型 Githyanki 队伍中，通常（75%）会有一件魔法物品；大型队伍会有 1–10 件。

Githyanki 与一群红龙（见《高级龙与地下城怪物图鉴》“龙，红龙”）订有契约；作为提供栖身处、食物和宝藏的交换，红龙在 Githyanki 位于物质主位面时充当坐骑协助它们。红龙会按照体型／年龄（亚成龙以上）运送 4–6 名以及按年龄计算的 1–5 名 Githyanki；因此，一条小型青年龙可以运送 5 名 Githyanki（体型计 4 名，年龄计 1 名），一条平均体型的老年龙可以运送 8 名（体型计 5 名，年龄计 3 名），一条巨型远古龙可以运送 11 名（体型计 6 名，年龄计 5 名）。这些红龙只会在 Githyanki 位于物质主位面时服从它们。

Githyanki 在星界位面的移动速度为 96"。
