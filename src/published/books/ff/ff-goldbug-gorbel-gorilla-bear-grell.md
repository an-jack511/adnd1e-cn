Goldbug 是一种甲虫，身体扁平而呈圆形，外壳金色，大小和形状都像一枚金币。它是一种行动非常迟缓的生物，大多数时间都在睡觉，经常选择一堆金币作为床铺。只有非常仔细的检查才能把它与自己躺卧的金币区别开来。因此，尽管它自己没有宝藏，却占据着其他生物的宝藏。

受到惊扰时，它会像大型蜘蛛一样施放带毒的啮咬，使受害者受到 1–4 点生命值伤害；受害者还必须通过对抗毒素的豁免，否则死亡。

一种奇异的生物。Gorbel 看起来像一个由薄而有弹性的材料制成的红色球体，直径约 3 英尺（其高护甲等级来自很高的敏捷），有一张小嘴，六只小眼睛平均分布在上半球的短小可收缩眼柄上，还有两条带爪的腿；它用腿以惊人的速度移动。

Gorbel 发动攻击时（这通常是它的做法），会试图用爪子附着在受害者的背上；初次命中意味着它已经附着，并造成 1–4 点生命值伤害。此后，在它死亡之前都无法将它取下；它每轮自动命中受害者，造成 1–6 点抓挠伤害。最初，它按 2 生命骰生物的方式攻击。

钝器的命中不会伤害 Gorbel，但尖锐或刃器的命中会使它爆裂，将它杀死，并对 5 英尺内的任何人造成 1–4 点爆炸伤害。

Gorbel 附着在受害者身上时，会自然失去敏捷加值，此时其护甲等级为 10。

Gorbel 是顽皮、反复无常且易怒的生物。

这些怪物拥有大猩猩的头、身体和腿，以及熊的尖牙和有力手臂。它们具有灰熊的好斗性格和穴居熊的肉食倾向。它们的听觉、嗅觉和视觉都非常优秀，因此很少（15%）被突袭。它们的敏捷也很高，这解释了它们得到改善的护甲等级。

这种野兽用两只手掌攻击，每掌造成 1–8 点伤害；如果手掌以 18 或更高的命中骰命中，则表示野兽还会擒抱，额外造成 2–12 点伤害。如果掷出的 18 不足以命中受害者，只有掷出 19 才会擒抱；如果 19 仍不足，则只有掷出 20 才会擒抱。掷出 20 意味着无论受害者的护甲等级如何都会擒抱。

Gorilla Bear 不具备普通熊在生命值降至零以下后仍能继续战斗的能力。

## Grell

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 4 |
| 移动 Move | 12" |
| 生命骰 Hit Dice | 5 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 11 |
| 每次伤害 Damage/Attack | 10×1–4／1–6 |
| 特殊攻击 Special Attacks | 麻痹 |
| 特殊防御 Special Defences | 免疫闪电 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 中立邪恶 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | VI／840 + 每点生命值 5 |

这种可怕生物的外形确实令人恐惧——身体像一个直径约 5 英尺的巨大裸露大脑，正面有一张喙，下面拖着十条 6 英尺长的触手。野兽通过悬浮过程“飞行”，触手的轻微偏转控制水平方向的移动。它的机动等级为 D。

Grell 通常在地下发现，但偶尔也会出现在废弃／荒废的建筑中。它们特别危险且凶残，只要环境允许，就会从上方落到受害者身上。

十条触手会全部用于对付单一受害者。每条触手造成 1–4 点生命值伤害，并带有能向受害者注入毒液的小刺；除非受害者以 +4 加值通过对抗麻痹的豁免，否则会被麻痹。如果有一条触手成功使受害者麻痹，之后每个近战轮中，两条触手会继续锚定在受害者身体上，Grell 用另外八条触手抽打，每条造成 1–4 点生命值伤害，并用喙撕裂，造成 1–6 点生命值伤害。初次造成麻痹后，这些攻击都不需要“命中”检定——Grell 一旦抓住受害者，能活着逃脱已属幸运。

任何对触手的命中都会使其停止工作（但如果生物存活，触手会在 1–2 天内再生），不过伤害不会从生物的生命值中扣除；只有命中身体才能像通常那样伤害 Grell。身体和触手的护甲等级都为 4。

Grell 免疫闪电，但除此之外，对普通攻击和魔法攻击具有标准抗性。

Grell 的身体呈暗淡的橄榄色，并带有白色条纹；触手呈淡橄榄绿色。
