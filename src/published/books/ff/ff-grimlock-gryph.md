## Grimlock

| 巢穴概率 % in Lair | 50% |

| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–6 或依武器类型而定 |
| 特殊攻击 Special Attacks | 无 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 按 6 级战士进行豁免（另见下文） |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 中立邪恶 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 战士：II／28 + 每点生命值 2；首领：II／50 + 每点生命值 3；冠军：III／85 + 每点生命值 4 |

这些凶猛的地下类人生物居住在深邃洞穴中，只在深夜成群结队地出来袭扰地表，寻找人类加以屠杀和吞食。它们的眼睛空洞而失明；然而它们的听觉和嗅觉高度发达，使它们能在 20 英尺内有效“看见”。

它们免疫影响视觉神经的法术效果，例如幻象术、黑暗术、隐形术、镜像术等。不过，听觉幻术之类的法术会使它们部分“失明”：有效“视野”缩短至 10 英尺，命中概率降低 2。若吸入鼻烟等物质，也会对 Grimlock 产生同样效果。

每遇到 10 名 Grimlock，其中就有一名 3 生命骰、护甲等级 4 的“首领”；每遇到 40 名，还会有一名 4 生命骰、护甲等级 3 的“冠军”。在 Grimlock 巢穴中会有雌性（数量为雄性的额外 80%，每只 1 生命骰、护甲等级 6）和幼体（数量为雄性的额外 100%，每只 1 点生命值、护甲等级 8，不参与战斗）。

Grimlock 很少与其他生物结伴，不过有少量机会（10%）允许 Medusa 与它们共用巢穴；游荡的 Grimlock 群体还有 2% 的机会由 1–2 名夺心魔陪同。正因为后者，Githyanki 特别憎恨 Grimlock。

Grimlock 喜欢带刃的放血武器。虽然它们可以徒手战斗（造成 1–6 点伤害），但通常会装备武器（概率 90%），分配如下：

| 武器 | 概率 |
| --- | ---: |
| 手斧 | 20% |
| 战斧 | 15% |
| 双手剑 | 15% |
| 巨剑 | 15% |
| 宽刃剑 | 15% |
| 长剑 | 20% |

首领和冠军会使用战斧或双手剑。

如果在岩石地形中遇到 Grimlock，它们能够与周围环境融为一体；只要保持静止，除非有人真的撞上它们，否则除了使用侦测隐形术外无法发现它们。

所有 Grimlock——无论是战士、首领还是冠军——都按 6 级战士进行所有豁免。

<strong>描述：</strong>体格强壮的类人生物，皮肤厚实、带鳞且呈灰色；通常穿着深色破布。头发又长又黑，通常蓬乱不整。它们的牙齿洁白而格外锋利。

## Gryph

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1–6 |
| 护甲等级 Armour Class | 6 |
| 移动 Move | 21" |
| 生命骰 Hit Dice | 2–4 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 2–12 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 动物 |
| 阵营 Alignment | 中立邪恶 |
| 体型 Size | S |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 2 生命骰：II／28 + 每点生命值 2；3 生命骰：II／50 + 每点生命值 3；4 生命骰：III／85 + 每点生命值 4 |

Gryph 是一种有多条腿的鸟——通常有四条，但也见过六条甚至八条的个体。它的大小大致只有鹰那么大，有一张带锋利锯齿、颚部有力的喙。它的啄击造成 2–12 点生命值伤害；它通常会从地下洞穴高处的阴影中高速发动攻击。就空战而言，它的机动等级为 B。

如果遇到 3 只或更多这种鸟，其中一只会是雌性，并且有 35% 的概率已经准备下蛋。如果这样的雌性 Gryph 发动攻击，它会试图用腿擒抱受害者；如果命中，就会把小卵注入受害者的血流。注意，在这种情况下不会使用喙进行攻击，受害者也不会受到伤害——卵是通过从鸟腹部伸出的细管注入的。

如果这些卵保持存活，它们会在 1–3 天内孵化，立即杀死受害者，并释放 1–4 只幼 Gryph。在此期间，受害者会感到轻微不适，腹部出现肿胀；临近孵化前，不适会增强到令人痛苦的程度。事实上，受害者体内远不止 1–4 枚卵——只是只有这个数量能存活过 1–3 天的时期。

从卵被注入到孵化之间，对受害者施放治愈疾病术或驱散邪恶术会杀死卵。当然，如果使用得当，祈愿术或类似法术也会产生这一效果。
