Hellcat 是魔鬼的同伴和 Familiar，因此通常能在它们位于地狱的本土层面找到。它们偶尔会前往物质主位面，通过成为强大守序邪恶角色的仆从来为地狱的目的服务。

Hellcat 在任何光源存在时都处于隐形状态，但在黑暗中可以看见一道微微发光的幽灵般轮廓，双眼燃烧着深红色火焰；其形态像一只老虎大小的家猫。

它只能被魔法武器伤害，而且即使如此，魔法伤害加值也不适用（例如，一把 +2 匕首命中它时造成的伤害是 1–4 点，而不是 3–6 点）。它基础上拥有 20% 魔法抗性，并且完全免疫所有控制心灵的法术效果（例如魅惑、定身、睡眠、建议术等）。

如果遇到的 Hellcat 尚未依附于某个角色或生物，它会选择队伍中拥有守序邪恶阵营的最强成员并侍奉他。如果有两名或更多同阵营成员的经验等级同样高，Hellcat 会优先选择牧师，然后是魔法使用者或幻术师，再然后是战士，最后才是其他职业。一旦选定主人，Hellcat 会协助此人实施邪恶行为，保护并防卫此人，并且只通过心灵感应与他交流，心灵感应范围为 9"。它只会侍奉具有智慧的守序邪恶生物。

Hellcat 与主人的联系有两种方式可以解除。第一，当遇到一名更强大的守序邪恶新主人时，Hellcat 总会放弃当前主人而选择新主人，前提是这名潜在的新主人愿意接受它；否则，Hellcat 与现有主人的联系保持不变。如果生物选择了新主人并被其接纳，那么在命令下，它毫不犹豫地攻击前任主人。因此，一个角色可能从某个怪物那里“偷走”一只 Hellcat，然后又被另一个角色反过来“偷走”。

第二，Hellcat 作为主人的仆从只能在物质主位面停留一年零一天；之后必须返回地狱的家乡。它后来可以再次返回，但与前任主人的联系不会自动恢复。如果主人再次遇到它，可以用之前相同的方式取得它的服务。

Hellcat 为换取服务提出的唯一要求，是每周支付一名活人作为它的食物。主人必须提供受害者——如果主人没有提供，他本人就会承担这个角色。

Hellcat 用两只爪子攻击，每只造成 2–5 点生命值伤害，并用啃咬攻击，造成 2–12 点生命值伤害。

如果队伍遇到一只已经侍奉某人或某生物的 Hellcat，它可能按上述方式转换效忠，也可能继续侍奉现有主人。

如果一支队伍遇到 Hellcat，而队伍中没有任何成员属于守序邪恶阵营，则有两种可能。如果队伍包含一个或多个邪恶倾向的人或生物（即中立邪恶或混乱邪恶），Hellcat 会逃跑；但如果队伍完全不包含任何邪恶阵营的人或生物，无论组合如何，Hellcat 都会攻击。

## Hoar Fox

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 1–6 |
| 护甲等级 Armour Class | 6 |
| 移动 Move | 15" |

| 巢穴概率 % in Lair | 20% |
| 宝藏类型 Treasure Type | 见下文 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–6 |
| 特殊攻击 Special Attacks | 吐息武器 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |

| 等级／经验值 Level/X.P. Value | II／28 + 每点生命值 2 |

Hoar Fox 栖息在寒冷地区，通常以小群出现，除非受到威胁，否则很少（10% 概率）主动攻击。然而，它们银灰色、漂亮的皮毛非常有价值——一只未受损的完整标本在公开市场上能卖 100 金币——因此经常受到冒险者的威胁。

它们攻击时会用牙齿咬，造成 1–6 点生命值伤害，但主要武器是吐息武器：一道射程 30 英尺、宽度刚好能覆盖一名受害者的寒冷锥。寒冷造成 2–12 点生命值伤害（豁免成功则伤害减半）。在吐息攻击中，受害者的护甲等级按 10 计算（但允许使用敏捷调整值）。

Hoar Fox 免疫寒冷类攻击，但会从火焰中受到双倍伤害（而且火焰当然会使皮毛失去价值）。
