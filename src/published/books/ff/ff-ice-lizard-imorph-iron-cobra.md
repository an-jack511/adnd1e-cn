Ice Lizard 看起来像一只小型（长 3 英尺）的有翼蜥蜴，不过它每天可以两次使用自我变形术，每次持续两小时，变成白龙形态（见《高级龙与地下城怪物图鉴》“龙，白龙”）。它还可以每天各施放两次睡眠术和恐惧术。

虽然对大多数魔法形式具有很高抗性，但它对魅惑术和定身术相当脆弱（针对两者的豁免均为 −2）。

它可以像白龙一样使用寒冷吐息武器，每天最多三次，造成 2–16 点生命值伤害。除此之外，它用两只爪攻击，每只造成 1–3 点生命值伤害，并用啃咬攻击，造成 1–6 点生命值伤害。

Ice Lizard 生活在地下寒冷地区，天然形态呈暗银色。在天然形态下，它的机动等级为 C；变成龙形后，机动等级变为 E。

## Imorph

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见（至多如此） |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 5（见下文） |
| 移动 Move | 6"（见下文） |
| 生命骰 Hit Dice | 5（见下文） |
| 巢穴概率 % in Lair | 10% |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 2 |
| 每次伤害 Damage/Attack | 1–4／1–4 |
| 特殊攻击 Special Attacks | 无 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 动物 |
| 阵营 Alignment | 中立 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／130 + 每点生命值 5 |

这种野兽的自然形态是一个灰绿色、凹凸不平的圆柱体，高约 4 英尺，平均直径 2 英尺。主体后面拖着一条短腿，脚部有像蜗牛一样的吸盘。主体下方还有其他类似吸盘，使野兽能够以颠簸的方式移动。身体顶端伸出两条长 5 英尺的触手，但看不出眼睛、耳朵或其他特征——实际上，整个生物都是一种颜色类似胆汁色人类皮肤、不断变化的橡胶状面团物质。

除非受到威胁，否则这种生物通常不会攻击；但攻击时会用触手抽打，每条造成 1–4 点生命值伤害。

进入近战后，这种生物展现出惊人的拟态能力。从每个近战轮开始时（第一轮除外），它会分别将自己的生命骰和护甲等级向对手的数值改变 1 点，同时逐渐改变形状以模仿对手。当生命骰和护甲等级（以及由此产生的外形）与对手相同时，生物会立即改变自己的攻击和移动方式，以适应目标。

注意，Imorph 只采用对手的物理外观；虽然它会长出各种附肢来模仿对手的武器和肢体，但它每轮仍会以两条触手的等效方式发动攻击，每条造成 1–4 点伤害（即使一条触手看起来像握剑的手臂，另一条看起来像持盾的手臂）。即使生命骰数值改变，Imorph 的生命值也保持不变。不过，生物会改变自己的命中概率，使其符合新的生命骰数值。

当 Imorph 的形状、生命骰和护甲等级都与对手完全相同时，它会改用适合该形态的攻击矩阵来决定命中概率，例如与人类战士战斗时使用战士表。它会继续使用那张表进行攻击，直到再次开始向原始形态改变。

近战结束，或 Imorph 的生命值降至 8 点或更低时，它会通过反向过程恢复原始形态，每个近战轮将护甲等级和生命骰改变 1 点。

如果同时面对多名攻击者，Imorph 会随机选择一名作为攻击和模仿对象。如果原本的“模型”在近战中死亡或撤退，Imorph 会立即开始改变，以模仿另一名对手。

这种生物体内有一个对应人类肝脏的小器官，由橡胶状绿色物质构成。器官内是同色的液体；将其与等量的水混合后，可制成一瓶自我变形术药剂。单个 Imorph 中的液体足以制作 1–3 剂这种药剂；正因如此，冒险者会攻击 Imorph。

| 每次伤害 Damage/Attack | 1–3 |
| 特殊攻击 Special Attacks | 毒素 |
| 特殊防御 Special Defences | 见下文 |

Iron Cobra 是某位伟大魔法使用者或小神祇的发明。这种分节的自动机由未知金属制成，形状仿照蛇。据认为，全世界只有十几只这种生物；它们非常有价值（高等级魔法使用者认为，在停用且控制词已知的情况下，一只的价值为 2,000 金币）。

眼镜蛇由创造者设定的关键词启动和停用；启动后，它能服从简单的口头命令。静止时它绝对无声；移动时通常发出轻柔的沙沙声，与普通蛇发出的声音并无不同。

它没有心智，因此不受影响心灵的法术影响（例如睡眠术或魅惑术），也不受蛛网术影响。非魔法武器对它只造成一半伤害。它拥有 8 级盗贼的隐藏于阴影能力（此时红外视觉也无法发现它，因为它不发出体热），还能够从背后发动突袭；必要时，它能在短时间内完全无声地移动。

它的咬击带有致命毒素（同时造成 1–3 点生命值伤害），受害者必须以 −2 惩罚进行豁免。不过，毒牙的容量有限；三次毒性咬击后，毒液供应耗尽，毒牙只造成 1–3 点生命值伤害。（当然，如果蛇的控制者就在附近，便可在有机会时重新为毒牙装填毒液。）

面对魔法攻击时，除上述已提及的法术外，Iron Cobra 按 12 级魔法使用者进行豁免。

Iron Cobra 可以被安排守护宝藏，或充当护卫。也可以命令它追踪并消灭任何已知姓名的人，只要该人在一英里以内。在后一种情况下，生物通过追踪目标的心灵振动来锁定猎物（如果受害者意识到 Cobra 正在追踪自己，可以使用心灵空白术或类似法术阻断这些振动）。

据说有些 Iron Cobra 的毒牙中装的是致使麻痹、诱发睡眠的药物，而不是毒素；面对这类毒牙，受害者必须进行一次普通豁免。
