Jaculi（单数和复数形式相同）是敏捷的蛇，拥有类似变色龙的伪装能力。它们通常出现在树林和森林中，因为其本质上是树栖生物，以树上的苔藓和昆虫为食；不过，有些群体已经将栖息地适应为有柱大厅之类的地方。Jaculi 群体虽然天生并不凶残，却具有很强的领地意识和容易激动的性格，会反感任何超过短暂进入、侵入它们认定领地的行为。由于它们的伪装能力，即使在清楚可见时也只有四分之一的机会被发现，因此在攻击前被看见的可能性很小。

这种蛇有一条长而强壮的身体，以及宽阔、扁平的头部；头部两侧各伸出一道锋利的骨脊。它能从任何高处以标枪般的力量和准确度将自己射出，在此前未被发现时会令受害者措手不及。因此它的“飞行速度”很高（移动率 61"）；但以这种方式发动攻击后，它不能再从地面发动攻击，必须爬上另一棵树或柱子后才能再次攻击。

## Jermlaine（Jinxkins）

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 不常见 |
| 出现数量 No. Appearing | 12–48 |
| 护甲等级 Armour Class | 7 |
| 移动 Move | 15"（具有天才级的狡猾） |
| 生命骰 Hit Dice | 1–4 点生命值 |
| 巢穴概率 % in Lair | 特殊 |
| 宝藏类型 Treasure Type | 每 10 名个体：O、Q；巢穴中：C、Q（×5）、S、T |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–2 或 1–4 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 见下文 |
| 智力 Intelligence | 平均（具有天才级狡猾） |
| 阵营 Alignment | 中立邪恶（带有轻微守序倾向） |
| 体型 Size | S（高 1 英尺以上） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 普通：I／7 + 每点生命值 1；年长者：II／32 + 每点生命值 1 |

Jermlaine，或称 Jinxkins，有时也称 Bane-midge，居住在地下精心修建的隧道和巢穴网络中——通常深在地表之下。它们与各种老鼠（甚至巨型老鼠）自由混居，因此经常（75%）与这类啮齿动物一同发现；并且有 50% 的概率与它们共享一套整合的洞穴、隧道和孔道系统。（如果遇到 Jermlaine，掷百分骰得到 01–75 表示有老鼠（25%）或巨型老鼠（50%）与它们在一起；如果 Jermlaine 在巢穴中，则有 50% 的概率存在相连的鼠道。）这种共同居住延伸到各种形式的相互合作与防御。

这些邪恶的小矮子很懦弱，只有在看起来可以压倒受害者而无需面对严重点的反抗时才会攻击。因此，Jinxkins 会伏击已经虚弱或受伤的队伍，或粗心、睡眠中的单独个体。强大的队伍或保持警觉的冒险者不会遭到身体上的攻击，但 Jermlaine 群体一定会试图伤害他们，以纯粹的恶意加以折磨。这种对冒险者的伤害既会给 Jermlaine 带来个人收益，也可能最终带来新的受害者。

Jermlaine 移动极快，步态急促而轻盈，非常安静，是保持不被看见的大师。不过，偶尔如果某支队伍或某个个体突然停下并仔细聆听，就可能听到它们的移动声，或叽叽喳喳、吱吱叫的语言。

任何时候遇到 Bane-midge 时，它们有 60% 的概率位于巢穴 60 英尺以内；但通向这些地点的隧道是曲折的迷宫，任何比侏儒更大的生物都无法通过——即便是侏儒也必须匍匐爬行，而入侵者当然会因此暴露在攻击之下。

Jermlaine 通常装备针尖般锋利的飞镖，可以投掷到 12" 远并造成 1–2 点生命值伤害。除飞镖外，每个小矮子还携带一件长 1½ 英尺的矛状武器：一根柔韧木制短棒，顶端有锋利金属尖头。它可作为矛或长矛使用，造成 1–4 点生命值伤害。不过，它们偏好的攻击方法是用坑或网伏击，从而活捉受害者。

在很少使用的通道中，这些肮脏的生物会费力地挖掘坑洞，并用伪装的活板门覆盖；或者用巨型蜘蛛蛛网中的丝线编织高悬的网，等待经过的猎物。在更常使用的道路上，Jermlaine 会拉起细却结实的绳索（通常用人发编成）绊倒粗心的人。没有被陷阱击昏的受害者会被挥舞皮革棍棒的 Bane-midge 打得失去意识，棍棒中填有沙子或铅丸；其他 Jermlaine 则用绳索和绳带缠住倒地的生物。注意，用棍棒殴打时，每一击都有 2% 的累积概率使受害者失去意识，但穿着鳞甲、带甲或板甲的人不会遭受这种攻击。无法被牢牢捆住的重甲受害者会遭到杀戮，可能使用燃油投射物或酸液。某些受害者会被 Jermlaine（或它们的老鼠伙伴）吃掉，但大多数人类会被剥光、剃发，然后被捆住，毫无反抗地留在通道中。Jermlaine 通常会从安全的藏身处观察这些受害者，等待某个经过的怪物把被捆住的人吃掉，以此取乐。

如果警觉的生物碰巧在一群藏起来的 Jermlaine 附近停留，这些恶毒的东西会偷偷出来割断腰带和带子，割开背包和接缝——通常每个 Jinxkin 进行一次这样的破坏行为，因为它们行动迅速，以便不被发现且不受伤害地逃走。它们的破坏通常要到 1–12 轮之后才会被发现，例如脆弱的带子断裂或接缝完全裂开等。更糟的是，如果背包或其他物品放在 Jinxkin 能够触及的地方，这些凶恶的小害虫会污染水，令酒变酸并变成醋，弄坏食物，亵渎圣水，偷走小物件（宝石、硬币、蒜瓣、药草等），卡住匕首或剑使其难以迅速拔出，割断弓弦，使箭变钝，刺破油壶，等等。

如果遇到超过 35 只这种生物，其中会有一只非常年老且格外邪恶的个体，拥有一种非常邪恶的力量：这只 Bane-midge 能够在 1–4 轮内吸走它能够拿持的任何魔法物品的全部魔法性质（神器或圣物除外）。

Jermlaine 灰褐色、布满疣的皮肤能够与泥土和岩石融为一体；它们总是穿着同色的碎布和破布，以便继续隐藏。再加上安静移动的能力，Jinxkins 很可能在掷出 1–5（d6）时突袭对手；如果进行寻找或聆听，它们有 75% 的概率无法被发现，除非动作突然发生、令它们措手不及。

就魔法攻击和豁免的效果而言，Jermlaine 按 4 生命骰生物对待。由于体型和敏捷，如果 Jinxkin 对通常会造成一半伤害的攻击成功豁免，它会毫发无伤地躲过攻击。

虽然它们的眼睛很弱，红外视觉范围也只有 30"，但 Jermlaine 拥有敏锐的听觉和嗅觉，因此在普通地下城环境中，即使是隐形生物也有 50% 的概率被它们发现。

Jermlaine 会说自己的语言和阵营语言，并且能与各种老鼠交谈。每 10 只中有 1 只能说通用语；同样的概率适用于矮人语、侏儒语、地精语和兽人语。

<strong>描述：</strong>Jinxkins 看起来像身穿宽松衣物、戴着不合头盔的小型人类。仔细观察会发现，那些宽松的“衣物”其实是它们凹凸不平、层层折叠的皮肤，而“头盔”其实是它们尖利、面目邪恶的头部——全部皮革般而光滑。这些生物的四肢结节状且弯曲，手脚末端长着厚实的指甲；指甲总是肮脏，却很灵活。
