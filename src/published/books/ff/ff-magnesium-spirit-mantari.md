## 镁光精魂 · Magnesium Spirit

| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 0 |
| 移动 | 36" |
| 生命骰 | 6+1 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 3–12 |
| 特殊攻击 | 能量和力量吸取，见下文 |
| 特殊防御 | 只能被银质和魔法武器命中；另见下文 |
| 魔法抗性 | 50%，另见下文 |
| 智力 | 极高 |

| 等级／经验值 | VII／1,300 + 每点生命值 8 |

据认为，这种生物只有三四只；它们最初是由一名高等级邪恶魔法师召唤到物质主位面，因召唤造成的压力而使召唤者死亡，并被困在此处。它们真正来自哪个位面尚无定论。它们的行为完全受一种需求支配：必须占据一名 5 级或更高等级角色的身体，才能完成复杂的施法仪式，返回自己的来源地。只有人类身体能提供它们所需的心灵参照框架，因此它们只攻击人类。

镁光精魂的外形像一根白色火焰圆柱，高 5 英尺、直径 3 英尺，拖着一条长 5 英尺的飘带状尾巴。不过它们不会放出任何可察觉的热量。

Spirit 以惊人的速度接近一支包含人类的队伍，迅速抵达所选受害者 10" 内的位置（从在场人类中随机选择），然后停下，以瞬间的白光爆发形成使人失明的闪光。所有在 20" 内观察 Spirit 的生物（包括非人类）都必须通过对石化豁免，才能避免失明 12 轮（两个完整小时）。将此效果视为幻术师的失明术。

然后 Spirit 发动攻击，每轮自动取得先攻，即使对手处于加速状态也是如此。如果命中，它会从受害者身上吸取一个生命能级和 2 点力量（后者每小时恢复 1 点，生命能级吸取则永久），并造成 3–12 点生命值伤害。一旦命中，它就锁定在受害者身体上，并逐渐与身体融合；融合过程中持续吸取能量和力量，每轮造成 3–12 点伤害。

融合两轮后，唯一能在不伤害受害者的情况下命中 Spirit 的方式是使用圣水；每瓶圣水会对 Spirit 造成 2–7 点伤害，并迫使它放弃融合过程（尽管下一轮它可能再次攻击同一名受害者，或改为攻击另一名人类受害者）。在融合过程中，Spirit 自动造成伤害，不需要命中检定。

如果 Spirit 在没有被迫放弃受害者的情况下完成三轮融合（即前两轮会受到普通攻击，第三轮只会受到圣水攻击），它就会接管受害者的身体，人类人格被抹除。如果受害者此时仍有五个或更多能量等级（由于初次攻击失去一个，三轮融合过程失去三个，因此受害者在受袭前至少必须是 9 级），Spirit 会利用身体发出自己的法术；施法需要 5 个时间单位，随后身体和 Spirit 会在闪光中消失。Spirit 已回到来源位面，永远不会返回。

如果受害者剩余能量等级少于五个（即在 Spirit 初次攻击前最多为 8 级），Spirit 会放弃身体并寻找另一个身体；如果附近有其他人类，它会转向另一名人类，并在其身上重新开始攻击过程。第一名受害者的身体此时已成为无心的躯壳，会倒下，并抵抗一切复活尝试（不过，如果使用得当，祈愿术等强力法术能够使受害者复生）。

镁光精魂只能被银质或魔法武器伤害。它拥有 50% 魔法抗性，并免疫睡眠、魅惑、定身、麻痹和恐惧法术。在融合过程中或其他任何时候，它都容易受到圣水影响；每瓶泼到它身上的圣水造成 2–7 点伤害。

## 曼塔里 · Mantari

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1–3 |
| 护甲等级 | 9 |
| 移动 | 18" |
| 生命骰 | 1+1 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 特殊，见下文 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立邪恶 |
| 体型 | S |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | III／65 + 每点生命值 2 |

这种飞行生物很像鳐鱼，身体扁平，长约 3 英尺（宽度几乎相同），拖着一条细长、鞭状的尾巴，长 4 英尺。曼塔里（单数和复数相同）通常以巨型老鼠之类为食，但遇到其他生物和人类时通常（85%）具有攻击性。它飞行时尾巴竖直向下；但攻击时——从离地 10 英尺至 12" 的高度俯冲向受害者——尾巴会与身体形成一个向前的锐角。

它唯一的攻击方式是用尾巴鞭打受害者。尾端的刺没有毒，但会作用于受害者的神经系统。一次命中造成的生命值伤害等于 19 减去受害者的体质值（例如，体质 12 的受害者会受到 7 点伤害）。刺的效果不允许豁免。

此外，如果同一名受害者在连续两轮中被命中，第二次命中造成四倍普通伤害。第三次或之后连续命中同一受害者时不再增加伤害加值——每次都按四倍普通伤害计算。

曼塔里可以出现在大多数环境中，不过偏好的藏身处是猎物丰富、肮脏的地下城房间。就空战而言，它的机动等级为 C。
