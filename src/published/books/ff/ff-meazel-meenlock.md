Meazel 是略小于人类体型的独居双足生物，离开巢穴很少遇到；巢穴位于沼泽或地下小型潮湿洞穴中。它们天生拥有 4 级盗贼的能力，很少公开攻击，更喜欢隐藏起来，安静而迅速地从背后勒死掉队者，或为了它们喜爱的金币而偷窃。Meazel 是兽人和狗头人的传统敌人。

Meazel 很少远离巢穴，并会把所有尸体带回那里安全食用。Meazel 巢穴附近经常能发现装满骨头的袋子堆（生物从宝藏中找到的宝石也会放在这些袋子里，因为它不懂贵重和半贵重宝石的价值）。出于同样原因，巢穴里不会有宝石。

大多数地下世界生物都会攻击 Meazel，因为即使在地下城居民中，它们也有恶劣名声。

战斗中它们用两只爪攻击，每只造成 1–4 点生命值伤害。或者，它们会使用一段结实而细的绳索勒死受害者；一次“命中”表示绳索已缠住受害者的脖子，除非受害者挣脱，或 Meazel 死亡、被迫放开绳索（例如为了应对另一方向的攻击），否则受害者会在两个近战轮内因窒息死亡。不过，只有当受害者为人类大小或更小，且 Meazel 能从背后未被发现地接近并取得突袭时，才能执行这种攻击。

<strong>描述：</strong>Meazel 的皮肤从浅灰色到深绿色不等；大多数（85%）个体身上会出现不规则的愤怒红色斑块，这源于一种皮肤疾病。该病除了毁容外不会伤害生物，也不具传染性，但在这个种族中很普遍，使 Meazel 几乎像麻风病患者。它们的眼睛漆黑，脚部带有部分蹼。

## Meenlock

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |

| 护甲等级 Armour Class | 7（但见下文） |
| 移动 Move | 9" |

| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 2 |
| 每次伤害 Damage/Attack | 1–4／1–4 |
| 特殊攻击 Special Attacks | 麻痹 |
| 特殊防御 Special Defences | 次元门 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 极高 |
| 阵营 Alignment | 守序邪恶 |
| 体型 Size | S（高 2 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | IV／240 + 每点生命值 4 |

Meenlock 是高约 2 英尺的小型双足生物，身上覆盖黑色蓬乱皮毛。它们的头是白色的，上面有深色脊纹。总的来说，它们外表可怕；任何看到它们且生命骰不超过 4 的人都会恐惧，使受害者僵倒在地 5–8 个近战轮（如果受害者通过豁免，轮数减半）。

Meenlock 的巢穴位于地下黑暗、封闭的竖井中。如果打开封口，看不见竖井底部，任何投入其中的东西都会无声地落在覆盖井壁和井底的厚苔藓“地毯”上。井中一片漆黑，腐尸的气味会向上飘出。即使不使用侦测邪恶术，除了最麻木的人之外，其他角色也会察觉到强烈的邪恶气息。垂直下降约 20 英尺后，竖井会扭曲弯折，因此即使使用光亮术也不可能看见底部；光亮术只能照出上部的细节。

如果勇敢的冒险者进入竖井，最终会在竖井最底部找到 Meenlock 巢穴——一个像小洞穴般的大空间。生物总会攻击（例外：如果能够做到，明亮光线会使它们逃走），并用两只爪攻击，每只造成 1–4 点生命值伤害。Meenlock 的触碰会造成麻痹（允许豁免）。不过，在巢穴等近距离环境中，Meenlock 的心灵感应力量几乎毫无用处——这就是它们故意制造腐尸气味的原因，用来阻止别人进入巢穴。

这些生物会想尽办法熄灭光源——火把、提灯等。它们拥有有限的次元门能力，每隔一个近战轮可以移动 6"；使用这一能力时，针对它们的攻击命中骰 −4。不过，它们不能在携带受害者时使用这一力量——需要三只 Meenlock 才能完成这样的搬运。

如果冒险者打开竖井顶部的封口，却随后没能进入 Meenlock 巢穴，生物就会充分利用这一点。冒险者离开时，邪恶的小生物会保持安全距离跟随；它们能利用苔藓地毯的消音性质，迅速而无声地爬上竖井。其中一名冒险者会被 Meenlock“标记”——随机选择，不过如果队伍中有圣武士，优先选择圣武士——此后 Meenlock 会集中攻击他，因为它们极其邪恶，强烈渴望向人类复仇。若队伍中有人类，受害者总会是人类；否则选择精灵、矮人或其他近人类生物。

从被“标记”开始，被选中的受害者会收到令人不安的心灵感应信息；Meenlock 能在 300" 范围内进行心灵感应。信息内容会变化，但威胁始终相同——Meenlock 正在无情追踪受害者，并打算把他变成同类。受害者还会意识到阴影中的悄然移动，以及沙沙、抓挠声（这些也都是通过心灵感应诱导出的幻觉）。受害者的同伴听不见也发现不了任何东西，可能会认为自己的同伴精神失常。

Meenlock 不会在队伍安营休息前攻击。不过，在此之前，受害者会越来越专注于自己的处境，越来越无法集中精力进行冒险，效率会因此降低；具体程度和效果由地下城主决定。可作为参考：Meenlock 每骚扰一小时，受害者的力量、敏捷、智力和智慧都会暂时各降低 1 点；此外，他在近战中的命中骰 −1，而如果他是施法者，法术豁免会获得 +2 加值。这些效果会累积，但只要 Meenlock 的威胁以某种方式被阻止（例如队伍进入 Meenlock 无法进入的明亮区域），效果就会消失。

当包含受害者的队伍安营休息时，Meenlock 会攻击，移动得非常安静（即使面对警戒中的守卫，也有 80% 的概率取得突袭；面对睡眠者则为 100%）。它们会试图让守卫安静下来并拖走受害者（除非绝对必要，不会用爪攻击受害者，但不会对其他人表现出同样的仁慈）。如果成功，它们会把受害者带到竖井，进入后封闭竖井。经过短暂但可怕的处理，受害者本人就会变成 Meenlock。
