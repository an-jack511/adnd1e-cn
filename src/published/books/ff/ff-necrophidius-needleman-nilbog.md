这种生物看起来像一条巨蛇的骨架，头部是一颗长着獠牙的人类头骨。它完全无声，免疫睡眠、魅惑和影响心灵的法术，免疫毒素，并且永远不需要进行士气检定。它的啃咬造成 1–8 点生命值伤害；除非受害者通过对抗魔法的豁免，否则会被麻痹（这不是毒素）。麻痹持续 1–4 轮。

Necrophidius 有 50% 的概率取得突袭（d6 掷出 1–3）；如果它自己没有被突袭，就会执行“死亡之舞”——一种催眠性的半魔法摇摆，令观察这条虫、却未能通过对抗魔法豁免的受害者注意力完全被吸引。失败意味着无法行动；按催眠术处理。这使虫可以不受阻碍地前进和攻击。

Necrophidius 是为某一个特定目的制造的，因此通常遇到时是在执行暗杀或守卫任务，而不是作为游荡怪物。

制造 Necrophidius 有三种方式。第一种是使用一种类似魔像制造手册的特殊魔法典籍。第二种是由高等级魔法使用者使用有限祈愿术、胁迫术和魅惑人类。第三种是由高等级牧师使用任务术、中和毒素、祈祷术、沉默术和蛇魅术。材料包括一条完整、关节可动的巨蛇骨架（有毒蛇或蟒蛇均可），以及一名在此前 24 小时内被杀死的冷血杀人者的头骨。制造费用为每点生命值 500 金币，需要 10 天建造时间。

尽管有若干相反特征，Necrophidius 并不属于不死生物类别，例如不能被牧师驱散。

这种栖木的智慧植物生命体看起来像僵尸，但实际上既不是动物，也不属于不死生物类别。它的“肉”中嵌满了遍布全身的大量细长尖针，类似松针。每轮它可以“发射”1–6 枚针，每枚对受害者造成 1–2 点伤害，射程和短弓相同，为 20 英尺。实际上，它的针供应是无限的。

这种生物特别容易受到魔法影响。魔法手段对它的攻击造成三倍正常伤害，不过它仍可照常进行豁免。其他非攻击性质的法术（例如魅惑植物）也会对它产生三倍效果，具体情况依此处理。当然，植物的事实也使它免疫某些法术。

Needleman 似乎特别憎恨精灵，会一见到精灵就攻击。

在针叶林或茂密灌木丛中，Needleman 几乎无法被发现（75%），并且有 75% 的概率取得突袭。在这种自然栖息地之外，极少遇到这种生物。

## Nilbog

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见（至多如此） |
| 出现数量 No. Appearing | 4–40 |
| 护甲等级 Armour Class | 6 |
| 移动 Move | 6" |
| 生命骰 Hit Dice | 1–1 |
| 巢穴概率 % in Lair | 40% |
| 宝藏类型 Treasure Type | 个体：K；巢穴：C |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–6 或依武器类型而定 |
| 特殊攻击 Special Attacks | 无 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 守序邪恶 |
| 体型 Size | S（高 4 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／53 + 每点生命值 1 |

这种生物看起来与普通地精完全相同，并拥有该种族的全部特征（见《高级龙与地下城怪物图鉴》“地精”），但有一个重要例外——它患有一种奇异的时空逆转。为什么只有地精容易受到这种奇怪疾病影响，仍然是个谜。Nilbogism（这个疾病的名称）似乎发生于过度使用魔法使时空连续体的结构承受压力之时，并导致一些非常奇怪的局部事件。导致 Nilbogism 的条件组合极其罕见，目前也只得到不完整的理解。虽然生物本身完全不会把疾病传染给周围生物，但某些效果会被传递。

关于 Nilbog 周围发生的时空扰动，人们收到了许多不同的说法。似乎唯一共同因素是：冒险者无法控制自己的行动，并且通常会采取违背正常意图的行动路线。例如，他们可能受到压倒性的强迫，把全部宝藏装入 Nilbog 巢穴中一只空宝箱，再空手离开。对这些效果没有豁免，也没有已知防御（不过，如果使用得当，祈愿术等强力法术很可能能够使当地人获得对效果的免疫）。

Nilbog 力量的另一个奇怪特征，是生物在受到攻击时会获得生命值，增加的数值等于本来要掷出的伤害。它只能通过对其施放治愈伤口法术、强行喂食治疗药水等方式失去生命值。

由于这些原因，遇到这种奇怪生物令人恐惧；因此，普通地精通常会受到极度谨慎的对待，以免它们最终证明是 Nilbog。除了使用诸如通晓语言术之类的法术，或通过试错外，似乎没有办法区分两者。

据目前所知，没有其他生物感染过 Nilbogism。
