## Penanggalan

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 正常形态 10；头部与内脏分离时 8 |
| 移动 Move | 正常女性的移动速度；头部与内脏分离时 12" |
| 生命骰 Hit Dice | 身体：可变；头部与内脏分离时：4 |
| 巢穴概率 % in Lair | 见下文 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 1–6，或按武器类型 |
| 特殊攻击 Special Attacks | 吸血 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 见下文 |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 守序邪恶 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |

这是一种力量可怕、外貌令人作呕的女性吸血鬼型不死生物。白天，这种邪恶生物会以一名有魅力的人类女性形象出现，而且可以属于任何职业。这名女性生前就是 Penanggalan 死亡前的那个人类。她会使用生前相同的战斗能力；如果生前是施法者，她会使用法术；如果生前是盗贼，她会使用盗贼能力，依此类推。她会使用生前偏爱的武器（或至少使用同一武器类型）。她的身体能够承受与死亡前（完全休息时）同样多的伤害，并会以她当时的经验等级进行战斗。不过，头部只能承受 4 个生命骰的伤害；如果头部本身受到攻击，必须另外记录它所承受的生命值。

<strong>例外：</strong>如果 Penanggalan 死亡前是牧师，无论生前属于什么阵营，她在新的形态下都不能使用“善良”法术，必须把法术限制为有害效果的法术。

对这种形态的生物施放侦测阵营术，会揭示 Penanggalan 生前所追随的阵营；然而，作为不死生物，它会按照守序邪恶阵营行事。

在这种形态下，Penanggalan 不受圣徽／邪徽影响，也不能被驱散或解除。和其他不死生物一样，它在任一形态下都免疫所有试图控制心灵或身体的法术。

以这种伪装出现时，Penanggalan 会试图结交任何毫无戒心的旅行者队伍，并尝试加入他们。它会极其有用：经过多年的不死生涯，它已经获得了关于自己如今游荡的地下城的广博知识，能够引导队伍找到宝藏，并警告他们注意可能的危险。当然，它会为这种知识找出某个似是而非的理由，有时还会对自己知道的区域故意犯错或假装无知，以免引起队伍的怀疑（如果新同伴表现得近乎全知，队伍成员自然会开始怀疑）。

加入冒险者队伍后，Penanggalan 会一直与队伍同行，甚至陪他们离开地下城。不过，它绝不会在地下城中与队伍一起露营过夜，也不会陪他们前往上层世界的所谓安全处过夜，而是找个理由离开。

到了夜间，Penanggalan 会显露真正的不死形态。它的头部和内脏会从身体上分离，从腹部垂直升起，飞出去寻找人类猎物，享用他们的活血。因此，它总会在夜幕降临前回到自己的某一个秘密巢穴（单只 Penanggalan 最多可以拥有六个藏在地下城各处的相同巢穴）。它尤其喜爱幼童或孕妇的血；但如果缺少这种受害者，它会选择队伍中看起来最容易受到催眠的人，更偏好女性而不是男性。它总会攻击人类，甚至会无视近似人类的生物。

任何不幸目睹 Penanggalan 的头部和内脏从身体上分离的见证者，都必须对魔法进行豁免检定，否则会立即死亡。如果豁免成功，则视为对他施放了弱智术。

头部和内脏会“飞”去寻找受害者；找到受害者后，头部会尝试催眠他。受害者必须以 −3 罚值对魔法进行豁免，否则会完全受该生物控制，直到它完成进食。它会在受害者的喉咙上造成两道小切口，并在整夜享用血液。每夜进食时，受害者会失去 1–6 点生命值，并各失去 1 点力量和体质。Penanggalan 会尽可能连续选择同一个受害者，并一夜又一夜地前来进食，直到受害者死亡。

如果受害者熬过这一夜，他不会记得发生过的事情，只会留下零碎印象，仿佛一个隐约记得的梦。如果由于某种原因，他避开了 Penanggalan 随后的纠缠，那么他仍会以每夜 1 点生命值的速度继续失去生命值，直到死亡，或直到对他施放驱散邪恶术。注意，Penanggalan 吸取的生命值不能用疗伤术之类的魔法手段恢复；实际上，被吸取的是受害者的最大生命值。这类法术只有在施放驱散邪恶术后，才会对损失的点数生效；即使是复原术这样的强力法术也不会产生效果。同样，受害者损失的力量和体质点数在施放驱散邪恶术前也无法恢复。不过，施放驱散邪恶术后，生命值会以每天 1 点的速度恢复，力量和体质则以每周各 1 点的速度恢复。

如果受害者第一次遭遇 Penanggalan 就屈服，生物必须在下一夜再次催眠他，之后才能进食。不过，受害者的豁免检定会逐渐变得更困难：第二次为 −4，第三次为 −5，依此类推。如果连续中断一夜或多夜，这种递增会停止；Penanggalan 在中断后重新尝试时，豁免仍为 −3。

如果预定的受害者在生物尝试催眠时豁免成功，Penanggalan 就无法再对他施加影响，并会恐惧地逃离他，然后寻找其他猎物。此外，此人将免疫该 Penanggalan 的后续尝试，并且无论它以何种伪装出现，都能认出某一只 Penanggalan 的真身。不过，如果生物至少吸过他一次血，他仍会按照上文所述，每夜损失 1 点生命值。

注意，受害者在 Penanggalan 来访期间始终处于“睡眠”状态。即使他对催眠豁免成功，也绝不会真正看见生物。生物绝不会攻击清醒的受害者。如果有人碰巧看见头部和内脏从身体上分离（例如预定受害者在生物来得及开始催眠前醒来），他必须进行恐惧豁免，否则会陷入极度恐慌并逃跑。不过，当生物处于这种形态时，牧师可以驱逐或解除它；在牧师／不死生物矩阵上按幽灵处理。如果头部和内脏因此被驱逐，它们必须返回巢穴，当晚不能再外出；如果被解除（矩阵上的 D 结果），它们会被摧毁，身体也会腐烂（见下文）。头部和内脏会在强行举起的圣徽前退缩，但不会受到伤害。

如果 Penanggalan 杀死男性受害者，他会保持死亡状态；如果尝试复活他，他承受系统震荡的存活概率只有正常值的一半。如果尝试失败，之后不可能再有任何尝试成功。如果它杀死女性受害者，女性会在三天后从坟墓中起来，成为 Penanggalan（不受原本那只生物控制）。如果在这三天期间尝试复活她，她承受系统震荡的存活概率只有正常值的一半；而该尝试失败后，之后不可能再有任何尝试成功，她变成 Penanggalan 的过程也就不可逆转。

不过，如果复活任一受害者的尝试成功，受害者会在两个月的休养恢复后恢复正常（生命值全部恢复，力量和体质恢复正常）；此外，该受害者会免疫 Penanggalan 的后续攻击，并能认出它的真身。

Penanggalan 的头部和内脏在巢穴中离开身体后，内脏会不断膨胀，无论是否发生进食都一样；在用醋浸泡一小时、恢复正常大小之前，它们无法回到腹腔。因此，这种生物总会在每一个巢穴中隐藏一个装满醋的大容器；Penanggalan 的巢穴常常可以通过其中弥漫的独特醋味来发现。

如果阳光射中与身体分离的生物头部和内脏，头部会陷入麻痹，直到夜幕降临前无力地落在地面上。因此，生物总会试图在鸡鸣前重新接合头部和身体。无论如何，如果头部和身体在最初分离后的七小时内没有重新接合，两者都会开始腐烂，赋予生物邪恶生命力的力量也会被迫返回地狱。因此，摧毁身体或头部，都是确定摧毁生物本身的方法。

与身体分离时，头部承受 4 个生命骰的伤害。

无论处于哪种形态，生物都会从所有武器中承受正常伤害。如果它没有武器且处于人类形态，可以咬击造成 1–6 点伤害，但它会尽量避免使用这种攻击方式，以免暴露自己的真实本性。

与身体分离时，内脏会不断滴下血液和消化液组成的高度挥发且恶臭的混合物；这种液体会对裸露的皮肤造成 1–4 点伤害，并使皮肤在痛苦的爆发中长出溃疡和疱疹。可怕的液体接触空气一轮后就会蒸发。

就空战而言，Penanggalan 的机动等级为 D。

## Pernicon

Pernicon 是一种色彩鲜艳、颇像蚱蜢的昆虫，长约 2 英寸，颜色有红、黄、赭色和浅蓝色。Pernicon 栖息在沙漠的外围地区，受到这些地区游牧民的高度珍视，因为它头上的触角能够寻找水源；当它距离大量水源 120°以内时，触角会振动并发出低沉的嗡嗡声。

Pernicon 通常没有攻击性，但如果受到干扰，无论是意外还是故意，它会成群攻击。它会跳到受害者身上，用腹部后方的钳子夹住暴露的皮肤。如果命中，Pernicon 会造成 1–3 点生命值伤害，并从受害者身上吸取水分和其他体液，导致其失去 1 点体质。此后每轮，这一过程都会自动继续，不需要再次进行命中检定。

即使 Pernicon 被杀死，它的钳子仍会紧紧夹住；从受害者身体上取下钳子时，还会造成 1–4 点生命值伤害。如果受害者的体质降至 3 以下，他会倒下并失去意识；降至 0 时死亡。如果受害者没有被杀死，他会以与损失生命值相同的速度恢复失去的体质点。不过，如果他死亡，死者复活术只能恢复其原本体质的一半，完全复活术则只能恢复其原本体质的 75%。

## Phantom Stalker

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1–2 |
| 护甲等级 Armour Class | 3 |
| 移动 Move | 12"／24" |
| 生命骰 Hit Dice | 6 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 2 |
| 每次伤害 Damage/Attack | 1–4／1–4 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 对火焰无效 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 半智能 |
| 阵营 Alignment | 中立 |
| 体型 Size | 可变——通常为 L |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | V／375 + 每点生命值 6 |

Phantom Stalker 来自火元素位面，通常只会以高等级魔法使用者仆从的身份出现在主物质位面。它们通过一种类似召唤隐形追猎者的法术召来（见《高级龙与地下城怪物图鉴》）。

Phantom Stalker 作为护卫，为保护主人而战。法师在下达指令时必须格外小心，因为它会逐字执行命令，并在可能的情况下曲解命令的意图，渴望获准返回自己的原生位面。

它们的召唤中有一条明确的内在指令：如果召唤者被杀，召唤者的 Phantom Stalker 会立即消失，并在 1–4 小时后重新出现，一心复仇，并从以太位面毫无偏差地追踪召唤者的杀手。Phantom Stalker 只有在主人死亡后才会获得这种以太追踪能力；一旦追踪到杀害召唤者的人，这种能力就会消失。

Phantom Stalker 能够自行变形，已知它们会呈现各种形态，但最常见的是身高 8 英尺、拥有巨大火焰双眼的红色类人生物。它们能够飞行，而且无论采取何种形状，这种能力似乎都不会受到影响（不过它们的机动等级会随形状而变化）。

Phantom Stalker 通常用尖锐的爪子攻击，每只爪子可以造成 1–4 点生命值伤害。它们不受火焰伤害影响，魔法火焰攻击实际上会为它们恢复生命值：每个伤害骰恢复 1 点生命值。不过，它们对寒冷进行豁免时受到 −2 罚值，而且这类攻击会使每个伤害骰额外造成 1 点伤害。如果 Phantom Stalker 正在进行近战，且死亡已迫在眉睫，它可以释放自身生命精华，形成一个 6 骰火球术；之后它会去物质化并死亡。有时它们会直接让火球在自身身上爆炸，以尽可能多地伤害敌人。这只会作为最后手段使用；如果这样会伤害召唤 Phantom Stalker 的人，它绝不会这么做，除非召唤者直接且立即对 Phantom Stalker 的死亡负有责任（例如命令它参加一场毫无希望且必死的战斗）。
