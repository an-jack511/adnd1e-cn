虽然游荡的 Poltergeist 很少遇到（在这种情况下，牧师可以像对待骷髅一样驱逐或摧毁它），这种不死生物通常会留在它最初被“杀死”的房间或走廊里（Poltergeist 与周围环境之间存在如此强的联系，以至于在这种情况下，在牧师／不死生物矩阵上应将它按食尸鬼处理）。

Poltergeist 是隐形且非实体的（除非攻击者能够看见隐形，否则攻击它时受到 −4 命中罚值）；只有银制武器和魔法武器能够伤害它。

Poltergeist 会通过投掷物体进行物理攻击——任何附近、轻到人类能够投掷的物体都可以。它命中目标的概率等于 5 生命骰怪物的命中概率。如果受害者被击中，不会受到伤害，但必须对恐惧进行豁免，否则会（如同对法术的豁免）逃离该区域，并朝随机方向奔跑 2–24 个近战轮，之后才会恢复。

受害者在逃跑过程中有 50% 的概率丢下手中拿着的任何东西，但不一定会在逃跑开始时丢下。（掷骰决定他必须逃跑多少轮；再次掷骰决定他是否丢下手中物品；如果确实丢下，再掷第三次决定是在逃跑的哪一个近战轮丢下。）

一个人完成豁免检定后，在该区域内会免疫 Poltergeist 造成的后续恐惧效果。

洒下圣水或强行举起圣徽会驱退 Poltergeist，但不会伤害它。

## Protein Polymorph

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 2 |
| 移动 Move | 9" |
| 生命骰 Hit Dice | 6–8 |
| 巢穴概率 % in Lair | 50% |
| 宝藏类型 Treasure Type | D |
| 攻击次数 No. of Attacks | 可变 |
| 每次伤害 Damage/Attack | 6–36，或按武器类型 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 平均 |
| 阵营 Alignment | 混乱中立 |
| 体型 Size | L |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | 6HD：V／400 + 每点生命值 6；7HD：VI／575 + 每点生命值 8；8HD：VI／925 + 每点生命值 10 |

Protein Polymorph 是有智慧的细胞群，能够采取它们选择的任何形态。它们可以采取无生命物体的形态，也可以采取 8 个或更少生命骰的有生命生物形态（取决于 Protein Polymorph 的大小，即 6、7 或 8 个生命骰）。所采取的形态实际上可能由多个形态组成，这些形态由一条几乎不可见的原生质丝或薄膜连接起来（发现概率为 10%）。Protein Polymorph 的细胞可以随意进行专门化或去专门化，呈现不同的质地和颜色，并在一轮内彻底改变。

这些“生物”极其多才多艺。它们可以模仿从一堆宝藏到一间小房间，再到半打人类或一打 Kobold 的任何东西。通常，它们会采取任何可能吸引猎物的形态，因为它们以人类和动物为食，并不在意猎物的种类和体型。它们甚至可以在自身结构中混入无生命物体，以增加真实性——例如，一间房间或一条走廊可能一部分是石头，一部分是 Protein Polymorph。被模仿的生物可以穿着真正的衣服，挥舞真正的武器（这些武器通常来自先前的受害者）。

Protein Polymorph 对细胞的控制程度存在限制——它不能准确复制面部表情，也不能有效复制说话的声音。这些限制可能导致伪装成有生命生物时暴露伪装。同样，如果 Protein Polymorph 把自己伪装成无生命物体，那么从 10" 外发现伪装的概率为 50%；不过，一旦触摸，细胞的生命性质就会立即暴露。

Protein Polymorph 的正常攻击方式是击打猎物，然后包裹并压碎它，每轮造成 6–36 点生命值伤害。当它采取会使用武器的生物形态时，无论是单个生物还是多个生物，它都会像这些生物通常会进行的那样攻击，并按照适当的武器类型造成伤害。

Protein Polymorph 拥有被模仿生物的正常力量，但不拥有那些生物的特殊能力。
