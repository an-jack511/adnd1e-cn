人们对这些身材高大、浑身白色长毛的双足生物知之甚少。有些人说它们曾经组成过好战的食人族；它们的攻击性确实毋庸置疑。任何逃跑或表现出威胁的队伍都会招致它们必然的攻击；即使一支队伍在 Quaggoth 的视野内保持静止，也有 75% 的概率遭到这些生物攻击。

Quaggoth 通常有 70% 的概率不带武器，此时会用两只爪子战斗，每只造成 1–4 点生命值伤害。遇到的 Quaggoth 群体中，有 30% 会装备战斧或双手剑。某一个 Quaggoth 群体要么全都不带武器（首领型除外），要么全都带武器；同一群体中绝不会混有不带武器和带武器的个体。

每遇到 12 只 Quaggoth，就会有 1 只拥有 15 点生命值、3 个生命骰和护甲等级 4 的首领型个体。首领型个体总会装备战斧或双手剑。

Quaggoth 完全免疫毒素。

如果 Quaggoth 的生命值降至 0 到 −5 之间，它会以狂暴状态继续战斗，命中概率获得 +2，伤害获得 +2。当它达到 −6 点生命值时死亡。

Quaggoth 特别憎恨居住在地表的精灵；为了帮助 Drow 与精灵作战，它们曾被发现成为 Drow 的奴隶。它们会以结结巴巴、原始的形式说通用语，只能理解非常简单的概念。

Quipper 是体型很小、凶猛的鱼，通常成大群游动。它们呈深绿色，栖息在淡水湖泊和溪流中。

Quipper 是一种稀有的冷水食人鱼。如果有人在鱼群附近游泳或涉水，Quipper 有 25% 的概率不会攻击。不过，如果它们发动攻击并命中，用尖利的牙齿咬出血来，造成 1–2 点生命值伤害，那么整个鱼群都会陷入狂暴，每轮发动的攻击次数变为正常数量的两倍。

最多可以有 20 只 Quipper 同时攻击一个人类体型的受害者。决定首次攻击时，先掷骰判断是否发动攻击；如果确实发动攻击，再掷百分比骰决定鱼群中有百分之多少会在第一轮尝试命中。为该数量的 Quipper 掷攻击骰；只要至少有一只命中，整个鱼群就会在下一轮攻击（实际尝试命中的数量不得超过 20）。如果第一轮攻击中的所有 Quipper 都未能命中，那么它们下一轮继续攻击的概率只有 40%。

## Qullan

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 1–6 |
| 护甲等级 Armour Class | 10 |
| 移动 Move | 12" |
| 生命骰 Hit Dice | 2 |
| 巢穴概率 % in Lair | 70% |
| 宝藏类型 Treasure Type | 巢穴中可有大多数类型，但数量很少（最多为 10%） |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 5–11 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 低 |
| 阵营 Alignment | 混乱邪恶 |
| 体型 Size | L（高 8 英尺以上） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／73 + 每点生命值 2 |

Qullan 是强壮、高大、看起来像疯子的人形生物，身上涂着各种冲突色彩的战纹，并自豪地展示战斗伤疤，常常还用化妆颜料加以强调。它们从不穿盔甲，要么裸身游荡，要么披着虎皮。

它们使用宽刃剑攻击，并把剑磨得异常锋利——这种技术至今仍无人类能够仿制。这些剑获得 +3 命中概率和 +3 伤害加值（因此造成 5–11 点伤害）。不过，剑很容易变钝：每次命中都有累计 20% 的概率使剑变钝，并恢复普通宽刃剑的性质。它们双手持用这些宽刃剑（但这样做不带来任何优势）。

Qullan 种族的所有成员都会持续向 5 英尺半径内放射困惑效果。任何与它们处于近战中的人都必须进行豁免，否则会陷入困惑，可能原地站立、攻击最近的 Qullan 而不顾自身安全，或攻击最近的朋友，三者概率相等。（掷 1d6 决定效果：1–2 表示原地站立；3–4 表示攻击 Qullan；5–6 表示攻击朋友。）每轮重复此掷骰，直到受害者豁免成功。只要仍在效果半径内，困惑的受害者每个近战轮都可以尝试豁免；一旦移出该半径，效果就会消失。

Qullan 从未与人类或近似人类的种族成为朋友；不论队伍的阵营或规模如何，每一次遭遇都见到 Qullan 发动攻击。

Qullan 混乱到了极端：任何试图强迫它做平时不会做的事情的行为，都会使它与生俱来的困惑力量“反馈”，导致该生物立即死亡。（当 Qullan 未能对任何魅惑或控制类法术进行豁免时，也会发生同样的反应。）因此，从来没有人能够了解它们锻造剑刃的锋利方法，也没有人能够诱使 Qullan 为非 Qullan 磨利一把精良宽刃剑的剑刃。

人类或近似人类的生物可以在近战中使用 Qullan 的剑，因为这种剑并非以任何方式具有魔法。不过，这把剑在命中时仍有普通的变钝概率；一把缴获的剑最多只能在 5 次命中中保持其特殊性质。
