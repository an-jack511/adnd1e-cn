Sandman 这个名字准确地描述了它：一种完全由沙子组成、通过某种魔法凝聚力维持在一起的类人双足生物。显然，这些生物来自另一个位面，但没有人知道它们在主物质位面的目的。

任何进入 Sandman 20 英尺范围内的人物或怪物，都必须对魔法进行豁免，否则会陷入睡眠，不论其经验等级如何。设法保持清醒的人，每次触摸 Sandman 或被它触摸时，都必须再次进行豁免（用武器击中 Sandman 不算“触摸”）。

Sandman 使受害者睡着后，就不会再对他采取行动，而是任由他打瞌睡；不过，如果遭遇发生在 Sandman 的巢穴中，它会先把睡着的人赶出去。

Sandman 会自动攻击人类，不需要进行士气检定。

无论发生什么，睡着的人都会整整睡三个完整回合。此后，睡眠者每过一回合自行醒来的累积概率增加 10%；如果受到猛烈干扰，他每轮醒来的概率为 95%。

Sandman 天生具有防护普通飞弹的能力。

Scarecrow 是普通稻草人的附魔版本，由各种材料制成，例如木制身体和四肢、萝卜头，外观也会各不相同。不过，它们总会呈现邪恶且带有恶意的样子。要制造 Scarecrow，必须使用某种特殊手册，或者由高等级邪恶牧师使用 animate object、quest、prayer 和 command。建造一个 Scarecrow 需要 3 周，但材料成本只有每点生命值 1 金币。只要命令不需要它自行解释，Scarecrow 就会服从创造者的简单指令，并逐字执行命令。

任何有智慧的生物只要遇到 Scarecrow 的目光，就会被魅惑，除非它对魔法豁免成功。Scarecrow 的触碰也有完全相同的效果；触碰需要成功的命中检定，并且还会造成 1–6 点生命值伤害。

魅惑效果是迷恋，而不是服从指令。受害者会站在那里凝视，仿佛受到定身术影响，允许怪物一次又一次地自由攻击他。如果 Scarecrow 被杀死或离开该区域，所有受害者会立即从魅惑中恢复。

## Screaming Devilkin

| 特殊防御 Special Defences | 无 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 低 |
| 阵营 Alignment | 守序邪恶 |
| 体型 Size | S（高 3 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／90 + 每点生命值 3 |

这种小生物在外表上类似 Mephit，但据目前所知，它完全是主物质位面的居民，并不效忠恶魔，也不效忠魔鬼（除了遵循自身阵营之外）。它高 3 英尺，比 Mephit 略小，拥有一条长约 2½ 英尺、带有肌肉和倒刺的尾巴。它的皮革翅膀翼展 5 英尺，是它唯一的移动手段；它的腿和手臂比例失调，太小，无法用于移动或战斗。就空战而言，它的机动等级为 D。

它总会攻击，绝不会自愿脱离战斗；它会用带有残酷倒刺的尾巴攻击，造成 1–6 点生命值伤害。它还会发出痛苦的嚎叫，在其他生物出现时持续尖叫。除了杀死这种野兽或用魔法使它沉默之外，没有任何东西能够阻止尖叫。即使大声喊叫，也无法透过尖叫听见交谈；没有塞住耳朵的人，只要在生物 60 英尺范围内，每个近战轮都必须进行豁免检定。如果豁免失败，受害者不能攻击、施放或控制法术，但仍可以防御。每轮只需进行一次豁免，无论范围内有多少只这种尖叫魔鬼崽。

注意，即使某人在一轮中豁免成功，如果想要采取任何行动，下一轮仍必须再次尝试。

如果魔法使用者、牧师或其他施法者豁免成功，那么即使尖叫使言语听不见，他仍可以在该轮施放包含言语成分的法术。
