## 幽影恶魔 Shadow Demon

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 9、5 或 1（见下文） |
| 移动 | 12"（但见下文） |
| 生命骰 | 7+3 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 3 |
| 每次伤害 | 1–8／1–6／1–6 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 极高 |
| 阵营 | 混乱邪恶 |
| 体型 | M |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | VI／825 + 每点生命值 10 |

这个来自下层位面的黑暗邪恶生物，是被囚禁在阴影形态中的恶魔的本质，而这种阴影形态正是它的外观。和 Shadow（见《高级龙与地下城怪物图鉴》）一样，这种生物有 90% 的时间无法被发现，因为它呈现模糊的形状，在地下城闪烁的光线下，很容易被误认为地下城结构或冒险者本身的影子。不过，它并非来自负能量位面，因此它的攻击不像 Shadow 的攻击那样吸取受害者的力量。它会正常地用两只爪子攻击（每只造成 1–6 点伤害），并用凶恶的咬击造成 1–8 点伤害。

这种生物的身体结构极其奇特，使它在黑暗中更强，在明亮条件下更脆弱。

因此，在日光或等效光线下，幽影恶魔的护甲等级为 9，并且承受所有攻击的双倍伤害。在火炬光下，护甲等级为 5，承受正常伤害；在这种条件下，它的攻击命中加值获得 +1。在黑暗或近乎黑暗中，护甲等级为 1，命中加值获得 +2，并且只承受攻击的正常伤害一半。

这种生物完全免疫普通或魔法形式的火焰、寒冷和闪电。不过，如果对它施放光亮术，幽影恶魔会像受到火球术一样受到影响（因此，五级魔法师施放的光亮术会对它造成 5–30 点生命值伤害，无论当时的照明条件如何）。

在通常情况下，即使有人看见它，也只有 50% 的概率能够辨认出它；这种生物拥有小型翅膀——翅膀太小，不能让它飞行，但足以在初次攻击时增强跳跃，使它跳到 30 英尺远。完成初次跳跃后，它会用四只爪子攻击（每只造成 1–6 点生命值伤害），但不再使用咬击。如果潜在受害者尚未发现它，它总会跳跃攻击。翅膀还使它能够以半飞半跑的方式移动，移动速度为 18"，每十轮可以使用一轮；如有必要，它通常会用这一动作作为逃跑的前奏。

幽影恶魔每天一次可以施放半径 10 英尺的黑暗术，并对 30 英尺半径施放恐惧术。每周一次，它可以对受害者发动魔魂壶攻击；如果受害者对这次攻击豁免成功，幽影恶魔会被震慑 1–3 轮。使用时必须有合适的容器在手边。

在牧师／不死生物矩阵上，幽影恶魔按“特殊”处理。人们认为它们由 Manes 形成（见《高级龙与地下城怪物图鉴》——恶魔、Manes〔亚恶魔〕），但幽影恶魔在冲突中表现出的高等智慧似乎否定了这一理论。

## 尸衣食尸鬼 · Sheet Ghoul

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动 | 9" |
| 生命骰 | 4+2 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 3 |
| 每次伤害 | 1–3／1–3／1–6 |
| 特殊攻击 | 喷射酸液 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 混乱邪恶 |
| 体型 | M |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | IV／170 + 每点生命值 5 |

裹尸幻影杀死受害者时会产生尸衣食尸鬼。它在牧师／不死生物矩阵上按幽魂处理。

尸衣食尸鬼用两只爪子攻击（每只造成 1–3 点生命值伤害），并用肮脏的獠牙攻击（造成 1–6 点生命值伤害）。它的触碰不会造成食尸鬼令人恐惧的麻痹（见《高级龙与地下城怪物图鉴》），但它每轮还可以从鼻子喷出细细的腐蚀性酸液，对其正在攻击的对手自动命中（目标必须在 10 英尺以内），造成 2–7 点生命值伤害。

这些生物会受到所有攻击方式的影响，但睡眠、魅惑和类似法术除外。

## 裹尸幻影 · Sheet Phantom

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 3 |
| 移动 | 6" |
| 生命骰 | 3 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 1–4 |
| 特殊攻击 | 窒息 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 混乱邪恶 |
| 体型 | 见下文 |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | III／105 + 每点生命值 4 |

这种令人极度恐惧的不死生物是一种缚灵，但作为不死生物，它的不同之处在于完全不像人类。它呈现为一块近乎透明、尺寸不一的矩形：宽 11–16 英尺，长 7–12 英尺，厚 ½ 英寸。它沿着天花板移动，并通过落到潜在受害者身上来攻击；如果命中目标，就会包裹住受害者，使其窒息；初次攻击之后的每轮造成 1–4 点生命值伤害（即使初次攻击命中，初次攻击也不造成伤害）。

被裹尸幻影包裹的受害者无法移动；而且，在它包裹俘虏时对裹尸幻影造成的任何伤害，也会同时由受害者承受。一次只能包裹一名人类体型的受害者，因为这种生物会把整个形体紧紧围绕受害者包成圆柱；除非受害者使用的武器很短（例如匕首），并且在生物落到他身上时武器确实已经握在手中，否则他无法反击。

如果裹尸幻影包裹的受害者因窒息死亡（或因同伴无意中造成的伤害而死亡），裹尸幻影会与他的身体合并，整体变成尸衣食尸鬼（见上文尸衣食尸鬼）。

这种生物与上文的 Lurker 有足够多的相似之处，因此有人推测其中一种可能是另一种的某种不死形态。

除睡眠、魅惑和其他类似法术外，这些生物容易受到所有攻击方式的影响，并且在牧师／不死生物矩阵上按幽魂处理。
