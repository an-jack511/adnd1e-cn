## Shocker

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |
| 出现数量 No. Appearing | 6–24 |
| 护甲等级 Armour Class | 0 或 10（见下文） |
| 移动 Move | 9" |
| 生命骰 Hit Dice | 1+2 |
| 巢穴概率 % in Lair | 无 |
| 宝藏类型 Treasure Type | 15% 概率每只拥有 1–4 颗宝石，见下文 |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 10 点生命值 |
| 特殊攻击 Special Attacks | 见下文 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 见下文 |
| 智力 Intelligence | 半智能 |
| 阵营 Alignment | 中立／混乱 |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／65 + 每点生命值 2 |

人们对这种形态异常的生物的起源和目的知之甚少。在主物质位面，它大约是人类大小的双足生物；身体被淡淡的浅蓝色火花包围，即使距离很远，听觉良好的人也能听见非常微弱的噼啪声，并且声音会随着 Shocker 接近而增强。很明显，这种生物并非起源于主物质位面，不过它访问该位面的目的仍未被发现；有人说它来自负能量位面，也有人假设存在一个与三个物质位面和元素位面相邻的电磁位面。无论情况如何，它在主物质位面的存在通常不会持续很久，这使人们猜测它在主物质位面上的形态只是一种投影——Shocker 的真实身体从未离开它的起源位面。

Shocker 会在命中时释放 10 点电击伤害（对死亡魔法的豁免成功则伤害减半）。金属盔甲对它们的攻击按护甲等级 10 处理，不过适用的魔法加值和敏捷加值仍然有效；Shocker 攻击板甲时，命中检定获得 +2 加值。

只有魔法武器能够影响 Shocker；如果手持金属武器击中它，效果就像 Shocker 发动攻击一样，电流会通过金属从 Shocker 的身体传到攻击者身上。对这种攻击，Shocker 的护甲等级为 10；但对飞弹攻击和非金属武器攻击，护甲等级按 0 处理。Shocker 放电后会塌缩成细小、无活性的尘埃，因此 Shocker 只能进行一次成功攻击。

有时（概率 15%），可以在每只 Shocker 的身体结构中发现 1–4 颗宝石；这些宝石会在生物放电时显露出来。

Shocker 免疫电击攻击、毒素和麻痹；它不受影响心灵的法术（例如睡眠术和魅惑术）影响。对其他魔法攻击，它拥有 50% 的抗性。

## Skeleton Warrior

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1 |
| 护甲等级 Armour Class | 2 |
| 移动 Move | 6" |
| 生命骰 Hit Dice | 9+2 至 9+12 |
| 巢穴概率 % in Lair | 90% |
| 宝藏类型 Treasure Type | A |
| 攻击次数 No. of Attacks | 1 |
| 每次伤害 Damage/Attack | 按武器类型 |
| 特殊攻击 Special Attacks | 使用武器时命中概率 +3 |
| 特殊防御 Special Defences | 见下文 |
| 魔法抗性 Magic Resistance | 90% |
| 智力 Intelligence | 非凡 |
| 阵营 Alignment | 中立（邪恶） |
| 体型 Size | M |
| 灵能能力 Psionic Ability | 见下文 |
| 攻击／防御模式 Attack/Defence Modes | 见下文 |
| 等级／经验值 Level/X.P. Value | 10–12 级：VII／2,550 + 每点生命值 14；13–15 级：VIII／3,700 + 每点生命值 16 |

这些是不死的 10–15 级领主，生前是强大的战士（如果生前拥有灵能能力，它们也会拥有）。它们只会受到魔法武器影响，并拥有 90% 的魔法抗性。外貌类似 Lich（见《高级龙与地下城怪物图鉴》）：身披强大战士所拥有的富丽、但褪色腐烂的装束的骷髅生物。

据说，许多年前，一位强大而邪恶的半神将每一名 Skeleton Warrior 的灵魂囚禁在一枚金色头环中，迫使它们进入类似 Lich 的状态。Skeleton Warrior 留在这个位面的唯一原因，就是寻找并取回封存自己灵魂的头环。

任何拥有其中一枚头环的人，都可以在 240" 范围内控制头环中囚禁其灵魂的 Skeleton Warrior。控制时，控制者能够透过战士的“眼睛”看见东西，但不能自行移动，也不能施放法术——他实际上无法这么做。因此，在“主动控制”期间，控制者可以让 Skeleton Warrior 战斗、寻找宝藏，依此类推。控制者也可以让生物进入“被动控制”模式；处于被动控制时，Skeleton Warrior 会保持不动，控制者无法透过它的“眼睛”看见东西，但控制者自己可以移动、战斗和施法。

无论哪一种情况，只要 Skeleton Warrior 移动到距离控制者超过 240" 的地方，或控制者离它超过 240"，或者头环从控制者头上取下，控制就会失效。如果头环仍在控制者手中，他之后可以恢复控制；但如果头环离开他的所有权范围，无论是意外还是故意，Skeleton Warrior 会立即停止正在做的事，以双倍速度（移动速度 12"）前去攻击并摧毁原控制者，在完成这一任务或重新建立控制之前绝不休息。如果头环落入 Skeleton Warrior 手中，它会“死亡”并消失，永远不再出现，而头环会变成细小的无价值尘埃。

当头环第一次落入某个人物手中时，尤其是人物没有意识到它的意义时，他可能不知道头环中囚禁灵魂的 Skeleton Warrior 正在跟踪自己。要建立控制，他不仅必须把头环戴在头上，还必须能够看见 Skeleton Warrior，并集中精神建立对生物的控制。如果他没有这样做，Skeleton Warrior 会攻击他，试图摧毁他并夺取头环。不过，一旦第一次建立了控制，控制只会按照上文所述的方式被打破。头环不能与任何其他头部装备一起佩戴来发挥作用；例如，戴上头盔会使它的力量失效，但 Skeleton Warrior 仍会意识到头环的存在。

仅仅看见 Skeleton Warrior，就会使任何生命骰少于 5 的生物惊慌逃跑。牧师没有机会驱逐它们。

Skeleton Warrior 通常使用双手剑战斗，但也有人见过它们使用其他类型的武器。无论使用何种武器，Skeleton Warrior 的命中检定都获得 +3 加值，不过武器本身不会因此变成魔法武器。
