Tabaxi（大多数人类称它们为猫人）是一种有智慧的猫科人形生物，居住在热带丛林的遥远深处，避开人类和有智慧的非人类。它们以 2–8 名成员组成小型狮群，每个狮群在大片领地上游荡，很少与其他狮群发生联系。

Tabaxi 是非凡的猎手，通过突袭和快速伏击捕捉猎物。两只 Tabaxi 经常把动物直接追到第三只的爪下。它们学会用芳香草药伪装气味，以躲避侦测。这一点，加上天生的伪装能力，以及快速、安静移动的能力，使它们成为热带森林中的致命对手。像其他猫科动物一样，它们有时会“玩弄”受伤的猎物，直到猎物死亡。它们也非常善于辨认陷阱的真面目：即使陷阱隐藏得极其仔细、构造得极其巧妙，困住猫人的概率也只有 10%。

只要方便，Tabaxi 就会使用工具。它们的工具通常是骨制或木制武器，复杂程度不会超过套索或投石器。不过，Tabaxi 对武器有惊人的天赋；只要武器不是复杂类型，它们很快就能学会使用，并在非常短的时间内熟练掌握。

Tabaxi 通常会避开进入它们森林的人类，除非看见容易获得武器的机会。

猫人身材高挑而纤细，动作像猫一样平稳轻盈。它们的细毛呈黄褐色并带有黑色条纹，图案类似老虎。它们不穿衣服，眼睛为黄绿色、瞳孔狭长，并拥有可伸缩的爪子。一个狮群通常有 1–3 只幼崽（1 个生命骰；受到攻击时有 50% 的概率战斗，50% 的概率逃跑）、1–3 只雄性和 1–3 只雌性。雌性的战斗能力至少与雄性相当。

Tabaxi 除了自己的语言外，也会说少量通用语。它们不会进行贸易，因为它们认为贸易有失尊严。

没有武器时，猫人会用两只前爪战斗（每只造成 1–3 点生命值伤害），并用咬击造成 1–3 点伤害。

## Tentamort

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 稀有 |

| 护甲等级 Armour Class | 触手 3；头部／身体 1 |
| 移动 Move | 1" |
| 生命骰 Hit Dice | 每条触手 2；头部／身体 4；总计 8 |
| 巢穴概率 % in Lair | 95% |
| 宝藏类型 Treasure Type | 无 |
| 攻击次数 No. of Attacks | 2 |
| 每次伤害 Damage/Attack | 1–6／1–6 |

| 体型 Size | S（但触手长 10 英尺） |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |

这种生物有许多名称，但如今最常用的是“tentamort”。它的头部／身体很小，形状大致是直径 2 英尺的球体。从球体上长出许多小触手，每条触手都有一排吸盘；通过这些吸盘，生物能够牢牢附着在几乎任何表面上，并沿表面缓慢移动。从身体与小触手相对的一侧，长出两条更长（10 英尺长）、更粗（直径最多 5 英寸）的触手。这两条长触手各有 2 个生命骰，彼此独立行动，每条都按 2 生命骰怪物进行攻击。头部／身体拥有 4 个生命骰，但本身不攻击。

其中一条长触手是强力的缠绕者。如果命中受害者，会造成 1–6 点生命值伤害。自然掷出 20，或掷出比命中所需数值高 2 点或更多的结果，表示它已经缠住受害者，将受害者的双臂压在身体两侧；之后它会自动缠紧（不需要命中检定），每轮造成 1–6 点伤害，直到触手或受害者死亡。

另一条长触手的末端有一根 6 英寸长的中空骨针。它也会用鞭打造成 1–6 点伤害，并在相同的要求下（20 或比正常所需数值高 2 点或更多）缠住受害者。这条触手不会收紧；相反，在受害者被困住的下一个近战轮，骨针会插入受害者的血肉，除非受害者豁免成功，否则会立即麻痹。随后，生物会通过骨针向受害者注入类似唾液的液体；如果受害者是人类体型，注满一剂需要两个近战轮。（受害者小于人类体型时只需一轮，大于人类体型时则需三或四轮。）剂量注入完毕后，受害者的内脏会开始软化，生物会通过骨针把内脏从受害者体内吸出。人类体型的受害者接受这种处理两个近战轮后会死亡（体型更小或更大的生物按上述比例调整）。如果触手在注射唾液期间被“杀死”，它会从受害者身上脱落；必须在一小时内对受害者施放疾病治疗术，否则受害者会死亡。不过，一旦唾液剂量已经注入，即使立即取下触手，也只有更强大的治疗魔法才能在一小时内挽救受害者。治疗术有效，再生术后接疗伤术也有效。

如果头部／身体被杀死，两条触手都会停止活动，但杀死一条长触手不会影响另一条。

如果两个受害者都在触手的攻击范围内，两条触手会分别攻击不同目标；但如果范围内只有一个受害者，两条触手都会集中攻击他。

这种生物呈深灰绿色；骨针的颜色与骨头相同。
