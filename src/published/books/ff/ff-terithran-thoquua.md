Terithran 是以太位面的生物——一种身高不高（4 英尺）的双足生物，拥有修长而结实的手臂，以及异常巨大、畸形的头部。它在主物质位面时呈现淡淡的阴影状外观（但不像非实体怪物那样淡），因此护甲等级为 3；它的实际护甲等级为 6。上方统计栏中括号内的数值，是它在以太位面上的属性。

在正常近战中，这种生物用两只爪子战斗，每只造成 2–5 点生命值伤害；但只要可能，它会避免这种战斗方式，以充分利用自己独特的魔法力量。

Terithran 开始厌恶大量魔法在主物质位面使用时，会在其故乡以太位面造成的旋涡、涡流和扭曲（它在自己的故乡从不离开巢穴）。如果它注意到这些扰动，就会在主物质位面负责施法的魔法使用者所在区域显形（距离他 1–10 英尺），试图吸取他的力量，并把他带回以太位面接受惩罚。它只会在魔法正在使用时出现，而且只有魔法足够强大时才出现。牧师或德鲁伊魔法不会吸引它，但魔法使用者或幻术师施放的魔法会（高等级游侠施放的魔法使用者法术也可能会）。

一般来说，单个法术不会吸引 Terithran 的注意，除非该法术等级很高。使用八级魔法使用者法术有 20% 的概率吸引它，九级法术为 30%（六级幻术师法术为 10%，七级法术为 20%）。不过，持续使用低等级魔法也可能吸引它；如果在连续的近战轮中使用了总计 16 个或更多魔法使用者法术等级（或 13 个幻术师法术等级），即使没有使用高等级法术，也有 65% 的概率吸引 Terithran。同样，连续三次使用魔法物品（例如寒冰魔杖）也有相同的吸引概率。注意，这些法术不必由同一个人施放；只要所有法术都在同一块 60×60 英尺区域内产生效果，就满足条件。不过，如果施法者不止一人，Terithran 会在他们之间的中点出现。

注意，怪物施放法术也会以与人物施法相同的方式、拥有相同概率吸引 Terithran。

Terithran 在任一位面都拥有 50% 的魔法抗性，还拥有若干天生魔法力量和一项天生魔法能力。该能力是无限次使用的侦测魔法。它的魔法力量如下：

<strong>震慑爆发：</strong>释放一股以太波，效果如同对半径 10 英尺内所有生物施放震慑律令术；对魔法的豁免成功可以抵消效果。

<strong>吸取力量：</strong>这一力量会移除魔法使用者（或幻术师或游侠）的所有魔法能力，直到适当的恢复时间过去；按施法者已经用完所有法术处理。像对龙息一样成功豁免，可以抵消该效果。

<strong>造成重伤：</strong>如同牧师法术，以触碰激活（需要正常的攻击检定）；不允许豁免。

<strong>传送：</strong>这允许 Terithran 把自己和另一个人（造成冒犯的施法者）带回以太位面；受害者必须先被抓住（视为两只爪子进行正常命中；只要一只或两只爪子命中，就表示受害者被抓住），但不允许豁免。

在主物质位面时，Terithran 每天最多只能使用 6 次力量。因此，在遭遇期间，它的首要目标会是抓住目标施法者，把他带回以太位面；它会保留一次力量使用次数用于传送，无论是带着受害者传送，还是如果抓捕失败且近战对它不利时独自逃跑。不过，它会使用其他力量（最多 5 次）来保护自己、接近预定受害者等。

注意，Terithran 的触碰不会自动造成重伤；只有当生物在该近战轮使用了特定力量时才会如此（不过一旦使用该力量，爪子的伤害也照常适用）。

如果在以太位面（它的巢穴中）遇到这种生物，它的爪子每只造成 2–9 点生命值伤害，每天可以使用 16 次力量，震慑爆发的力量会造成 2–7 个八面骰的伤害。

在主物质位面，只有银制或魔法武器能够命中 Terithran。

## Thoqqua（岩虫）

| 项目 | 数值 |
| --- | --- |
| 出现频率 Frequency | 极罕见 |
| 出现数量 No. Appearing | 1–2 |
| 护甲等级 Armour Class | 2 |
| 移动 Move | 12"（3"） |
| 生命骰 Hit Dice | 3 |
| 巢穴概率 % in Lair | 80% |
| 宝藏类型 Treasure Type | 10–60 颗宝石（基础价值 10 金币） |
| 攻击次数 No. of Attacks | 1 和 1 |
| 每次伤害 Damage/Attack | 4–32／2–12 |
| 特殊攻击 Special Attacks | 热量 |
| 特殊防御 Special Defences | 火焰攻击会治疗 |
| 魔法抗性 Magic Resistance | 标准 |
| 智力 Intelligence | 低 |
| 阵营 Alignment | 中立 |
| 体型 Size | S |
| 灵能能力 Psionic Ability | 无 |
| 攻击／防御模式 Attack/Defence Modes | 无 |
| 等级／经验值 Level/X.P. Value | III／65 + 每点生命值 3 |

人们怀疑这种野兽是土元素位面或火元素位面某种生物的幼体，尽管也有人推测它的起源位面是某个尚未确定的元素位面。它的形状像一条小型紫虫，直径 2 英尺，长 4–5 英尺。颜色为红银色。这种生物生活在主物质位面的岩石中，以每回合 30 英尺的速度挖掘岩石，制造一条直径约 3 英尺的赤热隧道。隧道在建成后保持炽热两轮；第一轮岩石呈红色，任何裸露皮肤接触它都会受到 4–14 点生命值伤害；第二轮岩石恢复正常颜色，接触造成 2–7 点伤害。两种情况下都不允许豁免，不过尤其在第一轮，岩石会向外辐射明显的热量。

在近战中，这种生物最初会向对手冲锋；在这次短距离爆发中，它可以以 48" 的速度移动，但距离不得超过 30 英尺。如果冲锋命中受害者，他会因热量和冲锋的动量受到 4–32 点生命值伤害。之后，它的攻击方式就是触碰受害者，造成 2–12 点热伤害；完成初次冲锋后恢复正常速度。

无论受害者是被冲锋还是普通攻击击中，攻击所指向的身体一侧上佩戴或携带的显眼物品，都必须对普通火焰进行豁免，否则会变得无用。如果是冲锋攻击，这些豁免检定受到 −4 罚值。

如果 Thoqqua 被火焰攻击击中，它会在暂时的 1–4 回合内把火焰攻击的伤害加到自己的生命值上。不过，寒冷攻击对这种生物造成双倍伤害。
