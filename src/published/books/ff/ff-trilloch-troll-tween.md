催亡精是来自负能量位面的能量生物，以垂死生物正在衰退的生命力为食，并使用其独特力量加速释放“食物”的过程。据目前所知，这种生物没有固定的明确形态。普通手段无法侦测它，不过在它 60 英尺范围内施放侦测魔法，会显现它独特的灵气；在同一范围内施放解除魔法，则会驱逐它。

据目前所知，没有其他魔法能对催亡精产生任何效果。

如果在催亡精存在时发生近战，无论它是否已被发现，所有攻击的命中概率都会获得 +1，成功命中还会额外造成 +1 伤害。它还能够影响非智能怪物的行为，使这些怪物攻击遭遇队伍的概率变为两倍。

催亡精经常跟随一只大型而强大的怪物，靠其受害者释放的大量生命力繁衍。如果这只“宿主”被杀，催亡精会附着到胜利者身上，并一直跟随他，直到被驱逐，或另一只更强大的生物杀死它的新宿主；此时它会转移到那只生物身上。

对催亡精行为的了解非常有限，因此它可能还有尚未发现的其他力量。可以确定的是，截至目前还没有找到能够伤害这种生物的方法。

## 巨魔 Troll

巨魔（《高级龙与地下城怪物图鉴》中有完整描述）是几乎所有气候中都能找到的可怕食肉生物。大多数生物都畏惧它们。不过，有些生物与巨魔杂交，产生了巨魔种族的可怕亚种。

所有亚种都拥有巨魔的能力：可以按需要把不同攻击指向不同对手。

巨魔的再生能力如下：受到伤害 3 个近战轮后，巨魔开始再生。再生每轮修复 3 点伤害，也包括重新接合被切断的肢体。巨魔令人作呕的肢体即使从身体上分离，也能继续战斗；手可以抓挠或勒颈，头部可以咬击，依此类推。完全肢解不会杀死巨魔，因为各个部分会彼此爬行靠拢、重新结合，巨魔会完整地站起来，继续战斗。要杀死巨魔，必须烧掉它或把它浸入酸中；任何分离的部分也必须用同样方式处理，否则它们会在 3–18 个近战轮内重新组成完整个体。

下文描述的亚种都继承了其中一些再生能力，以及巨魔的巨大力量。它们都拥有巨魔的特征：不知恐惧，持续不断地攻击。

巨型巨魔是丑陋的 Hill 巨人／巨魔杂交种（除了体型，其他方面都像后者），令人极度恐惧。它们的皮肤呈红棕色，眼睛周围发红（Hill 巨人的描述见《高级龙与地下城怪物图鉴》）。

尽管外表大腹便便，它们却拥有巨大的力量；用最喜欢的武器——一根带尖刺的大棒——可以造成可怕的 2–16 点生命值伤害。遇到巨型巨魔时，它有 10% 的概率没有这类武器；如果没有武器，它会用两只爪子战斗，每只造成 2–7 点伤害，并能把两只爪子指向不同的对手。

它们像巨魔一样再生，但每个近战轮再生 2 点生命值，并且不能重新接合被切断的肢体。

如果飞弹在攻击范围内，它们有 25% 的概率接住飞弹。

巨型巨魔被杀死前，必须至少受到 10 点火焰伤害。如果不满足这一条件，且巨型巨魔被削减到仅剩 1 点生命值，那么之后对它造成的任何伤害都不会产生效果，只会阻止再生。

巨型巨魔几乎存在于所有气候中。它们的嗅觉非常敏锐，并拥有 90 英尺红外视觉。

这些凶猛的双头巨人／巨魔杂交种拥有两个头，身高至少 10 英尺。它们像巨魔一样再生，但速度为每个近战轮 1 点生命值；不过，它们不能重新接合被切断的肢体。

这种普通巨魔的近亲与它更强壮的亲族非常相似，但拥有极其寒冷、半透明的身体。这些生物居住在地下城的潮湿区域，通常靠近流动的水；只要再生的肢体能够浸入水中，它们就拥有普通巨魔的再生力量，但速度为每个近战轮 2 点生命值。被切断的肢体可以移动 30 英尺去寻找水；只要范围内有水，它总会朝水移动。

它们拥有卓越的红外视觉（90 英尺）和敏锐的嗅觉。

这种可憎的生物是巨魔与隐形追猎者进行变态魔法杂交的产物，不过人们认为其创造秘密已经失传，目前已知仅有三十只左右。灵体巨魔是隐形的；能够看见隐形的人会发现它很像巨魔，只是稍矮，五官较为模糊。

这种生物只有受到魔法武器攻击时才会被命中。火焰对它造成完整伤害，但它不受寒冷影响。它像巨魔一样再生，速度也是每轮 3 点生命值。

它用獠牙和两只锋利的爪子攻击；如果愿意，可以分别攻击 3 个对手。獠牙造成的伤害（1–6 点生命值）是正常伤害，不过灵体巨魔会把对受害者造成的伤害点数加到自己的生命值上。爪子造成的伤害（每只 1–3 点生命值）不仅从受害者的生命值中扣除，也会从其力量点数中扣除。以这种方式失去的力量点数会在 2–8 个回合内恢复。如果人物的力量降至 0，他会死亡；如果降至 1 或 2，他会陷入昏迷，只有在力量恢复到 3 点或更多时（并且确实恢复）才会醒来。

灵体巨魔拥有敏锐的嗅觉和卓越的红外视觉（120 英尺）。

## 影伴 · Tween

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极罕见 |
| 出现数量 | 1（极少数情况下 1–3，10%） |
| 护甲等级 | 10 |
| 移动 | 可变 |
| 生命骰 | 1 |
| 巢穴概率 | 无 |
| 宝藏类型 | 无 |
| 攻击次数 | 1 |
| 每次伤害 | 按武器类型 |
| 特殊攻击 | 无 |
| 特殊防御 | 以太化 |
| 魔法抗性 | 标准 |
| 智力 | 极高 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无 |
| 攻击／防御模式 | 无 |
| 等级／经验值 | I／14 + 每点生命值 1 |

影伴是存在于以太位面的生物，但主物质位面的观察者能看见它烟雾般的人形轮廓。它们通常采取矮胖的人类形状，但变形能力有限。

只有拥有进入以太位面能力的人物，或使用以太油之类手段的人物，才能攻击它们。如果发生这种近战，影伴会用武器战斗，通常是剑。

影伴与主物质位面人类的接触，是通过选择宿主实现的；每只影伴通常都有宿主，但有时会暂时没有宿主（例如原宿主死亡后）。与新宿主相处数小时后，影伴会逐渐采取宿主的大致形状和特征，宿主身边会显现一个“影子”。一旦选定宿主，影伴就会永久与他在一起，直到宿主或影伴死亡。选择宿主时，影伴偏好有智慧的人类或近似人类的生物，但并不特别偏好玩家人物。影伴会与宿主进行心灵感应交流。

影伴能够看见未来几秒，并能提高宿主的运气。它还能够短距离移动物质物体，反应速度快到可以影响近战武器的运动。例如，它可以移动一把剑，使剑命中而不是失手。因此，任何拥有影伴“伙伴”的人物或生物，在需要掷骰时都会得到两次结果，并可以选择更有利的一次。（这适用于命中检定、豁免检定等。）

相反，影伴虽然会有益地影响宿主的行动，但会对宿主 50 英尺范围内的任何其他生物——朋友或敌人，人类或其他生物，玩家人物或其他人物——产生相反效果。受影响者每当需要掷骰时，也会掷两个结果；不过要选择较不利的一次。

因此，拥有影伴伙伴的人物对他的同伴而言可谓福祸相依。
