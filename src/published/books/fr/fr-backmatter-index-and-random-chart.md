## 随机怪物图表

原图标题为 <strong>Random Monster Charts（随机怪物图表）</strong>。表头依次为：<strong>Area（区域）</strong>、<strong>Terrain（地形）</strong>、<strong>Movement（移动）</strong>。表格先留下六个空白列供 DM 填写，再按 d20 给出稀有度栏：



| d20 | 稀有度 |
|---:|:---|
| 2 | VR/U |
| 3 | VR |
| 4 | VR/R |
| 5–6 | R |
| 7–8 | U |
| 9–13 | C |
| 14–15 | U |
| 16–17 | R |
| 18 | VR/R |
| 19 | VR |
| 20 | VR/U |

原书仅在图表中给出 VR（Very Rare，极罕见）、R（Rare，罕见）、U（Uncommon，不常见）和 C（Common，常见）缩写；VR/U、VR/R 等复合结果按原样保留，具体区域、地形与移动列由 DM 依战役需要填写。
