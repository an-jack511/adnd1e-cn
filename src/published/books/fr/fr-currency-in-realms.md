各种各样的物物交换与铸币在国度各地都很常见。以下体系属于科米尔这个国家，也代表了其他有组织国家的典型情况。

科米尔最受偏好的货币形式是王室铸币：一面印有龙，另一面刻有国库日期标记（在科米尔以及多数类似国家，伪造货币的惩罚是死刑）。这里没有纸币，只有 IOU；这些 IOU 被称为“血券”，因为它们必须由所有交易相关方（如果涉及两方以上，则由每一方）以血签名，并交给当地领主加盖王室印章。

国度各地的铸币通常按下列方式估价：

| 面值 | 等值 |
|---:|---|
| 200 cp | 200 枚铜币 |
|  | 20 枚银币 |
|  | 2 枚琥珀金币（electrum） |
|  | 1 枚金币 |
|  | 1/5 枚白金币 |

在科米尔，铸币术语如下：

| 缩写 | 科米尔称呼 |
|---|---|
| cp | 铜币；铜“拇指” |
| sp | 银币；银隼 |
| ep | 琥珀金币；“蓝眼睛” |
| gp | 金币；金狮 |
| pp | 白金币；三冠币 |

地方城邦经常自行铸造铜币、银币和金币，尽管琥珀金币与白金币更为少见，通常只有科米尔、深水城和安姆等更强大的国家会铸造这类货币。较小的国家，例如分裂的达马拉诸地区，会使用借自其他国家、或从古代来源掠取的铸币。

最后，国度各地的商人会使用“贸易条”（trade-bars），可以是银制的，也可以是琥珀金制的（利润更高的商队和商行会使用后者）。这些贸易条是特定金属的锭，面值分别为 10、25 和 50 金币，并带有该商人或公司的商路标记。

明智的做法是，了解你必须信任、与之做生意或同其冒险的任何人的宗教和／或阵营；但要小心，公开询问这些信息往往会被视为最高程度的冒犯。有人曾因询问他人的信仰而遭到攻击。
