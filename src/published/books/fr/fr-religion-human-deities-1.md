## 国度中的宗教 Religion in the Realms

国度中的“神”也被称为力量（Powers），是重要的存在；他们向崇拜者赐予魔法，并介入尘世事务，而且会随着自己拥有的凡人信徒数量而增强或减弱个人力量。侍奉神祇的牧师只有在取悦神祇时才会晋升：他们必须忠于神祇的规则与目标，并按照神祇的意愿行事。

国度中有许多神祇，即使在人类之间也是如此。这种神性存在的繁多，以及它们所代表或概括的“领域”差异极大，使国度普遍容忍各种信仰与对其他神祇的崇拜。这种容忍适用于所有不违反平民、王廷和国王军队所承认法律的人类。守序国度认为人祭是谋杀，把他人的财物用作祭品既是盗窃，也是肆意破坏。

个人，尤其是牧师，未必会宽容他人的信仰。询问一个人所不崇拜、也不太可能崇拜的神祇的祭祀细节，被认为是不礼貌的。

了解你必须信任、与之做生意或和他一起冒险的人的宗教和／或阵营，也许是明智之举；但要小心，公开询问这类信息往往是最高程度的冒犯。有人曾因询问他人的信仰而攻击对方。

以下列出国度中的主要神祇与半神，包括次要力量、元素领主、兽之教团以及非人类神祇的相关说明。

### 奥瑞尔 AURIL（AWE-RILL）

*霜少女（Frostmaiden）*

| 项目 | 内容 |
|---|---|
| 领域 | 寒冷之女神 |
| 阵营 | NE |
| 力量等级 | 次等力量（Demipower） |
| 主位面 | 混沌风暴位面（Pandemonium） |
| 象征 | 画在灰色菱形上的白色雪花，长轴垂直 |

<strong>说明：</strong>奥瑞尔被描绘成一位穿着白色斗篷的美丽蓝皮肤少女。她与塔洛斯有关。她的个人力量包括冰暴、奥蒂吕克冰冻法球等双倍强度的寒冷法术，以及接触时能杀死植物的冰息（如同冷锥术的效果；若适用则允许豁免），并且具有对她接触的所有金属施加成功冰冻定身术效果的能力。

### 阿祖斯 AZUTH（AH-ZooTh）

*至高者（High One）；魔法使用者的庇护者（Patron of Magic Users）*

| 项目 | 内容 |
|---|---|
| 阵营 | LN |
| 力量等级 | 半神力（Demipower） |
| 主位面 | 阿卡迪亚（Arcadia） |
| 象征 | 一只人手，食指向上，以蓝色火焰组成的光环勾勒 |

<strong>说明：</strong>阿祖斯被描绘成一个强壮的老人，年龄没有使他弯腰，手中握着一根法杖。阿祖斯被尊为最强大的法师，拥有 30 级魔法使用者和 20 级牧师的能力。此外，阿祖斯可能能够辨识面前武器的能力；他一触碰武器，就可能抵消一件物品（例如抵消权杖）的效果。

### 班恩 BANE（BAIN）

*班恩领主，黑暗之主（Lord Bane, The Black Lord）*

| 项目 | 内容 |
|---|---|
| 领域 | 纷争、仇恨、暴政之神 |
| 阵营 | LE |
| 力量等级 | 强大神力（Greater Power） |
| 主位面 | 赭红地狱（Acheron） |
| 象征 | 一只张开的黑手，拇指与手指并拢，有时位于红色背景上 |

<strong>说明：</strong>班恩领主从未现身，尽管有关于一只冰冷、黑爪的手以及燃烧之眼的传说。这个存在在国度中拥有强大的教会，此外还得到 Zhentil Keep（见该条目）法师们的支持。

### 贝莎芭 BESHABA（Beh-SHAH-ba）

*厄运少女、黑贝丝、末日女士（Maid of Misfortune, Black Bess, Lady Doom）*

| 项目 | 内容 |
|---|---|
| 领域 | 恶作剧、不幸、厄运、意外（背叛、变节）之女神 |
| 阵营 | CE |
| 力量等级 | 较小力量（Lesser Power） |
| 主位面 | 深渊（Abyss） |
| 象征 | 红色背景上黑色鹿角 |

<strong>说明：</strong>厄运少女显现为一个美丽的白发女子面孔，发出歇斯底里的笑声。看见她的人会遭遇厄运。贝莎芭出现之处，火焰计划往往会出错，坚固的武器或墙壁会突然失效，人与野兽都会遭遇离奇事故。

### 巴尔 BHAAL（Beh-HAHL）

*谋杀之主（Lord of Murder）*

| 项目 | 内容 |
|---|---|
| 领域 | 死亡之神 |
| 阵营 | LE |
| 力量等级 | 较小力量（Lesser Power） |
| 主位面 | 盖赫纳（Gehenna） |
| 象征 | 一圈逆时针落下的红色血泪，围绕一枚白色头骨 |

<strong>说明：</strong>巴尔一击必然命中；他的匕首会使受伤区域枯萎。他很少向崇拜者或其他人显现，但会以一具面孔野蛮、动作无声的血淋淋残尸形态出现在牧师面前。据说每一次谋杀都会增强巴尔。迈尔寇被承认为死者之主，而巴尔则是死亡本身的主宰——也就是杀戮这一行为的主宰。

### 查恩蒂亚 CHAUNTEA（Chawn-TEE-ah）

*大母神（Great Mother）*

| 项目 | 内容 |
|---|---|
| 领域 | 农业女神 |
| 阵营 | NG |
| 力量等级 | 强大神力（Greater Power） |
| 主位面 | 极乐境（Elysium） |
| 象征 | 被太阳环绕的含苞花朵，或一束金色麦穗 |

<strong>说明：</strong>大母神是农民与园丁的庇护者；凡人寻求栽培之处，都有她的手在场。查恩蒂亚不爱炫耀或盛大的仪式，而更重视微小的虔敬行为；她的神殿往往是长满绿植的小洞穴或朴素的房间。查恩蒂亚始终与奥瑞尔和塔洛斯交战。月之海群岛的地母可能是查恩蒂亚的一种伪装或化身。

### 德内尔 DENEIR（Deh-NEER）

*所有符文与图像之主（Lord of All Glyphs & Images）*

| 项目 | 内容 |
|---|---|
| 领域 | 文学、艺术之神 |
| 阵营 | NG |
| 力量等级 | 半神力（Demi-Power） |
| 主位面 |兽境（Beastlands） |
| 象征 | 一支点燃的蜡烛，下面通常有一只眼睛 |

<strong>说明：</strong>德内尔与奥格玛结盟，通常被描绘成一位留着火焰般白胡子的秃顶老贤者。他的牧师往往具有学者气质，并把大多数魔法典籍或著作（《理解之书》《清晰思想手册》等）归于他的名下。

### 埃尔达斯 ELDATH（EL-daTh）

*宁静者，歌唱之水女神（The Quiet One, Goddess of Singing Water）*

| 项目 | 内容 |
|---|---|
| 领域 | 瀑布、泉水、溪流、水池、静止、和平、安静之地、德鲁伊林地守护者 |
| 阵营 | N |
| 力量等级 | 半神力（Demipower） |
| 主位面 | 主物质位面（Prime Material Plane） |
| 象征 | 跌入静水池的瀑布，或边缘长着绿色蕨类的天蓝色圆盘 |

<strong>说明：</strong>据说埃尔达斯拥有压制一切附魔／魅惑类法术的力量，包括友好术、共情术、睡眠术，以及半径 15 英尺的寂静术。她与塞尔万纳斯结盟并为其侍奉，是最高度的和平主义者。她保护所有德鲁伊的林地；当她出现在某座林地中时，那片地方便成为圣所，不会有任何打击落下，也不会有人感到愤怒。据说精灵战争英雄泰尔瓦曾在这样的林地中扎营，此后再也没有拿起武器。埃尔达斯显现为一位穿着半透明绿色衣裙的美丽女子。

### 刚德 GOND（Gond）

*奇迹使者（Wonderbringer）*

| 项目 | 内容 |
|---|---|
| 领域 | 铁匠、工匠、工艺与建造之神 |
| 阵营 | N |
| 力量等级 | 较小力量（Lesser Power） |
| 主位面 | 协调对立位面（Concordant Opposition） |
| 象征 | 黄铜、青铜、铁或骨制的齿轮 |

<strong>说明：</strong>刚德显现为一名强壮的红肤铁匠，手持巨锤；他拥有锻炉与铁砧，能够用它们锻造星辰的材料。崇拜他的人主要是修补匠、炼金术士和建造者，但兰坦岛（见该条目）将刚德信仰视为国教，其他地方都没有如此强烈的发明狂热（或对发明成功的狂热）。

### 海姆 HELM（Hehlm）

*不眠之眼（He of the Unsleeping Eyes）*

| 项目 | 内容 |
|---|---|
| 领域 | 守护之神 |
| 阵营 | LN |
| 力量等级 | 下等神（Lesser God） |
| 主位面 | 天堂（Nirvana） |
| 象征 | 一只张开、凝视的眼睛，常画在金属护手上 |

<strong>说明：</strong>海姆永远警觉而且小心。他从不惊讶，并凭借智慧与观察预见大多数事件。他绝不会被击倒，很少会被欺骗，也永远不会背叛或忽视自己所守护之物。总之，他是守护者的理想形象；人们崇拜他，是希望他的某些品质能够降临于崇拜者，或在崇拜者身上显现。刚德的神殿往往位于邪恶或潜在危险迫近之处，例如黑堡脚下的赫鲁特瓦尔。

### 伊尔梅特 ILMATER（Ihl-MAY-ter）

| 项目 | 内容 |
|---|---|
| 领域 | 忍耐、苦难、殉难、坚忍之神 |
| 阵营 | LG |
| 力量等级 | 较小力量（Lesser Power） |
| 主位面 | 双重乐园（Twin Paradises） |
| 象征 | 血染的刑架，或绑在手腕处的交叉双手 |

<strong>说明：</strong>这个神显现为一个破碎的人，双手被砸烂却仍然有用。伊尔梅特是甘愿受苦者，是代替他人承受苦难的人。他能够显现在受折磨的生物身上，为它们减轻痛苦；但只有当这些生物属于善良阵营、且没有做过不配得到这种待遇的事情时，他才会这样做。

### 拉山德 LATHANDER（Lah-THAN-der）

*晨曦之主（Morninglord）*

| 项目 | 内容 |
|---|---|
| 领域 | 春天、黎明、受孕、活力、永恒青春、更新、自我完善、开端之神 |
| 阵营 | NG |
| 力量等级 | 强大神力（Greater Power） |
| 主位面 | 极乐境（Elysium） |
| 象征 | 玫瑰粉色的木盘 |

<strong>说明：</strong>晨曦之主拉山德是创造力的指挥者。崇拜其他力量的人在开始一项新事业，或组成一个联盟或公司时，会向他献上祭品。拉山德通常显现为玫瑰色的光辉或薄雾；在较早的描绘中，则是一个拥有金色皮肤、极其美丽的年轻男子。他的牧师穿着粉色或猩红色长袍，较高阶者的长袍会用金色饰带装点。

### 莉拉 LEIRA（LAIR-ah）

*迷雾女士（Lady of the Mists）*

| 项目 | 内容 |
|---|---|
| 领域 | 欺骗、幻术之女神 |
| 阵营 | CN |
| 力量等级 | 半神力（Demipower） |
| 主位面 | 混沌涡流（Limbo） |
| 象征 | 一块尖端朝下的三角牌，涂成阴云般的旋转灰色 |

<strong>说明：</strong>莉拉是自然与魔法欺骗和幻术的半神。她的真实形象无人知晓；她的牧师在角状祭坛前礼拜，祭坛向上弯曲的双臂之间只有空气。莉拉可以成为任何东西，出现在任何地方，只要那不是它看起来的样子。除幻术师之外，很少有人崇拜莉拉，因为很少有其他类型的角色能从误解和欺骗中获利；不过，许多人会向她致敬，以便在重要决策和裁判之前阻止或安抚她。她被视为中立而非邪恶，因为她代表的是自然的反复无常，而不是蓄意欺骗（后者属于马斯克的领域）。
