## 魔法法术

众所周知，在所有位面间维度中，奥斯土地（Oerth）的施法者都是整个多重宇宙中最强大的。每一位最强大的施法者都曾在某个时候将家安置于灰鹰城。以下列出的是这些强大法师所掌握的鲜为人知但极其有用的法术。我们费了很大力气，试图呈现其中最有用的法术，但也不至于泄露全部秘藏。没有 8 级和 9 级法术，因为即使是这位强大的抄录者也无法取得那些受到严密保护的法术。像 Drawmij 的瞬间剥除术（Drawmij’s Instant Stripping）和 Otto 的可食用明胶立方体变形术（Otto’s Gelatinous Cube Transformation to Edible Gel）这样的法术，则因为对最求知的法术制作师而言也过于深奥而被略去。

由于这些法师居住在灰鹰城，以及该城本身高度魔法化的性质，所有这些法术都能在城内外看到有人使用。装有这些法术的卷轴可以在所有最好的宝藏储藏中找到。奇异的魔杖和魔法戒指中也经常会植入这些法术，以便立即使用。

## Bigby 的法术

### Bigby 的书虫灾厄术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 1 |
| 成分 | V、S、M |
| 射程 | 20 码 |
| 施法时间 | 1 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术用于搜寻并消灭法师最为恐惧的敌人之一：书虫。施法时，法术会创造出一只无身躯的手，它将搜索一座图书馆，并压碎它找到的所有书虫。这只手每轮可以搜索 100 本书或卷轴，以 95% 的发现几率寻找书虫。一旦找到一只书虫，这只手便会不懈地追逐它，并以等同于施法者等级的战士技能进行攻击。这只手成功命中，意味着书虫会被立即压死。这只手的力量为 8，因此它可以在追逐逃跑的书虫时移开书籍和卷轴。这只手不会受到物理攻击伤害，但遭受 4 点或更多魔法伤害时会被摧毁。这只手无法执行任何其他功能，也不能与任何其他敌人战斗。Bigby 会定期使用此法术来保护他珍贵的图书馆。材料成分是一只用坚韧皮革制成的儿童尺寸手套。

### Bigby 的感觉手指术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 1 |
| 成分 | V、S、M |
| 射程 | 60 码 |
| 施法时间 | 1 段 |
| 持续时间 | 1 小时 + 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会在施法者的指挥下召唤出一只无身躯的手。这只手不能握持、抓取或搬运，但确实拥有惊人敏锐的触觉。这只手的触觉精细到可以注意到表面上的微小裂缝、分隔处或开口，因此有 50% 的几率发现秘密门或隐藏门。这只手每轮可以搜索一个 10 英尺乘 10 英尺的区域。这只手不会被物理攻击摧毁，但遭受 4 点或更多魔法伤害时会被驱散。如果陷阱位置已知，这只手可以触发非魔法陷阱。法术的材料成分是一只儿童尺寸的丝绸手套和一根天鹅羽毛。

### Bigby 的灵巧手指术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 2 |
| 成分 | V、S、M |
| 射程 | 90 码 |
| 施法时间 | 2 段 |
| 持续时间 | 每等级 3 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会召唤出一对无身躯的手，它们会遵从法师的每一道命令。这些手可以执行隐形仆从的所有功能，也能完成要求精细协调的工作，例如摆弄工具、操作实验室设备、雕刻、绘画或演奏乐器。这些手可以完成施法者能够完成的任何任务，包括法师所知的非武器熟练项。这些手的灵巧度等同于施法者。每只手可以单独握持和搬运最多 200 金币重量，合计可以搬运 500 金币重量。这些手彼此之间不能分开得超过施法者双手之间的距离。这些手无论搬运的重量为何，每轮都能移动 120 英尺，但它们离施法者不能超过 90 英尺，否则就会消失。这些手不能完成法术的姿势成分。这些手不能在近战中使用武器，也不能拳击或擒抱。虽然这些手免疫物理攻击，但遭受 6 点或更多魔法伤害时会被摧毁。材料成分是一双绣有法师姓名首字母的手套。

### Bigby 的缄默之手术（塑能系－附魔系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 2 |
| 成分 | V、S、M |
| 射程 | 40 码 |
| 施法时间 | 2 段 |
| 持续时间 | 每等级 2 轮 |
| 豁免检定 | 无 |
| 作用范围 | 一个生物 |

<strong>解释／描述：</strong> 此法术会创造出一只大小恰当的手，它将飞向选定的生物，并紧紧捂住该生物的嘴，除非该生物通过豁免检定。受此法术影响的生物将无法清楚说话，不能施放需要言语成分的任何法术，也不能使用由可听见的命令词触发的魔法物品。这只手无法从生物嘴上被拉开，也不会受到物理攻击伤害，但遭受 6 点或更多魔法伤害时会被摧毁，尽管大多数魔法攻击都有伤害受影响生物的风险。成功的解除魔法会在不伤害生物的情况下摧毁这只手。材料成分是一只涂有黏稠糖浆或蜂蜜的布手套。

| 持续时间 | 每等级 2 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会创造出一对真人大小的手，外形如握紧的、加衬垫的拳头。这双手以力量 18／50 的战士一半施法者经验等级的战斗效能进行捶打。这双手合起来以护甲等级 4、每法师等级 3 点生命值的角色进行战斗。这双手在耗尽生命值时会被驱散。这双手只能捶打，不能握持武器或擒抱，也不能进行摔绊，因为它们可以轻易挣脱。材料成分是一只填塞棉花、并带有黄铜铃的连指手套。

### Bigby 的破门铁拳术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 60 码 |
| 施法时间 | 4 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会创造出一股闪烁的紫色力量，其形状像一根攻城槌，握紧的拳头就是槌头。这股力量呈圆柱形，长 12 英尺、直径 2 英尺，但施法者可以将其长度缩短到 3 英尺，以便放入狭窄空间。

此法术发挥出强力攻城槌的作用：普通门一击摧毁，加固门三击摧毁，石门五击摧毁；对金属门则有 50% 的几率摧毁（如果铁拳失败，法术会被摧毁）。每轮只能进行一次攻击，就像普通攻城槌一样。将其用于更小的实体障碍物，例如地下城门或用魔法加固的金属栅门时，门必须在施法者施放加固法术的等级上进行豁免检定。如果豁免成功，铁拳法术会被摧毁。如果豁免失败，铁拳法术便开始作用于门。

对活着的目标，攻城槌不起作用。施法者必须始终处于攻城槌 60 英尺以内，否则它会消散。攻城槌不会受到物理攻击伤害，但若遭受相当于施法者生命值一半的魔法伤害，便会被摧毁。解除魔法或解离术也能摧毁铁拳。此法术不能用于打开箱子，也不能撞击门以外的任何物体。它只对设计成可以在某个时候打开的门户起作用。材料成分是一根金属棒，一端套着一只链甲手套。

### Bigby 的力量雕塑术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 30 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 这个非常灵活的法术能让法师创造出一个可见的力场平面，并将其塑造成施法者希望的任何形状。例如，施法者可以创造桌子、梯子、棍棒、水桶、高跷或手杖。一旦物体成形，它会在法术持续时间内保持形状。被仿制的物体必须相当坚硬，不能有活动部件，不能有尖锐的点或边，也不能具有精细的细节。绳子、长弓、剑、战车或精确的雕像都不能用此法术创造。所有由力量形成的物体都不会受到物理攻击伤害，但遭受的魔法攻击伤害点数超过创造者生命值时，会被魔法攻击驱散。每个施法者等级最多可以仿制 1 立方英尺的物质。法术材料成分是一团混入钻石尘的软黏土。

<strong>解释／描述：</strong> 此法术会为施法者的每三个等级创造一只手，每只手都握着一把长剑。每只手以施法者一半经验等级的战士技能进行战斗。由于体型小且速度快，每只手的护甲等级为 2；每只手在被驱散前可以承受 15 点伤害。每个剑士都有能力解除对手的武装，并且会在命中所需骰值再高出 4 点时这样做。被解除武装、失去剑的剑士会自动被驱散。施法者不需要集中精神来维持剑士运作，只需像对待侍从一样向它们下达命令即可。材料成分是一枚小型银制护符，形状像一只戴着铠甲的手握住一把镶宝石的剑，价值至少 1,000 金币（法术施放时护符会消失）。

### Bigby 的围城弩矢术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 6 |
| 成分 | V、S、M |
| 射程 | 特殊 |
| 施法时间 | 1 轮 |
| 持续时间 | 每施法者等级 2 级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术类似于魔法飞弹。施法时，法师能够每两个施法者等级发射一枚魔法攻城弩矢。弩矢在射程和效果上会表现得像某种给定的攻城器械投射物。弩矢模仿哪一种攻城器械投射物，取决于施法者的等级。

| 魔法使用者等级 | 模仿的攻城器械投射物 |
| --- | --- |
| 12 级 | 轻型投石机 |
| 14 级 | 重型投石机 |
| 16 级 | 配重投石机 |

在接下来的轮次中，弩矢必须以每两轮一枚的速度发射。在此期间，施法者不能做其他事情。如果法术被打断，就不能再发射额外的弩矢。弩矢会无误地击中目标。材料成分是一块撒有钻石尘的小石头。

| 项目 | 数据 |
| --- | --- |
| 等级 | 8 |
| 成分 | V、S、M |
| 射程 | 30 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 6 轮 + 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术是力量雕塑法术中最先进的形式。形成的物体可以高度复杂，包含许多活动部件，例如攻城器械或帆船。所仿制物体的部件可以像绳子或弓的木材一样柔韧，因此可以形成大型网、弩炮、绳桥或一组弩。与较低级的力量雕塑术一样，精细或准确的细节需要额外 2d4 轮来成形，同时还需要艺术家或工匠的足够技能。每个施法者等级最多可以仿制 1 立方码的物质。除上述例外外，此法术与同类 4 级法术完全相同。材料成分是一团混入价值 1,000 金币钻石尘的黏土，法术使用时会消失。
