## Drawmij 的法术

### Drawmij 的负重兽术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 1 |
| 成分 | V、S、M |
| 射程 | 30 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 每等级 2 小时 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会部分减轻放置在一匹坐骑上的货物重量。坐骑上所有物体（包括骑乘者）的有效负重都会减少一半，实际上等于让坐骑能够承载双倍重量。一匹坐骑若在没有法术保护的情况下突然发现自己承载了相当于最大负重一又二分之一的重量，就无法行走，会慢慢沉到地面，并有 50% 的几率变瘸。一匹坐骑若突然负担了两倍于最大负重的重量，就会倒地，受到 1d6 点伤害，并自动变瘸。材料成分是一块磁石和一撮金属锉屑。

### Drawmij 的轻步术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 1 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 1 段 |
| 持续时间 | 每等级 5 轮 |
| 豁免检定 | 无 |
| 作用范围 | 一个生物 |

<strong>解释／描述：</strong> 此法术赋予生物一种非常有限的悬浮能力。生物可以正常在任何表面上行走，但脚步如此轻盈，以至于身后不会留下足迹。如果生物开始冲锋或奔跑，法术会立即结束。

生物也可以在流体表面上移动，就像在固体表面上一样，但移动速度会降低到生物正常行走速度的一半，因为生物必须小心迈步。不过，轻步术无法让生物在湍流的水面或海浪上行走，因为流体的混乱运动会扰乱悬浮场。实际上，此法术会让生物无法触发陷坑。它不允许生物跳得更高，也不允许生物安全地从悬崖上跳下；它只允许生物迈出更轻的步子。在法术持续期间，此法术还会使生物的移动速度提高 50%。材料成分是取自猫爪的一小撮毛和一根鸭羽毛。

### Drawmij 的瞬间出口术（变化系－咒法系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 30 码 |
| 施法时间 | 1 段 |
| 持续时间 | 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术能让法师及其他人使用一种有限且危险的传送形式。施法时，一扇门会突然出现在施法者 3 码以内的墙壁或其他平坦表面上。施法者以及一轮内能够通过这扇门的其他人（通常速率为每段一个生物或人）可以穿过门口，进入一个虚无空间区域。当法师在身后关上门时，法师和虚无空间区域内与其同行的所有人都会被传送到门周围 250 码以内的随机地点。如果门在法术持续时间结束前没有关上，那么门会在该轮结束时自动砰然关闭。门会在被法师关上或自行关闭后消失。

队伍无法控制自己会被传送到哪里，而且法术总有 5% 的几率发生故障，将队伍丢入以太位面。要确定法师及其朋友被送到哪里，应查阅 DM 的地图，沿队伍行进的路径回溯，并将他们放在曾经到过的随机区域。此法术不能将队伍送入未知地域。材料成分是一扇饰有红宝石碎片、价值 5,000 金币的微型银门，施法后会消失。

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 0 |
| 施法时间 | 2 段 |
| 持续时间 | 每等级 5 轮 |
| 豁免检定 | 无 |
| 作用范围 | 以施法者为中心、半径 20 英尺的球体 |

<strong>解释／描述：</strong> 此法术会在施法者周围创造一个半径 20 英尺的空间体积；在其中，所有生物都受到保护，不受所有非魔法气体、烟雾和烟尘的影响。所有接触保护球边缘的天然气体都会被驱散。球体内的空气始终保持洁净、新鲜，并补充氧气，因此即使外界空气受到污染，或其中的氧气被火焰消耗，球体内的人也不会因缺氧而受苦。此法术在水下或真空中不起作用。球体会随施法者移动。如果保护球接触到魔法气体，或施法者使用魔法手段移动，球体就会被驱散。材料成分是一把扇子和一只装有至少价值 100 金币香水的小瓶；两者都会在施法后消失。

<strong>解释／描述：</strong> 此法术会帮助生物在狼人类生物的攻击中存活。狼人类生物对该生物发动的任何攻击，命中时都受到 −2 处罚。无论狼人类生物造成多少伤害，只要法术有效，生物就不会感染狼人化。如果伤势发生在法术施放之前或法术结束之后，此法术不会保护生物免于感染狼人化。材料成分是碾碎的月长石。
