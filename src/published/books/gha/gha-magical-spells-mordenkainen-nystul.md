## Mordenkainen 的法术

### Mordenkainen 的非魔法爬虫与两栖动物防御术（防护系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 3 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 3 段 |
| 持续时间 | 每等级 5 轮 |
| 豁免检定 | 无 |
| 作用范围 | 被接触的生物 |

<strong>解释／描述：</strong> 受到此法术保护的生物，在与非魔法爬虫或两栖动物战斗时会获得优势，包括蛇、恐龙、青蛙以及这类动物的巨型种。龙不受此法术影响，其他拥有非自然能力的生物也不受影响。所有此类动物在攻击受保护生物时，命中骰都受到 −2 处罚；该生物针对爬虫或两栖动物毒素的豁免检定获得 +4 加值。材料成分是一小片蛇皮和一条干青蛙腿，放在硬化皮革袋中。

### Mordenkainen 的忠诚幻影防卫者术（召唤系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 5 |
| 成分 | V、S、M |
| 射程 | 60 码 |
| 施法时间 | 5 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术召唤出一组幻影生物，它们显现为闪烁的紫色光线轮廓。防卫者会尽力停在法师与其敌人之间，为施法者提供足够时间和空间用法术保护自己。对大多数生物来说，幻影防卫者是实体，看起来像真实存在的生物。对法师而言，防卫者完全透明且没有实体，因此法师施放的任何攻击法术都不会影响防卫者。法师的法术可以穿过防卫者击中敌对生物。如果防卫者被施法者的法术作用范围覆盖，防卫者不会受到伤害。法师可以召唤四种不同的幻影防卫者组合之一，但施法者必须在记忆法术时决定召唤哪一组。每一组都最适合某种特定环境。四组防卫者如下：

<strong>三名忠诚幻影士兵：</strong> AC 4（幻影锁子甲和盾牌）；移动 9”；HD 4；hp 24；#AT 1；伤害 1d8（幻影长剑）；THAC0 15；AL N；特殊：能够击中只有 +1 魔法武器才能击中的生物。

<strong>两名忠诚幻影半人马：</strong> AC 5；移动 18”；HD 4；hp 28；#AT 1；伤害 1d6（幻影轻骑枪）；THAC0 15；AL N；特殊：能够击中只有 +2 武器才能击中的生物。

<strong>八只忠诚幻影巨蝙蝠：</strong> AC 8；移动 3”／18”；HD 2+2；hp 12；#AT 1；伤害 1d4；THAC0 16；AL N；特殊：能够击中只有 +3 武器才能击中的生物。

<strong>五条忠诚幻影鲨鱼：</strong> AC 6；移动 24”；HD 3；hp 15；#AT 1；伤害 1d4 + 1；THAC0 16；AL N；特殊：能够击中只有 +1 武器才能击中的生物。

材料成分是一尊描绘将被召唤的防卫者类型的小型铅水晶雕像，以及每个被召唤生物一颗价值 1,000 金币的翡翠。翡翠会在施法时消失。

### Mordenkainen 的忠诚幻影守卫术（召唤系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 6 |
| 成分 | V、S、M |
| 射程 | 特殊 |
| 施法时间 | 3 轮 |
| 持续时间 | 特殊 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会召唤一个忠诚的幻影生物，在一天之内看守并保护法师。守卫会留在以太位面，从那里作为无法被侦测的观察者监视施法者。守卫能看见施法者 60 英尺以内发生的事情，也能在法师周围区域发现隐形、错相、二维、以太或星界生物。如果守卫发现某个生物即将对施法者发动突袭，守卫会立即实体化，拦截攻击者并保护法师。

忠诚幻影守卫：AC 2；移动 15”；HD 6；hp 36；#AT 1；伤害 1d10（双手剑）；THAC0 13；AL N；特殊：能够击中只有 +2 魔法武器才能击中的生物。守卫会战斗最多相当于施法者每个等级一轮的时间，或直到它被摧毁。法师还可以选择随时将守卫召唤到自己身边。守卫会在一轮内出现，并在相同的时间限制下战斗。守卫一旦在主物质位面上耗尽了自己的时间，就完成了任务，不再继续看守施法者。

守卫会显现为闪烁的紫色光线轮廓。幻影守卫不能说话，因此如果法师遭到攻击，它无法大声向法师发出警告。材料成分是一颗价值 1,000 金币的钻石，施法时会将其送给守卫，作为提供服务的报酬。

| 成分 | V、S、M |
| 射程 | 30 码 + 每等级 5 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 特殊 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会将一小点来自负能量位面的微观能量召唤到施法者手中。施法者必须立即以 +2 加值进行一次对死亡魔法的豁免检定，才能控制黑微点。如果施法者通过检定，黑微点会在法师手中休眠一轮，积蓄力量。在此期间施法者不能做任何其他事情，因为必须全神贯注于黑微点。如果施法者在此期间集中被打断，黑微点会被驱散。一轮结束时，法术达到完全力量，黑微点可以被掷向法术射程内的一个生物。黑微点会自动击中目标，在黑暗与寒冷的爆发中爆炸，造成 2d6 点伤害，再加上施法者每个等级 1 点伤害。亡灵，以及来自负能量位面或下层外位面的生物，不受黑微点影响。

如果施法者未通过最初的对死亡魔法豁免检定，法师就会失去对微点的控制。它会立刻在施法者手中爆炸，造成 1 点伤害，并使法师麻痹 1d4 轮。材料成分是一小片取自亡灵骨骼的骨头。

<strong>解释／描述：</strong> 这是影响普通火焰术的更强版本，能让施法者迅速扑灭大火。施法时，会从灰烬准位面瞬间将反能量抽向火焰。每个施法者等级最多 10 英尺范围的非魔法火焰都能在短短一段内熄灭，因此此法术非常适合对付森林火灾和灌木火灾。对魔法火焰，此法术的效果较弱。扑灭魔法火焰的几率只有 60%，而且无论施法者等级如何，最多只能熄灭 10 码乘 10 码的区域。此法术对火焰生物或从生物身体喷出的火焰不起作用，例如火元素、火焰咕噜或 VI 型恶魔。材料成分是一小撮与盐混合的冷灰。
