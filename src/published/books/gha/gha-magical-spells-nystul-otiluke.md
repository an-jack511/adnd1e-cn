## Nystul 的法术

### Nystul 的黄金揭示术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 3 |
| 成分 | V、S、M |
| 射程 | 0 |
| 施法时间 | 3 段 |
| 持续时间 | 每等级 5 轮 |
| 豁免检定 | 无 |
| 作用范围 | 宽 30 英尺、长 60 英尺的锥体 |

<strong>解释／描述：</strong> 借助此法术，法师可以揭示锥形区域内隐藏、藏匿或隐形的生物。被藏匿的生物周围会被一道金色光环包围，光环以生物为中心直径 1 英尺向外发光，使其很容易被看见。法师可以在一轮内对该区域进行完整的 360 度扫视搜索。此法术可能揭示出躲在阴影中的盗贼、藏在自然地形中的野蛮人，或躲在障碍物后的生物。此法术会在区域内的隐形、错相、以太、二维或星界生物周围制造辉光，也会在使用精灵斗篷、混融长袍或变色龙之力戒指的生物周围制造辉光。不能针对受到黄金揭示术影响的目标进行豁免检定，尽管成功的魔法抗性可以保护生物，不被法术勾画出轮廓。材料成分是一只用蜡封羊皮纸包裹、内含萤光虫的盒子。

### Nystul 的辉光棱杖术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 3 |
| 成分 | V、S、M |
| 射程 | 0 |
| 施法时间 | 3 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 法师施放此法术时，会将一根由辉光准元素位面抽取的能量形成的细棱杖召唤到施法者手中。施法者可以选择让棱杖呈现彩虹七色中的任意一种。棱杖的攻击形式对应所选颜色，类似于辉光准元素生物的攻击，具体如下：

- <strong>红色棱杖：</strong> 寒冷能量（对火焰类生物 +1 点伤害；对寒冷类生物不造成伤害）。
- <strong>橙色棱杖：</strong> 热能（对寒冷类生物 +1 点伤害；对火焰类生物不造成伤害）。
- <strong>黄色棱杖：</strong> 酸性伤害（对法术进行豁免检定则不受伤害）。
- <strong>绿色棱杖：</strong> 中和毒素（如牧师法术）。
- <strong>蓝色棱杖：</strong> 电能（对金属护甲的敌人 +10 点伤害）。
- <strong>靛色棱杖：</strong> 亡灵专用（只有亡灵会受到伤害）。
- <strong>紫色棱杖：</strong> 植物专用（只有植物会受到伤害）。

棱杖命中时会造成基础 2d4 点伤害，再加上施法者每个等级 1 点伤害。伤害类型对应棱杖的颜色。棱杖颜色在施法时选择，此后不能改变。生物不能针对辉光棱杖的效果进行豁免检定。棱杖会自动击中在该近战轮成功击中施法者的任何生物；否则，施法者必须使用自己的 THAC0 来确定是否成功击中敌人。材料成分是一枚水晶棱镜（施法后会碎裂）和一组七根小型银棒。

### Nystul 的黑光爆发术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 每等级 10 码 |
| 施法时间 | 4 段 |
| 持续时间 | 瞬间 |
| 豁免检定 | 特殊 |
| 作用范围 | 半径 20 英尺的球体 |

<strong>解释／描述：</strong> 这个危险的法术会瞬间从负物质位面带来一股能量爆炸。作用范围内的生物每个施法者等级受到 1d4 点伤害；如果对死亡魔法的豁免检定成功，则只受到一半伤害。未通过豁免检定的受影响生物还会如同受到缓慢术影响一样，缓慢 1d4 轮。来自正物质位面或上层外位面的生物，每个施法者等级额外受到 1 点伤害，并且豁免检定以 −2 进行。这类生物若未通过豁免，还会被震慑 1d4 轮，而不是缓慢。法师总有 10% 的几率失去对法术的控制，此时作用范围内反弹的一道射线会击中施法者，使其受到法术攻击。亡灵永远不受此法术影响。材料成分是取自食尸鬼或食尸鬼王墓穴的一小块泥土。

### Nystul 的 Grue 召唤术（咒法／召唤系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 60 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 每等级 3 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术实际上是一组四个危险法术，会从四个元素位面之一召唤一只 grue——harginn、ildriss、chaggrin 或 varrdig：

| 元素位面 | 材料成分 |
| --- | --- |
| 空气 | 香 |
| 土 | 软黏土 |
| 火 | 硫磺 |
| 水 | 海水 |

想要召唤哪一种 grue，就必须使用对应的材料成分。召唤类型必须在施法者记忆法术之前决定。Grue 以不值得信任且难以控制而臭名昭著，因此施法者必须依靠的不只是集中精神，才能让 grue 服从命令。Grue 一被召唤，就会向施法者要求服务报酬。提供的报酬必须至少是价值 500 金币、且对 grue 有兴趣的物品，否则 grue 会被激怒并立即攻击施法者。如果 grue 对报酬满意，它会在法术持续期间勉强为施法者完成一项服务。如果 grue 觉得命令令人不快，它会设法破坏施法者的命令，或者公然违抗命令。

<strong>解释／描述：</strong> 此法术会在法师周围创造一个半径 20 英尺、无法穿透的黑暗区域。虽然施法者可以毫无困难地看见黑暗区域之内和穿过黑暗区域的东西，其他人却无法看穿这层包覆，甚至红外视觉或超视觉也不行。此外，球体内部还存在一种扭曲，看起来就像施法者拥有移位兽的移位能力。除了黑暗处罚外，施法者受到攻击时还会受到 −2 处罚。

Nystul 的瞬间日光术会抵消此法术。材料成分是一滴沥青、一根黑猫的胡须，以及一小撮移位兽皮毛。

<strong>解释／描述：</strong> 此法术会创造一道在施法者张开的双手之间拱起的闪烁彩虹光。一旦彩虹成形，施法者就可以从彩虹发射一道宽 1 英尺的射线，瞄准距离法师每等级 10 码以内的一个生物。射线可以呈现从辉光准位面抽取的七种能量颜色中的一种。

- <strong>红色：</strong> 寒冷能量（对火焰类生物 +1 点伤害；若目标是寒冷类则不造成伤害）。
- <strong>橙色：</strong> 热能（对寒冷类生物 +1 点伤害；若目标是火焰类则不造成伤害）。
- <strong>黄色：</strong> 酸性伤害（通过对法术的豁免检定则不受伤害）。
- <strong>绿色：</strong> 中和毒素（如牧师法术）。
- <strong>蓝色：</strong> 电能（对金属护甲的敌人 +10 点伤害）。
- <strong>靛色：</strong> 亡灵专用（只有亡灵会受到伤害）。
- <strong>紫色：</strong> 植物专用（只有植物会受到伤害）。

射线会造成每个施法者等级 1d6 点伤害，伤害类型与射线颜色相对应。如果生物通过豁免检定，只受到一半伤害。法师必须集中精神维持辉光拱门，因此任何打破施法者集中的攻击都会驱散彩虹，并阻止施法者发射射线。材料成分是一枚水晶棱镜（施法后会破碎）和一块中心钻有针孔的小黑板。

<strong>解释／描述：</strong> 此法术会创造一道闪烁的电能屏障，施法者可以将其塑造成墙、半球或直径 20 英尺的球体。它始终不可移动。任何穿过电屏的生物都会受到强烈震击。除非生物通过豁免检定，否则会受到 1d4 点伤害，因麻木而失去所有敏捷加值 1d4 + 1 轮，并在同样长的时间内承受 −2 命中处罚。通过豁免检定的生物不会受到伤害，也不会在敏捷上受到处罚，但会轻度麻木，并在 1d4 + 1 轮内以 −1 命中。穿着金属护甲的生物穿过屏障时以 −4 进行豁免检定。材料成分是一小撮毛、一根玻璃棒和一张精制水晶薄片，施法后全部消失。

### Otiluke 的剧痛屏障术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 6 |
| 成分 | V、S、M |
| 射程 | 每等级 5 码 |
| 施法时间 | 6 段 |
| 持续时间 | 每等级 3 轮 |
| 豁免检定 | 特殊 |
| 作用范围 | 每等级 20 英尺见方 |

<strong>解释／描述：</strong> 此法术会创造一道朦胧的灰色屏障，可以在指定尺寸内按施法者指挥塑造成墙、半球或球体。任何穿过这道屏障的生物都会受到影响，就像被瞬间传送到四个负准元素位面之一。屏障影响接触者的位面必须在记忆法术时选择。任何穿过剧痛屏障的生物都必须进行对死亡魔法的豁免检定。未通过者会被震慑 1d4 轮，并因震击和疼痛受到 4d4 点伤害。通过检定的生物在 1d4 轮内所有豁免检定受到 −1 处罚。

屏障可以模拟的四个位面及其特殊效果如下：

- <strong>真空：</strong> 震击由窒息造成。不需要呼吸的生物不受屏障影响。
- <strong>盐：</strong> 震击来自生物体内的水分被抽走。没有体液的生物不会受影响，例如魔像、亡灵或来自土、火、气元素位面的生物。
- <strong>灰烬：</strong> 震击由生物体温流失造成。亡灵和寒冷类生物不会受到屏障伤害。
- <strong>尘土：</strong> 震击由生物部分固体身体质量被驱散造成。气态或液态生物不会受到屏障伤害。
