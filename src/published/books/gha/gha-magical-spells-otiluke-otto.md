## Otiluke 的法术

### Otiluke 的容纳球术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 6 |
| 成分 | V、S、M |
| 射程 | 30 码 |
| 施法时间 | 1 轮 |
| 持续时间 | 特殊 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术用于为非常危险的物质创造一个实用容器。如果施法者拥有需要容纳的物体或物质，便可以施法创造一个直径 6 英寸的水晶球，最远出现在距离施法者 30 码处。水晶球会包围物体或半液态物质的一部分，并将其安全地容纳。球体内部拥有金刚钢的硬度，因此即便是最易挥发或最具腐蚀性的物质，也能被安全地装在其中。球内的时间被冻结，因此其中物质不会老化。球体不会被物理力量或大多数魔法攻击击碎，但解除魔法或解离术可以摧毁球体并释放其中内容物。

容纳球会存在一天，之后逐渐消失，释放其中内容物。如果在球体消失前再次施放此法术，法术会得到更新，球体会额外持续一天，而不会干扰其中内容物。材料成分是一颗封在玻璃中的价值 1,000 金币的钻石；施法时两者都会碎裂。

### Otiluke 的死亡屏障术（塑能系－变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 7 |
| 成分 | V、S、M |
| 射程 | 每等级 5 码 |
| 施法时间 | 7 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 特殊 |
| 作用范围 | 20 英尺见方 |

<strong>解释／描述：</strong> 此法术会创造一道灰色、雾蒙蒙的屏障，形状可由施法者决定。任何穿过屏障的生物都会突然发现自己被困在一个神秘的虚无空间区域中，受到从四个负准元素位面之一抽取的反能量影响。生物每被困一轮，就会失去当前生命值总量的 25%；如果生物无法逃脱，在第四轮结束时生命值降至 0。第五轮结束时，生物会以 −10 生命值死亡。生物每被困一轮，都有权进行一次对死亡魔法的豁免检定。成功意味着生物逃回主物质位面，从进入屏障的另一侧出来。逃脱豁免检定在第一轮以 −1 进行，第二轮 −2，第三轮 −3，第四轮 −4。

如果法术在生物逃脱或死亡前结束，生物会随着屏障消失而被释放到物质位面，就好像它自行逃脱了一样。重新出现在主物质位面的生物虽然受伤但仍活着，并会因从吸取生命的区域中恢复而晕眩 1d4 轮。被囚禁在区域中的生物可以自我治疗并使用其他魔法，但除非为该区域进行豁免检定，否则无法逃脱。材料成分是一张铅水晶薄片、一撮取自吸血鬼棺材的泥土，以及一个中空球体（用于真空）。

### Otiluke 的火冰双球术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 7 |
| 成分 | V、S、M |
| 射程 | 50 码 |
| 施法时间 | 7 段 |
| 持续时间 | 瞬间 |
| 豁免检定 | 特殊 |
| 作用范围 | 半径 30 英尺的球体 |

<strong>解释／描述：</strong> 施法时，一枚红色水晶球会立即出现在施法者面前，然后以极快速度飞向选定的区域。过了短短一瞬，一枚蓝色水晶球出现并迅速跟在红球后面。红球到达施法者选择的区域时，会以半径 30 英尺的火球爆炸，使作用范围内所有生物受到 4d4 点火焰伤害。成功的豁免检定会使伤害减半。短短一瞬之后，蓝球在相同作用范围内爆炸，对半径 30 英尺内的一切造成 4d4 点寒冷伤害。通过火焰豁免检定者也只受到寒冷爆炸一半伤害，但未通过者承受寒冷的全部伤害。

这一前后攻击组合对无生命物体的最大效果，是温度剧烈变化造成的巨大震击。作用范围内的所有物品都必须像非魔法物品一样进行豁免检定。豁免失败很可能会使材料裂开或碎裂。材料成分是一小撮磷和一颗小型石英水晶。

### Otiluke 的攻城球术（塑能系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 7 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 1 轮 |
| 持续时间 | 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 特殊 |

<strong>解释／描述：</strong> 此法术会创造一个大如巨石的力场球体，可以由投石机发射。攻城球会持续完整一轮后消失，因此必须在施法后一轮内发射。攻城球可以采取几种不同的形态，创造哪种球体必须在记忆法术时决定。攻城球在发射前坚硬如金刚钢，只能被一个祈愿、解除魔法或解离术摧毁。球体发射后会根据攻击类型采取不同形态。不论攻击采取哪种形态，攻城球在完成攻击后都会被驱散。不同类型的攻城球如下：

<strong>液态火焰：</strong> 攻城球击中目标时会立即碎裂，在半径 30 英尺的区域喷洒大量液态火焰。作用范围内所有可燃物都会被点燃。被液态火焰击中的生物，如果火焰没有被扑灭或燃烧的液体没有被冲洗掉，就会在 2d6 轮内每轮受到 2d4 点伤害。此形态的材料成分是一滴沥青、一点磷和一撮钻石尘。

<strong>水晶碎片：</strong> 攻城球会在地面上方 30 英尺处裂成碎片，在半径 20 英尺的圆形区域内降下水晶碎片。受影响区域内的每个生物都会受到 5d6 点伤害，不论其护甲等级如何。材料成分是一小批锋利的钻石薄片。

<strong>破城球：</strong> 接近目标时，球体的密度会剧烈增加，因此其撞击力（及伤害）达到重型投石机的三倍。材料成分是一块磁石和一撮钻石尘。

## Otto 的法术

| 施法时间 | 1 段 |

<strong>解释／描述：</strong> 此法术施放时，会响起一道精致的钟声，其震动会释放束缚单个生物或人物的任何非魔法束缚。钟声会解开绳子、松开链条和镣铐、解开皮带、解开口塞，或打开木枷。此法术甚至可以用来解开马匹的衔铁和缰绳，使坐骑摆脱骑手的直接控制。材料成分是一只小型黄铜管钟，施法后会消失。

<strong>12 级施法者——两名轻骑兵（如果有足够空间容纳马匹）：</strong> AC 6（环甲）；移动 12”；HD 3+2；hp 23；#AT 2 或 1（复合短弓或宽刃剑）；伤害 1d6 或 2d4（箭或宽刃剑）；THAC0 16；AL N。他们骑乘轻型战马：AC 6（皮革马铠）；移动 21”；HD 2；hp 14；#AT 2；伤害 1d4／1d4；THAC0 16；AL N。

<strong>14 级施法者——两名步行骑士：</strong> AC 2（板甲和大型盾牌）；移动 6”；HD 4+2；hp 30；#AT 1；伤害 1d10 + 3；THAC0 15；AL N。

材料成分是这对工艺价值 100 金币的士兵，以及一只价值 50 金币的微型黄铜号角；施法后都会消失。

| 豁免检定 | 否定 |
| 作用范围 | 一个生物 |

<strong>解释／描述：</strong> 此法术施放在一个生物身上时，一阵极其响亮、令人麻木的钟声会充满其心智。如果生物以 −2 进行豁免检定并成功，生物只会被震慑一轮。但如果豁免失败，生物会失去所有正常感官输入。生物无法看、听、感觉、尝或闻，实际上变得无助。如果生物参与近战，所有攻击都以 −6 命中，但生物不知道自己在攻击什么，甚至不知道攻击是否成功。仍然可以与生物进行心灵感应沟通，生物也可能通过这种联系获得有关世界的信息。一个祈愿术、治疗术或复原术会完全治愈这种状态。材料成分是一只微型金钟和一根微型金击槌，击槌头部是一块玉石；两者在材料与工艺上的总价值为 7,000 金币，施法后会消失。
