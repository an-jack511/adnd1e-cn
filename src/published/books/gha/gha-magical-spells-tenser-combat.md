## Tenser 的法术

### Tenser 的燃焰之刃术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 2” |
| 施法时间 | 4 段 |
| 持续时间 | 3 轮 + 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 一把匕首 |

<strong>解释／描述：</strong> 此法术会赋予一把匕首火焰或寒霜的力量，由施法者选择。每种力量的效果如下。

<strong>火焰：</strong> 刀刃会像火炬一样点燃，照亮半径 30 英尺的区域。火焰会点燃刀刃接触的任何可燃物。刀刃不获得魔法加值，但在近战中会额外造成 1 点伤害。刀刃对寒冷类生物额外造成 3 点伤害，因此燃焰匕首对雪怪会造成 1d4 + 3 点近战伤害。

<strong>寒霜：</strong> 刀刃会发出冷蓝色光环，照亮半径 10 英尺的区域。刀刃没有魔法加值，但命中时会额外造成 1 点伤害。寒霜刀刃对火焰类生物（例如 salamander 或火焰 grue）额外造成 3 点伤害。刀刃接触水时，还能每轮冻结最多 1 立方英尺的水。

此法术对已经拥有火焰或寒霜能力的武器无效。法术材料成分是用于制造燃焰之刃的磷，或用于制造寒霜之刃的石英水晶。

### Tenser 的巨力术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 1 轮 |
| 持续时间 | 每等级 3 轮 |
| 豁免检定 | 无 |
| 作用范围 | 被接触的人物 |

<strong>解释／描述：</strong> 这是力量术的改进版本，会以超人类的体能强化接受者。获得的力量取决于施法者的经验等级，如下表所示：

| 法师等级 | 力量提高至 |
| --- | --- |
| 7 级 | 16 |
| 9 级 | 17 |
| 12 级 | 18／01 |
| 13 级 | 18／75 |
| 14 级 | 18／90 |
| 15 级 | 18／00 |
| 16 级及以上 | 19 |

力量已经高于法术效果的生物，会再获得 1 点力量。永久术或祈愿术都不能使力量永久保持。材料成分是取自巨人或泰坦的一小撮毛发。

### Tenser 的武器大师术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 4 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 被接触的战士（仅战士） |

<strong>解释／描述：</strong> 此法术赐予战士时，会提高战士使用一种近战武器的技能。战士不熟练的武器，在该人物手中会变成一项熟练武器。熟练武器会被视为专精武器。此法术效果不允许双武器专精。法术只影响战士和战士子职业人物。武器大师术的材料成分是一根鹤羽。

### Tenser 的奔行战士术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 60 码 |
| 施法时间 | 4 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 一个人 |

<strong>解释／描述：</strong> 此法术会提高人物在奔跑战斗中的能力。首先，无论人物身上护甲或携带物品的负重如何，移动速度都被赋予 150 码。其次，无论人物在一个近战轮中移动多远，仍有权进行通常数量的近战攻击。如果人物原本每轮可以攻击 2/1 次，那么战士现在可以移动 60 码、攻击一个敌人、再移动 90 码并攻击第二个生物。材料成分是一小撮活狼的毛。

### Tenser 的重击法杖术（变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 4 |
| 成分 | V、S、M |
| 射程 | 0 |
| 施法时间 | 4 段 |
| 持续时间 | 每等级 2 轮 |
| 豁免检定 | 无 |
| 作用范围 | 法师的法杖 |

<strong>解释／描述：</strong> 此法术会提高施法者用法杖进行近战时的效力。此法术只对非魔法法杖有效。它使命中获得 +1 加值，伤害骰获得 +4 加值。材料成分是一根小铁棒。

### Tenser 的原始狂怒术（附魔系／变化系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 5 |
| 成分 | V、S、M |
| 射程 | 20 码 |
| 施法时间 | 5 段 |
| 持续时间 | 每等级 1 轮 |
| 豁免检定 | 无 |
| 作用范围 | 一个人（仅战士） |

<strong>解释／描述：</strong> 此法术会暂时赋予战士一股与狂战士相当的愤怒和能量。魔法恐惧不会影响被激怒的战士。战士在攻击和伤害骰上获得 +2 加值，并且每隔一个近战轮获得一次额外攻击，因此 3/2 的攻击序列会变成 2/1。战士还会暂时获得额外 4d4 点生命值；任何伤害都会先从这部分生命值中扣除，然后才减少角色永久生命值总量。不过，此法术也有风险，因为狂战士的愤怒会在法术整个持续期间保持。如果战士的所有对手都在法术结束前被击败，狂暴战士会转而攻击最近的活着生物，在法术结束前不分敌友地持续攻击。解除魔法会立即使狂暴战士恢复正常状态。材料成分是取自狼獾或灰熊的一小撮毛。

### Tenser 的战争福运术（防护系）

| 项目 | 数据 |
| --- | --- |
| 等级 | 6 |
| 成分 | V、S、M |
| 射程 | 接触 |
| 施法时间 | 1 轮 |
| 持续时间 | 特殊 |
| 豁免检定 | 无 |
| 作用范围 | 被接触的人物（仅战士） |

<strong>解释／描述：</strong> 此法术会赋予一名战士在战斗中的特殊幸运加值。战士获得一次机会，避免任何会将其生命值降到 0 或更低的攻击；也能避免任何会以石化、麻痹、石化术、睡眠、魅惑、恐惧、解离、死亡、死亡之词或其他魔法效果将战士移出战斗的魔法。即使先前的豁免检定失败，战士仍有权进行一次豁免检定来避免失败。战士必须以 −2 进行对死亡魔法的豁免检定。如果检定成功，战士就奇迹般地避免失败。正常会将战士生命值降至 0 或更低的伤害攻击，会改为将战士生命值总量降至当前值的一半；也就是说，一个拥有 17 点生命值的战士受到 17 点伤害时，会降到 9 点生命值。任何其他会造成即时失败的攻击，只要死亡魔法豁免检定成功，就不会产生效果。不论豁免检定结果如何，战争福运术都会在攻击后立即被驱散。

材料成分是献给战士守护战神的贵重祭品，必须是神祇感兴趣的物品，价值至少 5,000 金币。
