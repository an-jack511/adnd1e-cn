下表列出三种熊：黑熊、棕熊与穴熊。

| 项目 | 黑熊 | 棕熊 | 穴熊 |
|---|---:|---:|---:|
| 出现频率 | 常见 | 不常见 | 不常见 |
| 出现数量 | 1–3 | 1–6 | 1–2 |
| 护甲等级 | 7 | 6 | 6 |
| 移动力 | 12 寸 | 12 寸 | 12 寸 |
| 生命骰 | 3+3 | 5+5 | 6+6 |
| 在巢穴概率 | 无 | 无 | 无 |
| 财宝类型 | 无 | 无 | 无 |
| 攻击次数 | 3 | 3 | 3 |
| 攻击伤害 | 1–3／1–3／1–6 | 1–6／1–6／1–8 | 1–8／1–8／1–12 |
| 特殊攻击 | 抱住：2–8 | 抱住：2–12 | 抱住：2–16 |
| 特殊防御 | 无 | 无 | 无 |
| 魔法抗力 | 标准 | 标准 | 标准 |
| 智力 | 半智慧 | 半智慧 | 半智慧 |
| 阵营 | 中立 | 中立 | 中立 |
| 体型 | M（高 6 尺） | L（高 9 尺） | L（高 12 尺） |
| 灵能能力 | 无；攻击／防御模式：无 | 无；攻击／防御模式：无 | 无；攻击／防御模式：无 |

这些熊类都是杂食动物，不过体型巨大的穴熊更偏好肉食。它们的听觉和嗅觉都很灵敏，视力则相当差。表中体型是各品种的平均值；个体若更大，力量也相应更强。灰熊属于性情极为凶猛的棕熊。黑熊通常不具攻击性，棕熊具有攻击性，而穴熊则十分凶猛。

若熊以爪击命中时掷出 18 或更高，它还会抱住对手，并造成表中所列的额外伤害。棕熊与穴熊在生命值降至 0 至 −8 点后，仍会继续战斗 1–4 轮；受到 −9 点或更多伤害时，则会立即死亡。
