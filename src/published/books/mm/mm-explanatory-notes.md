“怪物”一词在本书中有两种用法。最重要的一种，是指遭遇到的任何生物——无论敌对与否，也无论是人类、类人生物还是野兽。在遭遇一方辨明眼前所为何物之前，它就是一个“怪物”。第二种用法则沿用通常含义，指某种可怕或邪恶的生物。例如，地下城探险中遇到一个“怪物”，最后发现那是一名邪恶的大祭司；而他也可能同时符合另一种意义上的“怪物”。不过，尽管本书如此用词，人类及其近亲（矮人、精灵、侏儒、半精灵与半身人）攻击时始终使用人类命中矩阵，即使他们在冒险中是以“怪物”身份遭遇的。

**出现频率 Frequency。**表示某种生物在其可能栖居的地区或区域出现的可能性。“极罕见”表示 **4%**，“罕见”表示 **11%**，“不常见”表示 **20%**，“常见”表示 **65%**。这些概率用于《高级龙与地下城》《地下城主指南》中的遭遇矩阵。

**出现数量 Number Appearing。**表示该生物较常见的数量范围，仅作指引；应根据具体冒险情况调整。通常不建议用此数值来确定地下城层级中的种群数量。

**护甲等级 Armor Class。**表示人类或类人生物所穿防护装备的类型；也可能来自生物自身的体格结构或魔法本质，或反映其速度、反应等因素造成的命中难度。

**移动力 Movement。**表示生物在地面、空中或水中的速度；在没有特别说明时，以每一轮可移动的距离表示。

**生命骰 Hit Dice。**表示生物拥有的生命骰数量及可能的加值。生命骰通常用 **d8** 掷出；如有加值，则加在掷骰结果上。生命骰为 **1–1** 或 **1–2** 等情况，表示其命中点数少于完整一个生命骰所能产生的数值。

**在巢穴概率 % In Lair。**表示遭遇发生在怪物居所及其储藏财宝地点的概率（若该生物拥有财宝）。若怪物不在巢穴中，它不会持有财宝，除非条目注明有“个体财宝”或携带某种魔法物品。遭遇是否发生在巢穴中，参与者可能要到遭遇解决后才会知道。

**财宝类型 Treasure Type。**指向列有该怪物可能拥有之财物参数的表格。若注明个体财宝，每只此类怪物都可能携带所列财宝；否则，只能在其巢穴中找到财宝。遭遇虽发生于巢穴且怪物有财宝类型，也不意味着冒险者必定能获得财物：许多类型规定了各种财物出现的概率，掷骰结果也可能显示某类财物并不存在。财宝类型基于平均出现数量与该怪物条目中的调整值；遭遇数量较少时应向下调整，远多于平均值时则可略微向上调整。地下城中由生物守护的财物通常不建议用财宝类型决定。某类财宝数量较大时会用括号中的倍数表示（如 **×10**），不要与财宝类型 X 混淆。

**攻击次数 Number of Attacks。**表示该生物每轮可进行的基本攻击次数。

**攻击伤害 Damage/Attack。**表示每种攻击造成的伤害。分隔号表示不同攻击分别造成的伤害；括号内的说明可能对应特殊攻击或不同目标。

**特殊攻击 Special Attacks、特殊防御 Special Defenses。**列出超出普通攻击或防御方式的能力；若无则记为“无”。

**魔法抗力 Magic Resistance。**对具有魔法抗力的怪物施放法术时，应按其抗力百分比判断法术能否生效。即便法术生效，怪物通常仍可进行正常豁免检定。魔法抗力也可能影响某些已经存在的法术，例如“封门术”：抗力说明怪物打破该法术的概率。

**智力 Intelligence。**表示大致相当于人类“智商”的基础智力评级。某些怪物天生或凭其他方式十分狡猾，条目会另行说明。评级大致如下：

| 评级 | 智力水平 |
|---:|---|
| 0 | 无智力或无法评级 |
| 1 | 动物智力 |
| 2–4 | 半智能 |
| 5–7 | 低 |
| 8–10 | 一般（人类） |
| 11–12 | 非常聪明 |
| 13–14 | 高度聪明 |
| 15–16 | 极其聪明 |
| 17–18 | 天才 |
| 19–20 | 超级天才 |
| 21+ | 神级智力 |

**阵营 Alignment。**表示怪物偏向守序、混乱、善良、邪恶或中立的特征，也可能受善恶意图影响。遭遇时判定怪物的一般行为，这项信息很重要。

**体型 Size。**“S”表示小于一般人类；“M”表示约为人类大小（身高 **5–7 尺**、体格大致相当）；“L”表示至少在某一方面大于人类，通常体重也更大。

**灵能能力 Psionic Ability 与攻击／防御模式 Attack/Defense Modes。**表示怪物在灵能方面的一般能力（如有）。必要时会配有怪物草图。各怪物的详细信息紧接上述数据栏列出。
