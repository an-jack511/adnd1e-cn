## 巨型章鱼 Octopus, Giant

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–3 |
| 护甲等级 | 7 |
| 移动力 | 3 寸／12 寸 |
| 生命骰 | 8 |
| 在巢穴概率 | 70% |
| 财宝类型 | R |
| 攻击次数 | 7 次 |
| 攻击伤害 | 1–4（×6）／2–12 |
| 特殊攻击 | 缠绕 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 标准 |

巨型章鱼栖息在温暖的中浅水域。它们以沉船与海底洞穴为巢穴，在夜间捕猎，抓住并吞食任何易受攻击的生命。它们会毫不犹豫地攻击游泳者，或抓住小船以便吞食船员。这些生物恶毒而狡诈；如果有机会，几只巨型章鱼会合作制服更大的船只。被巨型章鱼抓住的船只会失去航向，并在 <strong>3 轮</strong>内完全停下。

巨型章鱼通常会用 <strong>8 条触手中的 6 条</strong>攻击，同时用另外的触手固定自己。每条触手初次击打只造成 <strong>1–4 点</strong>伤害；但除非该肢体被松开或斩断，否则从之后的每个近战轮开始，都会造成初始伤害的两倍（<strong>2–8 点</strong>）。章鱼还有一张凶猛的喙，能够咬击附近的猎物，造成 <strong>2–12 点</strong>伤害。

除非目标身高或身长超过约 <strong>8 尺</strong>，否则它一次只会用一条触手击中该生物。被触手击中的生物有 <strong>25%</strong> 的概率被钳住上肢，也有 <strong>25%</strong> 的概率两条上肢都不会被抓住。若两条上肢都被钳住，生物无法用它们攻击；若只有一条上肢被钳住，攻击“命中”骰受到 <strong>−3</strong> 调整；若两条上肢都自由，攻击只受到 <strong>−1</strong> 调整。触手抓握力相当于 <strong>18/20</strong>，任何力量达到或超过 <strong>18/20</strong> 的生物都能抓住触手并抵消其缠绕；但这不会使该生物获释，章鱼会立即试图把受害者拖到嘴边吞食。要挣脱，必须斩断一条触手。每条触手需要承受 <strong>8 点</strong>生命值伤害才能断裂；这还要另外加上章鱼本身拥有的 <strong>8 个生命骰</strong>。

如果有 <strong>3 条或更多</strong>触手被斩断，章鱼有 <strong>90%</strong> 的概率会撤退，同时喷出一团黑色墨汁，高 <strong>4 寸</strong>、宽 <strong>6 寸</strong>、长 <strong>6 寸</strong>。之后章鱼会逃回巢穴，或躲到附近的其他地方，并改变颜色来融入周围环境。墨汁云会完全遮蔽其中任何生物的视线。
