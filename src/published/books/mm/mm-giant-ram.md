## 巨型公羊 Ram, Giant

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 2–8 |
| 护甲等级 | 6 |
| 移动力 | 15 寸 |
| 生命骰 | 4 |
| 在巢穴概率 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–12 |
| 特殊攻击 | 冲锋 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | L（肩高 6 尺） |
| 灵能能力 | 无；攻击／防御模式：无 |

巨型绵羊只出现在丘陵或山区。所有成年个体，无论雄性还是雌性，都遵循上述数据。不过雄性（巨型公羊）会冲锋攻击，以双倍于上列伤害参数的头槌发动攻击。这些动物通常并不具攻击性，但如果认为羊群受到威胁，就会战斗到死来保护羊群。

一个羊群由一只公羊、四只母羊和其余数量的羔羊组成（掷百分骰决定羊群规模，将骰值减半后再加上 <strong>50%</strong>）。
