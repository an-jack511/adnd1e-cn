## 巨型蝎 Scorpion, Giant

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–4 |
| 护甲等级 | 3 |
| 移动力 | 15 寸 |
| 生命骰 | 5+5 |
| 在巢穴概率 | 50% |
| 财宝类型 | D |
| 攻击次数 | 3 次 |
| 攻击伤害 | 1–10／1–10／1–4 |
| 特殊攻击 | 毒刺 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无；攻击／防御模式：无 |

巨型蝎是凶猛的捕食者；由于这些变异体适应力强，即使在地城等相对寒冷的地方也很可能遇到它们。它们很可能攻击任何接近的生物。怪物会用巨大的钳子抓住猎物，同时用分节的尾巴向前挥刺，用毒液将受害者杀死。后者每次命中造成 <strong>1–4 点</strong>伤害；若受害者未通过对抗毒素的豁免检定，就会立即死亡。巨型蝎一次最多能与 <strong>3 个</strong>对手战斗。

注意，若蝎子不慎刺中自己，其毒液也会杀死自己。被杀死的生物会被拖回巨型蝎巢穴中吃掉。
