## 巨型乌贼 Squid, Giant

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1 |
| 护甲等级 | 身体 3；头部与触手 7 |
| 移动力 | 3 寸／18 寸 |
| 生命骰 | 12 |
| 在巢穴概率 | 40% |
| 财宝类型 | A |
| 攻击次数 | 9 次 |
| 攻击伤害 | 1–6（×8）／5–20 |
| 特殊攻击 | 缠绕 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 标准 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | L |
| 灵能能力 | 无；攻击／防御模式：无 |

巨型乌贼栖息在深水中，偏好半英里或更深的水域。它们是好斗的猎手，偶尔会浮出水面攻击大型猎物——攻击经过巨型乌贼上方船只的概率为 <strong>10%</strong>。它们只害怕最大的抹香鲸，因为后者会捕猎巨型乌贼并轻易杀死它们。

巨型乌贼的身体由硬壳保护，因此身体护甲等级为 3，但触手与头部护甲等级为 7。如果感到受到威胁，生物能够以极快速度向后喷射。

巨型乌贼攻击时会用两条触手固定或稳定自己，再用另外 <strong>8 条</strong>触手攻击。每条触手在首次命中所在的近战轮造成 <strong>1–6 点</strong>生命值伤害，之后每个近战轮都会缠绕对手，造成 <strong>2–12 点</strong>伤害。要阻止缠绕，受害者必须斩断触手；除斩断触手或杀死乌贼外，没有办法松开抓握。巨型乌贼巨大的喙咬击造成 <strong>5–20 点</strong>伤害。

被巨型乌贼抓住的生物有 <strong>25%</strong> 的概率两条上肢都被钳住，<strong>50%</strong> 的概率一条被钳住，<strong>25%</strong> 的概率两条都自由。若两条上肢都被钳住，受害者完全无法用它们攻击；若一条被钳住，攻击“命中”骰受到 <strong>−3</strong> 调整；若两条都自由，攻击者只能受到 <strong>−1</strong> 调整。一次只有一条触手会击中人形大小的生物。乌贼的一条触手需要承受 <strong>10 点</strong>生命值伤害才能斩断，而且这还要加在巨型乌贼能够承受的 <strong>12 个生命骰</strong>伤害之外。

如果巨型乌贼有 <strong>4 条或更多</strong>手臂被斩断（或以其他方式失去），它有 <strong>80%</strong> 的概率喷出一团黑色墨汁，高 <strong>6 寸</strong>、长 <strong>8 寸</strong>，并向后喷射逃跑。此时乌贼总会回到巢穴。墨汁云会完全遮蔽其中所有生物的视线。

巨型乌贼总会设法把猎物拖入水下。除非船只很小，否则被巨型乌贼抓住的船不太可能被拖入水下，但会因拖拽在 <strong>1 轮</strong>内停在水中。若船被 <strong>8 条或更多</strong>触手抓住并固定，就会像遭到撞击一样受损；货舱进水的船很容易被拖入乌贼巢穴。
