## 尼克希 Nixie

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 20–80 |
| 护甲等级 | 7 |
| 移动力 | 6 寸／7 寸／12 寸 |
| 生命骰 | 1–4 点生命值 |
| 在巢穴概率 | 95% |
| 财宝类型 | C、Q |
| 攻击次数 | 1 次 |
| 攻击伤害 | 按武器类型 |
| 特殊攻击 | 魅惑 |
| 特殊防御 | 无 |
| 魔法抗力 | 25% |
| 智力 | 极高 |
| 阵营 | 中立 |
| 体型 | S（高 4 尺） |
| 灵能能力 | 无；攻击／防御模式：无 |

尼克希是栖息于湖泊中的水精灵。它们能够上岸，但很少这样做。尼克希用活海草编织住所，因此在距离不足 <strong>2 寸</strong>的地方，巢穴仍有 <strong>95%</strong> 的概率不会被发现。此外，尼克希会让巨型鱼守卫巢穴——<strong>1–2 条雀鳝（20%）</strong>或 <strong>2–5 条狗鱼（80%）</strong>——它们会服从尼克希发出的简单命令。尼克希还能够召来 <strong>10–100 条</strong>小鱼。

尼克希喜欢奴役人类；如果一个或多个生物接近一群尼克希 <strong>30 尺</strong>以内，后者就会生成强力的魅惑法术，每 <strong>10 个尼克希</strong>产生一个这样的法术；受害者必须以 <strong>−2</strong> 调整后的骰值通过对抗魔法的豁免检定。如果被魅惑者在入水前受到驱散魔法法术影响，魅惑有 <strong>75%</strong> 的概率被解除，但一旦进入水中，解除概率只有 <strong>10%</strong>。若人类被尼克希魅惑，尼克希会将受害者带回巢穴奴役整整 <strong>1 年</strong>；之后魅惑消退，受害者获准自由离去。在这段奴役期间，尼克希会持续对人类俘虏施加水下呼吸法术。每个尼克希每天能够对任意生物施放一次水下呼吸法术，或每天解除一次该法术；法术持续 <strong>1 天</strong>。

尼克希装备长匕首与飞镖（标枪）。后者在水下作为矛使用，在水面上方则作为投射物使用。每个尼克希各携带一把这两种武器。标枪最多可投掷 <strong>6 寸</strong>（短距离为 <strong>1 寸</strong>，中距离为 <strong>3 寸</strong>，依此类推）。

虽然尼克希有 <strong>25%</strong> 的魔法抗力，但它们害怕火焰与极强的光。一把燃烧之剑或一道光亮法术就能将尼克希逼退。持续光亮法术能够让它们一直退避，直到它们通过召来小鱼聚集在光源周围、使光线变暗来抵消法术。

尼克希会说自己的语言和通用语。

<strong>外观：</strong>尼克希看起来是非常漂亮的人形生物，皮肤带绿色，头发深绿，双眼银色。它们的皮肤覆有细鳞，手脚有蹼。
