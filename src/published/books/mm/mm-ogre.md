## 食人魔 Ogre

| 项目 | 数据 |
|---|---|
| 出现频率 | 常见 |
| 出现数量 | 2–20 |
| 护甲等级 | 5 |
| 移动力 | 9 寸 |
| 生命骰 | 4+1 |
| 在巢穴概率 | 20% |
| 财宝类型 | 个体：M（×10）、Q、B；巢穴：S |
| 攻击次数 | 1 次 |
| 攻击伤害 | 1–10，或按武器类型 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 低 |
| 阵营 | 混乱邪恶 |
| 体型 | L（高 9 尺以上） |
| 灵能能力 | 无；攻击／防御模式：无 |

食人魔几乎可以出现在任何地形，包括地下场所。它们脾气丑恶，且贪婪暴食。食人魔也喜爱财宝，有时会在兽人部落或邪恶牧师的队伍中充当雇佣兵，也会与豺狼人结盟发动有利可图的袭击。食人魔与巨魔和某些巨人相处融洽，有时还会被某些恶魔奴役。

若遇到 <strong>11 名或更多</strong>食人魔，其中必有一名首领（护甲等级 3、<strong>30–33 点</strong>生命值，按 <strong>7 个生命骰</strong>生物进行攻击，每次攻击造成 <strong>2–12 点</strong>伤害）。若遇到 <strong>16 名或更多</strong>，则会有两名这样的首领，另加一名食人魔酋长；酋长护甲等级 4，生命值 <strong>34–37 点</strong>，按 <strong>7 个生命骰</strong>怪物攻击，每次攻击造成 <strong>4–14 点</strong>伤害。

（若用武器类型决定攻击伤害，则给予食人魔 <strong>+2 点</strong>标准加值；首领／酋长再分别获得额外的 <strong>+1／+2</strong> 加值。）

若在食人魔巢穴中发现它们，巢穴内会有 <strong>2–12 名</strong>雌性；她们像普通食人魔一样战斗，但每次只造成 <strong>2–8 点</strong>伤害，且每个生命骰最多只有 <strong>6 点</strong>生命值。还会有 <strong>2–8 名</strong>幼崽，它们会像地精一样战斗。食人魔会抓俘虏，将其当作奴隶（25%）或食物（75%），因此食人魔巢穴有 <strong>30%</strong> 的概率包含 <strong>2–8 名</strong>奴隶／俘虏。它们非常喜欢半身人、矮人或精灵的肉，因此只有 <strong>10%</strong> 的概率能在食人魔巢穴中发现仍然活着的这类生物。

食人魔会说自己的语言，以及混乱邪恶阵营、兽人、巨魔和石巨人的语言。

<strong>外观：</strong>食人魔的皮肤从暗淡的黑褐色到死黄不等。罕见个体呈病态紫色。它们疣状的隆起通常颜色不同，或至少比皮肤更深。头发从黑蓝色到暗深绿色不等。双眼紫色，瞳孔白色。牙齿和爪子或为黑色，或为橙色。食人魔穿戴各种皮革或毛皮；它们对手臂与护甲的保养尚可。食人魔的寿命不短于 <strong>90 年</strong>。
