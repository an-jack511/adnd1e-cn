## 兽人 Orc

| 项目 | 数据 |
|---|---|
| 出现频率 | 常见 |
| 出现数量 | 30–300 |
| 护甲等级 | 6 |
| 移动力 | 9 寸 |
| 生命骰 | 1 |
| 在巢穴概率 | 35% |
| 财宝类型 | 个体：L；巢穴：C、O、Q（×10）、S |
| 攻击次数 | 1 次 |
| 攻击伤害 | 1–8，或按武器类型 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 普通（低） |
| 阵营 | 守序邪恶 |
| 体型 | M（高 6 尺以上） |
| 灵能能力 | 无；攻击／防御模式：无 |

兽人部落之间竞争极其激烈，彼此相遇时有 <strong>75%</strong> 的概率互相战斗，除非现场有一名强力首领（例如巫师、邪恶牧师或邪恶领主）并带着足够的力量控制兽人。兽人是恃强凌弱者，强者总会恐吓并支配弱者。（例如，如果附近有地精，而兽人足够强，它们就会乐于欺凌地精。）兽人居住在阳光昏暗或根本不存在的地方，因为它们憎恨光线。在完整的日光下，它们的攻击骰必须减 <strong>1</strong>，但即使在完全黑暗中也能看得很好（红外视觉）。

已知的兽人部落包括：邪恶符文、血首、死亡之月、断骨、邪眼、麻风之手、腐眼、滴血之刃。如果在某地区遇到来自其中一个部落的兽人，那么附近其他兽人很可能也属于这个部落。

每遇到 <strong>30 名</strong>兽人，就会有一名首领和 <strong>3 名</strong>助手。这些兽人每人有 <strong>8 点</strong>生命值（因为他们是群体中最大、最强、最凶恶的成员）。若遇到 <strong>150 名或更多</strong>兽人，队伍中还会增加一名副首领和 <strong>3–18 名</strong>卫兵；每人的护甲等级为 4、生命值为 <strong>11 点</strong>，并按 <strong>2 个生命骰</strong>的怪物战斗（造成 <strong>2–7 点</strong>伤害）。若兽人不在巢穴中，它们有 <strong>20%</strong> 的概率会护送一列 <strong>1–6 辆</strong>货车与 <strong>10–60 名</strong>奴隶搬运工，将补给和战利品运给首领或更强大的兽人部落。货车装载价值 <strong>10–1,000 金币</strong>的货物，每名奴隶携带价值 <strong>5–30 金币</strong>的货物。若出现这类运输队，首领与助手的数量加倍，每辆货车增加 <strong>10 名</strong>普通兽人，并且运输队中必定有一名副首领及 <strong>5–30 名</strong>卫兵负责指挥。

兽人巢穴有 <strong>75%</strong> 位于地下，<strong>25%</strong> 是地面村落。若在兽人巢穴中遭遇它们，则总会有以下额外兽人：一名首领和 <strong>5–30 名</strong>贴身卫兵（护甲等级 4、生命值 <strong>13–16 点</strong>，按 <strong>3 个生命骰</strong>的怪物攻击，造成 <strong>2–8 点</strong>伤害）；雌性数量等于雄性数量的 <strong>50%</strong>；幼崽数量等于雄性数量的 <strong>100%</strong>。若巢穴位于地下，则有 <strong>50%</strong> 的概率会有 <strong>2–5 名</strong>食人魔与兽人同住。若巢穴位于地面，则会是一座由木屋组成的简陋村落，外有壕沟、土垒和木栅栏保护。村落有 <strong>1–4 座</strong>瞭望塔和一道大门。每 <strong>100 名</strong>成年雄性兽人（取最接近的整百数）配有 <strong>1 架</strong>投石机和 <strong>1 架</strong>弩炮。

兽人的典型武器配备如下：

| 武器 | 比例 |
|---|---:|
| 剑与连枷 | 5% |
| 剑与矛 | 10% |
| 斧与矛 | 10% |
| 斧与长柄武器 | 10% |
| 斧与弩 | 10% |
| 斧与弓 | 10% |
| 剑与战斧 | 5% |
| 矛 | 10% |
| 斧 | 10% |
| 长柄武器 | 20% |

首领及更高等级的兽人总会拥有两件武器。如果队伍中有副首领，那么 <strong>40%</strong> 的概率会带有部落军旗；只要部落首领在场，军旗就必定在场。军旗会使 <strong>6 寸</strong>范围内的所有兽人战斗得更加凶猛（命中骰和士气检定骰均 <strong>+1</strong>）。

兽人残酷而普遍憎恨生物，但它们尤其憎恨精灵，总会优先攻击精灵而不是其他生物。它们抓捕奴隶，用于劳动、食物和娱乐（折磨等），但不会奴役精灵，因为它们会立即杀死精灵。

兽人是出色的挖掘者与矿工。它们在地下工程中有 <strong>35%</strong> 的概率注意到新的或不寻常的建造，并有 <strong>25%</strong> 的概率发现倾斜的通道。

大多数兽人除兽人语与守序邪恶阵营的语言外，还会说地精、大地精和食人魔的语言。

<strong>外观：</strong>兽人的外貌尤其令人厌恶，因为它们的肤色——带蓝色光泽的棕色或棕绿色——衬托出粉红色的鼻子与耳朵。它们的粗硬毛发呈深棕色或黑色，有时带有棕褐色斑块。即使护甲也很难看——肮脏，且往往已经生锈。兽人总体偏好令人不快的颜色。服装带有部落色彩，盾徽或饰边也一样。典型颜色包括血红、锈红、芥末黄、黄绿色、苔绿色、绿紫色和黑褐色。它们能活 <strong>40 年</strong>。

<strong>半兽人 Half-Orcs：</strong>由于兽人会与任何生物繁殖，因此存在许多带兽人血统、令人厌恶的混血儿，尤其是兽人与地精、兽人与大地精以及兽人与人类的混血。兽人不能与精灵杂交。半兽人通常极度偏向兽人血统，因此这类生物基本上就是兽人，不过有时（<strong>10%</strong>）能伪装成其另一种血统的真正生物（地精、大地精、人类等）。
