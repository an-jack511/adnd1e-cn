## 奥提尤格 Otyugh

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1（2） |
| 护甲等级 | 3 |
| 移动力 | 6 寸 |
| 生命骰 | 6–8 |
| 在巢穴概率 | 无 |
| 财宝类型 | 见下文 |
| 攻击次数 | 3 次 |
| 攻击伤害 | 1–8／1–8／2–5 |
| 特殊攻击 | 疾病 |
| 特殊防御 | 永不受突袭 |
| 魔法抗力 | 标准 |
| 智力 | 低至普通 |
| 阵营 | 中立 |
| 体型 | M–L |
| 灵能能力 | 无；攻击／防御模式：无 |

这些怪异的怪物是杂食性食腐者，完全不介意在由粪便、脏物和腐肉组成的食谱中加入一点新鲜肉类。它们厌恶直射阳光或强光，因此大多数情况下都在地下发现。通常（<strong>90%</strong>）只会遇到一只，因为奥提尤格通常与其他地下怪物共生。奥提尤格会与其他强大怪物保持休战，以便捡食排泄物及其他残余物。大多数情况下，奥提尤格居住在粪便与垃圾堆中，并在那里繁衍兴盛。

奥提尤格有一根感觉器官触须和两条触手臂，从丑陋的身体上伸出。它们的眼睛总是伸到生物所居粪便的上方，这使其不会受到突袭。它们的触手带有锋利的棱，用来向猎物施以重击。生物的嘴像吸盘一样，里面长满牙齿；如果咬中任何受害者，有 <strong>90%</strong> 的概率使其感染疾病（斑疹伤寒）。

这些怪物对人类所理解的财宝完全没有兴趣，但它们的同伴有时会有兴趣，并以允许奥提尤格半共生地居住在一起作为让奥提尤格守护财宝的条件。奥提尤格会说自己的语言，并且具有半心灵感应能力，因此在它们愿意时，通常能够与其他生命形态交流。
