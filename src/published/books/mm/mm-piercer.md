## 穿刺怪 Piercer

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 3–18 |
| 护甲等级 | 3 |
| 移动力 | 1 寸 |
| 生命骰 | 1–4 |
| 在巢穴概率 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 次 |
| 攻击伤害 | 1–6／2–12／3–18，或 4–24 |
| 特殊攻击 | 95% 概率突袭 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | S 至 M |
| 灵能能力 | 无；攻击／防御模式：无 |

穿刺怪栖息在洞穴、岩洞及类似地下场所。它们拥有石质外壳，无法与洞穴顶部常见的钟乳石区分。穿刺怪会被声音与热量吸引；当有活物从它们上方的位置下方经过时，它们会落下，将其杀死并吞食。较大的种类会与较小的种类一同被发现。

穿刺怪的体型等于其生命骰数，成为 <strong>1、2、3 或 4 个生命骰</strong>大小的概率相同。最大的穿刺怪约长 <strong>6 寸</strong>，底部直径 <strong>1 寸</strong>，重 <strong>500 磅</strong>。
