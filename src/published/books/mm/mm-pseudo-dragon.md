## 伪龙 Pseudo-Dragon

| 项目 | 数据 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动力 | 6 寸／24 寸 |
| 生命骰 | 2 |
| 在巢穴概率 | 5% |
| 财宝类型 | Q（×10） |
| 攻击次数 | 1 次 |
| 攻击伤害 | 1–3 |
| 特殊攻击 | 毒刺 |
| 特殊防御 | 变色能力 |
| 魔法抗力 | 35% |
| 智力 | 普通 |
| 阵营 | 中立（善良） |
| 体型 | S（长 1½ 尺） |
| 灵能能力 | 无；攻击／防御模式：无 |

伪龙可以出现在任何气候中，但最寒冷或最炎热的气候除外；在那些地方，即使出现也极其少见。这些生物确实很稀有，也备受追寻。它们在巨大的空心树或小型洞穴中筑巢。

伪龙能够用小巧的龙形颚进行凶猛的撕咬，但主要武器是带有毒刺的尾巴。这条附肢很长，也非常灵活；伪龙能够以闪电般的速度挥动它，攻击的“命中”骰获得 <strong>+4</strong>。被毒刺击中的生物必须通过对抗毒素的豁免检定，否则会进入持续 <strong>1–6 天</strong>的强直性昏厥状态。在此期间受害者看起来像死了一样，并有 <strong>25%</strong> 的概率确实死亡。

伪龙拥有类似变色龙的能力，因此能够与任何典型背景融为一体；对于无法看见隐形物体的生物，它们有 <strong>80%</strong> 的概率不会被发现。伪龙能够看见隐形物体。

魔法抗力是伪龙与生俱来的特性。当伪龙接触另一名生物时，它能够将这种抗力传递给一名人类（或类人）同伴。

伪龙通过一种有限形式的心灵感应进行交流。如果伪龙选择成为一名人类（或类人）的同伴，它还能将自己所看到与听到的内容传递给同伴，距离最远 <strong>24 寸</strong>。

<strong>外观：</strong>伪龙看起来与微型红龙完全相同。不过，它们的基本颜色是红棕色，并且能够如上所述改变颜色。
