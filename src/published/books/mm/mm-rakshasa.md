## 罗刹 Rakshasa

| 项目 | 数据 |
|---|---|
| 出现频率 | 极罕见至罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | −4 |
| 移动力 | 15 寸 |
| 生命骰 | 7 |
| 在巢穴概率 | 25% |
| 财宝类型 | F |
| 攻击次数 | 3 次 |
| 攻击伤害 | 1–3／1–3／2–5 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 见下文 |

| 阵营 | 守序邪恶 |
| 体型 | M |
| 灵能能力 | 无；攻击／防御模式：无 |

最初在印度被发现的这些包裹于肉身中的邪恶灵体正在扩散。它们喜爱以人肉为食，并且作为幻术大师，能够轻易达到这一目的。罗刹能够使用 ESP，然后制造出曾与它们相遇者认为友善的幻象。之后它们可以暂缓攻击，直到猎物失去戒心。

罗刹能够使用魔法使用者法术（最高 <strong>3 级</strong>）与牧师法术（<strong>1 级</strong>），但不受 <strong>8 级以下</strong>法术影响。非魔法武器无法伤害罗刹；低于 <strong>+3</strong> 的魔法武器只造成一半伤害，但牧师祝福过的弩矢命中罗刹会将其杀死。若在罗刹巢穴中遇到不止一只罗刹，群体中会有一名雄性和一名或多名雌性。
