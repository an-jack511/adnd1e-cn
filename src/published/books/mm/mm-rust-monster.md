## 锈蚀怪 Rust Monster

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–2 |
| 护甲等级 | 2 |
| 移动力 | 18 寸 |
| 生命骰 | 5 |
| 在巢穴概率 | 10% |
| 财宝类型 | Q（×10） |
| 攻击次数 | 2 次 |
| 攻击伤害 | 无 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无；攻击／防御模式：无 |

锈蚀怪只栖息在黑暗的地下场所。它们在这些地方游荡，寻找自己的食物——各种金属，但主要是铁质金属，例如铁、钢以及钢合金（比如秘银与精金制成的武器和护甲）。如果锈蚀怪用两根触须接触金属（掷“命中”骰），金属就会生锈或腐蚀。要注意，拥有魔法力量的物品可以进行豁免检定；每有一个加值，就有 <strong>10%</strong> 的概率不受影响。例如，<strong>+2</strong> 武器或护甲有 <strong>20%</strong> 的概率得以保全。受到影响的金属会锈蚀或腐蚀，并立即碎裂成小片（这些碎片很容易被生物吃掉并消化）。攻击锈蚀怪的武器会像被其触须接触一样受到影响。

锈蚀怪能在 <strong>9 寸</strong>外嗅到金属。若逃跑的队伍丢下诸如一把铁钉或一根钉头锤之类的物品，它们会停下一个近战轮吞食这些东西；但与铜、银等金属相比，它们会优先追逐铁质金属。
