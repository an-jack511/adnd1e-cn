## 沙华鱼人 Sahuagin

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 20–80 |
| 护甲等级 | 5 |
| 移动力 | 12 寸／24 寸 |
| 生命骰 | 2+2 |
| 在巢穴概率 | 25% |
| 财宝类型 | 个体：N；巢穴：I、O、P、Q（×10）、X、Y |
| 攻击次数 | 1 次 |
| 攻击伤害 | 按武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 标准 |
| 智力 | 高 |
| 阵营 | 守序邪恶 |
| 体型 | M（部分为 L） |
| 灵能能力 | 无；攻击／防御模式：无 |

沙华鱼人有时被称为“海魔”或“深海魔人”，栖息在深度 <strong>100–1,500 寸</strong>的温暖咸水中。关于这些怪物的传说与历史将在后文讨论。沙华鱼人极其嗜杀，对所有生物都构成持续威胁，因为它们杀戮不仅为了食物，也为了运动与乐趣。这些生物憎恶淡水。它们不喜欢光线，强光（例如光亮法术制造的光）会伤害它们的眼睛，后文会讨论这一点。沙华鱼人会在黑暗无月的夜晚登岸，袭击并掠夺人类村落。它们甚至憎恨邪恶的恶魔魟（见相关条目），只有鲨鱼能得到它们的友善。

沙华鱼人的社会结构建立在国王统治之上。国王在海浪深处一座庞大的海底城市中设朝。其领地分为 <strong>9 个省</strong>，每省由一名王子统治；每位贵族控制自己封地中居住的小群沙华鱼人。这种组织方式仿照地狱位面的结构，因为沙华鱼人是魔鬼崇拜者。

一队沙华鱼人总由一名酋长率领。队伍中每有 <strong>10 名</strong>成员，就会有 <strong>1 名</strong>副官。酋长拥有 <strong>4 个生命骰 +4 点</strong>生命值，每名副官拥有 <strong>3 个生命骰 +3 点</strong>生命值；这些人都不计入队伍的基本数量。

若在沙华鱼人巢穴中遇到它们，还会有以下额外成员：

| 成员 | 数量或数据 |
|---|---|
| 男爵 | 1 名（6 个生命骰 +6 点生命值） |
| 卫兵 | 9 名（3 个生命骰 +3 点生命值） |
| 雌性 | 30–120 名（2 个生命骰） |
| 幼体 | 10–40 名（1 个生命骰） |
| 蛋 | 20–80 枚 |

此外，每 <strong>10 名</strong>雄性沙华鱼人有 <strong>10%</strong> 的概率会有一名邪恶牧师和 <strong>1–4 名</strong>助理女祭司；这些生物的宗教生活由雌性主导。若巢穴队伍中有牧师，她的能力等级为 <strong>5–8 级</strong>，而她的低阶牧师为 <strong>3 或 4 级</strong>。

沙华鱼人的巢穴中总有 <strong>2–8 条</strong>鲨鱼。沙华鱼人能够让这些怪物服从一至两个词的简单命令。

每当发现一个沙华鱼人巢穴，就有 <strong>5%</strong> 的概率那是某位王子的要塞。王子拥有 <strong>8 个生命骰 +8 点</strong>生命值；要塞有 <strong>9 名</strong>酋长级卫兵，以及一名 <strong>8 级</strong>沙华鱼人邪恶高阶女祭司和 <strong>4 名 4 级</strong>低阶女祭司。王子巢穴中雄性、雌性、幼体与蛋的数量均为普通骰数的两倍。这里始终有 <strong>4–24 条</strong>鲨鱼。

沙华鱼人的巢穴是真正的村落或城镇，由石头建成。建筑物呈穹顶状，周围生长的海草和类似海洋植物使其难以被发现。

虽然这些生物不穿护甲，但它们的鳞片非常坚韧，效果等同于护甲等级 5。沙华鱼人穿戴背带，用于携带个人装备与武器。一群沙华鱼人的典型武器配备如下：

| 武器 | 比例 |
|---|---:|
| 矛与匕首 | 30% |
| 三叉戟、网与匕首 | 50% |
| 重弩与匕首 | 20% |

矛只用作刺击武器。网带有数十枚钩子，几乎无法从未着甲的受害者身上取下；力量未达到 <strong>16</strong> 或无法抓住并撕裂网的生物也很难脱身。沙华鱼人登岸劫掠时，会用 <strong>3 枝标枪</strong>替换网。弩在水下最远发射 <strong>30 寸</strong>，通常是在水面上方使用。网用于困住受害者。三叉戟有三种用途：刺杀小型猎物、刺住被网困住的猎物，以及在海湾中牵制具有威胁的敌人。

即使没有武器，沙华鱼人也非常擅长攻击。它们蹼状的手上长有长而锋利的爪子，每次攻击造成 <strong>1–2 点</strong>伤害，而且可以同时使用两只手。它们强壮的后腿同样长有利爪；若用后腿踢中对手，每只脚命中造成 <strong>1–4 点</strong>伤害。沙华鱼人的嘴里长满牙齿与獠牙，成功咬中对手时造成 <strong>1–4 点</strong>伤害。因此，未持武器的沙华鱼人一个近战轮可以攻击 <strong>3 或 5 次</strong>，造成 <strong>1–2／1–2／1–4</strong>，以及在双腿能够抓挠时造成 <strong>1–4／1–4</strong>。

这些怪物的眼睛与耳朵尤其敏锐。沙华鱼人在深度 <strong>100 寸</strong>的水下能看见 <strong>30 寸</strong>远的东西。每增加 <strong>100 尺</strong>深度，视野就减少 <strong>1 寸</strong>；例如在 <strong>500 尺</strong>深处能看见 <strong>26 寸</strong>，在 <strong>1,000 尺</strong>深处能看见 <strong>21 寸</strong>。它们的耳朵敏锐到能在 <strong>1 英里</strong>外听见金属碰撞声，或听见同样距离外船桨拍水的声音。不过在距离 <strong>24 寸</strong>以内，它们反而无法侦测游泳或类似声音，尽管仍然能听见金属或其他东西的碰撞、咔嗒、撞击等声响。

沙华鱼人会说自己的语言；有些显然还能用恶魔魟的语言与其交谈。

<strong>外观：</strong>典型沙华鱼人的背部呈黑绿色，向腹部渐变为绿色。鳍呈黑色。巨大凝视的双眼深邃而发亮，呈黑色。每 <strong>216 名</strong>沙华鱼人中约有 <strong>1 名</strong>变异体，拥有 <strong>4 条</strong>完全可用的手臂；这些个体通常呈从黑色渐变为灰色。雌性与雄性难以区分，只是体型稍小。幼体颜色较浅，但会在孵化约 <strong>1–2 个月</strong>后变深并长成完全体。

<strong>历史与传说：</strong>沙华鱼人因其邪恶而被记录下来；它们一次又一次袭击陆地，使整片海岸荒芜，当然也不断摧毁路过的船只。沙华鱼人的确切起源不明。有人认为，在洪水降临大地时，最强大的守序邪恶神祇从一群特别邪恶的人类中创造了它们，以便保存这些人类。不过，据说鱼人曾表示沙华鱼人与海精灵有遥远的亲缘关系，并声称卓尔孕育了沙华鱼人。

很少有人能在被沙华鱼人俘获后活下来，因为俘虏通常会被囚禁、折磨并吃掉。活捉的生物会被带到沙华鱼人巢穴，关在牢房中。虽然沙华鱼人能够离水最多 <strong>4 小时</strong>，但典型村落的囚禁区域没有空气；贵族城镇中则有专门的房间维持需要呼吸空气的生物。沙华鱼人会留下少数俘虏折磨并供其取乐——通常是在竞技场中安排两个不同生物决斗至死。绝大多数俘虏会被直接杀死并吃掉。俘虏很少逃脱，尽管沙华鱼人喜欢让俘虏以为自己已经获得自由，随后再由残酷的卫兵包围，而一群鲨鱼则前来结束杀戮。

沙华鱼人残酷而野蛮，强者总会欺凌弱者。任何受伤、残废或体弱的个体都会被这些同类相食的怪物杀死并吃掉。即使是不完美的幼体也会受到同样处理。这种严酷的法律造就了强大的种族，但任何首领都始终会受到挑战。沙华鱼人不会停止生长，尽管速度缓慢；多数个体在长到巨大体型前就已经死亡。首领是其中最大、最强的个体。据说 <strong>9 位</strong>沙华鱼人王子和国王都是拥有四条手臂的种类。无论如何，挑战决斗的失败者总会被杀死——无论在战斗中还是之后。决斗不使用武器，只允许使用獠牙与爪子。

据说国王居住在沙华鱼人能够生存的最深处某座城市中。这座城市据称建在海底峡谷内，宫殿与居所沿峡谷两侧而建。那里居住着整整 <strong>5,000 名</strong>沙华鱼人，不计入国王由王后、妾、贵族、卫兵等组成、据说超过 <strong>1,000 人</strong>的随从。沙华鱼人国王据报道体型巨大（<strong>10 个生命骰 +10 点</strong>生命值），邪恶至极。他总有 <strong>9 名</strong>贵族卫兵陪同（<strong>6 个生命骰 +6 点</strong>生命值），以及所有沙华鱼人的邪恶高阶女祭司和她带领的 <strong>9 名</strong>低阶女祭司。
