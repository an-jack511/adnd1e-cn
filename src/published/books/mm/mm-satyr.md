## 萨梯 Satyr

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 2–8 |
| 护甲等级 | 5 |
| 移动力 | 18 寸 |
| 生命骰 | 5 |
| 在巢穴概率 | 40% |
| 财宝类型 | I、S、X |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–8 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 50% |

| 灵能能力 | 无；攻击／防御模式：无 |

萨梯（或称牧神）只栖息在森林中。它们主要只对玩乐感兴趣——嬉闹、吹笛、追逐树精等。不过它们憎恨闯入者，会赶走任何冒犯它们的生物。有时可以用上等葡萄酒引诱或贿赂它们。

萨梯通常用两只锋利的角顶撞攻击。它们偶尔（20%）会使用魔法武器。萨梯很可能会先用笛子吹奏曲调；这种乐器只有萨梯能够正确使用。借助笛声，萨梯可以使 <strong>6 寸</strong>听觉范围内的所有生物魅惑、睡眠或恐惧，除非这些生物通过对抗魔法的豁免检定。

每群中大概只有 <strong>1 名</strong>萨梯拥有笛子。如果队伍中有漂亮的女性，笛声会用来魅惑；如果闯入者相对无害，笛声会用来使其睡眠（并从沉睡者身上偷走贵重物品）；但如果队伍很强大，笛声会用来制造恐惧。任何对笛声的任意一种效果成功豁免的生物，都不会再受同一支笛子发出的其他音乐影响。

萨梯非常安静，感官敏锐。它们只有在掷出 <strong>1</strong> 时才会受到突袭，并能与树叶融为一体；对于无法看见隐藏或隐形事物的生物，它们有 <strong>90%</strong> 的概率不会被发现。

这些生物会说自己的语言，也会说精灵语（只有森林精灵能够理解）和通用语。住在半人马附近的萨梯有 <strong>80%</strong> 的概率对半人马友善，会与其合作并说半人马的语言。

<strong>外观：</strong>萨梯上半身的皮肤从棕褐色到浅棕色不等，其他部位的毛发呈中棕、红棕或深棕色。角与蹄子呈黑色。
