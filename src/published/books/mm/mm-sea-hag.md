## 海巫婆 Sea Hag

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–4 |
| 护甲等级 | 7 |
| 移动力 | 15 寸 |
| 生命骰 | 3 |
| 在巢穴概率 | 10% |
| 财宝类型 | C、Y |
| 攻击次数 | 1 次 |
| 攻击伤害 | 匕首 |
| 特殊攻击 | 死亡凝视 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 50% |
| 智力 | 普通 |
| 阵营 | 混乱邪恶 |
| 体型 | M |
| 灵能能力 | 无；攻击／防御模式：无 |

海巫婆栖息在温暖海域茂密植被覆盖的浅滩中。极罕见的种类生活在淡水中。它们隐居并憎恨美丽，因此巢穴很可能位于非常阴郁、丑陋的地方。海巫婆的外貌恐怖到足以使生物因恐惧而虚弱；除非通过对抗魔法的豁免检定，否则生物会在 <strong>1–6 轮</strong>内失去一半力量。更糟的是，海巫婆能够在最远 <strong>3 寸</strong>处施展致命凝视；任何未通过对抗毒素豁免检定的生物都会被这一眼杀死。海巫婆每天只能使用这种武器 <strong>3 次</strong>。海巫婆的任何受害者都会很快被可怕的胜利者吞食。
