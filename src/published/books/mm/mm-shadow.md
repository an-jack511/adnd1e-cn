## 阴影 Shadow

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 2–20 |
| 护甲等级 | 7 |
| 移动力 | 12 寸 |
| 生命骰 | 3+3 |
| 在巢穴概率 | 40% |
| 财宝类型 | F |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–5 |
| 特殊攻击 | 力量吸取 |
| 特殊防御 | 需要 +1 或更好的武器才能命中 |
| 魔法抗力 | 见下文 |
| 智力 | 低 |
| 阵营 | 混乱邪恶 |
| 体型 | M |
| 灵能能力 | 无；攻击／防御模式：无 |

这些可怕的不死生物出现在古老废墟之间或地下深处。由于它们主要存在于负能量位面，只要触碰对手就能吸取力量。它们毫不犹豫地攻击活物，以获得猎物的生命力。除了冰冷触碰造成的 <strong>2–5 点</strong>伤害外，每次命中还会吸取受害者 <strong>1 点力量</strong>。如果人类对手的力量或生命值降至 0，阴影就会吸取他的生命力，使其变成阴影。注意，被触碰后，生物的力量会在 <strong>2–8 轮</strong>后恢复。阴影不受睡眠、魅惑或定身法术影响，也不受寒冷类攻击影响。阴影有 <strong>90%</strong> 的概率不会被发现，因为看起来不过就是它们名字所代表的影子。如果施放强光——例如持续光亮法术制造的光——它们就会清晰可见。
