## 精灵妖 Sprite

| 项目 | 数据 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 10–100 |
| 护甲等级 | 6 |
| 移动力 | 9 寸／18 寸 |
| 生命骰 | 1 |
| 在巢穴概率 | 20% |
| 财宝类型 | C |
| 攻击次数 | 1 次 |
| 攻击伤害 | 按武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗力 | 标准 |
| 智力 | 极高 |
| 阵营 | 中立（善良） |
| 体型 | S（高 2 尺） |
| 灵能能力 | 无；攻击／防御模式：无 |

精灵妖栖息在草地与林间空地。它们非常羞怯而隐居，但憎恨各种邪恶与丑陋。它们装备细剑（等同于匕首）与小弓，射程和效果只有短弓的一半。不过，它们的箭涂有特殊药膏，被击中的生物必须通过对抗毒素的豁免检定，否则会睡眠 <strong>1–6 小时</strong>并陷入昏迷。精灵妖随后会杀死邪恶生物，或将善良生物带到远离精灵妖遭遇地点的地方。注意，任何生物有 <strong>75%</strong> 的概率不会注意到精灵妖；除非先受到骚扰，否则它们只会攻击邪恶生物。

精灵妖可以随意变为隐形，在 <strong>5 寸</strong>范围内侦测善良／邪恶，并且能够无声移动。隐形时，它们会使对手的“命中”骰受到 <strong>−4</strong> 调整。

精灵妖会说自己的语言和通用语。
