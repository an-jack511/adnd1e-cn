## 血蚊 Stirge

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 3–30 |
| 护甲等级 | 8 |
| 移动力 | 3 寸／18 寸 |
| 生命骰 | 1+1 |
| 在巢穴概率 | 60% |
| 财宝类型 | D |
| 攻击次数 | 1 次 |
| 攻击伤害 | 1–3 |
| 特殊攻击 | 吸血 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无；攻击／防御模式：无 |

血蚊只出现在非常黑暗、纠结的森林或地下巢穴。它们埋伏温血生物，俯冲下来；细长锋利的口器一旦刺入，受害者的血液就会被吸出吞食。

血蚊攻击时按拥有 <strong>4 个生命骰</strong>的生物计算，而不是按 1+1 个生命骰计算。血蚊蛇形的口器命中时造成 <strong>1–3 点</strong>伤害。命中后的每个近战轮，直到吸取价值 <strong>12 点</strong>生命值的血液为止，血蚊都会吸取相当于 <strong>1–4 点</strong>生命值的血液。吸饱血后，血蚊会拍翅飞走，消化自己的食物。将血蚊从猎物身上弄下来的唯一方法是杀死它。

<strong>外观：</strong>血蚊的羽毛呈锈红到红棕色，双眼与双脚偏黄色。血蚊垂下的口器尖端呈粉红色，向根部渐变为灰色。
