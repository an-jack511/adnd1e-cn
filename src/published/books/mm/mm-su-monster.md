## 苏魔兽 Su-monster

| 项目 | 数据 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–12 |
| 护甲等级 | 6 |
| 移动力 | 9 寸 |
| 生命骰 | 5+5 |
| 在巢穴概率 | 30% |
| 财宝类型 | C、Y |
| 攻击次数 | 5 次 |
| 攻击伤害 | 1–4（×4）／2–8 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 普通 |
| 阵营 | 混乱 |
| 体型 | M |
| 灵能能力 | 120；攻击／防御模式：见下文 |

苏魔兽栖息在荒废的荒野地区，也栖息在地下巢穴。它们有可抓握的尾巴，用来在树枝间荡行或倒挂。从这种位置，它们能够用四只带爪的脚以及下颚攻击。四只脚都可抓握，并且长有又长又锋利的指甲。苏魔兽既能直立，也能倒挂；后者是它们伏击猎物的偏好方式之一。

若遇到超过 <strong>4 只</strong>苏魔兽，则有 <strong>50%</strong> 的概率该群体由一只雄性、一只雌性与幼体组成。幼体的成长状态以二十面骰决定，每 <strong>10%</strong> 为一个阶段；将 10% 视为 20%，将 100% 视为 30%。若幼体受到攻击，雌性会以双倍数值战斗 <strong>6 轮</strong>；若雌性受到攻击，雄性会以双倍数值战斗 <strong>4 轮</strong>。

苏魔兽具有潜在的灵能能力；若其 <strong>12 尺</strong>内有人使用灵能，它每天可以攻击一次。掷六面骰决定攻击形式：<strong>1–2</strong> 为心灵碾压，<strong>3–4</strong> 为灵能爆破，<strong>5–6</strong> 为心灵突刺。无需灵能防御，因为苏魔兽本身不受灵能攻击。

<strong>外观：</strong>苏魔兽的毛发呈肮脏灰色。它们的尾巴与面部为黑色，爪子呈血红色。
