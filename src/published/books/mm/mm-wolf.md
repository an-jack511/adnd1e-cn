### 狼 Wolf

| 项目 | 数据 |
|---|---|
| 出现频率 | 常见 |
| 出现数量 | 2–20 |
| 护甲等级 | 7 |
| 移动力 | 18 寸 |
| 生命骰 | 2+2 |
| 在巢穴概率 | 10% |
| 财宝类型 | 无 |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–5 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无 |

狼是从极地到温带森林都能发现的食肉动物，总是成群狩猎。饥饿时（75% 概率）会跟踪并攻击猎物，寻找其疏于防备的时刻。狼嚎有 50% 概率使未被人类控制和安抚的食草动物惊慌。狼喜爱马肉；巢穴中每对成年狼有 30% 概率有 1–4 只幼崽。幼狼不战斗，但可训练为战犬或猎兽。

### 恐狼 Dire Wolf（座狼 Worg）

| 项目 | 数据 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 3–12 |
| 护甲等级 | 6 |
| 移动力 | 18 寸 |
| 生命骰 | 3+3（座狼为 4+4） |
| 在巢穴概率 | 10% |
| 财宝类型 | 无 |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–8 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 半智能（座狼偏低） |
| 阵营 | 中立；座狼为中立（邪恶） |
| 体型 | M（座狼为 L） |
| 灵能能力 | 无 |

恐狼只是典型的更新世巨型狼，其他特征与普通狼相同。邪恶的座狼（worg）拥有自己的语言，常与哥布林合作以获得猎物或享受杀戮；它们与小马一样大，可以骑乘，其他特征同恐狼。

### 冬狼 Winter Wolf

| 项目 | 数据 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–8 |
| 护甲等级 | 5 |
| 移动力 | 18 寸 |
| 生命骰 | 6 |
| 在巢穴概率 | 10% |
| 财宝类型 | I |
| 攻击次数 | 1 次 |
| 攻击伤害 | 2–8 |
| 特殊攻击 | 冰霜吐息 |
| 特殊防御 | 无 |
| 魔法抗力 | 标准 |
| 智力 | 平均 |
| 阵营 | 中立（邪恶） |
| 体型 | L |
| 灵能能力 | 无 |

冬狼是只生活在寒冷地区的可怕大型食肉动物，性情恶劣。它们能用凶猛下颚攻击，或从口中呼出霜冻，覆盖嘴部 1 寸内的生物，造成 6–24 点伤害；通过龙息豁免则伤害减半。每 10 个战斗轮只能使用一次冰霜吐息。冬狼免疫寒冷攻击，但火焰攻击额外造成每骰 1 点伤害。它们有自己的语言，也能与座狼交流；皮毛闪亮白色或银色，眼睛淡蓝或银色，皮可卖 5,000 金币。
