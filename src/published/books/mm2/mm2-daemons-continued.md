## 水栖达厄蒙 · Hydrodaemon

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 2–8 |
| 护甲等级 | 2 |
| 移动 | 6"/6"（MC：D）//24" |
| 生命骰 | 9+36 |
| 巢穴内百分比 | 5%（斯堤克斯河附近 90%） |
| 财宝类型 | I、Y |
| 攻击次数 | 3 或 5 |
| 每次攻击伤害 | 1–4/1–4/1–8/1–8/1–10 |
| 特殊攻击 | 吸取生命能级 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 对一环法术 70% |
| 智力 | 低 |
| 阵营 | 中立邪恶 |
| 体型 | L（10 英尺高） |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | VIII/3450 + 14/生命值 |

这些怪异的两栖生物是已知唯一能够在斯堤克斯河中游泳而不丧失记忆的生物。因此，只要下层位面出现斯堤克斯河及其支流，就可能在各处发现成群的水达厄蒙（10–30 只）。

水达厄蒙可以跃入空中，像飞鱼一样高速滑翔，最多持续 1 回合。在空中时，它们可以进行 5 次攻击：用脚抓挠造成 1–4 点伤害，用手抓挠造成 1–8 点伤害，再用嘴咬击造成 1–10 点伤害；在地面上则进行 3 次攻击。水达厄蒙的咬击造成 1–10 点伤害，并从受害者身上吸取 1 个生命能级。

水达厄蒙可以随意无误传送，有时会用任意门升到空中开始滑翔。它们还可以随意在 10 英尺内制造黑暗、制造水，以及使用水上行走术（如同戒指）。它们可以尝试召来另一只水达厄蒙，成功率为 50%。如果在主物质位面遭遇，水达厄蒙可以召唤一只 12 生命骰的水元素；水元素会为它战斗，但不受其控制。

除了达厄蒙通常拥有的抗性外，水达厄蒙受到基于水的攻击时只承受一半伤害；如果通过豁免，则完全不受伤害。

水达厄蒙经常被派往主物质位面为邪恶效力。它们偏好水、火或熔岩环境，但几乎任何地方都能找到它们。

## 欧诺达厄蒙 · Oinodaemon

| 项目 | 数值 |
|---|---|
| 出现频率 | 独一无二 |
| 出现数量 | 1 |
| 护甲等级 | -6 |
| 移动 | 18" |
| 生命骰 | 233 点生命值 |
| 巢穴内百分比 | 50% |
| 财宝类型 | R、W |
| 攻击次数 | 2 或 5 |
| 每次攻击伤害 | 2–12/2–12；或 2–12+造成疾病 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 对一环法术 120% |
| 智力 | 神一般 |
| 阵营 | 中立邪恶 |
| 体型 | L（9 英尺高） |
| 灵能能力 | 326–365；攻击/防御模式全部/全部 |
| 等级/经验值 | X/29,555 |

中层位面只有一位达厄蒙之主与统治者，称号为欧诺达厄蒙；他是一个独一无二、拥有巨大力量的个体。现在的欧诺达厄蒙是腐朽者安斯拉克瑟斯，理论上所有达厄蒙都向他致敬。

安斯拉克瑟斯拥有许多强大能力。他的触碰本身就能使外位面生命患病；这种疾病会阻止治疗，并在 1 周内致死。他的凝视每轮可以固定 1 个目标，使目标无法移动，直到达厄蒙之主允许为止。（成功通过对法术的豁免可以抵抗这一效果。）

安斯拉克瑟斯可以随意使用下列能力，每轮一次：烟火术、燃烧球、燃烧之手、变形术、侦测魔法、解除魔法、解除幻象、欺诈、心灵感应、水下呼吸、无误传送，以及以 85% 的成功率召来 1–3 个他选择的其他达厄蒙。每天一次，他可以制造火墙、冰墙和力场，竖起小型无敌球，施放智力衰退术，或使用如同同名魔杖的取消术。这些能力均按 25 级魔法师处理。

作为欧诺达厄蒙，安斯拉克瑟斯持有“下层位面权杖”；只有在安斯拉克瑟斯死亡后，其他达厄蒙才能挥舞它。权杖拥有群体魅惑、诱导（如同魔杖）、指使术以及赐予他人愿望的能力。注意，安斯拉克瑟斯只有在愿望以某种方式导致灾祸并使邪恶获益时才会使用最后一项能力。魅惑和诱导能力即使对其他达厄蒙也能生效，并会自动克服它们的魔法抗性。

安斯拉克瑟斯还拥有以下灵能能力：身体平衡、侦测善恶、扩张、支配、对心灵印象的感受，以及主要学科心灵屏障和分子重排；他利用后者把铅变成铂。所有灵能学科都按 20 级掌握等级处理。

安斯拉克瑟斯是下层位面最强大的达厄蒙，但他的地位受到其他独一无二的达厄蒙生物挑战，主要挑战者包括布博尼斯（Bubonis）、科勒里克斯（Cholerix）、泰弗斯（Typhus）和迪弗瑟里乌斯（Diphtherius），以及学者未知或未记录的其他存在。

安斯拉克瑟斯看起来像一个身穿腐烂灰色西装和斗篷的高大男子。他的头是一个因疾病而变形的公羊头；嘴里冒着泡沫，羊毛成把地从皮肤上脱落。裸露的皮肤上遍布疖子和水泡，皮肉紧贴骨骼。

## 鱼形达厄蒙 · Piscodaemon

| 出现数量 | 3–12 |
| 护甲等级 | -1 |
| 移动 | 6"//18" |
| 生命骰 | 6 |
| 巢穴内百分比 | 50% |
| 财宝类型 | E |
| 攻击次数 | 2 |
| 每次攻击伤害 | 2–16/2–16 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 对一环法术 60% |
| 智力 | 平均至很高 |
| 阵营 | 中立邪恶 |
| 体型 | M（5 英尺高） |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | V/455 + 6/生命值 |

鱼尾、斜视的鱼达厄蒙拥有红色甲壳、像龙虾一样的身体，鸟的爪，以及食腐巨虫的头。它的手臂虽像人类，却在末端长着一对蟹钳。这种生物遍布下层位面，通常服从更强大的达厄蒙；但对任何比自己弱的生物都欺凌、施虐。

尽管外表如此，鱼达厄蒙相当强壮。如果它的两只巨大钳子都命中，被攻击的生物就会被达厄蒙抓住并拖向大嘴。随后，它会用短触手攻击，试图把一种毒液注入目标；毒液会在 6 轮内致死（可进行对毒素豁免；成功时角色会迟缓 6 轮）。被抓住的角色攻击时受到 -1。中毒角色可能会被鱼达厄蒙带走，留到以后进食。

怪物头部两侧凸出的多面眼，使鱼达厄蒙能够看到周围和身后，因此不会被突袭。此外，由于其水生本性，所有基于水的攻击每颗伤害骰减去 1 点。

鱼达厄蒙经常被召唤到主物质位面，充当劳工或守卫。它们怨恨这种任务，并会策划推翻、奴役主人。

## 终极达厄蒙 · Ultrodaemon

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | -5 |
| 移动 | 15"/16"//15"（MC：C） |
| 生命骰 | 14+28 |
| 巢穴内百分比 | 25% |
| 财宝类型 | G、R |
| 攻击次数 | 2 |
| 每次攻击伤害 | 2–8/2–8 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 只能被 +2 或更好的武器击中 |
| 魔法抗性 | 对一环法术 110% |
| 智力 | 天才至超天才 |
| 阵营 | 中立邪恶 |
| 体型 | M（6.5 英尺高） |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | X/8100 + 20/生命值 |

阴影般的终极达厄蒙可以随意漫游下层位面，几乎没有生物能挑战它们的力量。它们看起来是没有面孔的类人生物，长着大眼睛，眼睛像火蛋白石。任何与这些生物对视的存在都必须进行对法术的豁免，否则会被迷住（如同受到人类定身术影响），凝视颜色和图案的流动。豁免成功者看不见终极达厄蒙，而会看见某个自己爱戴或尊敬的人。

终极达厄蒙每轮可以随意使用下列能力：接触即恐惧、魅惑人类或怪物、无误传送、心灵感应、千里眼、千里耳、如同魔杖制造幻象、建议、误导、魔魂壶和心灵遥控（6000 gp 重量）。每天一次，它们可以使用火墙术；刻写说服、疯狂或绝望符文；或制造刀刃屏障。这些类似法术的能力均按 15 级施法者处理。
