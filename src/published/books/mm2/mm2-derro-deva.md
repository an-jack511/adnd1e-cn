## Derro

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 3–30 |
| 护甲等级 | 见下文 |
| 移动 | 9" |
| 生命骰 | 3 |
| 巢穴内百分比 | 20% |
| 财宝类型 | 见下文 |
| 攻击次数 | 1 或 2 |
| 每次攻击伤害 | 按武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 30% |
| 智力 | 很高至天才 |
| 阵营 | 混沌邪恶 |
| 体型 | S（4 英尺高） |
| 灵能能力 | 仅个体具有；攻击/防御模式：仅个体具有 |
| 等级/经验值 | 数值不固定 |

Derro 是一种身材像矮人的退化种族，可能是邪恶人类与矮人的混合后代。它们居住在 drow 及其同类（kuo-toan、夺心魔、troglodyte 等）常见的广大地下领域。Derro 憎恨光，在阳光下会感到恶心，但它们会在夜间通过隐秘的竖井出口来到地表，偷窃并绑架人类作为奴隶。传闻说，有些人类还会被吃掉。

Derro 拥有很高的敏捷（15–18），因此护甲等级必须相应调整。护甲与武器按下列概率出现：

* 40%–50% 的 derro 会使用镶钉皮甲和连发轻弩（最大射程 12"，每轮 2 发，容量 6 枝弩矢，每枝造成 1–3 点伤害）。弩矢上的 derro 毒素会额外造成 2–12 点伤害，除非目标成功豁免。
* 20%–30% 的 derro 会使用镶钉皮甲、钩镰戟（一种超过 6 英尺长的武器，造成 1–4 点伤害，有 25% 的概率把人类大小或更小的受害者拉得失去平衡）和匕首。
* 10%–20% 的 derro 会使用鳞甲皮（龙皮或类似材料，防护力等同链甲）、匕首、小圆盾（带尖刺，攻击时等同匕首）和 aklys。Aklys 带尖刺和钩子，拉倒或拉失对手平衡的效果只有钩镰戟的一半。
* 10%–20% 的 derro 会使用鳞甲皮、小圆盾、矛和皮革镐（伤害等同军用镐）。

每遇到 3 只 derro，就会有 1 只拥有 4 个生命骰。每遇到 6 只，就会有 1 只拥有 5 个生命骰。如果遇到 10 只或更多，就会有一只 7 生命骰的首领和一只 6 生命骰的副官。所有这些高等级 derro 都是在最初数量之外额外出现的。所有高等级 derro 都穿鳞甲皮并使用精良武器。如果遇到 20 只或更多，还会有一名 savant（下文详述）和两名 student savant。

Derro 巢穴总会有 30 只加上 3–12 只额外的普通 derro、相应数量的高等级首领、1–3 名 savant、2–5 名 student savant、15–40 名奴隶（80% 为女性）以及 1–3 只 gargoyle（概率 70%）或一只 lamia（概率 30%）作为盟友。

Savant derro 具有贤者般的气质，能够使用任何种类的魔法物品和武器。他们会施放下列法术：影响普通火焰、反魔法外壳、闪现、光、闪电箭、次级创造术、魅惑人类、云杀术、心灵感应、催眠图案、冰风暴、隐形、浮空术、麻痹、排斥术、阴影魔法、蜘蛛攀爬、腹语术、雾墙、力墙。

他们拥有称作 student savant 或学生的学徒。后者只知道一个较小的研究领域，并且只有 25% 的概率能够使用非战士魔法物品。Derro savant 拥有 5–8 个生命骰；学生拥有 4–7 个生命骰。Savant 会有 2–3 件有用且正在使用的攻击和/或防御魔法物品；学生会有 1 件较弱物品。Savant 知道 6–9 个法术，学生知道 1–3 个。他们也能理解语言和阅读魔法。能力按 12 级处理。

典型魔法物品包括：任意药水；任意卷轴；火焰抗性、隐形、防护和法术储存戒指；任意魔杖；+1 镶钉皮甲与盾牌；防御护腕、护盾胸针、防护斗篷等；最高 +3 的任意剑；以及任意杂项魔法武器。

据说 derro 在地下深处有一座主要据点；他们的 savant 在那里策划阴谋，准备毁灭上层世界并奴役全人类。Derro 的红外视觉很差（范围 30 英尺），但紫外视觉很好（120 英尺）。他们会说自己的语言、一些通用语，并知道地下世界的贸易通用语。

Derro 与人类非常相似，只是更矮，按身高比例来说肌肉略强壮。五官通常粗陋。头发为淡棕色或黄色，皮肤非常白并带有蓝色底调，眼睛很大。

## Deva 总则

Deva 种族居住在善良的上层外位面。Deva 是各种善良阵营神祇的仆役和使者；有些 deva 守序，有些混沌，有些中立，但全部善良。

Deva 绝不是它们所居住位面上最强大的生物，然而毫无疑问，它们是善良阵营强有力的爪牙（参见 Planetar、Solar）。

所有 deva 都能在善良阵营位面间旅行，尽管守序性质的 deva 只有在遵守神祇指示时才会这样做；即使是混沌 deva，除非执行任务，也很少从一个地方漫游到另一个地方。所有 deva 也都能变为以太状态，不过除了星界 deva，其他 deva 只有在受神祇命令时才能进行星界旅行。它们通常能在任何环境（包括水中）同样良好地行动。

在主物质位面或任何元素位面，只有 deva 的物质身体能够被摧毁。Deva 的灵魂不可侵犯；肉身被毁后，灵魂会立即回到自己的位面，在那里停留十年，重新获得再次形成肉身所需的力量。不过，在其他任何位面上，所有 deva 都可能真正死亡。Deva 绝不会与邪恶的生物或怪物谈判，但非守序 deva 可能与非邪恶的中立者达成交易。Deva 通常可以评估对手，判断谁最强大、谁构成最大威胁，并据此攻击。只要愿意，攻击可以在一轮内分配给多个目标。

所有 deva 都能使用下列类法术能力，每次一种、每轮 1 次，次数达到适用上限：治病术（每天 3 次）、治疗轻伤（每天 7 次）、治疗重伤（每天 3 次）、侦测邪恶、侦测幻术、侦测魔法、侦测陷阱（每天 7 次）、解除魔法（每天 7 次）、以太化、治疗术（每天 1 次）、侦测阵营、隐形（自身或半径 10 英尺）、光（效果变化）、自我变形、阅读魔法、移除诅咒、移除恐惧、无误传送、语言、紫外视觉、防护邪恶。

Deva 不受寒冷、电击、魔法飞弹、石化、毒素、普通火焰或任何气体攻击法术影响。除 monadic deva 不受任何火焰影响外，deva 受到龙息和魔法火焰攻击时只承受一半伤害。酸攻击对它们造成全部伤害。普通铁或银武器不会伤害它们，但魔法铁或银武器会造成全部伤害。以下是在上层外位面任何地方都能遇到的 3 种 deva。

## Astral Deva（星界天使）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–3 |
| 护甲等级 | -6 |
| 移动 | 18"/42"//15"（MC：A） |
| 生命骰 | 9+36 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 4–15/4–15（+6 力量加值） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 65% |
| 智力 | 天才（感知=20） |
| 阵营 | 善良 |
| 体型 | M（7 英尺高） |
| 灵能能力 | 210；攻击/防御模式：A、B、C、E／F、G、H |
| 等级/经验值 | X／10,100 + 25/生命值 |

星界 deva 主要在星界位面或下层外位面工作。它们独自或成群行动，为自己的君主服务。无论步行还是使用强大的翅膀飞行，它们都极其迅速。星界 deva 通常携带一件巨大的杖棒状武器，并能灵活挥舞。由星界 deva 使用时，这件武器具有 +3 的价值。

同一近战轮内被它击中两次且所受伤害超过 20 点的生物，必须进行对抗法术的豁免，否则昏迷 14 轮。该武器还作为驱散之锤使用，命中机会如同 9 级牧师持用。

星界 deva 可以随意使用上文列出的类法术能力，每轮 1 次，达到适用上限。它释放的光可以按需要具有 4–40 英尺半径。防护邪恶是半径 10 英尺、正常（+2）力量的区域。星界 deva 还可以解除幻术、解除任何形式的隐形、自我变形或移除诅咒，这些能力也都是每轮 1 次。每天 1 次，星界 deva 可以制造一道持续最多 7 回合的 blade barrier。

星界 deva 永远不会被突袭。只有 +7 或更好的魔法武器才能伤害它们。完全真空不会伤害星界 deva。它们免疫生命等级损失（无论来自不死生物还是魔法），灵魂不能被困住或囚禁，并免疫死亡法术。它们的魅力效果为 20。

星界 deva 高大、纤细而优雅，皮肤和头发呈金色，眼睛琥珀色，巨大的白色翅膀带有金色阴影。其他方面与人类相似。

## Monadic Deva（单子天使）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | -4 |
| 移动 | 15"/36"//18"（MC：B） |
| 生命骰 | 8+32 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 3–12/3–12（+4 力量加值） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 60% |
| 智力 | 天才（感知=19） |
| 阵营 | 善良 |
| 体型 | M（6 英尺高） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IX／8100 + 20/生命值 |

Monadic deva 通常受雇于以太位面和元素位面。任何环境都是这些生物的家园。Monadic deva 通常携带一根等同于 +2 武器的金属棒，可以在最多 10 英尺距离刺击或击打。任何被击中的非常致密生物（例如实心岩石）以及任何穿金属甲的对手，在同一战斗轮内第二次被击中时都会受到双倍伤害。

Monadic deva 可以随意使用 “Deva” 条目下列出的类法术能力，每轮 1 次，达到适用上限。它释放的光半径可按需要从 3–30 英尺变化。防护邪恶区域为半威力（+1）、半径 15 英尺。Monadic deva 还可以随意使用下列能力，每轮 1 次：定身怪物（仅元素；1 个生物，持续 8 回合；每天 3 次）或投影术（每天 1 次）。

Monadic deva 只能被 +7 或更好的武器击中。它们免疫来自魔法或不死生物的生命等级损失，也免疫任何来源的死亡魔法。它们的魅力效果为 19。

Monadic deva 呈乳白色，头发银色，眼睛无色。翅膀为白色并带银色光泽。除此之外，它们像非常强壮的人类，肩宽，身材英雄般健壮。

## Movanic Deva（摩瓦尼克天使）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–6 |
| 护甲等级 | -5 |
| 移动 | 12"/30"//21"（MC：B） |
| 生命骰 | 7+28 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 按武器类型（+5 力量加值） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 55% |
| 智力 | 非凡（感知=18） |
| 阵营 | 善良 |
| 体型 | M（6.5 英尺高） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IX／7850 + 18/生命值 |

Movanic deva 主要在物质位面、负能量位面、正能量位面和主物质位面上服役。对它们来说，力量是负面的还是正面的并无区别。Movanic deva 通常装备一把修长的剑，并以迅猛而娴熟的方式攻击。该武器通常在效果和命中、伤害特殊加值方面符合 +1 火焰之舌剑的特征。

Movanic deva 可以随意使用上文列出的类法术能力，每轮 1 次，达到适用上限。它释放的光半径可按需要从 2–20 英尺变化。防护邪恶是半径 10 英尺、半威力（+1）的区域。Movanic deva 还可以随意使用下列能力，每轮 1 次：造成或治愈失明、侦测陷阱，以及中和毒素（每天 3 次）。

Movanic deva 只能被 +7 或更好的武器伤害。任何种类的植物都不会、也不能伤害它们。同样，普通动物不会自愿攻击它们（爬行动物及类似生物和“怪物”可能会这样做）。它们免疫死亡魔法。生命等级损失、能量吸取以及负能量或正能量物质位面的其他能量效果都不会影响 movanic deva。它们的魅力效果为 18。
