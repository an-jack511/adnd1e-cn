## Dragonnel

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 3 |
| 移动 | 12"/18"（未骑乘时 MC：C；骑乘时 D） |
| 生命骰 | 8+4 |
| 巢穴内百分比 | 10% |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1–6/1–6/4–16 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立（邪恶） |
| 体型 | L（长 24 英尺以上） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／600 + 12/生命值 |

这些生物似乎同时与龙和空龙（翼龙）有着远亲关系，尽管它们是独立的物种。Dragonnel 虽然和小型龙一样大，却没有吐息武器。Dragonnel 会用长着利爪的前足凶狠地抓击，随后用满是尖牙的喙猛咬。这些生物智力低下，但有时也会做出邪恶行径。

过去，Dragonnel 曾栖息于 Greyhawk 世界，从 Kron Hills 和 Glorioles 一带直到 Drachensgrab Mountains；但除了 Pomarj 之外，这个物种如今几乎到处灭绝。在那里，这些怪物被捕获、驯服，如今被居住在当地、混迹于各类 humanoid 部落中的邪恶人类用作坐骑。

幸运的是，这些生物数量太少，不足以对周围国家构成严重威胁。不过有传言说，Wild Coast 沿岸曾有人目击过数十名骑乘 Dragonnel 的掠袭者。

Dragonnel 的腹部呈灰色，沿尾部渐渐变为尘土般的红紫色。背部棘刺为栗红色，喙为灰色，头部的褶冠为白色。

## Drelb（Haunting Custodian）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动 | 6" |
| 生命骰 | 5+3 |
| 巢穴内百分比 | 100% |
| 财宝类型 | 见下文 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 3–12 |
| 特殊攻击 | 寒颤（见下文） |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均至非常高 |
| 阵营 | 中立（邪恶） |
| 体型 | M |
| 灵能能力 | 见下文；攻击/防御模式：见下文 |
| 等级/经验值 | VI／800 + 6/生命值 |

Drelb 栖息于负能量位面，但心怀邪恶的人有时会将它们召唤到主物质位面，充当隐藏财富或秘密地点的守卫，因此它们只要在这个位面被遇到，就一定是在守护某种东西。不幸的是，Drelb 看起来非常像 wraith，在它发动攻击前，两者根本无法区分。

Drelb 的幽冥寒颤会使受害者在接下来一轮浑身发抖地倒在地上（无法豁免），立刻丢下手中持有的一切，并且在寒颤结束前无法进行任何行动。当一名牧师试图驱散它，或猎物显得犹豫不决时，这个狡猾的怪物会使用幻术诡计。它让自己的形体在向前平滑滑行时迅速缩小。这样有 90% 的概率会使观察者产生 Drelb 正在撤退的印象，而实际上它正向前移动并准备攻击。

虽然 Drelb 看起来像不死生物，但它们并不是不死生物，也不能被驱散。伤害 Drelb 需要魔法武器；银没有效果，除非是附魔银武器，而附魔银武器会造成双倍伤害。

Drelb 还拥有模仿和／或反射灵能的能力。在这种生物 30 英尺范围内使用的任何灵能，或指向它的任何灵能攻击，都会被模仿或反射回攻击者身上。

Drelb 只能说它们自己奇异的语言，但能够理解通用语中的简单短语。把 Drelb 吸引到主物质位面的魔法，很可能只能在日落至日出期间发挥作用；因此，和不死生物十分相像，Drelb 只会在暮光或黑暗中出现。

## Drider

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 3 |
| 移动 | 12" |
| 生命骰 | 6+6 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 个体财宝（×2）、Q |
| 攻击次数 | 1 |
| 每次攻击伤害 | 依武器类型，或 1–4 |
| 特殊攻击 | 法术、麻痹 |
| 特殊防御 | 无 |
| 魔法抗性 | 15% |
| 智力 | 高 |
| 阵营 | 混沌邪恶 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／875 + 8/生命值 |

Drider 是 Lolth 魔法的特殊产物。当具有潜力的 drow 达到 6 级或略高等级时，Lolth 会召唤它们，并让它们接受一项特别设计的试炼。未能通过的 drow 会变成 Drider。

Drider 看起来像巨型蜘蛛与 drow 的混合体。苍白、臃肿的 drow 躯干、头部和手臂上会长出 8 条蜘蛛腿。由于身体臃肿，无法分辨 Drider 的性别，但遭遇到的 Drider 中有 60% 为雌性。

Drider 会保留转化前拥有的 drow 能力；因此所有 Drider 都具有魔法或牧师能力，具体类型取决于它们是雄性还是雌性。雌性 Drider 拥有相当于 6 级或 7 级牧师的牧师能力；雄性 Drider 拥有相当于 6、7 或 8 级魔法使用者的魔法能力。

此外，Drider 还拥有 drow 的天然法术能力，因此每天能够施放以下法术一次：舞光术、黑暗术、侦测魔法、妖火、侦测阵营和浮空术。雌性 Drider 还可以每天施放一次洞悉术、侦测谎言、解除魔法和建议术。

战斗中，所有 Drider 都按 7 生命骰怪物进行战斗，通常使用剑或斧，不过许多 Drider 会把弓背在身后。Drider 也可以用咬击攻击，造成 1–4 点伤害。被咬者必须以 -2 惩罚进行对抗毒素豁免，否则会因 Drider 的唾液麻痹 1–2 轮。

Drider 是 drow 社群的弃民，因此对 drow 毫无好感。它们很少成群出现，更喜欢独自行动。Drider 有 10% 的概率会有 2–12 只巨型蜘蛛陪伴。它们通常生活在地下，经常尾随受害者，直到出现合适的击杀机会。它们的食物主要是受害者的血，因为它们已经获得了蜘蛛的习性。
