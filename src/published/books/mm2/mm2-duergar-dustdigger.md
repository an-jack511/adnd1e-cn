## Duergar

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–8 或 201–300 |
| 护甲等级 | 4 |
| 移动 | 6" |
| 生命骰 | 1+2 |
| 巢穴内百分比 | 5% |
| 财宝类型 | 个体：M、Q；巢穴：B（仅魔法物品）、F |
| 攻击次数 | 1（或更多） |
| 每次攻击伤害 | 依武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 豁免获得 +4 |
| 魔法抗性 | 标准 |
| 智力 | 平均至天才 |
| 阵营 | 守序邪恶（中立） |
| 体型 | S（高 4 英尺） |
| 灵能能力 | 71–90（每等级 2 点）；攻击/防御模式：B、C、D/F、G、H |
| 等级/经验值 | 可变／可变 |

Duergar 是一种很少遇见的邪恶矮人种族，也被称为灰矮人或灰色者。他们极端恶毒，居住在地下深处，在那里邪恶的本性不必承受阳光。通常只能发现少数这种邪恶生物，但偶尔也会发现拥有数百名 Duergar 的巢穴。

每遇到 4 名普通 Duergar，就会有 1 名拥有双倍生命骰，也就是说每 4 名中有 1 名为 2 级。若在巢穴外遇到 9 名，则会有一名拥有三倍或四倍生命骰（3 或 4 级）的额外 Duergar 领导这群生物。

一级 Duergar 携带镐、锤、矛链和盾牌，出现概率为 75%；二级 Duergar 携带镐、轻弩链和盾牌，出现概率为 25%。额外的武器和护甲如下：

| 数量 | 等级与装备 |
|---|---|
| +1/16 | 3 级：锤、短剑、板甲和盾牌 |
| +1/16 | 4 级：锤、短剑、板甲和盾牌 |
| +4–6 | 5 级：锤、短剑、板甲和盾牌 |
| +2–3 | 6 级：锤、短剑、板甲和盾牌 |
| +1 | 7–9 级：锤*、短剑*、板甲*和盾牌* |
| +4–6 | 3–6 级／3–6 级牧师／刺客：任意可用装备*／任意可用装备* |
| +1 | 7–9 级／7–9 级牧师／刺客：任意可用装备*／任意可用装备* |

*每等级有 5% 的概率出现魔法物品；若等级分段，取较低等级的一半加到较高等级上，并向上取整，以确定实际大致等级。

此外，还会有相当于普通战士总数 10% 的非战斗幼年 Duergar，也就是每 21–30 名中有 1 名幼年个体。Duergar 的巢穴总是在地下，规模庞大，由许多通道、房间、厅室和秘密区域组成。巢穴综合体中有 25% 的概率饲养着某种怪物守卫。巢穴中有 10–40 名奴隶的概率为 75%。掷 1d20 决定奴隶的种类：

| 1d20 | 奴隶 |
|---:|---|
| 1–8 | 山地矮人或兽人 |
| 9–12 | 矮人或地精 |
| 13–16 | 侏儒或 Xvart |
| 17–18 | 粗壮型半身人或 Kobold |
| 19 | Svirfneblin 或 Norker |
| 20 | 冒险者或其他生物 |

冒险者的类型通常是标准类型，而“其他生物”则包括 drow、Grimlock 等。

已知 Duergar 会与 Derro（见该条目）及类似的邪恶生物共同居住，但这种社群很少见。Duergar 以 3/6 的概率使敌人措手不及，而它们自己只有 1/10 的概率被措手不及。和普通矮人一样，Duergar 对魔法攻击（死灵魔法、变形术、魔棒等以及法术）的豁免获得 +4。它们免疫麻痹和毒素。幻术／幻象类别的法术不会影响 Duergar。

所有 Duergar 都拥有以下灵能学科：扩张、隐形、分子吸引和缩小。其施展等级等于经验生命骰数。

Duergar 拥有 12" 范围的红外视觉。它们会说地下生物使用的无声语言、自己的语言以及矮人语。有些还会说其他语言。

Duergar 看起来像消瘦、面容邪恶的矮人，皮肤为中灰至深灰色。他们喜欢穿暗淡颜色的衣服，通常选择能够融入环境的服饰。他们的寿命比普通矮人更长，有些能活到 500 岁以上。

## Dustdigger

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–20 |
| 护甲等级 | 4 |
| 移动 | 3" |
| 生命骰 | 4 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–8 + 受害者的护甲等级 |
| 特殊攻击 | 幻术／海市蜃楼（见下文） |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／165 + 4/生命值 |

Dustdigger 栖息在干旱地区，那里的土壤松散而多沙，例如沙丘。Dustdigger 通常会挖出一个洞，用一层沙子把自己盖住，然后使身体膨胀，填满自己挖出的洞，让上方地面与周围地形齐平。

当一只动物走到 Dustdigger 上方时，Dustdigger 会收缩，制造出极像流沙坑的区域。Dustdigger 会利用向自己口部移动的沙子减缓猎物逃跑。完全收缩后，它会把手臂折叠到受害者周围，并试图在吞食之前杀死对方。Dustdigger 的背面护甲等级为 4，但正面只有护甲等级 7。一旦 Dustdigger 折叠起来，猎物就会被困住，无法攻击。因此，最好的防御策略是在 Dustdigger 折叠之前认出它。

Dustdigger 看起来像围绕中央巨口、长着 5 条臂的巨型海星。它们只在夜间出现在地面上，而且一次从不超过几分钟。它们经常成群行动。

20% 的 Dustdigger 天生具有幻术才能。当接近的受害者进入攻击范围时，它们通常会在沙漠沙地中制造出一片冒泡的水池幻象。
