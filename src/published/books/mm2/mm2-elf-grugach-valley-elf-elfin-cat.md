格鲁加奇野精灵是与森林精灵相近的“野生”精灵，但体型更小、更瘦，肤色也非常白。他们完全排斥外族，甚至不信任其他种类的精灵。因此，除了在自己的部族群体中，他们几乎不会、甚至从不在外界被遇到。

除非另有说明，格鲁加奇野精灵符合木精灵以及精灵族的一般具体规则。尽管身材矮小，格鲁加奇野精灵肩膀宽阔、力量强大（力量骰额外 +2；将 19 或 20 按 18 处理）。

格鲁加奇野精灵不是魔法师，但拥有双职业的个体会是战士／德鲁伊。他们与森林中的所有动物关系良好，邪恶动物除外。他们经常（70%）以雄鹿为坐骑。

据称与木精灵的随机接触中，大约 20% 实际上会是与格鲁加奇野精灵的接触。所有成年格鲁加奇野精灵都能设置陷阱。这些陷阱主要是设在其家园领地内部及周围的坑洞和套索。所有这种陷阱都隐藏得很好，经过附近的生物几乎有 90% 的概率会掉入其中。如果角色在穿越陷阱区域时仔细检查，掉入陷阱的概率会降至 30%。

坑洞通常有 10 英尺深并布满尖桩，因此伤害为 1–4 点（落入土底坑洞），再加上每根尖桩 1–6 点，并有 50% 的概率附带毒素。套索通常会套住生物并把它们猛地拽离地面，使其悬在离地 5 英尺或更高处。有些套索可能是落木陷阱：沉重的木头会砸下，造成 5d6–8d6 点伤害，并把受害者压在下面。

无论谷地精灵是一个独立的精灵种族，还是灰精灵的一个分支，法师之谷（Mage Valley）的精灵（谷地精灵）都有鲜明的特征和个性。他们与大多数人类一样高大，身材纤细，面部特征尖锐而突出。他们隐居，并且憎恨入侵。总的来说，谷地精灵属于中立阵营。

除此之外，他们往往遵循灰精灵的相同特征，尽管据目前所知，除马以外他们不会使用其他坐骑。所有其他种类的精灵，包括黑暗精灵（卓尔），都会避开谷地精灵。反过来，后者也不喜欢与任何种族交往，或许只会容忍侏儒族。

在栖息地类型、群体构成、武器和特殊能力方面，谷地精灵遵循《怪物图鉴 I》中“精灵”条目（见该条目）的数据。

谷地精灵使用精灵犬（见该条目）作为守卫动物；75% 的游荡群体中会有 1–4 只，而在它们的巢穴中有 90% 的概率会有 2–8 只。在灰鹰世界（WORLD OF GREYHAWK™）奇幻世界设定中，谷地精灵只出现在法师之谷的紧邻区域。成群的谷地精灵曾袭入比塞尔（Bissel）、大边疆（Gran March）、凯特（Ket）和杰弗大公国（Grand Duchy of Geoff），这很可能是奉其领主之命行事。

他们对侏儒的容忍，可能源于这些半人类同样为法师之谷服务这一事实。

## 精灵猫 · Elfin Cat

|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 4 |
| 移动 | 18" |
| 生命骰 | 3+6 |
| 巢穴内百分比 | 5% |
| 财宝类型 | 见下文 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1–2/1–2/1–3 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 20% |
| 智力 | 半智能至低 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／135 + 4/生命值 |

精灵猫只栖息于温带地区的森林、林地。它通常被误认为野猫，或者可能是猞猁，但这是因为这种生物不希望被认出有什么不寻常之处。精灵猫速度很快，攀爬极其迅速，游泳良好，还能轻易跳跃 20 英尺或更远。

它们独居，但如果在巢穴中遇到，则会有 1 只成年雌性、1–4 只幼猫，并且 1 只雄性会在 1–4 轮内从一段距离外赶来。巢穴中的任何财宝，都是某个友善生物（例如精灵或侏儒等）放在那里安全保管的物品。

虽然精灵猫能用爪和牙攻击、防卫自己，但它们更喜欢避免这类冲突。它们依靠魔法力量生存，包括：放大术（每天 1 次）、缩小术（每天 2 次）、无踪无迹、树（树枝，不是整棵树；每天 2 次）和绊倒（每天 1 次）。放大术实际上会将攻击力提高到正常值的两倍。这些类法术能力按 9 级能力施展。

此外，精灵猫移动时能达到 99.9% 的无声程度。它们以 90% 的概率隐藏在自然环境中。敏锐的感官使它们除非在 20 次中出现 1 次，否则不会被突袭；反过来，它们以 5/6 的概率突袭对方。

精灵猫使用一种有限的超感知觉能力，读取附近生物的思想，以确定对方的友善或敌对意图。这些生物用自己的语言彼此交流。由于与精灵交往，它们会说几句精灵语；有些也会说侏儒、棕精灵等语言。

一只或多只精灵猫会与森林精灵、林地侏儒、棕精灵、小仙灵等社群结伴。作为食物和保护的回报，精灵猫会充当哨兵，报告区域内出现的怪物或其他入侵者，并说明这些生物有何意图。

精灵猫会以小型形态在田野和森林中游荡。它们只有为了吓退潜在敌人才会使用放大后的形态。

精灵猫大约有普通狗那么大。皮毛呈灰褐色，带有深棕色或黑色条纹。
