这种混沌的 pseudodragon 分支生活在所有气候中宁静而纠缠的森林里，常常与一群 sprites 或 pixies 同住。

Faerie dragon 可以随意变为隐形。隐形时它们仍能攻击，也能使用魔法或吐息武器。它们按 4 生命骰怪物攻击，咬击造成 1–2 点伤害。不过，faerie dragon 更可能使用“欣快气体”吐息武器。该生物喷出一个直径 2 英尺的球形气云，大小刚好足够让目标吸入一剂。

未能通过对抗吐息武器豁免的受害者，会在 3–12 轮内幸福地四处游荡；此期间无法攻击，实际护甲等级比正常情况差 10%。只要每轮在 1d20 上进行一次不高于自身智力的豁免，受害者就能继续把注意力放在周围情况上。一旦某轮智力豁免失败，他就会完全失去对当前事务的兴趣，表示气体已经发挥最大欣快效果。

除非走投无路或防卫巢穴，faerie dragon 绝不会以任何方式直接攻击。不过，它会在任何机会使用魔法对路人制造恶作剧。大多数（65%）faerie dragon 会按随附表格所示等级、像魔法使用者一样施法；35% 会使用德鲁伊法术。所有法术选择都只考虑制造恶作剧的潜力。除非某只 faerie dragon 想出了一个精妙的恶作剧，否则不会学习攻击性或防御性法术。所有 faerie dragon 在第一次有机会时都会学习水下呼吸和传说学识术。

虽然许多 faerie dragon 的恶作剧是临时起意，但一个大型恶作剧往往要准备数月。Faerie dragon 喜欢游泳和潜水。它们能够悬停，机动等级为 A。它们吃水果、根、块茎、坚果、蜂蜜和谷物，有时会费尽心思弄到新鲜苹果派。

所有 faerie dragon 都能在最远 2 英里的距离内相互进行心灵感应交流。它们会说自己的语言和阵营语言，以及 sprite、pixie、elf 的语言，还有当地鸟兽的语言。它们经常利用森林生物帮助自己制造恶作剧。

Faerie dragon 看起来像纤细的微型龙，长着可抓握的长尾巴、蝴蝶翅膀和巨大的笑容。它们的颜色从极幼个体的红色到远古个体的紫色，范围见附表。雌性的皮肤在阳光下闪耀明亮金色，雄性则带有银色光泽。

## Mist Dragon（Draco Nebulus Obscura）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1 或 2 |
| 护甲等级 | 1 或 -2 |
| 移动 | 6"/33" |
| 生命骰 | 9–11 |
| 巢穴内百分比 | 35% |
| 财宝类型 | X、Y、Z |
| 攻击次数 | 4 |
| 每次攻击伤害 | 1–4/1–4/2–24/2–8 |
| 特殊攻击 | 吐息武器、魔法使用 |
| 特殊防御 | 魔法使用 |
| 魔法抗性 | 标准或 30% |
| 智力 | 非凡 |
| 阵营 | 中立 |
| 体型 | L（51 英尺长） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 睡眠概率 | 20% |
| 等级/经验值 | VIII／3450 + 5/生命值；超过 36 生命值后每点 +50/生命值 |

Mist dragon 是独居生物，遇到一对配偶的概率只有 10%。这种生物只在瀑布、海岸或降雨量很大的地方（例如雨林）附近发现。遇到配偶时，双方总是成年或更老（年龄阶段掷 1d4+4）。巢穴总是某个巨大的天然洞穴、岩洞或类似地点。

至少有 50% 的概率，除非生物自己愿意，否则遭遇时无法认出 mist dragon。Mist dragon 能变成凝聚的气态形态并显现为雾，这是它们偏好的形态。受到烦扰或威胁时，它们当然会变为实体并攻击。雾形态下护甲等级为 -2，魔法抗性为 30%；实体形态下护甲等级为 1，魔法抗性为标准值。处于气态（雾）形态时，只能施放法术；其他攻击需要实体身体。

Mist dragon 的正常攻击顺序是双爪击、撕咬，以及用锯齿鳞片尾巴抽打。尾巴攻击只有当对手位于身后时有效。Mist dragon 每天 3 次可以喷出一团雾状蒸气，云团宽 3"、长 9"、深 3"。云中的所有呼吸空气生物都会失明 1–4 轮，并且必须进行对抗吐息武器豁免；失败者在留在云中期间每轮承受 3–12 点溺水伤害。成功通过豁免的生物会咳嗽、窒息，但每轮只承受 1–4 点溺水伤害。雾会持续 5–8 轮，取决于风的情况。Mist dragon 不受这种云雾影响。

### Mist Dragon 年龄法术

Mist dragon 会在适当年龄阶段获得下列法术。法术等级等于龙的生命骰；每种每天可以使用 2 次：

1=降水术（9–11 段时间）；2=制造水；3=水下呼吸；4=Zephyr；5=预测天气；6=云爆术；7=风之冲击；8=空气之水。降水术和云爆术见 Cloud Dragon；Zephyr 规则如下。

Mist dragon 会说自己的龙语方言，也能与几乎所有其他种类的龙交谈。大多数还会说一些通用语。

Mist dragon 的身体形态像金龙。即使在实体形态中，它们也半透明，颜色从灰白到蓝白不等。

### Zephyr

Zephyr 使一股温和气流从施法者处移动，并沿施法者面对的方向前进；气流会持续到达到法术区域范围为止。法术力量足以使小火焰摇曳跳动；它会扇动更大的火焰和火堆，使其燃烧更热（如适用，伤害骰 +1）。它能把移动中的蒸气云（如 cloud kill）挡住 1 轮；也会削弱 fog cloud 和 wall of fog，使持续时间减半。

它能把停滞空气、蒸气甚至毒气向后推 1"；除非蒸气或气体在某个源头被重新补充，这股力量也会使它们的持续时间和效力减半。持续时间：1 段时间；射程：0；效果区域：宽 1" 的路径，长度为每等级 1/2"；施法时间：2 段时间。
