## Foxwoman（狐女）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1（见下文） |
| 护甲等级 | 2、4 或 6 |
| 移动 | 24"、18" 或 12" |
| 生命骰 | 8+1 |
| 巢穴内百分比 | 25% |
| 财宝类型 | E、Q（×5）、S |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–2 或 2–12，或依武器 |
| 特殊攻击 | 魅惑、法术 |
| 特殊防御 | 只有银制武器或 +7 及更好的魔法武器才能命中 |
| 魔法抗性 | 标准（精灵女人形态除外） |

| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1700 + 12/生命值 |

Foxwoman 有 3 种形态。它们对同类之外的生物而言总是独居；所有形态都拥有 6" 黑暗视觉。它们喜欢偏僻的林地，并且总有 2–5 名被魅惑的人类男性作为仆人和伴侣。巢穴是藏在树林中的小屋，或布置舒适、具有各种人类生活用品的洞穴。男性会武装自己来保护主人。男性伴侣有 25% 的概率是精灵，25% 是人类，50% 是半精灵。

至少有一名男性是战士（70%）或游侠（30%），等级为 2–5 级；第二至第五名男性有 50% 的概率是 1–4 级战士。另有 10% 的概率会有一名牧师（10%）、德鲁伊（45%）、魔法使用者（6%）、幻术师（5%）、盗贼（25%）或其他职业（10%），等级为 1–4 级。精灵和半精灵有 25% 的概率兼任多个职业；如果掷骰结果显示出职业重复，则自动视为兼职。其余男性都是 0 级战士，或拥有 1 个生命骰的精灵／半精灵。魔法物品依照《地下城主指南》附录 P 使用。

巢穴有 10% 的概率藏着一名被偷来的精灵女孩。她的年龄为 1d8+4（6–13 岁）；12 或 13 岁的女孩正常成为 Foxwoman，其他年龄的女孩不会战斗。只有 Vixen 形态能够传染这种状态。

### Silver Fox 形态

Silver Fox 是一只大型狐狸，移动率为 24"，可以使用无踪步。只要不在视野内，且有天然掩护，它有 90% 的概率不会被发现。

### Vixen 形态

Vixen 是狐狸与精灵的混合体，长着银色皮毛、精灵身体和狐狸头。它的咬伤会感染精灵或半精灵女性；除非在 3 天内同时施展祛除疾病和移除诅咒，否则受害者会变成 Foxwoman。

### Elven Woman 形态

Elven Woman 的美貌值为 21，对人类和半人类男性尤其有效。智慧低于 14 的男性会被魅惑；智慧为 14 或更高的男性不会被魅惑，但仍会被吸引。她会留下自己喜欢的男性，其他人则被悄悄杀死。只要有机会，矮人、侏儒和半身人都会被自动杀死。

她以 1–4 级魔法使用者的能力施法，但不会继续升级；戏法和法术随机决定。她有 90% 的概率抵抗睡眠和魅惑，并在使用弓和剑时获得 +1。银色头发和寡妇峰是识别她的线索。

## Seawolf（Greater）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 4–16 |
| 护甲等级 | 5 |
| 移动 | 9"／27" |
| 生命骰 | 9+2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 或 2 |
| 每次攻击伤害 | 3–12，或 1–2 及依武器 |
| 特殊攻击 | 无 |
| 特殊防御 | 只有银制、冷铁或 +1 魔法武器才能命中 |
| 魔法抗性 | 标准 |
| 智力 | 低至高 |
| 阵营 | 混沌邪恶 |
| 体型 | L（长 12–15 英尺）或 M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／800 + 12/生命值 |

Seawolf 是邪恶的狼人形生物，成群生活在海水中。它们曾经是渔夫或水手，会跟踪船只，以人形偷偷登船，发动攻击，咬伤或杀死 1–2 名甲板水手，夺取武器，然后发动全面进攻。铁制武器和银制武器、魔法武器一样，都能伤害 Greater Seawolf。

没有致命伤的咬伤会在 2–5 天内造成 Seawolf 狼人感染。被感染者会在夜间跳下船，变形后游向狼群。

它们能呼吸空气；潜入水下 17–24 分钟后，必须浮出水面换气。人形具有狼一般的面孔、小耳朵、厚毛和鬃毛。Seawolf 形态是长着狼头的巨大海豹，拥有獠牙。

Lesser Seawolf 有 2 种形态：一种是长着狼头、覆盖皮毛的鼠海豚般生物，另一种是狼人的形态。它们成群在海中猎食，会包围猎物并撕咬。狼形人是人类外形，拥有毛皮、爪和牙齿。

它们呼吸空气，必须像海豚一样浮到水面。与其他狼人形生物不同，普通武器能够命中它们。人类只要承受至少相当于全部潜在生命值 50% 的伤害，就会感染；在陆地上时，它会冲向大海；在海上时，它会在下一个满月跳入海中消失。

狼群会攻击船只，随后变成狼形人登船，杀死所有人并击沉船只。
