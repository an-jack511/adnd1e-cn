|---|---|

| 特殊防御 | 见下文 |

Galeb Duhr 是一种奇特的巨石状生物，附肢充当手和脚。这些有智慧的生物体型巨大，行动缓慢。它们生活在岩石或山区，在那里能感受“土之力量”，并控制周围的岩石。

Galeb Duhr 可以像 20 级魔法使用者一样施放下列法术，每轮一次：移土术、塑石术、穿墙术、石转泥和石墙术。它们能像 Treant 控制树木一样，使 6" 内的 1–2 块巨石活动起来（护甲等级 0；移动 3"；生命骰 9；伤害 4d6）。

Galeb Duhr 受到寒冷类攻击时承受双倍伤害，并以 -4 惩罚进行对抗寒冷的豁免。它们不受闪电或普通火焰伤害，但会承受魔法火焰的全部伤害，对火焰攻击的豁免获得 +4。

## GIANT

巨人是体型巨大的类人生物。《怪物图鉴 I》中描述了巨人族的 6 个主要种族，下面以及《恶魔宝典》中还列出了若干次要种族。每个种族都与其他种族有一些相似之处，也有许多差异。共同特征见《怪物图鉴 I》中的“Giant”条目。

## Fomorian Giant

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–4 |
| 护甲等级 | 3 |
| 移动 | 9" |
| 生命骰 | 13+1–3 |
| 巢穴内百分比 | 45% |
| 财宝类型 | D、Q（×10） |
| 攻击次数 | 1 |
| 每次攻击伤害 | 4–32 |
| 特殊攻击 | 无 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 中立邪恶 |
| 体型 | L（高 13.5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／2750 + 18/生命值 |

Fomorian 是巨人族中最丑陋、畸形且邪恶的种类。他们倾向于独居，栖息在山洞或废弃矿井等荒凉地点。他们厚实、多毛的皮肤，加上用于保护自身的毛皮和奇怪金属片，使有效护甲等级达到 3。

虽然这些畸形怪物相对于自身大小移动缓慢，但它们可以极其隐蔽地移动，并根据地形获得 +1 至 +3 的突袭优势。

如果在巢穴中遇到它们，则每名雄性有 25% 的概率会有 1–2 名雌性；每名雌性还会有 1–3 名幼体。雌性与雄性相同，但生命骰不获得额外加值。幼年 Fomorian 具有以下数据：

| 体型阶段（年龄） | 生命骰 | 伤害 |
|---|---:|---:|
| 小型（1） | 7d4 | 2–8 |
| 半成年（2–3） | 13d4 | 4–16 |
| 接近成年（4–6） | 13d6 | 4–24 |

虽然畸形使它们无法投掷岩石，但同样的缺陷也让 Fomorian Giant 在正常情况下永远不会被突袭。位置奇怪的眼睛、巨大的耳朵和／或大鼻子，使它们能够察觉任何正常的接近方式。

使用的武器从巨大木棒到连接沉重金属球的链条不等。最强壮的 Fomorian 有时会使用粗制盾牌和更好的护甲，因此护甲等级可能达到 2，甚至 1。

Fomorian 会有可怕的畸形，例如一条手臂长在错误的位置；短腿上长着巨大的脚；像鱼一样位于侧面的眼睛，或者头后长着一只眼睛；背部有驼峰；尖而狭长的头；扇动的耳朵；张开的或极小的嘴；巨大的鼻子或口鼻部，等等。它们身上零散地长着一片片像铁丝一样坚硬的毛发。

## Firbolg

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 或 4–16 |
| 护甲等级 | 2 |
| 移动 | 15" |
| 生命骰 | 13+2–7 |
| 巢穴内百分比 | 45% |
| 财宝类型 | 个体：M（×10）、Q；巢穴：E |
| 攻击次数 | 1 |
| 每次攻击伤害 | 依武器类型 + 力量加值 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 15% |
| 智力 | 平均至天才 |
| 阵营 | 中立（混沌善良） |
| 体型 | L（高 10.5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VIII／3650 + 18/生命值 |

在巨人族的次要种族中，Firbolg 是最强大的。他们谨慎、狡猾，并拥有相当强的魔法力量。他们已经学会不信任并畏惧人类，只会出现在偏远而荒野的地方。90% 的遭遇会是小群 Firbolg 或一名独行者；不过有 10% 的概率，遭遇的是为某种目的聚集在一起的几个群体组成的联盟。

Firbolg 偏爱双手剑和大型 halberd。所有 Firbolg 武器都非常巨大，因此他们用一只手使用自己偏爱的、由人类制造的武器，而自己的武器则用一只或两只手使用。他们的双倍尺寸木棒、斧、矛等武器，若用双手使用，会造成双倍正常武器伤害。

一只手空闲的 Firbolg 能够拍开箭、弩矢、子弹、飞镖和石块之类的射弹，或抓住诸如标枪之类的射弹。他们每轮可以这样做两次，并在 1d20 上掷出 6 或更高即可成功（75% 的概率）。

除魔法抗性外，每名 Firbolg 还拥有与生命骰有关、且不受年龄影响的天生类法术能力；只要没有在近战中被其他事情占用，就能随意使用，每轮一次。这些能力是：侦测魔法、如药水般的缩小术（效果和最大持续时间均加倍）、伪造黄金、遗忘术和改变自身。每项能力每天可使用一次。

每遇到一名 Firbolg，就有 5% 的概率其中 1 名是萨满。不过，除标准萨满法术外，Firbolg 萨满还能每个等级使用 2 个随机决定的一环幻术师法术。在 6 级和 7 级时，Firbolg 萨满同样会获得随机决定的二环幻术师法术。因此，7 级萨满除其他法术和类法术能力外，还会有 10 个一环和 4 个二环幻术师法术。

这些看起来像人类的巨人并不总会张开双臂欢迎陌生人，但通常 Firbolg 不会试图杀死他们（当然，除非受到挑衅）。不过，他们确实喜欢伪装成小个子，骗走人类的财宝。

## Verbeeg

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–2、1–6 或 5–30（见下文） |
| 护甲等级 | 4 或更好 |
| 移动 | 18" |
| 生命骰 | 5+5 |
| 巢穴内百分比 | 30% |
| 财宝类型 | 个体：K、L、M（×5）；巢穴：B（但魔法物品为 25%） |
| 攻击次数 | 2 |
| 每次攻击伤害 | 依武器类型 + 力量加值 |
| 特殊攻击 | 投掷矛造成 1–6（+力量加值） |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均至非常高 |
| 阵营 | 中立（邪恶） |
| 体型 | L（高 8.5–10 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／275 + 6/生命值 |

Verbeeg 或人类巨人，是一种居住在与 hill giant 和 ogre（见相关条目）相同区域的人类巨人种族。与 Verbeeg 的遭遇有 30% 的概率会与 hill giant（40%）或 ogre（60%）一起发生；有 50% 的概率会遇到 1–6 名游荡生物；有 30% 的概率是在巢穴中，此时共有 5–30 名 Verbeeg；另有 20% 的概率会遇到 1–2 名加上其他生物。

由于 Verbeeg 有智慧，它们通常会指挥与其共同居住的 hill giant 或 ogre。此外，如果这些巨人拥有防护材料，也会用来改善护甲等级，例如毛皮、兽皮、盾牌等奇怪金属片。Verbeeg 通常使用木棒和矛，但那些能获得更好武器的个体会使用更好的装备。

Verbeeg 的力量范围为 18/51 至 18/00。掷 1d10 确定力量及相应加值：

| 1d10 | 力量 | 加值与投掷距离 |
|---:|---|---|
| 1–2 | 18/51–75 | +3，投掷距离 +3" |
| 3–6 | 18/76–90 | +4，投掷距离 +4" |
| 7–9 | 18/91–99 | +5，投掷距离 +5" |
| 0 | 18/00 | +6，投掷距离 +6" |

投掷矛拥有正常射程，另加 3–6" 的奖励射程。因此，力量 18/00 的 Verbeeg 能把矛投到 9" 远，造成 7–12 点伤害。每名 Verbeeg 遭遇时至少会有 3 支矛。

Verbeeg 的巢穴中总会有一名力量 18/00、生命值不低于 40 的首领。首领会有 2 名雌性，每多 1 名雄性就会有 1 名雌性。幼年 Verbeeg 约占总人口的 50%。当人口超过 9 时，所有遇到的 Verbeeg 有可能（每名 Verbeeg 2%）带有一名任意性别的萨满。Verbeeg 萨满最高可达 7 级。

部落有 90% 的概率不会拥有它们无法理解或使用的魔法物品。雌性与雄性在战斗中相同。幼年个体的战斗能力相当于 Bugbear（50%）或 Goblin（50%）。巢穴中会有 2–8 只狼（75%）或 1–4 只 worg（25%）作为守卫。在北极气候中，会饲养 1–3 只冬狼（25%）或 1–2 只北极熊（75%）来执行这一职责。

Verbeeg 相对于自身的巨大身高而言异常瘦削。有些还带有畸形，使其外表更加可怕。著名的 Verbeeg 通常是跟踪人类的恶棍（Jimmy Squarefoot 和 Jack-in-Irons 就是其中两名），除此之外它们看起来像人类。
