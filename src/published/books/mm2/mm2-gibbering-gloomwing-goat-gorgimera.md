## Gibbering Mouther

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 1 |
| 移动 | 3"/6" |
| 生命骰 | 4+3 |
| 巢穴内百分比 | 95% |
| 财宝类型 | Q |
| 攻击次数 | 6+ |
| 每次攻击伤害 | 1（×6）+ 每轮 1 |
| 特殊攻击 | 吐液、喃喃、对抗混乱的豁免 |
| 特殊防御 | 控制半径 5 英尺内地面的密度 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立 |

| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／210 + 5/生命值 |

Gibbering Mouther 是一种类似变形虫的生命形态，由大量嘴和眼睛组成。它最喜欢闭上眼睛和嘴，潜伏等待，使自己看起来像一块土质材料。这样一来，它就能突袭偶然经过的队伍。它唯一的动机是吃掉一切可食且够得着的东西，无论食物是动物、植物还是矿物。由于过度饥饿，Mouther 的巢穴及周围区域都会被啃食得一干二净。

Gibbering Mouther 喜欢栖息在寒冷和地下区域。这种生物通过向前渗流来推动自身，先把数张嘴固定在地上，再将身体向前拉动。在泥浆和流沙等流动、黏稠的地形上，Mouther 能通过一连串肌肉收缩移动得更快。若有机会，它会使用自己的特殊能力改变地面（见下文），让这种快速移动方式成为可能。

Mouther 的大脑位于身体中部，而胶状身体使这个要害很难被击中；因此它的护甲等级为 1。

Mouther 的攻击方式不止一种。如果 Mouther 的唾液击中坚硬而寒冷的表面，就会爆发出明亮的闪光。若正在看向闪光的角色未能通过对抗石化的豁免，闪光会使其失明 1 轮。

Mouther 会伸出嘴并以每轮 6 张嘴进行撕咬。每张命中的嘴都会咬住目标，并在保持连接的每轮额外吸取 1 点伤害。当 3 张或更多嘴同时咬住一名角色时，该角色从此每轮必须检查是否滑倒。在 2d6 上掷出 4 或更低表示角色倒地（若敏捷为 15 或更高则获得 +1）。若角色倒地，Gibbering Mouther 会流过受害者，用另外 12 张嘴进行撕咬。如果有机会在拖倒一名受害者后继续捕猎，Mouther 会困住其他猎物。

当 Mouther 看见任何可食物体时，它可以开始发出语无伦次的喃喃声；除非在对抗法术时豁免成功，否则半径 6" 内的所有角色都会陷入混乱。每听到喃喃声 1 轮，范围内角色都必须再次豁免。如果角色陷入混乱，掷 1d8 决定其行动：

| 1d8 | 混乱行动 |
|---:|---|
| 1 | 徘徊 1 轮 |
| 2–5 | 晕眩站立 1 轮 |
| 6–7 | 攻击最近的活物 1 轮 |
| 8 | 视为受到恐惧术影响（豁免获得 +2），逃跑 2 轮 |

Mouther 会持续加热自己半径 5 英尺内的地面和石头，并能通过改变这种材料的稠度来控制其状态，使其变成面团状、黏稠的流沙或混凝土。改变泥土需要 5 段时间，而使石头转变为下一个最接近的形态需要完整 1 轮。

Gloomwing 是速度和敏捷都极高的空中食肉动物。它们的幼虫阶段是 tenebrous worm（见该条目）。虽然 Gloomwing 不如 tenebrous worm 强壮，但仍然是致命的对手，会积极寻找空中和地面上的猎物。

这种生物的翅膀和身体带有黑色与银色的几何图案；任何从正上方直视怪物的有智慧生物都会因此陷入混乱（对抗法术豁免，否则混乱）。这种色彩还提供了极佳的伪装，使 Gloomwing 几乎无法被发现。因此，Gloomwing 在 1d6 上掷出 1–3 时获得突袭。

地面上体型小于半身人的生物会被带走，并在半空中吞食；较大的猎物则会遭到悬停和劈砍攻击，使用 2 只前爪和颚，因为这种生物缺乏同时使用全部 8 只爪的力量和协调能力。在近战的第 2 轮以及每个后续轮次，Gloomwing 会释放一种可能导致非昆虫生物虚弱的信息素。暴露的生物必须进行对抗毒素的豁免，否则每暴露一轮失去 1 点力量。失去的力量会在暴露停止后 1–4 段时间恢复。第一次豁免成功的生物不必再次豁免，多个 Gloomwing 也不要求多次豁免。

这种气味还可能吸引额外的 1–4 只 Gloomwing（每轮 20% 的概率，与现场已有 Gloomwing 的数量无关）。

产卵雌性（1d6 掷出 1–2）会把被杀死猎物的尸体用作产卵处；12 天后，4–10 条 tenebrous worm 会从尸体中孵出。除非用祛病术清除感染，否则尸体无法承受任何复活尝试。如果不杀死蠕虫，它们会将尸体完全吞食。

Gloomwing 是巨大的蛾，翅膀和身体布满黑银条纹。大型蕨类植物般的触角为暗紫貂色，尖端为白色。8 条腿的每一条都装备着彩虹色珍珠爪。伸出的嘴配有两组象牙颚，每只 Gloomwing 的颚价值 25 gp。

| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 混沌邪恶 |
| 体型 | L（肩高 5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／2557 + 14/生命值 |

虽然 Gorgimera 的外表与 Chimera 相似，但它是更可怕的怪物。这种不育的混合体拥有 gorgon 的后躯和头部、lion 的前躯和头部，以及 red dragon 的中段身体、翅膀和头部。

只有 Lion 部分的护甲等级为 5。Gorgimera 可以用爪攻击，用 Lion 头咬击，用 Gorgon 头顶撞，用 Dragon 头咬击。此外，Gorgon 头每天可以两次呼出石化吐息（长 3"、底部宽 1" 的锥形区域），Dragon 头每天可以两次呼出火焰吐息（长 5"、底部宽 2" 的锥形区域）。

面对 10 英尺或更远的对手时，怪物总会使用其中一种吐息武器，因为它知道吐息武器的范围和效果。在近战中，它有 1/6 的概率使用火焰吐息，也有相同概率使用石化吐息（掷 1d6：1=龙息；2=石化吐息；3–6=标准攻击顺序）。

龙息造成 3–24（3d8）点伤害，适用对抗吐息武器的豁免。除非受害者成功通过对抗石化的豁免，否则 Gorgon 吐息会将其变成石头。Gorgimera 会说一种极其有限的 red dragon 语言。Gorgon 头能够看入星界位面和以太位面，其吐息武器也能延伸到这些位面。

Gorgimera 看起来几乎与 Chimera 完全相同，只有 Gorgon 部分呈金属蓝色。Gorgon 的眼睛为带红色边缘的淡蓝色。
