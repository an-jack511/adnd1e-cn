## Greenhag

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | -2 |
| 移动 | 12"/12" |
| 生命骰 | 9 |
| 巢穴内百分比 | 40% |
| 财宝类型 | M（×100）、N（×10）、Q（×5）、X |
| 攻击次数 | 2 |
| 每次攻击伤害 | 7–8/7–8 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 35% |
| 智力 | 低至非常高 |
| 阵营 | 中立邪恶 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1600 + 12/生命值 |

Greenhag 是一种邪恶生物种族，与 annis 和 nighthag（见相关条目）都有亲缘关系。和 annis 一样，Greenhag 栖息在主物质位面。许多这种可怕生物生活在森林和荒凉的沼泽地，也有一些居住在湿地和河流中。后面这些通常被称为 shellycoat。它们的巢穴总是一个小洞穴，可能是挖在土中的。

任何种类的 Greenhag 都用岩石般坚硬的爪子抓击攻击。它们的力量为 18/00，因此每次这种攻击的伤害额外获得 +6。

为了把受害者引诱到身边，Greenhag 通常使用模仿能力。这使它们能够模仿成年或未成年、男性或女性、人类或半人类的声音。呼救声、哭泣声等都是 Greenhag 经常使用的欺骗手段。它们还能够模仿常见动物的声音，例如家禽、猫、狗、山羊、绵羊和牛的声音。

Greenhag 拥有以下类法术能力：一次只能使用 1 项，每轮 1 次，且可以随意使用：听觉幻象、舞光术、隐形术、无踪通过、改变自身、与怪物交谈、水下呼吸、虚弱术。每项能力都按 9 级能力施展。

由于颜色，以及它们有 90% 的概率能够无声移动并藏在树叶中（即使是水下植物），Greenhag 以 5/6 的概率发动突袭（若从隐形状态攻击则为 19/20）。由于感官极其敏锐，包括红外视觉和超视觉，它们只有 1/20 的概率被突袭。

Greenhag 会说自己的语言（Annis 的一种方言）、Ogre 语、通用 Giant 语和通用语。

典型的 Greenhag 看起来像有绿色皮肤的 Nighthag。毛发颜色从接近黑色到橄榄绿色不等，眼睛颜色从琥珀色到橙色不等。它们经常像农民一样穿衣。

## Grippli

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–10；巢穴内 5d6 |
| 护甲等级 | 9 |
| 移动 | 9"/15" |
| 生命骰 | 1+1 |
| 巢穴内百分比 | 30% |
| 财宝类型 | Q（×4）、I |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–4 或依武器类型 |
| 特殊攻击 | 以 1–4 突袭 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 非常高至非凡 |
| 阵营 | 中立 |
| 体型 | S（高 2.5 英尺） |
| 灵能能力 | 1561–250；攻击/防御模式：A、C/G、J |
| 等级/经验值 | II／45 + 2/生命值 |

Grippli 看起来像小型、聪明的类人树蛙。它们吃昆虫和水果。Grippli 的手脚适合在树枝间轻松移动。它们的寿命可达 700 年，后代很少。Grippli 生活在沼泽和雨林中。灰绿色的皮肤为它们提供天然伪装（以 1–4 突袭）。它们拥有 10" 范围的超视觉，因此无论昼夜都能很好地活动。

Grippli 不好战。它们喜欢鲜艳的颜色，据说曾袭击旅行者，偷走鲜艳衣物来装饰自己的小屋。它们用套索、网、毒镖和弩矢保护自己，偶尔也使用剑或匕首。少数个体（1%–2%）拥有灵能力量。

Grippli 的巢穴建在地面上，由泥土和木头小屋组成。巢穴中会有 5–30 名雄性、同样数量的雌性以及 1–6 名后代（非战斗者）。此外，部落母亲也会在那里；她的护甲等级为 7，生命骰为 3，伤害为 1d6+1，并且每天一次可以释放麝香云，将其视为臭云术。部落母亲会有 1–3 名配偶，配偶的护甲等级为 8，生命骰为 2，伤害为 1d4+1 毒素。
