## Grig

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–12（或 5–50） |
| 护甲等级 | 2 |
| 移动 | 6"（或跳跃 12"） |
| 生命骰 | 1/2+1（2–5 点生命值） |
| 巢穴内百分比 | 10% |
| 财宝类型 | X、Y |
| 攻击次数 | 3 或 2 |
| 每次攻击伤害 | 依武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 法术 |
| 魔法抗性 | 30% |
| 智力 | 低至平均 |
| 阵营 | 中立善良 |
| 体型 | S（高 1.5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／50 + 1/生命值 |

跳跃的 Grig 看起来像某种 Sprite。它们只在 sylvan woodland 和草地中发现，害羞怕生，但其他方面性情善良友好。它们是夜行生物，在大多数情况下会在林间空地被遇到。那里可能有 1 个或几个其他 Grig 群体，或者一支 Atomie 部族（见该条目），或两者都有；它们会聚集在月光下游戏和跳舞。

其他 Grig 或 Atomie 出现的概率为 30%：1–15=5–50 只 Grig；16–25=2–12 只 Grig 和 30–120 只 Atomie；26–30=5–50 只 Grig 和 30–120 只 Atomie。一个或多个 Grig 会演奏弓弦乐器，其他成员则享受圆圈舞和其他消遣。

Grig 的高护甲等级来自体型、敏捷和跳跃能力。它们的腿更像蟋蟀或蚱蜢，而不是 Sprite 的腿；再加上小而纱质的翅膀，这些肢体使 Grig 能跳跃很远的距离。

它们只攻击邪恶敌人或骚扰 Grig 的人。通常会结合发射投射物和近战攻击。由于技巧和敏捷，Grig 投掷投射物时命中获得 +2。每只 Grig 至少携带 6 支小镖，会在跳跃飞行中投掷；随后落地，用针状匕首刺击。

Grig 的小镖由 Grig 使用时等同大型镖，但其他人使用时每支只造成 1 点伤害。同样，Grig 的匕首对 Grig 而言等同短剑造成伤害，但在其他人手中只是一把小刀。

Grig 拥有以下类法术能力：一次只能使用 1 项，每轮 1 次，可以随意使用：改变自身、纠缠、隐形术、烟火术、绊倒和腹语术。这些魔法能力按 6 级能力使用。

Grig 喜欢用这些魔法进行快乐的恶作剧，也用来保护自己；与这些生物相遇时，人们报告过许多恶作剧。

Grig fiddler 有 25% 的概率能够演奏出效果等同于魔法使用者法术 Otto's Irresistible Dance 的曲调。对抗法术的豁免适用于演奏者 30 英尺范围内的所有生物。豁免失败意味着受害者必须一直跳舞，直到 Grig 停止演奏，或受害者因疲惫倒下。Grig 可以演奏数小时。

Grig 有 90% 的概率发动突袭，自己被突袭的概率只有 10%。它们的听觉是人类正常水平的两倍，拥有 180 英尺红外视觉和超视觉。

除了自己的语言外，Grig 还会说 Atomie、Brownie、Pixie 和 Sprite 的语言。当然，如果它们愿意放慢语速并降低音调，也能说通用语。

## Grim

| 项目 | 数值 |
|---|---|

| 出现数量 | 1 |
| 护甲等级 | 0 |

| 生命骰 | 4+2–8 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 见下文 |
| 每次攻击伤害 | 见下文 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 25% |
| 智力 | 平均 |
| 阵营 | 中立善良 |

| 等级/经验值 | V／285 + 5/生命值 |

Grim 是守卫者，会监视并对抗邪恶。它们是夜行生物，通常出没于人类聚居地的边缘或墓地。Grim 会以以下形态中的任意一种被遇到：黑猫（攻击方式如 Giant Lynx：1–2/1–2/1–4，并带撕裂攻击）、黑狗（攻击方式如 War Dog：2–8）以及黑猫头鹰（攻击方式如 Giant Owl：2–8/2–8/2–5）。

每只 Grim 必须以所选形态完整维持一整夜。白昼时它们会变成以太态，等待太阳落山。前一天承受的伤害会在第二天日落时减轻。

除所选形态本身的攻击方式外，Grim 还能像 8 级牧师一样驱散不死生物；如果对象是来自下层外层位面的邪恶生物，驱散骰获得 +2。

只有具有 +7 或更高魔法附魔的武器才能命中 Grim。每只 Grim 会在 10 英尺半径内持续散发防护邪恶，并能在 7" 距离内侦测邪恶。因此，邪恶生物永远不会突袭它们，而它们的感官使其能够以 1/10 的概率突袭其他生物。

Grim 通常驱逐邪恶生物，并警告善良生物这些怪物即将带来的危险。警告通过奇怪的叫声完成，可能是哀鸣、嚎叫或悲伤语调的呜咽。除非眼前即将发生冲突，否则它们不会与人类或半人类交流，也不会为此做其他事情；在这种情况下，它们总会协助对抗邪恶。

## Grue, Elemental：Chaggrin

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见（不常见） |
| 出现数量 | 1（2–5） |
| 护甲等级 | 4 |
| 移动 | 12"（3"） |
| 生命骰 | 5+5 |
| 巢穴内百分比 | 无（20%） |
| 财宝类型 | 无（C、Q×5） |
| 攻击次数 | 2 |
| 每次攻击伤害 | 3–6/3–6 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 需要 +7 或更好的武器才能命中；免疫土元素魔法 |
| 魔法抗性 | 标准 |
| 智力 | 低至平均 |
| 阵营 | 中立邪恶 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／425 + 6/生命值 |

Chaggrin 或 soil beast，是来自土元素位面的 Grue。在主物质位面上，它通常呈现黄色刺猬的形态，但像头骨一样的头部很容易将它与普通动物区分开。它虽然只有 2–3 拃长，却重达 140 磅，有些甚至重达 210 磅。

Chaggrin 喜欢折磨受害者，通常会把长而锋利如剃刀的前爪挖进猎物体内，然后抓住不放；可怜的受害者会四处奔逃，试图逃离或甩掉这个 Grue。

这种黏附每轮额外造成 7–12 点伤害。若 Grue 处于刺猬形态，未受保护的皮肤接触它的刺，每轮会受到 1–4 点伤害。

任何影响土地的法术都不能对 Chaggrin 生效，包括地震术、挖掘术、透视术、石化术、塑石术、穿墙术、移土术、玻璃钢术、石转泥、石墙术和石转肉。仅仅有 Chaggrin 在这种魔法 40 英尺内，就会驱散该魔法，即使其魔法效果此前已经永久化。魔法物品不受影响。

Chaggrin 可以随意变成大型鼹鼠、刺猬或双足类人形态。最后一种是它在自己位面的自然形态。在这种形态下，它能融入天然土壤或石头的表面，并突然出现，以 1–5 的概率突袭对手。唯一能发现这个 Grue 存在的线索，是仔细观察区域时才能隐约看见的一道潮湿、黑暗轮廓。

Chaggrin 的自然形态令人恶心。身体看起来像块状、潮湿的黏土，面容不对称而凶恶。小眼睛闪烁着野兽般的光芒。
