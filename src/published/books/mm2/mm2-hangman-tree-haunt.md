## Hangman Tree

| 特殊防御 | 见下文 |

Hangman Tree 因其绳索般的附肢而得名。这些强韧藤蔓的末端像套索，垂下时看起来就像悬挂的绳子。Hangman Tree 是落叶树，分布于温带至亚热带气候。浅根系和少量叶片使它们必须通过直接摄入蛋白质来补充营养，因此每棵树都会捕捉猎物。

Hangman Tree 能非常缓慢地移动，完全长成后每天实际只移动几英尺。幼树*每小时移动约 6 英尺，成熟树的速度约为其三分之一。所有 Hangman Tree 都独居。天气结冰时，它们会扎下主根并进入休眠。

Hangman Tree 对任何财宝都不感兴趣，而且因为不断移动，附近很少能找到财宝，不过无法消化的物品会定期从树干腹部排出。

树会把套索般的附肢垂向猎物进行攻击。每棵树有 6–9 条附肢，但一次只能控制 3 条。切断并摧毁一条藤蔓需要 13–20 点伤害；这不计入对树本体造成的伤害。

藤蔓附肢接触受害者后会收紧。藤蔓每轮造成 1–3 点伤害，并收紧、吊起重达 1000 磅的猎物，将其送到上方树干的开口处。这需要完整 4 轮。第 5 轮，受害者会被丢入 Hangman Tree 树干桶状腔体内的酸性分泌物中。受害者每轮受到 3–12 点酸伤害，直至死亡，随后开始消化。

由于树干胃部开口周围有尖锐的生长物，且尖端向下、向内，几乎不可能从树干胃中逃脱。一次最多约能容纳 3 名与人类同等大小的受害者。

每棵 Hangman Tree 都有一种幻觉香气，可以随意释放，通常在猎物距离 30–80 英尺时释放。这会使受害者以为它是一种普通的 quickwood、Treant 等。经过多年学习，这种树可以结结巴巴地说通用语。每棵树还根据年龄拥有魔法抗性，因为它从周围环境中汲取力量。

闪电或电击攻击树时会造成双倍伤害。极度寒冷会使树进入休眠，直到解冻。黑暗也会使它的活动减慢，虽然它仍以一半效率运作。

Hangman Tree 看起来像枝条很少、叶片稀疏的粗壮橡树。树干上通常很高的位置会有结节状突起，那些是感觉器官。树干下部会有一个疤痕般的位置，用来排出无法消化的东西。

*树龄可选参考：非战斗幼芽 1–10 年；幼树 11–25 年；成熟树 26–75 年；老树 76–150 年；远古树 151 年以上。

注：统计栏中以斜线分开的数值，左侧指 Haunt 的自然状态，右侧指 Haunt 位于被附身受害者体内时的状态。

Haunt 是一个人死时留下重要任务未完成而产生的 restless spirit。Haunt 栖息在死亡地点周围 6" 的区域内。Haunt 唯一的目的，是附身于活人的身体并利用它完成任务，从而获得最终解脱。

Haunt 可以随意采取两种形态之一：悬浮的发光光球（外观与 will-o-wisp 完全相同），或其生前身体的朦胧半透明影像。Haunt 的外表类似 groaning spirit、spectre 或 ghost，因此经常被误认成它们。

Haunt 每次攻击会吸取 2 点敏捷。随着角色的敏捷被吸走，他会承受敏捷降低带来的惩罚。角色会感觉身体上逐渐爬满麻木和寒冷。当角色的敏捷降至 0 时，Haunt 会进入身体并附身。身体一旦被附身，敏捷便会恢复正常。

Haunt 会利用被附身的身体完成未完成的任务，而任务未必危险。任务完成后，Haunt 会进入最终安息，受害者重新获得身体控制。当 Haunt 离开受害者时，角色的敏捷为 3。失去的敏捷可以通过完全休息恢复，每次完整休息一轮恢复 1 点。如果 Haunt 所附身的身体被杀死，它会继续在身体被杀死的地点作祟。

如果被附身受害者的阵营与 Haunt 相反（善良对邪恶），Haunt 会试图勒死角色。它在命中检定成功后，会用鬼手环住受害者的脖子。第一轮造成 1 点伤害，第二轮 2 点，第三轮 4 点，以此每轮翻倍，直到受害者死亡或 Haunt 被驱离。

Haunt 不能被驱散，因为它与死亡地点相连。在自然状态下，只有银制武器、魔法武器和火焰能命中 Haunt。武器每次攻击只造成 1 点伤害，另加武器的魔法加值。火焰每轮造成 1 点伤害，魔法火焰造成全部伤害。Haunt 降至 0 生命值时会失去对灵质的控制并消散。

Haunt 会在 1 周后于其地点重新形成，并继续在那里作祟，直到任务完成。驱魔术会永远摧毁 Haunt。

对被附身角色的任何攻击都会对角色造成全部伤害。释放被附身者的唯一安全方式是驱魔术或定身术。使用定身术时，Haunt 必须对抗麻痹豁免，否则会被逐出身体。

在附身身体之前，Haunt 必须停留在死亡地点 6" 范围内。对付 Haunt 最好的防御，就是离开它栖息的区域。
