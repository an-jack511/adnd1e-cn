组成 Hades 大军的 Hordling，形态、大小、力量和外表各不相同。它们共同拥有丑陋和可憎的特征。它们在 Hades 的各处游荡，以一切事物为猎物，包括彼此。强者会杀死并吞食弱者。

它们会在 night hag 等强大首领手下服务，但 Hordling 不可信、叛逆而好争吵，因此 Hordes 的寿命并不长（Hordling 的寿命也不长）。事实上，Hordling 的性情是混沌的。类似生物在 Tarterus 位面也很常见，Abyssal Planes 中也有少数。

已知能够将超过 1 只 Hordling 召到主物质位面的唯一方法，是使用 bringer of doom；这是一件在 Invoked Devastation 期间通过奥术魔法创造、如今已经遗失的奇异装置（见 WORLD OF GREYHAWK™ 设定集）。

某只 Hordling 的准确外表和能力由随机结果决定。护甲等级、移动率、生命骰、魔法抗性、智力和体型按上方数据使用 1d4 决定（体型 1=小型，2–3=中型，4=大型）。下列每项身体特征掷 1d6。

## Hybsil

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1d6×10 |
| 护甲等级 | 7 |
| 移动 | 15" |
| 生命骰 | 1–1 |
| 巢穴内百分比 | 30% |
| 财宝类型 | I |
| 攻击次数 | 1（武器） |
| 每次攻击伤害 | 1–4 或依武器类型 |
| 特殊攻击 | 无 |
| 特殊防御 | 所有豁免获得 +4 |
| 魔法抗性 | 标准 |
| 智力 | 平均至非常高 |
| 阵营 | 守序善良 |
| 体型 | S（高 3 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／22 + 1/生命值 |

这些小型羚羊半人马看起来像 centaur 与 pixie、brownie 或 sprite 的混合体。它们会说 Hybsil 语、Elf 语和通用语。Bugbear、Ogre，尤其是 Gnoll，是它们的死敌。它们通常与大多数四足哺乳动物关系友好，包括羚羊、斑马、鹿和马。

战斗中，它们使用短匕首，但主要武器是弓箭。箭造成 1–4 点伤害，并涂有一种稀有植物汁液，会导致睡眠 1–4 小时（对抗毒素的豁免受到 -4 惩罚）。由于体质强健，Hybsil 的所有豁免都获得 +4。

Hybsil 生活在温带或亚热带草原上的大家庭或紧密部族中。他们是半游牧民族，可能漫游广阔区域，也可能一生都生活在一小片灌木丛或林间空地中。部族首领会是一名巫医，能够施展德鲁伊（60%）或魔法使用者（40%）法术，施法等级最高可达 7 级。
