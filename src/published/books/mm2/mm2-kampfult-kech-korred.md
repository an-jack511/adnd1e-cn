Kampfult 也被称为 sinewy mugger，最初栖息在茂密的林地中，把绳索般的身体伪装在藤蔓和蔓生植物之间。毫无戒心的猎物会被困住，因为 Kampfult 会把藤蔓般的附肢绕成环，缠住受害者，将其压碎并勒死。

人类积极猎杀这种生物后，残存的 Kampfult 现在通常出现在废墟或地城中。在那里，它们看起来像绳子或网，使粗心大意者遭到突袭。

它们可以同时攻击数个生物。一旦被附肢击中，受害者就无法逃脱，直到 Kampfult 被杀死。只有生物的中央部分会受到伤害。Kampfult 有 6 条约 6 英尺长的攻击附肢，以及 6 条 1 英尺长的移动附肢。这些附肢沿着略粗的身体部分排列，中央躯干约 4 英尺长。怪物会收起或拉入附肢，以伪装自己。

## Kech

|---|---|

| 特殊防御 | 伪装 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 中立邪恶 |

| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／205 + 5/生命值 |

Kech 是邪恶的森林魔物，生命中的主要目标似乎是误导、设套并吞食人类。它们遍布所有气候的深林，从热带到亚北极地区都能发现。它们在那里挖坑、设套索、架设落木陷阱，捕捉毫无戒心的旅行者。

更糟糕的是，几支小群体有时会合并，袭击森林中的社群，把毫无防备的受害者带到遥远地点，以便 Kech 不受干扰地享用。它们也经常模仿求救声，把猎物引入设好陷阱的区域进行伏击。

攻击方式是爪击和咬击。由于 Kech 有 5/6 的概率发动突袭，它们通常会冲向 1 或 2 名选定的受害者，将其杀死，然后带走尸体。它们的伪装颜色和林地技巧使追踪脚印的概率降低至 50%。它们有 50% 的概率无声移动。

Kech 是披着叶状韧皮的绿色类人生物。长臂和带抓握趾的脚使它们能够极快地爬树（每轮 60 英尺），也能在高处树枝间摆荡。它们的人类般面孔长着塞满獠牙的大嘴和突出的下颚。

| 特殊防御 | 笑声（6"） |

| 智力 | 非常高 |
| 阵营 | 混沌中立 |
| 体型 | S（高 3 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／900 + 8/生命值 |

这些热爱舞蹈的族群总会携带木棒和大袋子，袋中装有头发、剪刀及其他物品。他们能在 1–4 轮内将头发编织成会活动的纠缠绳索和套索，从而困住入侵者（绳索：护甲等级 1；生命值 5；移动 3"；对抗麻痹豁免，否则被困）。Korred 袋中的物品如果洒上圣水，就会变成金子（价值 50–200 gp）。

Korred 力量很大，能把巨石投到 10" 远（伤害 2d8），并有传言说它们建造了德鲁伊的石圈。它们可以用剪刀攻击（伤害 d4+4）、木棒攻击（伤害 d6+4），或徒手攻击（伤害 1–2+4）。

Korred 每天可以笑 3 次。6" 内听到笑声的生物必须在 1d20 上掷出不低于自身魅力，否则会被击晕 1–4 轮。Korred 可以随意使用以下能力：塑石术、活化岩石、石门术（传送 3"）、粉碎岩石、石转泥和与石交谈。

Korred 每周会有一天假日，在那天跳舞和演奏音乐。打断舞蹈的人必须对抗法术豁免，否则会自己跳起来，每轮失去 1–4 点生命值，直到死亡、被束缚，或 Korred 逃走。
