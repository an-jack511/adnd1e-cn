## Land Lamprey（陆地七鳃鳗）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 2–12 |
| 护甲等级 | 7 |
| 移动 | 12" |
| 生命骰 | 1+2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 每轮 1 点生命值 |
| 特殊攻击 | 吸血、负重 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 非智能 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／36 + 2/生命值 |

Land Lamprey 是由海七鳃鳗变异而来的生物。它们能呼吸空气，外形像蛇，几乎可以在除沙漠和极端寒冷地区以外的任何气候中生存，但偏好阴暗潮湿的地方。

它们咬住受害者后，会用括约肌状的口部紧紧附着，并连续 3 轮吸血，每轮造成 1 点生命值伤害。附着期间，每只 Land Lamprey 都会使受害者的敏捷等效降低 1 点，因为它会增加相当于这种程度的负重。只有杀死它或用火烧它，才能迫使它松口；为了避开火焰，它会主动解除吸附。

Land Lamprey 约 3 英尺长，粗而沉重，颜色从浅绿到近黑的绿色不等。

## Luck Eater（食运兽）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1 |
| 护甲等级 | 7 |
| 移动 | 15" |
| 生命骰 | 4 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 无 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 中立 |
| 体型 | S（长 1 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | III／125 + 4/生命值 |

Luck Eater 外表具有欺骗性，通常看起来像一只金色毛发的猫。它几乎可以出现在任何地方，但总会藏在隐蔽的角落里，并以 1–4 的突袭概率发动作用。

它在 30 英尺内发出呼噜声。范围内的生物必须进行对抗法术的豁免，否则会被吸引过去。被吸引的生物会想把它完整无损地带走，并允许它留在身边呼噜 2–5 小时。呼噜声的光环会使范围内所有生物进行任何豁免、伤害和命中检定时承受 10%（-2）的惩罚。

豁免失败不会立即产生其他效果，但目标每轮都必须重复豁免，直到被吸引。Luck Eater 以这些生物失去的好运为食；在规定时间过后，它便吃饱了。如果在任何一个 3 轮时段内没有获得食物（即 30 分钟内没有进行任何掷骰），它的呼噜声会发生轻微变化。那些为它提供好运的生物会攻击下一个生物。

如果再过 3 轮仍然没有食物，提供好运的生物会互相攻击，持续 10 轮或直到其中一方死亡。只有采取极端措施，才能解除这种魔法；在接近结束时，Luck Eater 会悄悄溜走而不被注意。否则，它吃饱后会迅速离开，但仍会继续呼噜。

被吸引的生物会允许 Luck Eater 离开，也会保护它。离开后 1–6 轮，它们的感官才会恢复正常。

## Lycanthrope（狼人形生物：总则）

人类可以变成动物形态。黑暗是最常见的变形诱因；在满月时，狼人形生物有 90% 的概率会被迫改变形态。它们通常保持人形。每一种狼人形生物都有自己的语言，并且都会说通用语。

任何人形生物只要被咬伤，所受伤害至少达到其全部潜在生命值的一半，却没有死亡或被吃掉，就会受到感染。若在 1 小时内服用颠茄，感染有 25% 的概率被治愈；服用者会失去行动能力 1–4 天，并有 1% 的概率因毒性死亡。否则，必须在 3 天内由 12 级或更高等级的牧首施展祛除疾病，或受害者会在 7–14 天后变成狼人形生物。其他变形方式很少见。
