## Marid

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 0 |
| 移动 | 9"／15"／24"（MC：B） |
| 生命骰 | 13 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 8–32 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 25% |
| 智力 | 高至天才 |
| 阵营 | 混沌 |
| 体型 | L（高 18 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VIII／5000 |

Marid 是精灵种族中力量最强的一支，属于水元素生物。它们很少离开自己的位面，极少来到主物质位面。

Marid 可以随意使用下列类法术能力，但一次只能使用 1 项，每日 2 次：侦测邪恶／善良、侦测隐形、侦测魔法、隐形术、液态形态（如同气态形态），变形术和净化水。它们每天最多可以使用 7 次：气化形体、降低水位、分水术、雾墙术，以及赋予水下呼吸（持续 1 天）。

它们总能制造水，并将水塑造成一股射程 6" 的水流；水流会使目标失明（豁免成功则避免），并造成 1–6 点伤害。Marid 可以在水面上行走。它们每年一次可以改变现实。它们以 26 级法术使用者的能力施法。

Marid 可以自由携带 10,000 金币；超过这个数量后，每多携带 2,000 金币，双倍负重时间就增加 1 轮。它携带 20,000 金币时能坚持 3 轮，因此携带 12,000 金币时能坚持 8 轮。疲倦后必须休息 6 轮。

Marid 游泳极快，能够在任何深度呼吸水，并拥有超视觉和红外视觉。水系法术不会伤害它们。寒冷攻击使其豁免获得 +2、每个伤害骰 -2；火焰攻击每个伤害骰额外 +1，并使其豁免受到 -1。蒸汽不会伤害它们。

它们容忍 Djinn 和 Jann，厌恶 Dao 与 Efreet。Marid 由一位帕迪沙统治，贵族拥有不同头衔。普通 Marid 独立、傲慢且自负；贿赂和奉承通常只能得到一点帮助，不能依赖它们履行承诺。

Marid 通过心灵感应掌握所有语言。它们可以进入星界位面、元素位面、以太位面和主物质位面。

## Shadow Mastiff（影獒）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 4–16 |
| 护甲等级 | 6 |
| 移动 | 18"（明亮光线下 9"） |
| 生命骰 | 4（明亮光线下每个生命骰 -1 生命值） |
| 巢穴内百分比 | 20% |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 2–8 |
| 特殊攻击 | 吠叫造成恐慌 |
| 特殊防御 | 藏入阴影 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立邪恶 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／185 + 4/生命值 |

Shadow Mastiff 通常生活在阴影位面，成群结队，或作为看门兽使用。在阴影环境中，它们几乎无法被看清；它们发动攻击和融入阴影时有 40% 的概率不被发现。在明亮光线中，它们的移动率减半，并且无法隐藏。

群体巢穴有 50% 的概率拥有 2–5 只幼崽；幼崽可卖得 200–500 金币。

Shadow Mastiff 的吠叫会造成恐慌，使目标逃离，并丢下手中持有的物品，除非目标通过豁免。每有 1 只 Shadow Mastiff（不超过 10 只），豁免受到 +1 惩罚；数量超过 12 只后，每多 2 只，目标豁免获得 -1 修正。掷出 1 总是失败。
