## Mihstu

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | -2 |
| 移动 | 6"／6"（MC：B） |
| 生命骰 | 8+2 |
| 巢穴内百分比 | 10% |
| 财宝类型 | I |
| 攻击次数 | 4 条触手 |
| 每次攻击伤害 | 每条 1d6+1 |
| 特殊攻击 | 吸取体质 |
| 特殊防御 | +2 武器才能命中 |
| 魔法抗性 | 10% |
| 智力 | 高 |
| 阵营 | 中立邪恶 |
| 体型 | M（直径 6 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1700 + 12/生命值 |

Mihstu 是拥有自由意志的元素生物，来自气元素位面的副元素“空气”部分。它们偏爱阴凉、潮湿、几乎没有阳光的地方；雾云会从裂缝中渗入。

它们的形体会伸出 4 条触手，末端是锋利的爪。Mihstu 会包住受害者，每轮吸取 1 点体质；体质降到 0 时，受害者死亡。失去的体质每天只能恢复 1 点，而且必须休息。Mihstu 被包住时，只有魔法攻击能够伤害它。

只有 +2 或更好的武器才能命中 Mihstu。它们免疫电击和飞射物，包括魔法飞弹。寒冷会使其昏迷 2d6 轮。

Mihstu 独居，形体如幽灵般，会惊吓入侵者。有些 Mihstu 会为强大的魔法使用者服务，以换取强力魔法物品。

## Miner（矿伏兽）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1 |
| 护甲等级 | 4 |
| 移动 | 3"（6"） |
| 生命骰 | 10 |
| 巢穴内百分比 | 40% |
| 财宝类型 | G |
| 攻击次数 | 见下文 |
| 每次攻击伤害 | 见下文 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 高度智能 |
| 阵营 | 中立 |
| 体型 | 大型 |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／1000 + 14/生命值 |

Miner 是 Trapper 的近亲，同样擅长捕猎和林地生存，以小型林地动物为食。它会在道路或路径下面挖掘隧道，发动伏击，把脊柱上的刺从地面刺出，看起来就像树枝。

如果路人处于突袭状态，每个经过的生物有 75% 的概率不会注意到这些刺；如果没有突袭，则每个生物仍有 25% 的概率忽视它们。德鲁伊和游侠若没有被突袭，则每等级有 5% 的概率识别出这些刺。刺带有毒素，豁免毒素失败者会麻痹 2–40 轮。

Miner 会等到地表的震动停止，然后挖出地面，像 Trapper 一样攻击。除非把它从地下挖出来，否则很难攻击它。它像一条没有尾巴的水生鳐鱼，颜色为斑驳棕色或棕绿色；头部有一块坚硬的骨头，一直延伸到背部脊梁，脊梁上有 6–25 根棕色刺。

## Minimal（微型动物）

### 总则

| 项目 | 规则 |
|---|---|
| 出现频率 | 极罕见；有 50% 的概率出现两倍数量 |
| 护甲等级 | 比原条目差 2 级 |
| 移动 | 原移动率的 2/3，向上取整 |
| 生命骰 | 见下表，约为原条目的 1/4 |
| 巢穴内百分比 | 原条目数值 +10% |
| 财宝类型 | 40%：J、K、L、M、N；5%：魔法物品 |
| 攻击次数 | 与原条目相同，或更少 |
| 每次攻击伤害 | 单次攻击最高 3–6 |
| 特殊攻击 | 肉食动物获得 +1 突袭修正 |
| 特殊防御 | 更难被突袭，等效 +1 |
| 魔法抗性 | 对所有攻击获得 +2；对抗法术时按等同等级生命骰计算 |
| 豁免 | 像原尺寸动物一样，对毒素和死亡进行豁免 |
| 智力 | 动物至半智能 |
| 阵营 | 中立至混沌 |
| 体型 | 正常身高的一半，正常重量的八分之一 |
| 等级/经验值 | 见下表 |

Minimal 是小型哺乳动物，通常由类似“巨型动物”的法术创造。它们生活在与世隔绝的区域；如果当地没有大型肉食动物，任何一种哺乳动物成为 Minimal 的概率为 80%。没有大型天敌时，它们更常成群出现，也更具攻击性和混沌性。

任何动物都有 50% 的概率以 Minimal 形态出现。尺寸缩小使护甲等级再恶化 2 级，移动率变为原来的 2/3，生命骰通常为原来的 1/4，但最低仍可达到 3+4。巨型动物很少成为 Minimal；人类、半人类和类人生物不会成为 Minimal。
