## Decaton（十阶 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1（100 个中的 1 个） |
| 护甲等级 | 2 |
| 移动 | 15"／3"（MC：E）／／9" |
| 生命骰 | 10+10 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 10 |
| 每次攻击伤害 | 1–4（×10） |
| 特殊攻击 | 使用法术 |
| 特殊防御 | 需要 +2 或更好的武器才能命中 |
| 魔法抗性 | 10% |
| 智力 | 高 |
| 阵营 | 守序中立 |
| 体型 | M（高 7 英尺，触手长 5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／2550 + 14/生命值 |

Nirvana 只有 100 个 Decaton，它们是位面上最低阶的官员。这些生物呈球形，拥有 10 条触手和短腿，负责基础 Modron 的身体福利。Nirvana 的每个区段分配 1 个 Decaton，其余 36 个与指挥位面军队的 Hexton 一起服役。

Decaton 拥有相当于 10 级牧师的施法能力，但不能驱散不死生物。它们还拥有以下只对其他 Modron 生效的类法术能力：治疗 144 英尺内所有 Modron 1 点伤害、在半径 12 英尺内治愈疾病、每轮以接触治愈最多 10 个 Modron，以及每轮以接触解除最多 10 个 Modron 的麻痹。上述能力一次只能使用 1 项，但可以随意使用，每轮一次。

球形 Decaton 通过在体内产生轻质气体飞行。只有在指挥大量基础 Modron、需要俯瞰情况时才会升空。

## Nonaton（九阶 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1（81 个中的 1 个） |
| 护甲等级 | 0 |
| 移动 | 18"／18" |
| 生命骰 | 11+11 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 9 |
| 每次攻击伤害 | 1–6（×9） |
| 特殊攻击 | 使用法术 |
| 特殊防御 | 需要 +2 或更好的武器才能命中 |
| 魔法抗性 | 20% |
| 智力 | 高 |
| 阵营 | 守序中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：全／全 |
| 等级/经验值 | VIII／5260 + 16/生命值 |

81 个 Nonaton 是法律与秩序的主要监督者。这些圆柱形 Modron 充当 Pentadrone 警察部队的队长和总检查员。每个区段有 1 个，Tertian 有 9 个，另外 8 个直接向 Primus 报告。

每个 Nonaton 有 12 名 Pentadrone 中尉；每名中尉指挥 12 名 Quadrone 中士，每名中士指挥 12 名 Tridrone 警察。

Nonaton 以 12 级牧师的能力施法。此外，它们随意拥有以下类法术能力，每轮近战一次：心灵感应、镜像术、缓慢术、蛛网术、侦测善恶、侦测谎言和侦测魅惑。它们每天可以使用一次震慑权能。

Nonaton 通常负责调查叛变 Modron 单位和入侵 Nirvana 的小队。面对后者，它们会先试图侦测队伍的意图，再据此行动；扰乱秩序的团体会被消灭或放逐。
