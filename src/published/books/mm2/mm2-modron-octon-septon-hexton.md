## Octon（八阶 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1（64 个中的 1 个） |
| 护甲等级 | 1 |
| 移动 | 9"／9"（MC：B）／／9" |
| 生命骰 | 12+12 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 8 |
| 每次攻击伤害 | 1–8（×8） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 需要 +2 或更好的武器才能命中 |
| 魔法抗性 | 30% |
| 智力 | 超凡 |
| 阵营 | 守序中立 |
| 体型 | L（高 7–10 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VIII／5250 + 16/生命值 |

64 个 Octon 各自负责 Nirvana 的一个区段。区段内的基础 Modron，以及分配给这些总督的 Decaton 和 Nonaton，都被视为 Octon 的辖民和责任。

Octon 极其严格地守卫自己的区段，确保法规得到遵守、日常程序得到执行、报告始终准确无误。它们通过肩膀高度的圆形项圈在空气和水中移动；项圈是身体的一部分，会迫使空气或液体穿过，从而提供升力、推进力和高度机动性。8 条触手状手臂连接在项圈外侧。

Octon 以 14 级牧师的能力施法。它们还可以随意使用以下类法术能力，每轮一次、一次 1 项：水上行走、加速术、侦测善恶，以及对 3500 金币重量使用心灵遥控。它们完全免疫灵能战斗和灵能效果。

每个 Octon 的私人职员包括 1 名 Decaton、1 名 Nonaton、5 名 Pentadrone、16 名 Quadrone、81 名 Tridrone、256 名 Duodrone 和 1728 名 Monodrone。它们维护小型塔楼，是 Quarton、Secundus 和 Primus 塔楼的缩小版本。

## Septon（七阶 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1（49 个中的 1 个） |
| 护甲等级 | -1 |
| 移动 | 9"／9" |
| 生命骰 | 13+13 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 7 |
| 每次攻击伤害 | 1–10（×7） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 需要 +2 或更好的武器才能命中 |
| 魔法抗性 | 40% |
| 智力 | 超凡 |
| 阵营 | 守序中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IX／8250 + 18/生命值 |

Septon 是维护秩序、确保所有法规得到遵守的官员。每名 Quinton 有 1 个，每名 Secundus 有 4 个，Primus 直接拥有 8 个。它们从一个地方前往另一个地方，检查和检验工作及记录，并负责把边远地区的信息转交给区域塔、四分区塔和首都塔。

Septon 看起来像长着巨大秃头的类人生物。它们有类似 Octon 的肩部项圈，不过更小；项圈不足以让它们在空中移动，却非常适合水下运输。

为了确保工作正确完成，每个 Septon 都有 7 种持续运作的感知：听觉、视觉、嗅觉、味觉、触觉、心灵感应（范围 30 英尺）和侦测魔法。它们也是强大的施法者，拥有 16 级牧师法术和 12 级魔法使用者法术。

与所有没有灵能能力的高阶层 Modron 一样，Septon 完全免疫灵能攻击和灵能战斗。

## Hexton（六阶 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1（36 个中的 1 个） |
| 护甲等级 | -2 |
| 移动 | 12"／12"（MC：C）／／12" |
| 生命骰 | 14+14 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 6 |
| 每次攻击伤害 | 2–13（×6） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 需要 +3 或更好的武器才能命中 |
| 魔法抗性 | 50% |
| 智力 | 天才 |
| 阵营 | 守序中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IX／8250 + 18/生命值 |

36 名 Hexton 每人统领 Nirvana 的 1 支军队。这些军队用于维持秩序，并防止来自 Acheron、Arcadia 和 Concordant Opposition 位面的入侵。每个区域分配 1 名 Hexton 及其军队；每个总督四分区有 2 名直接服役；Tertian 有 3 名作为特别警察；剩下 9 名服务于 Primus。

Hexton 看起来像长着 6 条手臂的类人生物：2 条是有 6 根手指的大型人类手臂，下面还有 4 条末端带利爪的触手。它们的肩膀连接着薄薄的扇形折叠翅膀。

Hexton 以 18 级牧师的能力施法；除了阶层 Modron 的通用能力外，没有其他特殊类法术能力。它们免疫所有灵能攻击。

任何 Hexton 都有 75% 的概率拥有自己的卫队，由 12–48 名对 Hexton 忠诚至狂热、必须保护其生命的特别 Pentadrone 组成。
