## Quadrone（四功能 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–4 |
| 护甲等级 | 4 |
| 移动 | 15"，或 16"／15"（MC：D） |
| 生命骰 | 4+4 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 4 或 2 |
| 每次攻击伤害 | 4–7（×4），或 6–9（×2），或依武器类型 |
| 特殊攻击 | 按 8 生命骰生物计算的攻击 |
| 特殊防御 | 免疫幻术与影响心灵的魔法 |
| 魔法抗性 | 标准 |
| 智力 | 非常高 |
| 阵营 | 守序中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／165 + 5/生命值 |

球形的 Quadrone 是 Nirvana 位面中层工人的上级。它们拥有 4 项完整职能，其中大多数并不与某一具体操作相连。它们也担任 Nirvana 军队的战地军官；每场战斗都有一个特别的“十二单位”，由最有能力的 Quadrone 战士组成。

球形 Quadrone 是优秀的弓箭手，能够同时使用 2 把弓。作为四功能生物，它们能报告行动和观察结果、制订计划、应对意外情况，并采取行动纠正意外。

部分 Quadrone 有翅膀，翅膀取代一组手臂，因此不能使用弓箭。这些有翼 Quadrone 被用于特别任务或空战。

所有 Quadrone 的感知能力都是人类正常值的 150%，并拥有红外视觉（180 英尺）和红外以上视觉（200 码）。由于感知器官位于六个面上，Quadrone 在正常情况下不会被突袭。

## Pentadrone（五功能 Modron）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1 |
| 护甲等级 | 3 |
| 移动 | 18"／6" |
| 生命骰 | 5+5 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 5 |
| 每次攻击伤害 | 5–8（×5） |
| 特殊攻击 | 麻痹气体 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 非常高 |
| 阵营 | 守序中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／350 + 7/生命值 |

Nirvana 的工人群体由 Pentadrone 进行日常警察管理。这些五臂生物像长着细长高跷状腿的海星。除了强力的手臂攻击和 18/00 的有效力量外，Pentadrone 还能喷出麻痹气体，形成直径 2 英尺、长度 5 英尺的气流。被气流击中的任何生物都必须进行对抗麻痹的豁免，否则保持不能移动 5 轮。Pentadrone 每 5 轮最多使用一次气体，每天最多 5 次；或者，它们可以把气体用于悬浮，如同 5 级魔法使用者。

作为五功能生物，Pentadrone 能够交流、操作、监视、计划和管理，也能应对未计划的情况。它们总管所有低阶 Modron。在 Nirvana 军队中，每个团部总有 12 名 Pentadrone 作为精锐单位，其他 Pentadrone 则实际指挥团。

Pentadrone 几乎能存在于任何环境中，可以毫无不适地承受华氏 210 度至 -100 度的温度。对它们的寒冷、火焰和酸攻击每个伤害骰都受到 -2 修正。它们免疫幻术和影响心灵的魔法，只有 +7 或更好的魔法武器才能伤害它们。

Pentadrone 拥有双倍人类感知能力，以及双倍正常范围的红外视觉和红外以上视觉（分别为 180 英尺和 200 码）。
