| 巢穴内百分比 | 35% |
| 财宝类型 | C |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–4、1–6、1–8、1–10，或依武器 |

Mongrelman 并非独立种族，也不明确属于任何其他种族。每个个体都可能混有人的、兽人、Gnoll、Ogre、矮人、Hobgoblin、Bugbear、精灵、Bullywug 及其他生物的血统。由于这种混杂，它们很少受到守序或善良社会欢迎，通常被混沌和邪恶团体虐待或奴役。这种待遇迫使它们发展出各种求生技能。

所有 Mongrelman 都拥有伪装和模仿能力。使用伪装时，它们能极其熟练地隐藏自己、其他生物和物品。通常需要 1 轮伪装一名 Mongrelman、另一生物或一件物品；在第 1 轮之后，每再准备 1 轮，保持不被发现的概率增加 1%，最高 95%。因此，准备 8 轮的 Mongrelman 有 87% 的成功率。

伪装建筑和构筑物需要以周而不是轮计算。成功伪装的人或物不会被注意到，除非它移动或被接触；成功伪装的建筑在距离超过 50 英尺时无法辨认（可依建筑大小和类型调整）。模仿能力使 Mongrelman 几乎能完美模仿任何动物或怪物的声音，但不能模仿特殊攻击形式。

为了获得所需的物品和货物，所有 Mongrelman 都是熟练扒手，每个个体有 70% 的成功率。每 10 个 Mongrelman 至少有 1 个拥有 2 个生命骰；每 30 个至少有 1 个拥有 3 个生命骰；每 40 个至少有 1 个拥有 4 个生命骰。巢穴中还有一名首领（AC4，移动 12"，5 个生命骰，伤害 1–12，命中 +1）和 5 名护卫（4 个生命骰）。战斗中通常使用棍棒或剑，但每群有 5% 的个体装备吹箭筒和毒箭或麻痹箭。

Mongrelman 通常生活在人口混杂地区，巢穴位于废墟、废弃建筑或人类曾经居住或建造的地方。它们的外貌差异极大，总是结合各种种族最糟糕的特征。它们说夹杂动物叫声和胡言乱语的破碎通用语，名字通常就是动物发出的声音。

## Moon Dog（月犬）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1（2–8） |
| 护甲等级 | 2、0 或 -2 |
| 移动 | 30" |
| 生命骰 | 8+16 |
| 巢穴内百分比 | 无 |
| 财宝类型 | N |
| 攻击次数 | 1 |
| 每次攻击伤害 | 3–12 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 25% |
| 智力 | 高至超凡 |
| 阵营 | 中立善良 |
| 体型 | M（肩高 3 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／2000 + 12/生命值 |

Moon Dog 也称黑猎犬或夜行者，常被误认为有害怪物；事实上，它们保护人类，专门在夜间寻找并杀死邪恶的捕食者。它们几乎从不在人口稠密地区出现。通常只有 1 只，但邪恶极盛的地方会出现 2–8 只。它们来自上层外位面的 Elysium，在那里会以更大数量出现。它们只为善良神祇和这些神祇的强大仆从（例如 Deva、Planetar 等）效力。

Moon Dog 的护甲等级取决于光照：在明亮、健康的光线中为 2；黄昏为 0；浓重阴影或黑暗中为 -2。

普通攻击是造成大量伤害的撕咬。不过 Moon Dog 还拥有针对邪恶对手的声音武器。吠叫会使 8" 内所有邪恶生物进行法术豁免，失败者恐慌逃跑，如同受到恐惧术。多只 Moon Dog 吠叫时效果累积。嚎叫会使 4" 半径内所有邪恶生物每轮受到 5–8 点伤害；此外，任何非主物质位面的受影响生物都会因痛苦而有累积的 5% 概率（每轮嚎叫一次）被迫返回自己的位面，不受魔法抗性影响。

Moon Dog 可以随意使用以下 12 级能力的类法术，每次 1 项、每轮一次：变身术、舞光术、黑暗术、高等隐形术、光亮术、镜像术、侦测术、幻影，每日一次，以及雾墙术。

此外，Moon Dog 可以变成以太形态，也能进行星界或以太旅行。它的所有视觉范围都是正常值的两倍，并且拥有异常敏锐的听觉和嗅觉，因此能够侦测邪恶、幻术（90%）、隐形（包括高等隐形，80%）、魔法（70%）以及套索和陷阱（100%）。它有可抓握的前爪，有时会使用小型物品。

在阴影光线下，Moon Dog 能通过特殊移动编织出相当于阴影催眠图案的魔法。只有邪恶生物会受影响；同时，范围内每个善良生物都会获得如同防护邪恶和移除恐惧的效果。编织图案时，Moon Dog 不能进行其他攻击或行动。

Moon Dog 只有 +2 或更好的武器才能命中，永远不会被突袭，但有 50% 的概率突袭对手。它不受恐惧影响。对基于寒冷、电击和火焰／热的攻击，它的豁免获得 +2，并相应只受一半或四分之一伤害。

Moon Dog 的呜咽可以驱散幻术，吠叫可以驱散邪恶，舔舐具有以下作用：治愈疾病、治疗轻伤或延缓毒发。每种功能每天只能对同一生物使用一次。与 Moon Dog 相处 1 小时或更久可以驱散魅惑或移除诅咒。Moon Dog 也能有效驱散魔法，但这样会消耗全部能量，被迫立即返回自己的位面。

Moon Dog 有自己的语言，也能与所有犬类和狼类交流；此外，它们会说通用语，并能以有限的心灵感应交流。它们会与善意的人类和半人类交流并提供帮助，但邪恶威胁解除后不会继续与其相伴。

Moon Dog 的外形类似犬类，像一只巨大的猎狼犬；头部略带人形，前爪可抓握，能够双足行走，移动率为 9"。身体是斑驳的深灰色，以最深的黑色为主，眼睛呈琥珀色。
