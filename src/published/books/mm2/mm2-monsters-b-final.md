## Boggle（波格尔）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–8 |
| 护甲等级 | 5 |
| 移动 | 9"（3"） |
| 生命骰 | 4+3 |
| 巢穴内百分比 | 25% |
| 财宝类型 | C |
| 攻击次数 | 3（2） |
| 每次攻击伤害 | 1–4/1–4/1–4 |
| 特殊攻击 | 后爪，1–4/1–4 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 混沌中立 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | IV/170 + 5/生命值 |

波格尔是高 3 英尺、模糊类人的生物，颜色从黑蓝色到深灰色不等。它们都有巨大的球状头部，但身体其他部分的比例各不相同，个体差异很大（大鼻子、长度不一的手臂、细长的腿等）。

波格尔的社会组织松散地呈部落形态。与其他生物打交道时，它们经常呜咽和喃喃乱语。离开巢穴时，波格尔有些胆怯，而且都倾向于做小偷；但在巢穴中遭遇时，它们会变得具有攻击性且贪婪。

波格尔会从身体的毛孔分泌黏稠、不可燃的黑油。任何踩到油上的人（波格尔等专门适应在光滑表面上攀爬的生物除外）都必须在 1d20 上掷出不超过自己敏捷值的结果，否则跌倒。跌倒的角色必须花费整整一轮才能重新站起。波格尔会试图偷走跌倒者的物品；它必须成功以护甲等级 5 为目标的攻击，才能从跌倒或昏迷的角色身上偷走一件物品。

波格尔拥有橡胶般的外皮，身体部分具有弹性。它们可以拉伸到原长的两倍，或收缩到原大小的一半。由于外皮光滑而有韧性，所有武器攻击对波格尔造成的每颗伤害骰都减去 1 点。波格尔天生抗火（如同火焰抗性戒指）。它们还可以随意施展蛛行术，并喜欢依附在天花板上，从那里落向毫无戒备的角色，获得额外 2 次爪击（与猫相同）。

波格尔可以随意使用次元门能力，穿过任何完整的框架一次移动最多 3"，例如洞口、门框、栅格、角色双腿之间等。它们可以伸手穿过一个洞，让手从另一处出来，从而从另一侧抓住或攻击角色。波格尔巢穴往往布满洞孔，或看起来像栅格；它们的主巢穴只能通过次元门或其他魔法手段进入。

最后，波格尔拥有异常灵敏的嗅觉，甚至能通过气味侦测隐形生物。其他种族知道利用波格尔作为守卫和哨兵，正是因为这一能力。当波格尔嗅到入侵者时，会发出高亢的哀鸣，警告主人。

## Boobrie（大沼鹭）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–2 |
| 护甲等级 | 5 |
| 移动 | 15/15"（MC：D） |
| 生命骰 | 9 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1–6/1–6/2–16 |
| 特殊攻击 | 突袭 2/6 |
| 特殊防御 | 免疫毒素 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | L（12 英尺高） |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | VI/900 + 12/生命值 |

巨大的大沼鹭像一只较小的、生活在沼泽中的鹏鸟近亲。除了巨型沼泽鲶鱼外，它最喜欢的食物是人类和羊。长腿让它能够快速奔跑，也能轻松穿过沼泽地，但它的爪子相对较弱。

大沼鹭飞得很慢。它主要用细长、弯曲的喙攻击。这些鸟完全免疫一切形式的毒素；如果偏爱的猎物不在附近，它们也会吃蛇、蜥蜴，甚至足够大的蜘蛛。它们会蹲在高草丛中，通过伪装获得突袭。如果遇到 2 只，它们要么是一对成鸟（每骰至少 5 点生命值），要么是一对幼鸟（每骰 4 点或更少生命值）。

大沼鹭看起来像一只巨大的苍鹭，喙则像苍鹭喙与鹰喙的混合物。喙的边缘排列着许多小而尖的牙齿。

## Bookworm（书虫）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–2（10–40） |
| 护甲等级 | 2 |
| 移动 | 12"（3"） |
| 生命骰 | 1/4（2 点生命值） |
| 巢穴内百分比 | 25% |
| 财宝类型 | 见下文 |
| 攻击次数 | 无 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式无 |
| 经验值 | I/7 + 1/生命值 |

这种只有 1 英寸长的小虫令魔法使用者极其恐惧，因为它会被一切形式的纸张吸引。它能在 60 英尺外嗅到卷轴、地图、奥术巨著和法术书。它通常是暗淡的灰色，但书虫的变色能力使它能本能地与任何背景融为一体。它的护甲等级来自速度与敏捷；静止不动时，护甲等级为 9。

书虫最初获得突袭的概率总是 95%。如果受害者能够看见隐形生物，这个概率降为 50%。注意，由于体型小、速度极快（相对于体型而言）、外表没有攻击性，即使对通常很难被突袭的生物（例如游侠和武僧），这些概率也照样适用。如果书虫最初成功突袭，之后有 25% 的概率会在受害者的腿外侧或背包上被发现；否则，除非携带纸张的受害者听见这种生物进食时的吵闹声，它会一直不被注意。进食中的书虫在遭到攻击前保持静止；每轮听见声音的基础概率为 50%。

书虫总会被区域内体积最大的纸张吸引。它能够以 3" 的速度钻过死木或皮革，并能在 1 个时间段内钻过皮革卷轴盒或背包，但无法消化任何形式的活物。它会以每轮 1 个法术等级的速度毁掉法术书和卷轴（例如，毁掉一张单个 5 级法术的卷轴需要 5 轮）。

书虫的巢穴总是某种图书馆或储藏室，无论该地点仍在使用还是早已废弃。遭遇书虫时，里面可能还留有未受损的纸质物品（30%）：地图（20%）、卷轴（30%）、奥术文书（魔法使用者等级 5–10，20%）或普通法术书（魔法使用者等级 1–8，10%）。如果指出存在任一类型的法术书，则其内容应适合所确定的魔法使用者等级，但会被书虫毁掉 0–90%（掷 1d10-1）。

## Bowler（滚石兽）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 2–12 |
| 护甲等级 | 4 |
| 移动 | 6" + 特殊 |
| 生命骰 | 2–5 点生命值 |
| 巢穴内百分比 | 35% |
| 财宝类型 | 见下文 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 每 1 点滚石生命值造成 1 点（2–5） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立 |
| 体型 | S–M |
| 灵能能力 | 无；攻击/防御模式无 |
| 等级/经验值 | I/6 + 1/生命值 |

滚石兽是在洞穴及类似地点发现的、像岩石一样的生物；岩石为它提供天然伪装。滚石兽对声音、振动和气味极其敏感，但没有视觉器官。感受到猎物接近后，滚石兽会向受害者滚去，并且每个战斗轮增加 1" 速度，直到达到 15" 的最大移动速度。（自身移动产生的振动能让怪物侦测并避开墙壁、坑洞等障碍。）

滚石兽的攻击方式是滚过并碾碎受害者。滚石兽每一点生命值约重 28 磅。碾碎猎物后，滚石兽会滚回猎物上方，一个像嘴的孔洞打开，吞食肉、骨、甲壳等。每只滚石兽的中央核心是一颗绿柱石，基础价值为 10 gp。

滚石兽起初滚动时很安静，因此猎物在它进入目标 40 英尺以内前发现它的概率只有 50%。滚石兽可能是拟态怪（见相关条目）的远亲。

## Buckawn（暗棕精灵）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 5–20 |
| 护甲等级 | 3 |
| 移动 | 12" |
| 生命骰 | 1-1 |
| 巢穴内百分比 | 10% |
| 财宝类型 | Q |
| 攻击次数 | 1 |
| 每次攻击伤害 | 按武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均至很高 |
| 阵营 | 中立 |
| 体型 | S（2.5–3 英尺高） |
| 灵能能力 | 无；攻击/防御模式无 |
| 等级/经验值 | II/65 + 3/生命值 |

暗棕精灵是棕精灵类型的林地半人类。他们比自己的亲族更不友善，也更狡猾。不过，暗棕精灵躲避与人类接触，也不与棕精灵保持固定往来。他们通常装备小匕首和飞镖箭袋。如果被攻击的一方曾经惹恼或冒犯过暗棕精灵，飞镖可能带有麻醉剂或毒药。

暗棕精灵可以在 6 级能力水平下使用以下类似法术的能力，一次一种、每轮一次、随意使用：可听幻象、改变自身、舞光术、隐形术。它们还可以每天各使用一次下列类似法术的能力，按 6 级处理：纠缠术、无痕步、召唤昆虫、绊足术。

暗棕精灵拥有极其优秀的感官，从不被突袭。它们的视觉不仅能看到红外和紫外光谱，还能毫无困难地侦测隐形生物。同样，它们听觉非常敏锐，使人在附近进行静默移动的可能性降低 50%。它们在 1 回合内可以以 80% 的概率藏入树叶或阴影，或静默移动。

暗棕精灵会说棕精灵语，以及少量小仙子、萨堤尔和树精使用的语言。

暗棕精灵看起来很像身材纤细、皮肤黝暗的棕精灵。他们穿着红褐色和绿色的衣服。
