库希或精灵犬只出现在精灵经常出没的林地或草地。最常见的情况是它们与森林精灵为伴。库希移动很快；当沿直线追逐目标时，速度会更快（21"）。战斗时，它会用巨大的前爪将人类大小或更小的双足生物击倒；这次攻击要在咬击前正常判定。倒地的对手当然更容易被咬（不获得敏捷加值，攻击命中获得 +2）。精灵犬会躲避其他犬类。它的吠声能传到一英里或更远，但只有在警告主人时才会吠叫。

库希有最大的普通犬那么大，毛皮呈带棕色斑点的绿色。这种颜色加上它安静移动的能力，使它很容易在灌木或林地中隐藏（75% 概率）。普通库希体重超过 168 磅，常常达到 310 磅。它的爪子巨大而长着重爪，尾巴卷曲并举在背上。

巨鹤生活在普通鹤、苍鹭、麻鳽及类似涉水鸟类相同的栖息地。它们在沼泽、湿地、水道两岸或湖边捕捉大鱼。巨鹤通常不主动攻击，但会保护配偶、幼鸟和筑巢区域。如果遇到超过 10 只，其中每一只额外出现的鸟都有 50% 的概率是未成年个体。如果遇到 20 只，有 50% 的概率它们属于一个有 31–50 只成员的大鸟群（1d20+30）；鸟群中会有 3–12 只半成年的雏鸟。

## Crysmal（水晶怪）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–6 |
| 护甲等级 | -4 或 0 |
| 移动 | 6" |
| 生命骰 | 6+6 |
| 巢穴内百分比 | 无 |
| 财宝类型 | Q（×2–8）/个体 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 3–12（2–8） |
| 特殊攻击 | 水晶飞弹 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 高至特别聪明 |
| 阵营 | 中立（邪恶） |
| 体型 | S（高 3.5 英尺） |
| 灵能能力 | 91–110；攻击/防御模式 BC/F |
| 等级/经验值 | VI/825 + 10/生命值 |

水晶怪是来自土元素位面的晶体生物。它偶尔会在主物质位面出现，但只会出现在富含矿物构造、能够提供食物的地下区域。它尤其喜欢石英、绿柱石、刚玉和碳晶体。水晶怪经常为了获得这些矿物而发动攻击。一只水晶怪体内会有 4–32 颗尚未消化的粗宝石。

由于水晶怪的晶体本质，使用刃器和穿刺武器攻击它时，其有效护甲等级为 -4；使用金属钝击武器时，有效护甲等级只有 0。水晶怪的结构也使它移动缓慢。它的棱面步行附肢有 4–6 条，只能让它跺着脚、以生硬的方式移动。

水晶怪会用从顶部伸出的锋利旋转附肢攻击。如果受到极大压力，怪物可以把这条附肢射到 2" 远，造成 9–16（1d8+8）点伤害。此后它只能用次级附肢攻击，伤害从 3–12 降为 2–8。

火焰或基于寒冷的法术不会伤害水晶怪。闪电术等电击攻击只造成四分之一伤害，或者根据豁免结果不造成伤害。毒素、气体等也不会伤害水晶怪。粉碎术会对它造成 3–18 点伤害；玻璃术会使它失明 2–5 轮；石化复原术会使它在 1 个近战轮内对所有武器的护甲等级降至 6。水晶怪能够像穴居怪（见相关条目）一样穿过固体岩石或泥土；它需要 1 轮改变自身的分子结构才能做到。如果它在改变结构时被相位门术击中，就会死亡。水晶怪憎恨穴居怪，因为后者会捕食它们。

水晶怪看起来像一堆截断的棱柱状半透明水晶。每个个体通常只有一种颜色，范围从浅琥珀色、橄榄色一直到深紫色。

中型水晶怪最多拥有 16 点生命值；大型水晶怪拥有 17 点或更多。生命值超过 28 的个体约 2 英尺宽、14 英尺长、半英尺厚。

| 生命骰 | 4 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 4–16 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | M 至 L |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | IV/225 + 4/生命值 |

水晶软泥是灰软泥（见相关条目）的一种，已经适应在水中生活。浸没时，它有 75% 的概率隐形。任何昏暗或黑暗的浅水体都可能成为水晶软泥的家。它离开水后仍能生存数小时。

水晶软泥的攻击方式是流过受害者，并分泌一种麻痹毒素。毒素会造成上方所列的伤害；除非成功通过对抗毒素的豁免，受害者会被麻痹，并在短时间内被吞食。当猎物的生命值降至 -20 时，就已经被完全消化。

水晶软泥不受酸、寒冷、热或火伤害。电击会造成全部伤害，魔法飞弹也会造成全部伤害。武器打击每次只造成 1 点伤害。木制武器会受到腐蚀性毒素影响；除非每次命中都成功通过对抗酸的豁免，否则木头会被吃掉或断裂。

|---|---|

| 出现数量 | 1–8 |
| 护甲等级 | 3 |
| 移动 | 12" |
| 生命骰 | 5 |
| 巢穴内百分比 | 35% |
| 财宝类型 | C |
| 攻击次数 | 1 |
| 每次攻击伤害 | 按武器类型 +2（力量加值） |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 低至平均 |
| 阵营 | 混沌至混沌邪恶 |
| 体型 | L（7.5 英尺高） |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | II/90 + 5/生命值 |

独眼人族喜欢居住在荒野地区，偏爱岩石地带，并生活在洞穴中。他们独居或组成小型群体，尽可能躲避其他生物，除非那些生物能成为猎物或奴隶。偶尔，某个特别强大的独眼人会把几个群体联合起来，袭击并掠夺低地。据说曾有一个这样的群体超过 80 只。

由于深度知觉很差，独眼人使用远程武器时命中受到 -2；不过，它们的力量使伤害获得 +2。典型的独眼人携带一根大棍棒（各方面等同于晨星）或一种带刃、类似长戟的武器。此外，每个独眼人还携带一把巨大投石索和一支重型投矛。

独眼人的头发蓬乱，颜色为黑色或暗蓝色；身体皮肤则从红褐色到泥黄色不等。它们的衣服通常用兽皮制成。独眼人的单眼通常是红色的。
