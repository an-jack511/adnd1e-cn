## Cheetah（猎豹）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 5 |
| 移动 | 15"（可短跑 45"，持续 3 轮） |
| 生命骰 | 3 |
| 巢穴内百分比 | 16% |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1–2/1–2/2–8 |
| 特殊攻击 | 后爪，1–2/1–2 |
| 特殊防御 | 只有 1/6 的概率被突袭 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | II/65 + 3/生命值 |

猎豹生活在热带平原和草地上。它是唯一拥有不可收回爪子的猫科动物；如果从小养大，它也是唯一能够始终被训练并驯化到可靠程度的大型猫科动物。（狮子爱好者声称，猎豹并不比狮子更忠诚；这个争论没有定论。）和所有猫科动物一样，猎豹是食肉动物，会主动追踪并杀死猎物以求生存。

由于保护色和狩猎技巧，猎豹有 3/6 的突袭机会。它们可以突然爆发到三倍速度，以 45" 的“短跑”速度持续 3 轮；之后必须休息 3 回合才能再次短跑。猎豹可以向上跳 10 英尺，或向前跳最多 20 英尺。如果攻击时两只前爪都命中，猎豹会追加 2 次后爪撕抓。

如果在巢穴中发现猎豹，且指示数量只有 1 或 2 只，那么巢穴中还会有 1–4 只幼崽。幼崽没有有效攻击。成年猎豹会为保护幼崽献出生命；保护幼崽的成年猎豹命中和伤害均获得 +2。

## Choke Creeper（窒息藤）

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1 |
| 护甲等级 | 藤蔓 6；茎 5 |
| 移动 | 1/2" |
| 生命骰 | 25（见下文） |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 8（或更多） |
| 每次攻击伤害 | 1–4 |
| 特殊攻击 | 绞杀 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 无 |
| 阵营 | 中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | IX/7600 + 35/生命值 |

窒息藤又名绞杀藤，似乎是披风怪、绞首树（见相关条目）的近亲。它的植物茎会长到接近树干的粗细，长度可能超过 100 英尺，并且拥有 20 条或更多会缓慢爬行、不断绞杀的藤蔓。藤蔓用柔韧的卷须以每轮 5 英尺的速度移动。每条藤蔓需要受到 2–16 点伤害才能切断；植物越大，藤蔓就越坚韧。

小型窒息藤每个生命骰只有 1 点生命值；巨大而古老的个体每骰拥有 8 点生命值（总计 200 点）。对绞杀藤蔓的伤害不会影响主体植物。藤蔓会被光线和移动吸引。由于它们看起来像普通植被，通常能抓住毫无戒心的受害者。

一旦抓住受害者，藤蔓每回合挤压并造成 1–4 点伤害。每次挤压有 10% 的概率改用绞杀握法；受害者会在下一回合结束时死亡。窒息藤每 10 英尺的长度通常有 8 条绞杀藤，末端部分数量翻倍。这些可移动的藤蔓通常会向四周展开，覆盖 360 度区域。每条藤蔓分枝长 9–16 英尺。

小型、火把大小的火焰不会影响窒息藤；燃油燃烧那样的高温火焰会造成正常伤害，并使可移动藤蔓离开。寒冷每个伤害骰只造成 1 点伤害，并会使被击中的植物部分在 2–56 轮内无法移动。电击攻击会使藤蔓的移动速度在 2–5 轮内翻倍，但不会伤害植物。

## Cloaker（披风怪）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 3（阴影中 1） |
| 移动 | 1"/15"（MC：D） |
| 生命骰 | 6 |
| 巢穴内百分比 | 15% |
| 财宝类型 | C |
| 攻击次数 | 2 + 特殊 |
| 每次攻击伤害 | 1–6/1–6/+特殊 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 高（见下文） |
| 阵营 | 混沌中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式无/无 |
| 等级/经验值 | V/350 + 6/生命值 |

披风怪是栖息于阴影中的异界生物。它们通常只在地底深处、黑暗的洞窟中遭遇。虽然它们拥有很高的智力，但思维过程对大多数种族而言都很陌生；通常只有魔法使用者能够与它们交流。

披风怪像一件巨大的半圆形披风或毯子，两个爪状附肢位于两端，另有一条长长的、像钉头锤一样的尾巴。它的背上布满像披风纽扣一样的黑色眼斑；尾巴隐藏起来时，几乎无法把它与真正的披风区分开来。正面中央有一张大而张开的嘴和 2 个发光的红色眼斑。由于拥有这么多眼睛，披风怪不会被来自后方的攻击突袭。

披风怪会飞向角色，用身体褶皱包住受害者，压住受害者的手臂，使其无法还击。角色被包住后，披风怪可以咬受害者的腹部或背部；伤害为 1–4 点加上受害者未经调整的护甲等级。披风怪通常每轮可以用尾巴攻击两次，每次造成 1–6 点伤害。它经常用尾巴抵挡攻击者，同时杀死被包住的受害者。尾巴护甲等级为 1，在被切断前可以承受 16 点伤害。

披风怪包住受害者时，任何针对披风怪的攻击都会让受害者和披风怪各承受一半伤害。火焰法术等范围效果攻击则会让两者都承受全部伤害。

披风怪会定期发出次声呻吟。石头会阻挡呻吟的效果。披风怪不能同时咬击和呻吟。呻吟可以按怪物意愿产生多种效果：

1. <strong>最低强度：</strong> 对所有处于范围内的人造成紧张与不安。连续听超过 6 回合后，听者的心智会麻木，变得像僵尸。呻吟听觉范围内的所有人进行攻击和伤害检定时受到 -2；范围为 80 英尺。
2. <strong>第二强度：</strong> 产生类似恐惧术的恐惧效果，范围为 30 英尺。角色必须进行对抗法术的豁免，否则惊恐逃跑。恐惧只持续 2 轮。
3. <strong>第三强度：</strong> 造成类似臭云术的恶心与虚弱。效果区域为长 30 英尺、开口端宽 20 英尺的锥形区域，持续 2–5 轮。区域内的所有人必须进行对抗毒素的豁免，否则因恶心而无助。
4. <strong>第四强度：</strong> 效果如同定身人类术，一次只能对 1 个目标使用，射程最多 30 英尺，持续 5 轮。

中和毒素术可以消除披风怪呻吟的效果。

披风怪还拥有操纵阴影的能力。它可以利用阴影隐藏自己，或遮蔽对手的视线，使自身护甲等级提高至 1。阴影操纵非常精确，足以制造阴影图像。披风怪裹在阴影中时，甚至能制造足以欺骗攻击者的阴影分身（按镜像术处理）。光亮术会使披风怪失明，并阻止阴影转移。
