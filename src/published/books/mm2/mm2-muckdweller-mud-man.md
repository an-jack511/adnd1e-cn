## Muckdweller（泥栖者）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 5–20 |
| 护甲等级 | 6 或 1 |
| 移动 | 3"／12" |
| 生命骰 | 1–4 点生命值 |
| 巢穴内百分比 | 40% |
| 财宝类型 | 巢穴：J、K、L、M、N；个体：Q |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–2 |
| 特殊攻击 | 水流 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 守序邪恶 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | I／7 + 1/生命值 |

Muckdweller 是一种两足的两栖怪物，潜伏在沼泽、湿地或泥底静水中。它们是杂食者，会吃植物、昆虫、水生动物甚至腐肉，但偏爱新鲜温热的血肉。Muckdweller 会成群潜伏等待粗心的受害者。

当目标接近时，一部分 Muckdweller 会向目标眼睛喷射泥水，射程最多 10 英尺；目标必须对抗魔杖豁免（若处于突袭状态，则无豁免）。其他 Muckdweller 会爬出来，用小而锋利的牙齿撕咬猎物。失明的受害者当轮无法反应，针对他的所有攻击获得 +2，且其护甲等级不能获得敏捷加值，因此 Muckdweller 的攻击非常危险。

这类生物的巢穴总在水下，但总有一块泥泞的陆上区域供它们休息和进食。Muckdweller 会在那里堆积闪亮物品。如果巢穴中遇到 16 只或更多怪物，Q 类财宝数量翻倍。

Muckdweller 偶尔会与蜥蜴人结伴，也有传闻说它们为 Kuo-toa 主人服务。它们说自己的呱呱嘶嘶语言，有时也会说蜥蜴人语。

Muckdweller 背部斑驳灰棕，腹部淡黄；短尾巴用于游泳和陆地行走。前足趾有抓握能力但很弱，后足部分有蹼。

## Mud-man（泥人）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–12 |
| 护甲等级 | 10 |
| 移动 | 3" |
| 生命骰 | 2 |
| 巢穴内百分比 | 100% |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 投掷泥块 |
| 特殊防御 | 需要魔法武器才能命中；免疫某些法术 |
| 魔法抗性 | 标准 |
| 智力 | 非智能 |
| 阵营 | 中立 |
| 体型 | S（约 4 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／28 + 2/生命值 |

Mud-man 形成于泥潭中：被附魔的水（即使只是侵蚀魔法建筑的轻度附魔水）聚集、蒸发并浓缩魔力后，便会产生它们。

它们的身体本质上是活化的泥；被唤醒时形成矮壮的类人生物。它们行动缓慢，不能离开泥潭，唯一目的就是杀死任何进入泥潭、行动比自己更快的生物。几乎所有生物，尤其是人类和半人类，都符合这个条件。

在休眠状态，Mud-man 躺在泥潭表面下，身体物质散布在整个泥潭中，以泥中的魔力为食。此时它们免疫武器攻击，无论武器是否为魔法武器，但容易受到法术攻击（见下文）。

当角色或生物进入泥潭，Mud-man 会立即感知到它；它们需要 1 轮聚拢身体物质，站起来准备在下一轮攻击。完全成形并站立后，它们可以被武器伤害，但武器必须是魔法武器。

Mud-man 会向对手投掷泥块；为判断命中，目标视为护甲等级 10（仍受敏捷影响）。泥块撞击后会变硬，减慢受害者的移动。开始时，Mud-man 只投掷泥团，最大射程 6"；命中会使受害者移动率降低 1"。投掷泥团时，Mud-man 仍以全移动率接近对手。

接近至 1" 内后，它们会把自己（确实是身体本身）投向对手，而不再只是投掷泥团。命中意味着 Mud-man 死亡，但也会使受害者移动率降低 4"；未命中则必须花下一轮重新成形，之后才能再次攻击。

移动率降到 0 的受害者无法移动并开始窒息；只要口或鼻没有被清出，每轮受到 1–8 点伤害。除非获救，受害者会在 5 轮后因窒息死亡。硬化泥块可以从完全或部分不能移动的生物身上剥离；每 5 轮能恢复 1" 移动率。

Mud-man 无法感知泥潭外的生物，也不会攻击它们。泥潭内没有活着的对手后，已经苏醒的 Mud-man 会沉回表面下；只有再次有人进入泥潭时才会重新出现。

所有会直接伤害活物的法术都会影响 Mud-man，例如治疗轻伤、魔法飞弹、火球和火焰打击。驱散魔法和挖掘术会像施法者同等级魔法使用者施放的火球一样作用。泥化石术能杀死其影响到的所有 Mud-man，不允许豁免。

它们免疫毒素，无论毒素是魔法产生的（例如毒云、毒术）还是其他来源；同样不受影响心灵的法术（例如魅惑、睡眠）和灵能影响。

只要 Mud-man 还没有完全从泥潭中成形，法术伤害就没有范围效果，例如魔法飞弹；由于它们的物质均匀散布在泥潭中，伤害会由所有 Mud-man 分摊，小数向下取整。
