## Nereid（水仙女）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 10 |
| 移动 | 12" |
| 生命骰 | 4 |
| 巢穴内百分比 | 100% |
| 财宝类型 | X |
| 攻击次数 | 无 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 吐唾液；控制巢穴内的水 |
| 特殊防御 | 接吻；魅惑男性 |
| 魔法抗性 | 50% |
| 智力 | 非常高 |
| 阵营 | 混沌 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／200 + 4/生命值 |

Nereid 来自水元素位面。她们的名字意为“蜜一般甜美者”，离开水时可以采用人类形态。这些形态总是美丽，而且大多是女性。Nereid 被描绘为年轻纤细、长着金色长发、苍白皮肤并拥有美妙歌声的生物。她们可能穿着白金色衣物，但经常不着衣物。她们有一条白色披巾，或拿在手中，或披在头顶和肩膀上。在水中，Nereid 是透明的，除非看起来像金色天使海藻，否则有 95% 的概率无法被发现。

她们可以出现在海洋、河流、水井、山泉、洞穴泉和水元素位面。像她们居住的水一样，她们的动机混沌而反复无常；具体是善良、中立还是邪恶取决于个体。大多数 Nereid 是混沌中立，但也有非常善良或极端邪恶的个体。所有 Nereid 都羞怯而飘忽不定，她们的行为带有顽皮性质。

Nereid 唯一的物理攻击是吐唾液，射程 20 英尺；命中后可以使目标失明 2–12 轮。毒液可以用水洗掉。失明的受害者攻击时承受 -4，豁免和护甲等级也各降低 4。

Nereid 对自己巢穴周围半径 3" 的水拥有一定控制力。她可以让水掀起巨浪，使移动率降至正常的四分之一，或令水沸腾翻滚，使溺水概率增加 10%。她能使波浪发出震耳欲聋的轰鸣；若不采取防护，6" 内的角色会失聪 3–12 轮。

最后，Nereid 可以塑造水形；水形可能只是令人愉快的娱乐，也可能成为有力的防御。后者会变成水蛇或拳头，按 4 生命骰怪物攻击，每次造成 1–4 点伤害。每轮只能进行其中 1 次攻击。

所有看见 Nereid 的男性都会发现自己无法伤害她，而她的行动看起来像漫不经心的调情。有人会坐着观看 Nereid 的嬉戏一整天，也有人会试图娶她，或只是追逐她的拥抱。这可能带来灾难，因为 Nereid 的吻既能带来甜美狂喜，也可能带来水中死亡。

如果 Nereid 被抓住，她可以进行对抗毒素的豁免，成功后会像水一样流走。然而，如果有人强迫她接吻（她很不愿意主动给出吻），角色必须以 -2 修正进行对抗吐息武器的豁免，否则立即溺死；否则会感到狂喜。

Nereid 最大的弱点是披巾，因为她的灵魂就在其中。如果披巾被毁，Nereid 会溶解成无形的水。因此，如果角色能得到她的披巾，就能命令 Nereid；她出于恐惧会服从。不过 Nereid 会说谎，并尝试除敌对行动以外的一切事情，以取回披巾。

Nereid 有 85% 的概率拥有宠物。掷 1d8 决定宠物：1 巨型鳗鱼；2 巨型水獭；3 巨型蛇（有毒）；4 巨型章鱼；5 巨型鱿鱼；6 海豚；7 巨型水蛭；8 刺鳐。

## Narwhale（一角鲸）

|---|---|

| 出现数量 | 1–6 |
| 护甲等级 | 6 |

| 生命骰 | 4+4、5+5 或 6+6 |

| 财宝类型 | 无 |
| 攻击次数 | 1 |

| 特殊防御 | 无 |

Narwhale 被称为“海洋独角兽”，常见于凉爽至寒冷的水域。它们是体型相当大的海洋哺乳动物，身长约 20–40 英尺，不包括 6–12 英尺长的螺旋“角”。

Narwhale 基本上不具攻击性，只有在受到严重威胁或实际攻击时，才会用巨角自卫。海豚群落会把它们当作宠物和守卫；水生精灵有时也会训练和使用它们。
