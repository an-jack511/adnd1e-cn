## Obliviax（记忆苔）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 2–12 |
| 护甲等级 | 10 |
| 移动 | 无 |
| 生命骰 | 1–2 点生命值 |
| 巢穴内百分比 | 100% |
| 财宝类型 | 无 |
| 攻击次数 | 无 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均 |
| 阵营 | 中立邪恶 |
| 体型 | S（半英尺见方） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／30 + 1/生命值 |

这种邪恶的黑色苔藓拥有从其他生物那里窃取记忆的魔法力量。智能生物进入 60 英尺内时，必须进行对抗法术的豁免，否则苔藓会窃取该生物过去 24 小时内的全部记忆，包括记忆中的法术。

Obliviax 每轮可以尝试从 1 个生物窃取记忆；成功后，24 小时内不会再次攻击。如果一块带有被窃记忆的 Obliviax 受到攻击，它会在 1 轮内将自身一部分塑造成被窃记忆生物的微小苔藓仿制体。这个 Mossling 仍附着在母苔藓上，只能通过施放任何被窃取的法术进行防御。

取回被窃记忆的唯一方法是吃下活的 Obliviax，这需要 1 轮。如果通过对抗毒素的豁免，食用者会获得全部被窃记忆，包括法术；豁免失败则会重病 3–18 轮。通过食用这种苔藓，也可能获得另一个人的记忆。任何因食用 Obliviax 而获得法术的人都能施放这些法术，但通过这种方式获得的记忆会在 24 小时后消退。

## Ogre、Aquatic（Merrow，水生食人魔）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 2–24 |
| 护甲等级 | 4 |
| 移动 | 6"／12" |
| 生命骰 | 4+4 |
| 巢穴内百分比 | 20% |
| 财宝类型 | A |
| 攻击次数 | 3 或 1 |
| 每次攻击伤害 | 1–6／1–6／2–8，或依武器 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 伪装 |
| 魔法抗性 | 标准 |
| 智力 | 低至平均 |
| 阵营 | 混沌邪恶 |
| 体型 | L（高 9 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／130 + 5/生命值；IV／250 + 6/生命值 |

这种水生食人魔通常比陆地同族更快、更强壮，也更凶猛。Aquatic Ogre 通常会在游泳冲锋中先用穿刺长矛攻击，造成 2–12 点伤害并获得 +1 命中，随后用利爪和牙齿进行近战。

它们利用绿色体色隐藏自己，根据地形有 10%–80% 的概率有效隐形，并从掩护处发动攻击，有 4/6 的概率发动突袭。

Aquatic Ogre 生活在相对浅的水域，深度约 50–250 英尺。它们居住在洞穴中，常与 Scrag 结伴。它们可以离开水中生存最多 2 小时，因此有时会袭击陆地。

一群 7–12 只食人魔中有 1 只拥有 31–36 点生命值；13–18 只中有 2 只；19–24 只中有 3 只。群体巢穴中会有：1 名首领（AC3，6+6 生命骰，伤害 +2）；2 名副首领（AC3，5+5 生命骰，伤害 +1）；2–24 名雌性（AC5，3+3 生命骰，造成 1–2／1–2／1–6 点伤害）；1–12 名幼体（AC6，2+2 生命骰，造成 1–2／1–2／1–4 点伤害）；以及 1 名萨满，可能是普通雄性或雌性。

Aquatic Ogre 会说食人魔语和自己的方言。它们呈绿色、有鳞片、肩膀倾斜，脖子长而粗，嘴巴巨大，下颌突出，手脚有蹼。

## Oliphant（古象）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1–8 |
| 护甲等级 | 4 |
| 移动 | 12" |
| 生命骰 | 8+4（10+5） |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 4 |
| 每次攻击伤害 | 3–12／3–12／3–12／3–12 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 中立 |
| 体型 | L（高 8 英尺；有些大得多） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／600 + 12/生命值 |

Oliphant 很可能是现代长毛象的近亲。它们多毛的皮肤使其能够在较凉爽的温带或亚北极气候中生存。独居的 Oliphant 避开有人居住的地区；如果足够年幼，可以捕获并训练。

Oliphant 用向下弯曲的獠牙和沉重的前腿攻击。鼻子太短，不能作为有效武器。它可以同时对付 4 名人类大小的对手、2 名食人魔大小的敌人，或 1 名巨人大小的敌人。

Oliphant 的智力使其在训练得当时成为毁灭机器，尤其是大型雄性。受到喂养和照料时，它们可以长到 10 英尺或更高，达到 10+5 生命骰，体重和体量也远超野生同类。这种动物会被用于战争和其他军事职责：披挂皮甲、鳞甲和板甲加固，头部和前腿伸出尖刺，背负城堡般的 Howdah，内有弓箭手和长枪兵。炎热气候中的大象会披甲，但智力较低的个体缺乏受训 Oliphant 的凶猛。

Oliphant 不害怕火，除非火焰直接威胁到它。它们具有攻击性，通常会试图消灭威胁而不是逃跑。Oliphant 的獠牙每根价值 100–400 金币，象牙约每磅值 4 金币。

如果遇到 3 只或更多 Oliphant，有 25% 的概率出现幼崽，有 75% 的概率出现半大个体；对超过最初 2 只的每一只分别检查。幼体雌雄数量相等。所有单独出现的 Oliphant 都是雄性；2 只或更多的群体中只有 1 只成熟雄性。
