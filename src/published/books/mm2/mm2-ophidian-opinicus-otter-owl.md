Ophidian 或蛇人通常出现在热带丛林。与 Naga 不同，Ophidian 拥有人类般的手臂和手，能够使用战士可以使用的武器、盾牌和魔法物品。

它先用武器攻击，再用带毒獠牙咬击。后者要求受害者进行对抗毒素的豁免；失败后会受到类似狼人病的感染。感染在 2–5 天后开始，持续 8–16 天；如果受害者是人类或类人生物，最终会变成 Ophidian，否则会死亡。祛除疾病术可以阻止这一过程。

Ophidian 很少组成自行决定的群体，通常是 Spirit Naga 或类似生物的仆人。它们看起来像短尾、粗身的蛇，手臂从颈部下方约 2 英尺处伸出；手臂与人类手臂相似，末端是四指的手。颜色从灰黑、黑色和深棕绿色到淡蓝绿色不等。

## Opinicus

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–2 |
| 护甲等级 | -2 |
| 移动 | 21"／30"（MC：B） |
| 生命骰 | 7+7 |
| 巢穴内百分比 | 10% |
| 财宝类型 | A |
| 攻击次数 | 4 |
| 每次攻击伤害 | 1–3／1–3／1–6／1–6 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 35% |
| 智力 | 非常高至超凡 |
| 阵营 | 混沌善良 |
| 体型 | M |
| 灵能能力 | 205–250 点；攻击/防御模式：全／全 |
| 等级/经验值 | VII／2300 + 12/生命值 |

Opinicus 是居住在沙漠中的善良生物，通常栖息于废弃城市、宫殿或神殿等古老遗迹。它们偶尔会在其他地方出现，通常是为了执行某项善行任务。虽然 Opinicus 以有益行为和友善性格闻名，也喜欢捉弄人和开玩笑；这些行为降低了它们的声望，但善良生物很少拒绝 Opinicus 的援助。邪恶生物当然会畏惧 Opinicus。

普通攻击是 2 次爪击（1–3／1–3）和后爪撕裂。此外，Opinicus 拥有 7 级牧师的施法能力，能够驱散不死生物。它们每天可以使用一次圣言术、每天两次次元门、每天 3 次治疗术。

Opinicus 拥有发光凝视，也称“太阳火花”：形状为 2"×1"×2" 的锥体，影响不死生物和下层外位面的生物，包括 Acheron、九层地狱、Gehenna、Hades、Tartarus、Abyss 和 Pandemonium。凝视每 10 轮最多使用一次，对受害者造成 2–16 点伤害；对抗法术豁免成功则伤害减半。

由于感知敏锐，Opinicus 永远不会被突袭。在自己的栖息地有 5/6 的概率突袭，在其他地方有 3/6 的概率突袭。它们能进行星界和以太旅行，拥有 3–5 种次级灵能学科和 1–2 种主级灵能学科，常用这些能力恶作剧。

Opinicus 看起来像猴、骆驼、狮子和鹰的混合体，但它们当然不是混合物，而是独立的生物。颜色从浅黄褐到金棕不等，翅膀比身体略深，前爪有抓握能力。

水獭是鼬类等动物的水生近亲，生活在河流、池塘和湖泊中。海獭是普通水獭中最大的一种，生活在浅海沿岸；上方括号中的数值代表海獭差异。它们行动迅速而顽皮，只有被逼入绝境时才会攻击。它们的皮毛具有毛皮价值。

## Owl（猫头鹰）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1 或 2 |
| 护甲等级 | 5 |
| 移动 | 1"／27"（MC：D） |
| 生命骰 | 1 |
| 巢穴内百分比 | 10%（仅白天） |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1–2／1–2／1 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | S（翼展 4–5 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／30 + 1/生命值 |

各种气候中都有猫头鹰。有些比这里列出的个体小，但多数遭遇都会是大型标本。它们用利爪和喙攻击。从 50 英尺或更高的高度俯冲时，攻击获得 +2 命中，造成双倍正常伤害，但不能进行喙击。

猫头鹰拥有双倍正常的红外以上视觉、四倍正常的听觉，并且飞行时完全无声。它们有 5/6 的概率突袭猎物，在黄昏或黑暗的白天绝不会被突袭。在从黄昏到白昼的光照中，它们的视觉略低于人类正常水平；因此，尽管听觉出色，如果在白天隐藏的栖息处被发现，仍有 3/6 的概率被突袭。

猫头鹰不能被训练来狩猎，但如果从小饲养并习惯人类存在，可以被部分驯养。由于乌鸦、渡鸦等通常会成为夜行猫头鹰的猎物，白天发现猫头鹰时，这些鸟类会成群攻击；攻击鸟类的愤怒和决心也会使它们为了杀死诱饵猫头鹰而失去谨慎。
