## Phycomid

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 5 |
| 移动 | 3" |
| 生命骰 | 4 |
| 巢穴内百分比 | 80% |
| 财宝类型 | 零星 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 3–6／3–6 |
| 特殊攻击 | 感染 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 无法评级 |
| 阵营 | 中立邪恶 |
| 体型 | S（最大直径 2 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／280 + 5/生命值 |

Phycomid 的外形像藻类纤维团和分解中的乳白色物质，上面长着有菌盖的真菌。它们攻击时会分泌高度碱性的物质。

攻击时，Phycomid 会伸出一根管状器官，向 7–12 英尺外发射小球状碱液。除了碱液伤害，液滴还可能使受害者成为新 Phycomid 生长的宿主。

目标若对抗毒素豁免失败，感染部位会在 5–8 轮内长出蘑菇状突起，并造成 5–8 点伤害。随后突起开始遍布宿主全身，在 5–8 轮内杀死宿主，并将其变成新的 Phycomid。治病术可以阻止感染在宿主体内扩散。

Phycomid 免疫所有形式的心灵攻击，包括魅惑、定身等。对火焰攻击进行豁免时获得 +4，所受伤害为一半或完全无伤。
