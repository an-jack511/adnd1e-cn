## Planetar

|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | -7 |
| 移动 | 16"／48"／24"（MC：B） |
| 生命骰 | 144 点生命值 |
| 巢穴内百分比 | 0% |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 依武器类型，+7（力量加值） |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |

| 智力 | 超级天才；智慧 21 |

Planetar 是强大灵体的化身，能够充当次级神祇的右手；数量众多的 Planetar 则会侍奉主要神祇。这些生物居住在善良的上层外位面，但能随意前往除最低层位面之外的任何位面：Hell、Gehenna、Hades、Tartarus 和 Abyss。若神祇命令，它们甚至能够进入最低层的邪恶位面。只有 Solar 的善良力量比 Planetar 更强。

Planetar 可以是任何善良阵营：守序、 中立或混沌；具体阵营由其侍奉的主人决定。每个 Planetar 每轮有 3 次攻击，通常使用只有 Planetar 能使用的巨剑。这把剑等同于同时具备 +4、守护者和伤口制造特性的武器，后者只对邪恶生物生效。判断攻击时，视 Planetar 敏捷为 21，并视为 17 级战士。

所有 Planetar 拥有相当于 7 级牧师和 7 级德鲁伊的类法术能力，并获得相应加值（智慧为 21）。此外，它们可以随意使用下列类法术能力，一次 1 项、每轮一次：活化物体（每日一次）、刃墙术（每日 3 次）、持续光亮（半径最多 10"）、控制天气（每日一次）、驱散邪恶（每日 3 次）、驱散幻术（每日 7 次）、驱散魔法（每日 3 次）、地震术（每日一次）、以太形态、弱智术（每日一次）、有限祈愿术（每日一次）、物品变形术、火焰风暴（每日一次）、火焰打击（每日 3 次）、治疗术（每日 3 次）、圣言术（每日一次）、高等隐形（半径最多 10 英尺）、虫灾（每日一次）、有限祈愿术（每日一次）、自身变形术、死者复活（每日 3 次）、阅读魔法、移除诅咒、移除恐惧、抵抗寒冷（双倍效果）、抵抗火焰（双倍效果）、复原术（每日一次）、变形（每日一次）、与死者交谈、符文（任意一种，每日一次）、无误传送术、真实视觉（每日 3 次）、召唤天气（每日一次）和风行术（每日 7 次）。

每个 Planetar 可以随意从自身向外维持一个防护邪恶球体，范围从自身大小到完整 40 英尺半径不等，维护自动进行。Planetar 需要时可以进行神谕。它们总能通过接触治愈失明、失聪、疾病或轻伤。

Planetar 自动侦测邪恶、幻术、隐形、谎言、魔法和陷阱，并始终保持侦测阵营。它能通过心灵感应或通晓语言交流，也能阅读任何语言。它始终拥有 12" 红外视觉和正常范围两倍的红外以上视觉。

每天一次，Planetar 可以召来相应数量的 Deva（1–3、1–4 或 1–6），类型可以是 Astral、Monadic 或 Movanic。每天一次，它还能召唤：守序善良时 1–4 Couatl；中立善良时 1–2 Baku；混沌善良时 1–2 Androsphinx。

Planetar 会受到 Deva 条目中所列攻击形式的影响。只有 +4 或更好的武器才能伤害它们。它们永远不会被突袭，免疫任何生命等级损失，无论来自不死生物还是魔法。它们不能被迷惑、魅惑、困惑、支配或弱智，灵魂不能被囚禁或捕获，并免疫死亡法术。

Planetar 每轮再生 4 点生命值。在上层外位面之外遭遇时，只有它们的物质身体能被伤害；Planetar 的灵魂会回到自己的位面，重新形成肉身，这一过程需要 4 个十年。它们的魅力效果为 21。

Planetar 拥有以下灵能能力：14 级动物心灵感应、光环改变、身体控制、身体平衡、9 级身体武器、17 级群体支配、分子搅动、预知、缩小、17 级心灵遥控和心灵投射。

Planetar 看起来像高大而强壮的类人生物。物质形态的皮肤呈蛋白石色，头部无毛，双眼发出蓝光；翅膀成对，也呈蛋白石色。
