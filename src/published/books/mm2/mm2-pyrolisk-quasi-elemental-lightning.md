## 火眼蜥 · Pyrolisk

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 6 |
| 移动 | 6"／18"（MC：C） |
| 生命骰 | 4+3 |
| 巢穴内百分比 | 30% |
| 财宝类型 | D |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–4 |
| 特殊攻击 | 凝视 |
| 特殊防御 | 免疫火焰 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 中立邪恶 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／240 + 5/生命值 |

火眼蜥几乎与鸡蛇完全相同，但仔细观察会发现尾部有一根红色羽毛，灰色翅膀带有红色。它和同族一样栖息在温带至热带地区。

除了较弱的喙击，火眼蜥还有凝视能力。与其凝视相遇的目标会因内部突然燃烧而爆发火焰：对石化豁免失败会立即死亡，成功则受到 2–13 点伤害。天生或魔法抗火（无论来自法术、戒指或其他效果）的生物免疫凝视；通过豁免的受害者此后免疫该只火眼蜥的凝视。

火眼蜥还能使 30 英尺内任何火源爆炸成烟火，效果等同德鲁伊的烟火术。它可以随意使用，每轮一次，只为享受火焰；效果区域是火源的 10 倍，持续完整 1 轮，并使其中所有生物暂时失明。

火眼蜥免疫所有火焰攻击，无论魔法或普通火焰。它们的天敌是凤凰，因为凤凰同样免疫火焰，而且是善良生物。

| 智力 | 低 |
| 阵营 | 中立（混沌） |

| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1000 + 15/生命值 |

这类生物生活在气元素位面和正能量位面，即使在那里也很稀有。主物质位面发生大雷暴时，大量闪电准元素有时会聚集。在这种猛烈雷雨中，它们进食并繁殖。

除正常移动外，闪电准元素可以“电弧跳跃”，跳到 6" 内任何接地或金属物体，只要该物体重量超过 50 金币。电弧跳跃不取代正常移动，可以在移动开始或结束时进行。
