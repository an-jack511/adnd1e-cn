## Pyrolisk

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 6 |
| 移动 | 6"／18"（MC：C） |
| 生命骰 | 4+3 |
| 巢穴内百分比 | 30% |
| 财宝类型 | D |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–4 |
| 特殊攻击 | 凝视 |
| 特殊防御 | 免疫火焰 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 中立邪恶 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／240 + 5/生命值 |

Pyrolisk 几乎与 Cockatrice 完全相同，但仔细观察会发现尾部有一根红色羽毛，灰色翅膀带有红色。它和同族一样栖息在温带至热带地区。

除了较弱的喙击，Pyrolisk 还有凝视能力。与其凝视相遇的目标会因内部突然燃烧而爆发火焰：对抗石化的豁免失败会立即死亡，成功则受到 2–13 点伤害。天生或魔法抗火（无论来自法术、戒指或其他效果）的生物免疫凝视；通过豁免的受害者此后免疫该只 Pyrolisk 的凝视。

Pyrolisk 还能使 30 英尺内任何火源爆炸成烟火，效果等同德鲁伊的烟火术。它可以随意使用，每轮一次，只为享受火焰；效果区域是火源的 10 倍，持续完整 1 轮，并使其中所有生物暂时失明。

Pyrolisk 免疫所有火焰攻击，无论魔法或普通火焰。它们的天敌是 Phoenix，因为 Phoenix 同样免疫火焰，而且是善良生物。

## Quasi-elemental、Lightning（闪电拟元素）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动 | 18"，另有特殊移动 |
| 生命骰 | 6、9 或 12 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–6 + 每生命骰 1 点 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 低 |
| 阵营 | 中立（混沌） |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1000 + 15/生命值 |

这类生物生活在气元素位面和正能量位面，即使在那里也很稀有。主物质位面发生大雷暴时，大量 Lightning Quasi-elemental 有时会聚集。在这种猛烈雷雨中，它们进食并繁殖。

除正常移动外，Lightning Quasi-elemental 可以“电弧跳跃”，跳到 6" 内任何接地或金属物体，只要该物体重量超过 50 金币。电弧跳跃不取代正常移动，可以在移动开始或结束时进行。

除用接触释放电击的普通攻击外，它每轮还能释放 1 个小型球状闪电，持续 6、9 或 12 轮（依生命骰）。球状闪电会漂浮在拟元素生物附近，直到有重量较大的物体（2000 金币或更多）或大量导电金属在 5 英尺内。随后球状闪电会移动到该物体并释放，造成 1–4、1–6 或 1–8 点伤害，依释放者的大小而定。

Lightning Quasi-elemental 只有 +7 或更好的魔法武器才能伤害。如果武器由导电材料制成，每当武器击中，持用者都会受到 1–4 点电击伤害。闪电和电击攻击不造成伤害；火焰和酸只造成一半伤害；寒冷造成全额伤害。水攻击每加仑造成 1–8 点伤害，即全额伤害的两倍。例如，冰风暴会造成 6–60 点伤害。落水（例如降雨）每降下 1/10 英寸水，就造成 2 点伤害。

Lightning Quasi-elemental 没有已知的社会组织。通常不可能召唤拟元素生物，不过强大的魔法使用者有时能够做到。
