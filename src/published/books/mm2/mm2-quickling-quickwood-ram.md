## Quickling

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 4–16 |
| 护甲等级 | -3 |
| 移动 | 96" |
| 生命骰 | 1½ |
| 巢穴内百分比 | 10% |
| 财宝类型 | O、P、Q、X |
| 攻击次数 | 3 |
| 每次攻击伤害 | 依匕首 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 按 19 级牧师进行豁免 |
| 智力 | 高至天才 |
| 阵营 | 混沌邪恶（或中立） |
| 体型 | S（高 2 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／200 + 3/生命值 |

这些细小、纤细而行动极快的生物据说是曾经涉足魔法和不该接触的神秘学、从而被改变的 Brownie 种族。传说中，这些小生物变成了极度恶毒、憎恨人类、半人类和其他小型生物的邪恶存在。它们生活在黑暗林地和荒野的邪恶地区。

在任何遭遇到的 Quickling 群体中，都会有 1 个 3 生命骰个体。若遭遇超过 10 个，则其中 2 个拥有 3 生命骰，另有 1 个 4½ 生命骰的首领。

由于惊人的速度，Quickling 拥有极佳的护甲等级。这种速度还使它们每轮能够用针状匕首攻击 3 次。首领有 75% 的概率拥有毒药；除非目标每次被这些生物的匕首命中后都成功通过对抗毒素的豁免，否则会陷入药物造成的沉睡。

所有 Quickling 每天可以使用一次、一次 1 项、随意使用以下类法术能力：传声术、遗忘术、浮空术、粉碎术、挖掘术和火焰魅惑。

Quickling 移动时有 90% 的概率能被看见，但若在天然掩护中静止，则完全隐形。攻击时只能看见一道模糊的影子。因此，它们的速度和 18 点敏捷使其对所有攻击形式的豁免都按 19 级牧师计算。Quickling 不可能被突袭。

Quickling 会说自己的语言、Brownie 语、Pixie 语和半身人语。多数 Quickling 能说许多通用语词汇，但音调很高、速度太快，难以理解。

Quickling 种族寿命短暂，因为它们的运动速度极快。它们约 1–2 岁成熟，12–15 岁死亡。

## Quickwood（窥视树）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1（90%），2–4（10%） |
| 护甲等级 | 5 |
| 移动 | 1"（根 3"） |
| 生命骰 | 5–10（每个生命骰 5 点生命值） |
| 巢穴内百分比 | 100% |
| 财宝类型 | 见下文 |
| 攻击次数 | 特殊 |
| 每次攻击伤害 | 见下文 |
| 特殊攻击 | 根、咬击、恐惧 |
| 特殊防御 | 永远不会被突袭；见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 非常高 |
| 阵营 | 中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／350 + 10/生命值 |

据说 Quickwood 只有通过某位大法师（也可能是德鲁伊）的魔法才能生长：他在用强大法术附魔 Mandragora 根后种下它。另一些人则认为，这些奇怪的树是植物生命自然发展到与人类等同状态的结果。

无论如何，Quickwood 确实拥有感知能力，不像世界上大多数植物。这棵巨大的硬木树看起来像橡树，但仔细观察会发现，它有类似扭曲人脸的面容和感觉器官。除非观察者进入 30 英尺内（如果 Quickwood 不使用感官来隐藏自己，则需 10 英尺），否则有 90% 的概率注意不到它的“脸”。它可以出现在任何能支持普通橡树的环境，包括生长常绿栎的温暖地区。

由于移动庞大树干非常困难，Quickwood 通常尽可能保持静止。但它可以伸出粗大的根，在松软表土中以每轮 3" 的速度移动。根能够抓住并固定体重低于 1000 磅的生物。根太强，无法徒手挣断；钝器也不能伤害它们，但可以用锋利武器割断。每条根视为大型物体，拥有 10 点生命值；根受到的伤害不会累积到摧毁 Quickwood 本体。

Quickwood 只允许 6 条根被割断，之后会把其余 7–12 条根收回安全处。它还拥有许多较小的根，用来感知接近的生物；敏感的叶片能察觉空气运动和压力变化。

它的视觉、听觉和嗅觉器官类似巨大的人眼、耳和鼻子，略优于人类正常水平；它拥有 120 英尺红外视觉。成熟的 Quickwood 还能使 2–8 棵普通橡树充当宿主。被占据的树会像 Quickwood 一样长出面容和感官器官，主树通过它们控制宿主并获取信息；控制范围为 36"。

Quickwood 的枝条太僵硬，不能用作攻击肢体，但它有一个嘴状开口，能咬合并造成 3–12 点伤害。目标必须接触树干，或被附近抓握的根强迫到合适位置，树口才能造成伤害。根本身不造成伤害，射程 30 码。

对 Quickwood 可以使用对植物有效的法术，但多数其他法术无效。它能通过出汗把自己浸湿，因此火焰不会伤害它；闪电会无害地被导走；毒素和气体也不会伤害它。解离术必然能摧毁它。

如果受到法术攻击，Quickwood 会把法术能量转化为恐惧，范围为法术能量每个等级 10 英尺。若施法者豁免失败，Quickwood 已将全部法术能量导入恐惧；若豁免成功，恐惧只是法术的副作用，魔法仍按正常方式生效。影响心灵的法术不能影响 Quickwood。

Quickwood 有时会被魅惑，或被其他方式说服充当财宝储藏处或地区守卫。前一种情况下，守护的财宝通常与放置财宝者的性质相符，物品总是藏在 Quickwood 的树干开口内。作为守卫，它会窥视入侵者；一旦发现目标，就发出空洞的鼓声，声音能传到 1 英里或更远。

## Ram（公羊）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1 或 1–6 |
| 护甲等级 | 6 |
| 移动 | 15" |
| 生命骰 | 2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–2 |
| 特殊攻击 | 冲锋 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／28 + 2/生命值 |

Ram 生活在亚北极至温带地区，偏爱多岩石的丘陵草地，避开树木茂密的地方。25% 的遭遇是单独一只；其他遭遇为 1–6 只，另有 3–18 只母羊和数量为母羊一半的羔羊。

只有在羊群无法通过飞奔逃脱时，Ram 才会攻击威胁羊群的生物。冲锋距离达到 20 英尺或更远时，攻击获得 +1 命中并造成双倍伤害。母羊只会顶撞，不会冲锋；羔羊不战斗。
