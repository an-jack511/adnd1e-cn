## Rat（普通鼠）

| 项目 | 数值 |
|---|---|
| 出现频率 | 常见 |
| 出现数量 | 1–100 |
| 护甲等级 | 7 |
| 移动 | 16" |
| 生命骰 | 1/2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |

从森林荒野到城市下水道，任何地方都能发现各种大小和颜色的老鼠。虽然胆小，被困住或逼入绝境的老鼠会凶猛战斗。饥饿时，鼠群会攻击任何活物以取得食物。像巨鼠一样，这类普通啮齿动物的污秽咬伤有 5% 的概率造成严重疾病，除非对抗毒素豁免成功。普通鼠害怕火，但饥饿时有时会冒险穿过火焰。

## Vapor Rat（蒸汽鼠）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 2–16 |
| 护甲等级 | 6（或特殊） |
| 移动 | 12"／6"（气态 1"） |
| 生命骰 | 2 |
| 巢穴内百分比 | 30% |
| 财宝类型 | 见下文 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–2 点生命值 |
| 特殊攻击 | 臭云术 |
| 特殊防御 | 气态形态 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 混沌（中立） |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／56 + 2/生命值 |

Vapor Rat 看起来不过是大型灰色巨鼠，但它们的栖息地与普通巨鼠不同，因为它们也生活在经常作为 Cloud Giant 居所的巨大云岛中。

Vapor Rat 可以改变身体物质，进入气态形态；此时看起来像一缕云或类似蒸汽。在正常固态中，它们移动非常快，游泳能力强，还能迅速挖入松土或云岛物质。在气态中，它们可以像船随风转向一样控制移动，从而在天空中从一座云岛移动到另一座云岛。

Vapor Rat 是杂食者，喜欢垃圾和腐肉，这是所有老鼠的典型习性。它们不会主动寻找财宝，但食物残骸中可能有有价值物品。若在巢穴中发现，以下每种财宝都有 25% 的概率出现：J（1–4）、K（1–4）、L（1–4）、M（1–4）、N（1–2）、宝石 C 类，以及其他 listed 类型。

如果 Vapor Rat 愤怒、饥饿或走投无路，会奔跑并用利齿攻击。每当一只被杀死或受到重伤，就会释放一小团有害烟雾。气体效果等同臭云术，但只影响 5–8 英尺内的 1 个个体；老鼠总是把烟雾对准对手，超过最大距离后气体消散。因此，从远处杀死它们很安全，但近距离尤其危险。

受伤或受到严重威胁的 Vapor Rat 总会进入气态形态。在这种状态下，只有能摧毁其蒸汽的攻击形式才能伤害它，包括极热或魔法火焰、闪电和异常强烈的风。

## Raven／Crow（乌鸦）

| 类型 | 出现频率 | 数量 | AC | 移动 | 生命骰 | 巢穴 | 伤害 | XP |
|---|---|---:|---:|---:|---:|---:|---:|---|
| Ordinary | 常见 | 4–36 | 7 | 1"／36" | 1/4 | 25% | 1 | I／无 |
| Huge | 稀有 | 2–8 | 6 | 1"／27" | 1–1 | 15% | 1–2 | II／30 + 1/生命值 |
| Giant | 稀有 | 4–16 | 4 | 3"／18" | 3+2 | 10% | 3–6 | III／60 + 4/生命值 |

所有 Raven 的攻击次数为 1，魔法抗性标准，灵能能力无。Ordinary 的智力为动物、阵营中立、体型 S（翼展 2–4 英尺）；Huge 的智力为半智能、阵营中立（邪恶）、体型 M（翼展 4–6 英尺）；Giant 的智力为低、阵营中立（邪恶）、体型 M–L（翼展 6–10 英尺）。

Raven（或 Rook）和 Crow 生活在寒冷温带至热带气候。它们主要是食腐动物，但作为杂食者，也会袭击庄稼、鸟巢或无人看管的食物储藏。所有此类鸟都会成群活动，但有时会遇到看似独自行动的侦察者。

一旦侦察者发现或察觉到可能威胁鸟群的生物，就会发出警告叫声，作为掩护并保持安全距离，同时跟踪目标，通过刺耳叫声和可能的动作向鸟群报告。因此，Raven 和 Crow 在有光照的环境中不会被突袭。

由于智力较高，它们有 10% 的概率攻击对手的眼睛；每次命中检定成功时，再有 1/10 的概率发动眼部攻击，导致器官丧失。

Raven 和 Crow 有自己的有限语言。某些 Raven，包括一些 Huge 和多数 Giant 个体，能说最多 100 个通用语词汇，并用有意义的短语交流。Huge Raven 倾向于恶毒，若有机会会为邪恶主人服务。

所有这类鸟都喜欢闪闪发光的物品，因此有 25% 的概率在巢中拥有若干小金属物品、宝石等。Giant Raven 好斗且容易训练（若从幼鸟养起），常被用作守卫和信使。它们的巢中可能有 Q 类财宝（每个巢穴有 1/6 的概率，宝石基础价值 10 金币）。
