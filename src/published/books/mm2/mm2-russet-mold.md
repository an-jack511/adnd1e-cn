## Russet Mold

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 片 |
| 护甲等级 | 9 |
| 移动 | 0" |
| 生命骰 | 每 10 平方英尺 12–16 生命值 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 0 |
| 每次攻击伤害 | 0 |
| 特殊攻击 | 孢子 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |

Russet Mold 只生长在地下潮湿地区。距离超过 30 英尺时，它常被误认为铁锈（概率 70%）。它免疫所有涉及武器、火焰和寒冷的攻击，但容易受到酒精、酸和对植物有害的化合物（例如盐）的作用。对它施展治病术或持续光亮术，可以立即杀死它。

Russet Mold 不进行物理攻击，但会在 3 英尺半径内释放几乎不可见的孢子云；超过这个范围，孢子会落到地面并失去作用。如果接触霉菌，它也会注入孢子。任何经过 3 英尺内或接触它的生物都会受到 5–20 点毒性伤害，并必须进行对抗毒素的豁免。豁免失败会患病，并在 2–5 轮内死亡，除非施展治病术。

任何因接触 Russet Mold 而死亡的角色都会发生变形。身体首先会从接触处残留的孢子长出新的霉菌；完全被霉菌包住后，一个 Vegepygmy 会从遗体中站起。整个过程需要 21–24 小时（1d4+20）。植物定身术会在法术持续期间停止霉菌生长；如果霉菌生长超过 1 小时，除非使用祈愿术，否则受害者无法恢复。

Russet Mold 的颜色从金棕色到锈红色不等，质地像冷粥，表面覆盖短小的毛发状突起。这些突起直立着，不停摇摆，仿佛处于微风中。
