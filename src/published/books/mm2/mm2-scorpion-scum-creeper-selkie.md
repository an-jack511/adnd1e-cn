## Scorpion（蝎子）

| 类型 | 出现频率 | 数量 | AC | 移动 | 生命骰 | 攻击 | 伤害 | XP |
|---|---|---:|---:|---:|---:|---:|---|---|
| Large | 常见 | 1–6 | 5 | 9" | 2+2 | 3 | 1–4／1–4／1 | II／90 + 3/生命值 |
| Huge | 不常见 | 1–4 | 4 | 12" | 4+4 | 3 | 1–8／1–8／1–3 | IV／165 + 5/生命值 |

两种 Scorpion 都会以钳子和尾刺攻击，魔法抗性标准、智力非智能、阵营中立、灵能能力无。尾刺击中时，受害者必须对抗毒素豁免，否则立即死亡；Large Scorpion 的毒较弱，豁免获得 +2。

它们经常出现在地下城和荒野中，只是 Giant Scorpion 的较小版本。

## Scum Creeper（污垢爬兽）

| 财宝类型 | 无 |

Scum Creeper 是小型蛞蝓状生物，生活在地下或阴暗沼泽。它们以植物和小嘴能够吞下的任何东西为食，包括腐烂的布、木材和肉体。无数细小带钩的脚和带吸力的腹部节片使其能够在墙壁和天花板上自由移动。

它的小型吸盘嘴拥有锋利的角质剪切板。攻击最初是试图附着到猎物；命中表示已经固定在猎物某处，20 次中有 1 次会附着到脸部，使受害者失明，直到怪物被移除。

此后每轮 Scum Creeper 自动造成 1 点伤害，持续到怪物死亡或受害者死亡。把岩盐擦在它柔软的身体上，会使其在 1–4 轮内每轮受到 2 点伤害；在之前的盐效果结束前，额外涂盐不会生效。

Scum Creeper 身体肥厚、黏滑而灰色，头部和腹部淡黄、病态白。它只有退化的眼睛，感知器官聚集在头部的纤毛上，嘴在头部下方。

## Selkie（海豹人）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 或 12–30 |
| 护甲等级 | 5 |
| 移动 | 12"／36" |
| 生命骰 | 3+3 |
| 巢穴内百分比 | 0% 或 90% |
| 财宝类型 | A；魔法物品，R |
| 攻击次数 | 1 |
| 每次攻击伤害 | 依武器类型或 1–6 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 平均至超凡 |
| 阵营 | 中立善良 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | IV／75 + 4/生命值 |

Selkie 是类似海豹的生物，可以变成人形数日，从而成为一种海豹人。它们通常变成人形，前往人类社区，与人类交换或购买群体需要的补给和物品。

Selkie 生活在海洋和寒冷温带至亚北极地区，巢穴是同时拥有空气区和水区的大型洞穴或岩洞，因为幼年 Selkie 在长到半大（约 1 岁）前必须呼吸空气。

Selkie 是杂食者，会吃鱼、贝类、甲壳类和各种海藻，也能吃人类食物，尤其喜欢葡萄酒。人形 Selkie 会携带武器，但海豹形态不能携带武器且游泳迅速；因此，水下遇到的 Selkie 有 90% 的概率没有武器，通常会用咬击攻击。若有武器，它会在必要时使用，尤其是保卫家园。

Selkie 社群由雄性和雌性组成，通常雌性略多，但两性地位平等。首领是一名年老 Selkie，能够使用占卜术、治疗轻伤、治愈疾病、召唤天气和控制天气。前三种每天每种 1 次、每轮一次；天气法术每次使用后需要休息 1 周，只在为精确复仇的极端需要时使用。

Selkie 社群的财宝来自沉船和海洋生物，因此可能拥有大量珍珠；货币财宝主要用于贸易。魔法财宝也从沉船中取得，用来援助和保护社群。

人形 Selkie 非常迷人俊美，眼睛尤其明亮。真形几乎无法与海豹区别，但仔细观察会发现它拥有带轻微蹼的手臂和手，而不是前鳍，也拥有腿而不是逐渐收窄的身体和后鳍。
