## Shadow Dragon

| 出现数量 | 1（75%）；2（25%） |
| 护甲等级 | -2 |
| 移动 | 18"/24"（MC：E） |
| 生命骰 | 4–6（每骰 +1） |
| 巢穴内百分比 | 40% |
| 财宝类型 | 见下文 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 2–5/2–5/3–12 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 20% |
| 智力 | 非常高至天才 |
| 阵营 | 中立邪恶 |
| 体型 | L（20–30 英尺长） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 说话概率 | 100% |
| 魔法使用概率 | 见下文 |
| 睡眠概率 | 日间 50%，其他时间 5% |
| 等级/经验值 | IV／245 + 5/生命值 |

Shadow dragon 是夜行、地下生物，或者栖息在 Shadowland 一类的幽暗位面。该物种同样独立而孤僻。只有偶尔才会遇到一对配偶。雌性会在黑暗处产下一窝 5–8 枚蛋，第一枚孵化的幼龙会迅速吞食其余幼龙。Shadow dragon 无法忍受极热气候或北极环境，但在较凉爽的温带地区十分兴旺。

Shadow dragon 更喜欢步行而非飞行，因为它们是糟糕的飞行者，只能飞行几轮便会疲惫。Shadow dragon 的体型决定其生命骰。25% 为小型（全部为雌性），50% 为平均型，25% 为大型（全部为雄性）。年龄像所有龙一样决定每生命骰的点数，但 Shadow dragon 每骰总是额外获得 +1，因此极幼龙（刚孵化）每骰有 2 点，而远古个体每骰有 9 点。

Shadow dragon 在明亮光线下的视觉能力较差。在星光下，它们仍能正常视觉（至少达到人类日光标准的 100%）。它们拥有超视觉能力，以及极其出色的红外视觉（180 英尺）。

所有 Shadow dragon 都会说所有邪恶龙的语言，并根据智力额外掌握 1–4 种语言（智力 11–12：1 种语言；13–14：2 种，依此类推）。

智力为 17–18 的个体能够使用 3–4 环幻术师法术；从成年阶段起，每个法术等级有 2 个法术。因此，一条智力为 17 或 18 的成年 Shadow dragon 会有 2 个一环幻术师法术；一条智力为 18 的远古龙则会在一至四环各有 2 个法术。

正常情况下，爪击和撕咬攻击会紧接着吐息攻击。Shadow dragon 的吐息武器是一团长 40 英尺、宽 30 英尺、高 20 英尺的黑暗云团。这种有形的物质会使范围内的生物失明，即使它们拥有红外视觉也一样；它还会降低受害者的生命能量，使其在持续时间内只剩通常活力的 25%（等级或生命骰；若豁免成功则为 50%），持续轮数等于龙的年龄阶段数。由于暴露于这种黑暗，法术会永久丧失，直到以正常方式重新学习或恢复。当然，暴露不会对 Shadow dragon 造成任何影响。

所有 Shadow dragon 都能像 10 级盗贼一样藏入阴影。由于它们的本质和物质构成，只有魔法武器才能伤害它们。它们免疫所有类型的生命等级损失。Shadow dragon 不能被制服，也不能被出售。

Shadow dragon 的宝藏通常是 10–80 颗不透明、颜色深暗的宝石，其中偏爱黑色。它珍视与阴影和黑暗有关的物品，并会尝试摧毁处理火焰和／或光明的魔法。同样，它不会使用光明或火焰类法术。

Shadow dragon 看起来像由深浅不一的阴影构成的蠕虫状龙。蝙蝠般的翅膀半透明，身体大部分也一样。若有人试图发现 Shadow dragon，最容易先看到的是它那一双如凶猛灰色乳光池般的眼睛；但到那时通常已经太迟了。

| 出现数量 | 1–6 |
| 护甲等级 | 3 |
| 移动 | 1"/36"（悬停）（MC：B） |
| 生命骰 | 7（大型个体 8+1–8） |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 3–12（大型个体 4–16） |
| 特殊攻击 | 先攻检定 +2 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 按 16 级魔法使用者进行豁免 |
| 智力 | 低 |
| 阵营 | 中立 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／525 + 8/生命值 |

不同于它们的小型近亲，Giant Dragonfly 是会猎杀人类的危险掠食者。由于无畏的本性和贪婪的食欲，这些巨型昆虫不只猎食其他各种类似生物，也会捕食任何温血生物。Giant Dragonfly 分布于亚热带至温带地区。热带地区还存在更大的个体，其怪物数据列在括号中。由于速度极快，能够悬停并突然冲刺，Giant Dragonfly 的先攻检定获得 +2。

如果 Giant Dragonfly 获得先攻，它们就无法被手持武器有效攻击，且对它们的射击攻击受到 -4 惩罚。若未取得先攻，手持武器可以正常命中，但射击仍受到 -2 惩罚。

Giant Dragonfly 除了鲜艳闪亮的颜色和有价值的皮肤外，并不起眼。皮肤若以魔法妥善保存，每平方英尺可卖到 600 gp。它可用于服装和装饰。普通个体只能取得约 6 平方英尺的皮肤。

## Dragon Horse

| 项目 | 数值 |
|---|---|
| 出现频率 | 罕见 |
| 出现数量 | 1 或 2–3（15%） |
| 护甲等级 | 0 |
| 移动 | 24"/48"（MC：B） |
| 生命骰 | 8 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 1–8/1–8 |
| 特殊攻击 | 吐息、法术 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 25% |
| 智力 | 平均至非凡 |
| 阵营 | 中立善良 |
| 体型 | L（肩高 6 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VII／1275 + 10/生命值 |

这种居于天空的 Dragon Horse 是 ki-rin 的近亲。它们漫游在空中的广阔地域（主物质位面上空或空气元素位面），在其他地方遇到它们的概率很低（5%）。遇到 2 或 3 只的概率同样很低；若确实遇到，它们会是一匹公马、一匹母马和一匹幼马（成长 50%–75%；用 1d6 掷骰，结果为 4–6 时分别为 50%–75% 的成长）。自由漫游的 Dragon Horse 对财物或宝藏毫无兴趣。

它们以两次蹄击攻击。如果生物在飞行中攻击，或通过后足站立攻击，则每次伤害 +2（3–10/3–10）。除蹄击外，Dragon Horse 还能将吐息作为武器或防御手段。每轮一次，Dragon Horse 可以随意呼出 fog cloud、gust of wind 或 cone of cold；吐息的尺寸和效果有限（底面直径 1"、长度 2"，造成 4d8 点伤害）。其他吐息武器的使用按 8 级能力施展。

Dragon Horse 的感官异常敏锐，包括红外和超视觉能力，均为正常水平的三倍。因此，这些生物永远不会被突袭。它们的视觉能力包括侦测灵光，所以能够感知所遇生物的阵营。这种能力，加上初步的共情能力，使它们几乎不可能被邪恶生物欺骗或奴役。

Dragon Horse 能够穿越星界位面和以太位面，虽然除非偶然穿越以太位面、短暂停留于空气元素位面，否则并不以此闻名。它们会说 ki-rin 语言的一种初级形式，大量交流通过彼此的共情接收完成。

Dragon Horse 是极受追求的坐骑和战马，但很少有人能真正将其用于此事，因为这种生物必须愿意成为同伴和伙伴，而且任何 Dragon Horse 都不喜欢长时间受困于陆地。一匹受到爱护、谨慎抚养，并且经常被带入天空穹顶的幼马，或许会成为值得信赖的同伴和坐骑，前提是绝不能要求它被陆地束缚。由于成熟过程需要 20 年，这样抚养幼马的案例几乎无人知晓。邪恶的存在会使这些生物想要离开、前往别处。

Dragon Horse 看起来像没有角的 ki-rin。它们的毛色从淡天蓝到银蓝不等，鬃毛和尾巴为纯白至银色。蹄子则是深天蓝到靛蓝色。
