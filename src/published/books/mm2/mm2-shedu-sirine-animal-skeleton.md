|---|---|

| 移动 | 15"／30"（MC：B） |
| 生命骰 | 14+14 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 3–18／3–18 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |

| 阵营 | 守序善良 |

| 灵能能力 | 120–150 点；攻击/防御模式：全／全 |
| 等级/经验值 | IX／5250 + 20/生命值 |

Greater Shedu 是 Lesser Shedu 的亲密盟友，通常最仁慈地统治 6 只或更多普通 Shedu 的群体。它们偏好 Lammasu 和 Shedu 都喜欢的温暖干燥气候，但经常漫游主物质、星界和以太位面，寻找需要帮助的善良生物，援助它们并与邪恶战斗。

Greater Shedu 以强力的前蹄击打攻击，在 10 英尺半径内散发防护邪恶。它们可以随意进入以太形态和隐形。Greater Shedu 拥有 7 个次级和 4 个主级灵能学科，以 14 级掌握度使用。

常见次级学科为：听觉或视觉、侦测邪恶或侦测魔法、支配或催眠、分子搅动、物品阅读或心灵感应，以及预知。常见主级学科为：身体控制或能量控制、群体支配或心灵屏障、分子操纵或心灵遥控（3150 金币重量）、形体改变。

Greater Shedu 使用维度行走、概率旅行和无力量消耗的无误传送术。除守序善良、Lammasu、Shedu、通用语和根语外，它们还能说话，并能与大多数动物和怪物进行心灵感应，甚至能以初级方式与植物交流。

## Sirine

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有／极罕见 |
| 出现数量 | 1 或 2–8 |
| 护甲等级 | 3 或更好 |
| 移动 | 12"／24" |
| 生命骰 | 4–7 |
| 巢穴内百分比 | 30% |
| 财宝类型 | 个体 L、M、N、Q；巢穴 X |
| 攻击次数 | 1 |
| 每次攻击伤害 | 依武器类型 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 20% 或更高 |
| 智力 | 高至天才 |
| 阵营 | 任意（等概率）；见下文 |
| 体型 | M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／350 + 10/生命值 |

Sirine 是美丽的人形女性，在咸水和淡水之上或之下都能生活。它们通常独居，所有遭遇都发生在偏僻、无人居住的地方。由于种族的高敏捷和魔法本质，Sirine 的护甲等级为 3。它们通常携带小型短剑和匕首；30% 会有标枪（其中 40%）或投石索（其中 60%）。任何武器有 10% 的基础概率是 +7 魔法武器或闪电标枪，应逐件检查。

Sirine 拥有以下魔法能力：歌声（3" 范围内所有具有敌意的听者会被魅惑）、自身变形、云雾术和高等隐形。每项每天一次，一次只能使用 1 项。与 Sirine 近战接触的任何智能生物必须对抗毒素豁免，否则变成白痴（智力 = 2）。这种白痴状态可以由 Sirine 随意移除，但需要 Sirine 接触；否则可以用驱散魔法恢复智力。Sirine 免疫所有形式的气体。

所有豁免按 11 级魔法使用者计算，对毒素的豁免另获 +2。若遇到超过 1 只（概率 30%），它们总在 Sirine 的家园地区。单只 Sirine 总是 6 或 7 生命骰。若遇到 2–8 只，至少有 1 只为 6 或 7 生命骰，其余以相等概率为 4、5、6 或 7 生命骰。

Sirine 群体在善良、邪恶和绝对中立方面的阵营总是相同；例如，邪恶 Sirine 群体中可以同时有守序、 中立和混沌成员。Sirine 同样能呼吸空气和水，拥有红外和红外以上视觉，会说自己的语言和通用语。

## Skeleton、Animal（动物骷髅）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 2–20 |
| 护甲等级 | 8 |
| 移动 | 6" |
| 生命骰 | 1–1 |
| 巢穴内百分比 | 85% |
| 财宝类型 | 见下文 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 1–4 |
| 特殊攻击 | 无 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 非智能 |
| 阵营 | 中立 |
| 体型 | S 至 M |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | II／10 + 1/生命值 |

Animal Skeleton 是用死者复生术把小型脊椎动物的骨骼活化而成。每个施法者等级能制造 1–1/2 个动物骷髅。它们通常被创造出来充当低级守卫，因此附近通常没有财宝，顶多有过去遭遇偶然留下的物品。

常见动物骷髅从家猫大小到大型犬大小不等；法术不能活化比人类更大的动物。

Animal Skeleton 没有特殊攻击。它们免疫魅惑、寒冷、死亡魔法、定身和睡眠。钝器造成正常伤害，锐器只造成一半正常伤害。它们像普通骷髅一样被驱散，但牧师获得 +1 优势；掷出 1d6+6 会被驱散或摧毁。
