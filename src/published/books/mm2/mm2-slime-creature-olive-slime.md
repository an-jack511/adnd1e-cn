Slime Creature 是 Olive Slime 的变形宿主。形成的新植物生物与 Olive Slime 进行共生连接。无论宿主原先是什么、总体形态如何，Slime Creature 只有小型、中型或大型三种，因此生命骰和伤害可变。

Slime Creature 会聚集起来，互相协助进食和防御；只有近距离仔细观察才能辨认。它们的栖息地从人口稠密的地下区域到潮湿森林、沼泽等地不等。攻击时，命中有 10% 的概率使对手感染 Olive Slime。

Slime Creature 会受到酸、严寒、火焰（仅水生个体受到魔法火焰影响）和魔法飞弹伤害。影响植物的魔法也能影响它们。其他所有攻击形式都无效。

它们的植物智力属于动物水平，但狡猾使其能够从经验中学习，也能利用狡猾设置陷阱。Slime Creature 能与同类进行有限心灵感应，范围最多 20"。

## Slime、Olive（橄榄黏液）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 9 |
| 移动 | 无 |
| 生命骰 | 2+2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 0 |
| 每次攻击伤害 | 无 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 非智能和特殊 |
| 阵营 | 中立 |
| 体型 | S |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／330 + 3/生命值 |

Olive Slime 是类似 Green Slime 的怪异植物，但在大多数方面接触更危险。它偏好地下生长区，以动物、植物和金属物质为食。经过生物的震动足以使其释放触手并掉落。

接触 Olive Slime 会使它分泌麻痹毒素。受害者必须对抗毒素豁免，否则不会察觉 Olive Slime 已经附着。附近其他人有 50% 的概率发现附着物；全组只检查一次，不逐人检查，魔法不提供调整。

随后它会覆盖受害者身体，并伸出寄生触手吸取宿主液体；人类通常附着在脊柱区域。宿主会受到 Olive Slime 分泌物影响，心智逐渐只关心进食、保护和促进其生长。食物摄入必须翻倍，否则宿主身体会消瘦，每天失去 10% 的生命值。

7–12 天后，宿主开始变形成植物生物。Olive Slime 逐渐取代皮肤和肌肉组织，并形成共生的大脑附着物。新生物不再关心原来的形态或同伴，成为更接近植物的新物种。它可以通过光合作用、寄生或两者进食。死亡后，生物会生成一块新的 Olive Slime。

Olive Slime 只能被酸、严寒、火焰或治病术伤害。影响植物的魔法也对它有效，其他攻击（包括法术）不能伤害它。Green Slime 和 Olive Slime 会互相攻击并中和。关于 Olive Slime 造成的变形生物，参见“Slime Creature”。
