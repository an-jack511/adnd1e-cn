## Spriggan

| 项目 | 小型形态 | 巨型形态 |
|---|---:|---:|
| 出现频率 | 极罕见 | 极罕见 |
| 出现数量 | 3–12 | 3–12 |
| 护甲等级 | 3 | 5 |
| 移动 | 9" | 15" |
| 生命骰 | 4 | 8+4 |
| 巢穴内百分比 | 30% | 30% |
| 财宝类型 | A | A |
| 攻击次数 | 2 | 2 |
| 每次攻击伤害 | 依武器 | 2–8／2–8 |
| 特殊攻击 | 法术、盗贼能力 | 无 |
| 特殊防御 | 见下文 | 见下文 |
| 魔法抗性 | 标准 | 标准 |
| 智力 | 平均 | 平均 |
| 阵营 | 混沌（邪恶） | 混沌（邪恶） |
| 体型 | S（高 3 英尺） | L（高 12 英尺） |
| 等级/经验值 | VI／1000 + 10/生命值 | VI／1000 + 10/生命值 |

这些丑陋阴郁的生物是 Gnome 的近亲，生活在偏僻社区附近或无人地区，巢穴是洞穴或废墟。它们会变成巨型体形，以恐吓、抢劫和进行其他卑劣行为。它们只比憎恨人类更憎恨 Gnome，只与同类来往。

Spriggan 可以随意使用以下类法术，一次 1 项、每轮一次：影响普通火焰、变成巨人、恐惧（因丑陋使豁免受到 -2）、粉碎术。巨型形态不能施放其他魔法，但可以随意恢复小型形态。

小型 Spriggan 拥有 8 级 Gnome 盗贼的全部能力，敏捷 18：扒窃 75%、开锁 78%、寻找／解除陷阱 70%、静默移动 77%、隐藏在阴影中 64%、听声 35%、攀墙 81%、阅读语言 40%。背刺造成三倍匕首伤害，只能在小型形态使用。

小型形态的 Spriggan 基本上是盗贼，巨型形态则是巨型强盗。如果有利于它们的邪恶目的，一个群体完全可能混有不同大小的个体。

## Squealer（尖叫兽）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1（或 2–4） |
| 护甲等级 | 6 |
| 移动 | 12"／9" |
| 生命骰 | 12 |
| 巢穴内百分比 | 16% |
| 财宝类型 | 见下文 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 7–12／1–3／1–3 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 伪装 |
| 魔法抗性 | 标准 |
| 智力 | 半智能 |
| 阵营 | 中立 |
| 体型 | L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／3000 + 16/生命值 |

Squealer 只生活在温带至热带森林，通常独居；遭遇交配对（并且最多带 2 只幼体）的概率为 10%。幼体每个生命骰有 1–2 点生命值，只能咬击，造成 1–4 点伤害。

Squealer 不在意财宝，但大多数猎物会被拖回巢穴附近吞食，因此那里可能有有价值的物品。Squealer 能完美模仿许多声音，会模仿其他生物的求救声、死亡尖叫、求偶声等吸引猎物。它们是贪食野兽，会攻击其他肉食动物或食草动物。

典型的 Squealer 会蹲在低矮树枝上，猎物接近时用 3 条肢体抓住树枝，头朝下摆荡并撕咬猎物。若 2 次爪击都成功，它会抓住并固定猎物，下一轮扑下，造成 5–8 点挤压伤害，并追加 2 次爪击。完整攻击顺序为：咬、爪、爪、爪、爪（7–12／1–3×4）。Squealer 拥有 18/00 力量，体重至少 400 磅。

置身树叶中时，Squealer 的体量因颜色、静止和谨慎隐藏而有 75% 的概率不可见。若发动突袭，每次攻击命中和伤害都获得 +2。它有 50% 的概率突袭猎物，极其凶猛；成年个体约有大型 Gorilla 大小，几乎不惧任何对手。

Squealer 的毛发很长，黄绿斑驳相间。身体上方是驼肩和前伸的猪样头部；头约 2 英尺长，主要是塞满尖牙的大嘴。手臂状前肢从驼背伸出，后肢从臀部高处伸出；前肢近 4 英尺长，后肢 3 英尺长。背部中央还有第 5 条肢体，长 4 英尺，可向前或向后弯曲。所有肢体末端都有 3 个带爪趾，前肢和背部肢体的趾头具有抓握能力。
