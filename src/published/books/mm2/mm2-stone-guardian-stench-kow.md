## Stone Guardian（石卫士）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1–4 |
| 护甲等级 | 2 |
| 移动 | 10" |
| 生命骰 | 4+4 |
| 巢穴内百分比 | 100% |
| 财宝类型 | 见下文 |
| 攻击次数 | 2 |
| 每次攻击伤害 | 2–9／2–8 |
| 特殊攻击 | 无 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 见下文 |
| 智力 | 非智能 |
| 阵营 | 中立 |
| 体型 | 75% M、25% L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／550 + 8/生命值 |

Stone Guardian 是一种特殊的魔像状人形。它通过附魔物品、泥化石术、魔法口、侦测隐形，以及有限祈愿术或祈愿术制造，方法类似魔像或奇物雕像。

制造者用泥塑造一个人类至食人魔大小的生物形体（太小或太大都不行），为它装入一颗石心。石心必须先施展附魔物品，随后把泥变成石头并施展祈愿术。魔法口是必须的，以便在精确条件下启动它；不过每次启动有 20% 的概率忽略精确指令，随后攻击任何东西。

制造时可以同时制作一枚专门的防护石卫士戒指。戒指佩戴者及其 10 英尺内所有人免疫该卫士的攻击；戒指只对制造它时制作的 Stone Guardian 有效，对其他卫士无效。

Stone Guardian 只受到锐器四分之一伤害，普通飞射物完全不能伤害它；寒冷、火焰和电击法术只造成一半伤害。它免疫毒素、定身、魅惑、麻痹和恐惧，因为没有心智，也没有活体。

它会一直攻击直到被摧毁。石化为肉、泥化石、塑石术或挖掘术能立即杀死它，不允许豁免。Stone Guardian 能通过祈愿术获得视觉和听觉，但只有制造时使用了侦测隐形术，它才能侦测隐形。

## Stench Kow（恶臭牛）

| 项目 | 数值 |
|---|---|
| 出现频率 | 常见（仅地狱） |
| 出现数量 | 15–60 |
| 护甲等级 | 2 |
| 移动 | 15" |
| 生命骰 | 3+3 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 2–8 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | L（野牛大小） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | V／150 + 4/生命值 |

Stench Kow 是九层地狱的牛，漫游于恶臭平原、火焰原野甚至下层地狱的冰冷荒地。有些远至 Acheron、Gehenna，甚至 Hades 都能见到。它们像普通畜群一样组成大群，以邪恶土地上有毒恶臭的植物为食。

一群中有 5–30 只幼体，但幼体没有攻击形式。每遇到 5 只，就有 1 只公牛；公牛每个生命骰至少有 6 点生命值，伤害不会低于 5 点，按 6 生命骰怪物计算。

如果 Stench Kow 冲锋命中，伤害翻倍（公牛至少 10 点），并追加一次践踏命中检定；成功则造成 2–12 点伤害。冲锋至少需要移动 1"，通常只有公牛冲锋，除非畜群被逼入绝境。

Stench Kow 免疫所有形式（包括魔法）的寒冷、火焰、毒素和毒气。近距离内，它们呼吸和身体的恶臭极其强烈；生物必须对抗毒素豁免，否则受到如同臭云术的效果。未受影响者每暴露 3 轮必须重新检查。

Stench Kow 像巨大、畸形的野牛。公牛肩膀上有巨大驼峰，母牛驼峰较小；角长而向下弯曲；头部巨大，五官粗短，圆眼大，舌头下垂。颜色暗橙，鬃毛绿色而纠结。
