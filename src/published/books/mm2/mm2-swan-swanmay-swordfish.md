## Swan（天鹅）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1 或 2–16（25%／75%） |
| 护甲等级 | 7 |
| 移动 | 3"／18"（MC：D） |
| 生命骰 | 1+2 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 3 |
| 每次攻击伤害 | 1／1／1–2 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 只有 1/10 的概率被突袭 |
| 魔法抗性 | 标准 |
| 智力 | 动物以上 |
| 阵营 | 中立 |
| 体型 | M（翼展 8 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | I／无 |

Swan 是水鸟，生活在类似水禽聚集的河流、池塘、湖泊和沼泽。单独出现的天鹅必定是雄性，单独遇到一只的概率为 25%；其他遭遇是雄雌配对，以及每对 1–2 只已长成但仍未成熟的幼鸟。

当领地被侵犯或受到实际攻击时，雄雌都会视情况积极威胁或攻击。它们用飞跃、强力喙击和双翼拍击攻击；这种攻击有 50% 的概率使对手失明并迷失方向，导致该轮无法反击。Swan 的感官极佳，90% 的概率注意到接近的危险。

如果有蛋，巢中会有 1–3 枚；没有蛋或幼鸟时，天鹅会在严重危险下游泳或飞走。

## Swanmay（天鹅女）

| 项目 | 数值 |
|---|---|
| 出现频率 | 极罕见 |
| 出现数量 | 1 或 2–5 |
| 护甲等级 | 7 |
| 移动 | 3" 或 15"／18"（MC：D） |
| 生命骰 | 2 或更高 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 见下文 |
| 攻击次数 | 如 Swan 或人形 |
| 每次攻击伤害 | 如 Swan 或依武器 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 每个生命骰 2% |
| 智力 | 高至天才 |
| 阵营 | 如游侠 |
| 体型 | M |
| 灵能能力 | 不太可能；攻击/防御模式：见下文 |
| 等级/经验值 | 可变 |

Swanmay 是拥有魔法力量、能变成天鹅的人类女性。力量来自一件物品的魔法；从未有男性成功获得并使用过这种物品。变身能力通常储存在羽毛信物或羽饰服装中（变成天鹅后成为羽毛的一部分），也可能储存在印戒中（变成天鹅腿上的环）。

天鹅形态的 Swanmay 只有 +7 或更好的魔法武器才能伤害，并拥有每个生命骰 2% 的魔法抗性。人形时，所有 Swanmay 都是游侠，拥有该战士子职业的全部特征和能力。

用 2d6 决定等级，结果代表 1–11（12）级：掷出 3 表示 2 级，掷出 4 表示 3 级，依此类推。虽然是游侠，Swanmay 主要亲近孤独、自然和自己选择的同类；可能帮助需要帮助的善良者，但会避开人类社会和文明，更厌恶地下区域。她们不吸引追随者，也可以像普通人类一样拥有灵能。

遭遇时，Swanmay 会把轻甲和装备、弓箭、剑和匕首仔细藏在附近。这些物品通常不是魔法物品。Swanmay 通常与森林小民（如 Sylvan Elf、Dryad 等）友好，厌恶喧闹鲁莽的生物、凶猛野兽和一切邪恶。只有 Druid 会定期与她们交往，通常是为了帮助她们对抗某种邪恶。

## Swordfish（剑鱼）

| 项目 | 数值 |
|---|---|
| 出现频率 | 不常见 |
| 出现数量 | 1–8 |
| 护甲等级 | 6 |
| 移动 | 无／24" |
| 生命骰 | 1+1、2+2 或 3+3 |
| 巢穴内百分比 | 无 |
| 财宝类型 | 无 |
| 攻击次数 | 1 |
| 每次攻击伤害 | 2–12、3–12 或 4–16 |
| 特殊攻击 | 无 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | M 至 L |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | I／35 + 3/生命值 |

Swordfish 是咸水中常见的强壮鱼类。它们速度快，通常没有攻击性，会逃跑而不是战斗。但被攻击、激怒、控制或训练时，会用长而骨质的“剑”作为可怕武器。较小的剑鱼通常被水生精灵和海豚群落当作宠物和守卫。
