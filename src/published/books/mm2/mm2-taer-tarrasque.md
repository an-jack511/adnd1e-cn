Taer 看起来像白发、油腻、蓬乱的穴居人，可能确实是人类的某个亲族。发色从灰色到雪白，头很大但几乎没有额头。

这个邪恶种族生活在最寒冷的山区，居住在洞穴中，不断寻找食物。普通攻击是踢、拳和咬；其中 50% 的个体拥有粗制长矛，会在接近近战前投掷，命中 +1、伤害 +3。

Taer 会分泌脂肪物质，散发特别恶臭。10 英尺内任何生物必须进行对抗吐息武器的豁免；失败者迷失方向并恶心 2–5 小时，攻击命中受到 -2、伤害受到 -1。分泌物还能帮助它们抵抗寒冷，包括魔法寒冷。

Taer 的财宝通常是抛光牙齿、角和粗刻石像。财宝来自人类受害者的概率为 15%；若有财宝，其中包含 1 件魔法物品的概率为 10%，尤其可能是武器。

## Tarrasque

| 项目 | 数值 |
|---|---|
| 出现频率 | 独一无二 |
| 出现数量 | 1 |
| 护甲等级 | -3 |
| 移动 | 9"（冲刺 +6"） |
| 生命值 | 300 |
| 巢穴内百分比 | 见下文 |
| 财宝类型 | 见下文 |
| 攻击次数 | 6 |
| 每次攻击伤害 | 1–12／1–2／2–24／5–50／1–10／1–10 |
| 特殊攻击 | 锋锐咬击、恐怖 |
| 特殊防御 | 见下文 |
| 魔法抗性 | 标准 |
| 智力 | 动物 |
| 阵营 | 中立 |
| 体型 | L（长 50 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | X／37500 |

传说中的 Tarrasque 可能是最可怕的怪物；活动时会蹂躏数英里乡野。所有植物和动物生命都会被吞食或驱逐。它经过的土地会变成荒地，需要多年才能恢复。Tarrasque 贪婪且不停进食，所有活物都是食物，不过偏爱温血生物。

普通攻击是 2 只前肢爪、横扫尾击、凶猛咬击和 2 次角刺。咬击如同锋锐剑：命中骰掷出 18 或更高时，会切断受害者的一部分（肢体、头、躯干等）。Tarrasque 每轮只能冲刺一次，因为它体型巨大而笨重。

仅仅看见 Tarrasque 就极其恐怖：3 级或更低等级／生命骰的生物会麻痹，直到离开视线，不允许豁免。3 级／生命骰以上者会惊慌逃跑；7 级／生命骰以上者若成功通过麻痹豁免则不受影响。

Tarrasque 的甲壳异常坚硬且有反射性。闪电箭、寒冷锥甚至魔法飞弹等射线和箭矢对它无效；其中 1/6 会直接反射回施法者，其余无害弹开。任何火焰都无效。它每轮再生 1 点生命值。

只有 +7 或更好的魔法武器才能命中。传说只有把它降低到 -30 或更少生命值，再使用祈愿术要求其死亡，才能杀死 Tarrasque；否则哪怕最小碎片也会完全再生。

传说可以从 Tarrasque 甲壳中提取巨大财宝：上半部分经酸处理并在熔炉中加热，会得到 10–100 颗基础价值 1000 金币的钻石；下腹材料与血液和陨铁混合后，可由矮人工匠锻造成 1–4 面 +5 魔法盾牌。

Tarrasque 只在短时间内活动。通常它会出来觅食 1–2 周，蹂躏除少数平方英里外的所有土地；随后寻找地下隐蔽巢穴，沉睡 5–20 个月。每十年左右会特别活跃，外出数月；之后除非受扰，休眠期会变为 4–16 年。活动与休眠比例约为 1:30。
