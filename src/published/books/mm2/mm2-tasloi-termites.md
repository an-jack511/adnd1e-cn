## Tasloi

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1–6 |
| 护甲等级 | 5（持盾） |
| 移动 | 9"（树上 15"） |
| 生命骰 | 1 |
| 巢穴内百分比 | 30% |
| 财宝类型 | Q（×5） |
| 攻击次数 | 2 或 1 |
| 每次攻击伤害 | 1–3／1–3，或依武器 |
| 特殊攻击 | 1–4 突袭 |
| 特殊防御 | 无 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 中立 |
| 体型 | S（2–3 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | I／10 + 1/生命值 |

Tasloi 生活在湿热的热带森林中，很少被人类看到。它们害羞而恶意，喜欢从树上伏击弱小、粗心的目标。适应地面以上生活的 Tasloi 在地面上缓慢笨拙，只能采取半直立姿态；但在树上通道中敏捷迅速。

它们精通隐蔽，掷 1d6 得 1–4 即突袭，也有 75% 的概率隐藏在阴影中。它们有红外视觉，适合黑暗丛林；完全日光下命中检定受到 -1。

Tasloi 什么都吃，尤其喜欢人类和精灵等各种肉。它们通常从上方攻击，尽量捕获目标；若成功突袭，会使用网。如果队伍警惕或有所准备，Tasloi 会以短促、突然的袭击和撤退逐渐消耗对手；若可能，还会在战斗后偷走敌人的尸体。

Tasloi 以由数个家庭组成的松散部族生活。每 70 名以上有 1 名首领（5 生命骰），部族有 30% 的概率有萨满，萨满最高可升至 5 级。武器组合为：小盾和标枪 20%；棍棒和标枪 40%；短剑和小盾 10%；标枪和网 15%；短剑和网 10%；标枪和套索 5%。使用盾牌时，护甲等级为 5。穿越树木时，标枪和盾牌通常背在身后。

巢穴中除了雄性外，有 70% 的雌性和 50% 的幼体。幼体完全不战斗。巢穴由 1–6 棵大树组成，树上有 4–24 座离地 50–100 英尺的平台，树之间以藤蔓和绳索相连。有 60% 的概率拥有 1–6 只训练过的巨型蜘蛛，20% 的概率拥有 2–8 只训练过的巨型黄蜂；据说 Tasloi 能骑黄蜂远行。

Tasloi 会说自己的语言，也会说猴类和猿类语言；约 5% 的个体学会用于交易的混合通用语。它们是长腿、扁头的类人生物，弯腰行走，偶尔用指关节触地；皮肤有光泽的绿色，稀疏覆盖粗黑毛；眼睛像猫，呈金色；脚长而有抓握能力，夜间能听见它们高而轻的耳语。

## Termite、Giant Harvester（巨型收割白蚁）

| 类型 | 出现频率 | 数量 | AC（头／身） | 移动 | HD | 攻击伤害 |
|---|---|---:|---|---:|---:|---:|
| Worker | 见下文 | 6–60 | 2／10 | 9" | 1½ | 1–2 |
| Soldier | 见下文 | 3–18 | 2／8 | 9" | 2½ | 1–4 |

两种白蚁都生活在亚热带和热带森林、丛林中，要求有大量植被。巢穴是直径约 100 英尺、高 200–500 英尺、硬如石头的土丘。顶部有许多直径 5–8 英尺的圆形开口，通向地下的垂直、斜向和水平通道及各个房间。

白蚁夜行并躲避光线。超过 30 只 Worker 的群体总有 3–16 只 Soldier 陪同。Soldier 的强颚会咬击，并喷出类似煤油的刺激性液体；被击中的生物若对抗毒素豁免失败会失明 5–20 轮。液体接触火焰或高热会燃烧；吐在目标上并点燃会造成 5–16 点火焰伤害，每轮只能喷吐一次，射程 1"，体积约 1 品脱。

巢穴中总有首次遭遇数量 10 倍的 Worker 和 Soldier，分散在巢穴各处。此外还有：产卵室 5–30 名工人／侍从与 2–12 名士兵／卫兵；王室 4–24 名工人／侍从与 2–8 名士兵／卫兵；1 名国王（AC5，移动 8"，6+6 HD，至少 30 生命值，攻击 +1，伤害 3–18，液体喷吐射程和数量翻倍，可每隔一轮使用，体型 L）；1 名王后（AC4，移动 3"，8+8 HD，至少 40 生命值，攻击 +1，伤害 5–30，体型 L）。

国王和王后只会在地下巢穴底部附近的王室，产卵室就在附近。卵的数量等于 Worker 与 Soldier 总数。入侵者进入产卵室或王室时，所有普通白蚁（不包括特别侍从和卫兵）会移动到被入侵处；已经在场者会拼死保护房间。所有这些工人和卫兵命中、伤害都获得 +1，后来进入者也一样。

王室附近有一条通往储藏井的竖井，用来倾倒无法使用的金属和矿物物品，可能有少量零星财宝。Giant Termite 最大的敌人是 Formian；Formian 更大、更聪明，憎恨白蚁，喜欢吃它们的卵。白蚁发现袭击者后会立即防卫巢穴；平时通过触碰触角交流，危机时发出群体心灵感应呼叫。
