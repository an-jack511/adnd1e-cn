## Thessalhydra

|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 1 |
| 护甲等级 | 0 |
| 移动 | 12" |
| 生命骰 | 身体 12 |
| 巢穴内百分比 | 50% |
| 财宝类型 | 见下文 |
| 攻击次数 | 最多 10 |

| 特殊攻击 | 酸性唾液、喷吐 |
| 特殊防御 | 免疫酸 |

Thessalhydra 喜欢阴暗潮湿环境，因此通常在沼泽、丛林和地下巢穴中出现。它的巨大主口周围环绕一圈蛇头；每次咬击造成 1–6 点伤害，除非受害者对抗毒素豁免成功，否则再受 1–6 点毒素伤害。主口咬击造成 1–20 点伤害，豁免失败时再受 1–20 点酸性伤害。尾部钳击可抓住对手，造成 1–12 点伤害，并在同一轮把受害者放进中央巨口。

每个边缘蛇头长约 6 英尺，因此许多生物都能在同一近战轮受到攻击。每个边缘头受到 12 点伤害才会被切断；切断头部不会伤害身体，Thessalhydra 会在 12 天内再生失去的头。

每天一次，Thessalhydra 可以从主口喷出一团酸性唾液，范围是距离 3" 内、直径 12 英尺的圆。范围内生物受到 12–72 点酸伤害，对抗毒素豁免成功则减半。任何酸，包括有毒酸，都不会影响 Thessalhydra。

放进中央巨口的物品通常会被毁坏；物品持有者每轮必须进行酸和挤压豁免，直到物品取出。

## Thri-kreen（螳螂战士）

| 项目 | 数值 |
|---|---|
| 出现频率 | 稀有 |
| 出现数量 | 2–12 |
| 护甲等级 | 5 |
| 移动 | 18" |
| 生命骰 | 6+3 |
| 巢穴内百分比 | 5% |
| 财宝类型 | Q |
| 攻击次数 | 5 或 3 |
| 每次攻击伤害 | 1–4（×4）／d4×1，或依武器 +2 |
| 特殊攻击 | 见下文 |
| 特殊防御 | 闪避飞射物 |
| 魔法抗性 | 标准 |
| 智力 | 低 |
| 阵营 | 混沌中立 |
| 体型 | M（6 英尺） |
| 灵能能力 | 无；攻击/防御模式：无/无 |
| 等级/经验值 | VI／350 + 9/生命值 |

Thri-kreen 是居住在沙漠和干燥草原的肉食昆虫人。他们生活在没有光线的小洞穴中，不是社会性生物。螳螂战士会捕猎各种生物，尤其喜欢精灵。

Thri-kreen 强壮敏捷，能向上跳 20 英尺、向前跳 50 英尺。他们经常使用 2 种自制特殊武器：一种是两端带刃的长柄武器，可像长刀一样砍击，也可像标枪投掷，伤害 2–8；另一种是坚硬晶质材料制成的小型三角“投掷楔”。楔子会返回投掷者身边，若未命中可接住再次投掷。

每个 Thri-kreen 最多携带 10 枚投掷楔，射程 9"，伤害 3–6。它们掷 1d20 结果为 9 或更高时，能成功闪避飞射物。

即使没有武器，Thri-kreen 也会用 4 条带爪、臂状附肢攻击，造成 1–4 点伤害，并用颚咬击，造成 2–5 点伤害。被咬中的生物必须对抗麻痹豁免，否则麻痹 2–16 轮。
