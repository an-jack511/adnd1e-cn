这种植物深绿色茎高 5–8 英尺，顶端是鲜橙、亮黄和强红色的喇叭形花。橙花从中心射出 2–8 条、每条 3 英尺的卷须；被击中的生物必须对抗花粉毒素豁免，否则昏睡。黄花会立刻向睡着的受害者弯下（根须能感知其位置）并颤动，洒下黏性酶，每轮造成 2–8 点伤害，直到受害者完全腐烂。受害者受伤的同一轮倒一瓶水可减 1 点伤害；完全浸水会除去树液。红花伸出 1 英尺管状卷须插入睡眠中的受害者，每回合吸取 1–6 点生命值，酶溶解身体后再吸食残余物。其他花色组合包括白、淡银灰、粉、金褐、巧克力褐和铁锈色。

## 海生巨魔 Troll, Marine

| 项目 | 淡水型 | 咸水型 |
|---|---:|---:|
| 出现频率 | 稀有 | 不常见 |

| 移动 | 3"/15" | 3"/12" |
| 生命骰 | 5+5 | 6+12 |
| 巢穴内 | 20% | 15% |
| 财宝类型 | C | D |
| 攻击 | 3 | 3 |
| 伤害 | 2–5/2–5/3–12 | 1–4/1–4/9–16 |
| 特殊攻击 | 见下文 | 见下文 |
| 特殊防御 | 再生 | 再生 |
| 魔法抗性 | 标准 | 标准 |
| 智力 | 半智至低 | 低至平均 |
| 阵营 | 混沌邪恶 | 混沌邪恶 |
| 体型 | M（7 英尺以上） | L（10 英尺） |
| 灵能能力 | 无；攻击／防御模式：无／无 | 无；攻击／防御模式：无／无 |
| 等级/经验值 | V/400 + 每生命值 8 | VI/900 + 每生命值 12 |

海生巨魔是普通巨魔的有鳃形态，居住在大型水体中，需要广阔空间捕猎，颜色从蓝绿到橄榄色。淡水海生巨魔比普通巨魔小，覆有厚鳞，爪不如普通巨魔强，但增大的下颚长满细而尖的獠牙；单个近战轮最多攻击 3 个不同对手。它们如巨魔一样再生，但只有浸在淡水中才会再生。

咸水海生巨魔至少与普通巨魔一样大，皮肤厚且鳞片重。10% 的个体足够聪明，会用贝壳、鲨鱼皮等制作护甲，使有效护甲等级为 1。前肢较短弱，但咸水型长出巨大口器和许多獠牙，弥补失去的爪攻击；它们只有在咸水环境中再生。

暮光花是有毒植物，又称紫色死亡。植株高 8–13 英尺，茎粗而无枝，顶部有蕨状叶；紫色杯形花向上，银色雄蕊在花中。植株基部的细苔状垫其实是根。花朵散发极具吸引力的香气和甜汁。生物经过杯状薰衣草色花朵下方时，震动会使花轻轻倾斜，从花中滴下糖浆状毒液；有 25% 机会击中生物。未能通过毒素豁免者立即死亡，分解后的身体滋养根部。
