## 黑柳 · Black Willow

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极稀有 |
| 出现数量 | 1 |
| 护甲等级 | 2 |
| 移动 | 1/4" |
| 生命骰 | 12–19 |
| 巢穴内 | 100% |
| 财宝 | 见下文 |
| 攻击 | 7–12（树干 30 英尺内） |
| 伤害 | 每次 1–4 |
| 特殊攻击/防御 | 见下文 |
| 智力 | 低至极高 |
| 阵营 | 中立邪恶 |
| 体型 | L（树干直径 6–9 英尺） |
| 等级/经验值 | VIII/2400 + 每生命值 20。 |

黑柳是有移动能力、具智慧且邪恶的树。它栖居普通柳树生长的区域，但只从日光、空气、水和土地得到部分营养；它是食肉者，尤其喜欢精灵、侏儒和人类。90% 的生物不会认出黑柳，因为它能改变树干和树枝，伪装成普通柳树：有时树干光滑、枝条宽阔而诱人；有时树干底部或高处出现看似安全的洞。树人能立即识破，德鲁伊也必须借助 <strong>寻觅植物</strong> 等魔法。

它有时在根下埋藏财宝、骨头和不能被弱酸消化的物质，前提是受害者本来携带财宝且黑柳已在当地停留数周。通常用鞭状枝条攻击。生物爬上看似安全的枝条时，黑柳会在半径 20 英尺内产生昏睡气场，疲惫者自然入睡且无豁免；枝下打开洞口，把受害者拖入空心枝，再滑入树干消化腔。树干入口会关闭困住受害者，胃部覆有黏性不可燃树液。消化液从根部上升，每 10 轮 1 英尺，填满 8 英尺腔体；酸液每轮造成 1–4 点伤害，直至死亡。被消化到 -12 或更低后不能复活。内部空间只能用短而尖的武器，正常伤害每轮最多 1 点；魔法和力量加值仍适用。黑柳每轮再生 1 点。

## 披着羊皮的狼 Wolf-in-Sheep's-Clothing

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极稀有 |
| 出现数量 | 1 |
| 护甲等级 | 根触须 3、树桩身体 5、眼柄 7 |
| 移动 | 1" |
| 生命骰 | 9（见下文） |
| 巢穴内 | 无 |
| 财宝 | 无 |
| 攻击 | 1–3 |
| 伤害 | 1–4，随后咬击 2–12 |
| 特殊攻击 | 见下文 |
| 智力 | 低 |
| 阵营 | 中立 |
| 体型 | 有效 S |
| 等级/经验值 | VI/900 + 每生命值 14。 |

这种奇异植物怪物潜伏在灌木或草地。它用 7 条根触须移动、觅食和捕捉活物，2–3 条眼柄提供宽广视野。树桩身体可承受 9 HD 伤害；附肢被折断或割下不会永久伤害它，1–4 周可再生。每根根触须须承受 19–22 hp，每根眼柄 13–16 hp。

它诱使猎物接近 12 英尺，再以 1–3 条根触须抓取；命中造成 1–4 点并缠住，下一轮拖到树桩口，除非猎物挣脱，否则再受 1–4 点并被咬 7–12 点。力量 13 以上才有机会挣脱；每点力量提供 5% 机会，18 点力量为 30%，再按例外力量增加，只有有例外力量者能折断根触须。它有 90% 机会伏击，用树桩或会长出小毛兽形状的诱饵吸引猎物。

化人狼能变成极有魅力的人类男女，秘密追猎并吞食人类、半身人、精灵等。它通常与普通狼（30%）或座狼（70%）成群活动；遇到强敌会逃回巢穴，换上人类衣物，以朝圣者、吟游诗人、修补匠等身份接近，常携带弦乐器。它能半变形，长出类人手脚并使用人类武器，仍可咬击。歌声令听者昏睡，如同 <strong>缓慢术</strong>，除非通过法术豁免；昏睡持续 5–8 轮且不能被抵消。化人狼与狼人有强烈仇恨，厌恶并躲避狼毒草。

它们是阴影位面的大型昆虫捕食者，森林区域更常见，寻找温血猎物却会犹豫攻击人类。头部强力颚部滴着高度腐蚀的酸；被颚击中的对手须以 -3 对抗毒素，否则咬击伤害加倍。头和前身覆硬刺；徒手、爪、咬、<strong>造成伤口</strong> 等攻击接触时，刺会刺入，造成 1–4 点伤害并要求毒素豁免，失败则麻痹；1–4 轮内须用 <strong>中和毒性</strong> 或 <strong>延缓毒发</strong>，否则接触致死。武器攻击者按其（不计盾牌和敏捷加值的）护甲等级×10 判定接触，头部再减 20%。切下的珍珠颚每套价值 1000–300
