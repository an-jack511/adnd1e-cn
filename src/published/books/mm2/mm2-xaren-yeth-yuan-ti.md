## 萨伦 · Xaren

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 1 |
| 移动 | 9" |
| 生命骰 | 5+5 |
| 巢穴内 | 70% |
| 攻击 | 4 |
| 伤害 | 1–3×3、4–16 |
| 特殊攻击 | 1–5 伏击 |
| 特殊防御 | 免疫火与寒冷 |
| 智力 | 平均 |
| 阵营 | 中立 |
| 体型 | M（4 英尺高） |
| 等级/经验值 | 55 + 每生命值 8（原表未列等级） |

萨伦是石鼎兽的亲族，来自土元素位面，也会到主物质位面进食，最喜欢铁、铜、银、金和电金。魔法金属物品的每一点魔法加值可使它永久增加 1 点生命值，但总生命值最多 45；它们因此渴求魔法金属。萨伦像石鼎兽一样与岩石环境融合，极易伏击；20 英尺可闻到矿石，40 英尺可闻到魔法金属。每餐 5–8 磅金属足够维持 1–4 天。

它们能说奇怪语言，心灵感应或 <strong>通晓语言</strong> 可帮助交流；会接近索取金属，闻到没有交给它的魔法金属时 80% 攻击，不给普通金属时 40% 攻击。火和寒冷无效，闪电造成半伤或无伤；<strong>移土术、化肉为石、挖掘术</strong> 可立即杀死，<strong>化石为泥</strong> 使 AC 变为 10，持续 1–4 轮；利刃半伤，钝器全伤。它可能咬魔法武器（将武器视为 AC -2），咬中会彻底摧毁武器，但持有者可作粉碎打击豁免。它可随意回土元素位面，以 9" 穿过固体岩石，调整分子需完整 1 轮。

主物质位面的萨伦常靠近矿脉或财宝。巢穴财宝概率为 40% 的 2–200 枚金币（每种硬币 2 枚，白金除外）、20% 的 1–8 颗宝石（基准 10 gp）、10% 的 1–2 件非金属魔法物品且价值低于 10,000 gp；70% 在岩石内约 10 英尺处。战斗失利会逃回巢穴，进入后再逃往土元素位面。

野吠兽只在最荒野偏僻之地出现，日光消退前躲在地下巢穴，出来猎食温血动物，尤其喜爱类人、棕精灵等。它们的可怖嚎叫可传一英里；9" 内生物须对抗法术豁免，否则恐慌逃跑，通常被群犬扑倒啃死。它们常与夜鬼婆、邪恶人类及其他邪恶猎手合作；会与其一同狩猎者不受嚎叫恐惧。外形是暗黑巨犬，头部近似人脸，耳朵像角，眼睛樱红发光。

## 蜡融妖 Yochlol

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 常见（深渊），其他处极稀有 |
| 出现数量 | 1–4（极稀有时 1） |
| 护甲等级 | -10 或 10 |
| 移动 | 12" |
| 生命骰 | 6（1d10） |
| 巢穴内 | 0 |
| 财宝 | 无 |
| 魔法抗性 | 50% |
| 智力 | 高 |
| 阵营 | 混沌邪恶 |
| 体型 | M |
| 灵能 | 133，C.D/F |
| 等级/经验值 | VII/1275 + 每生命值 10。 |

蜡融妖通常没有可辨形体，是雾状气柱，需要时形成拟肢；只有恶臭和空气中模糊污痕显示它的存在。若不采取实体形体，它的有效 AC 为 -10。气态时触摸效果等同 <strong>臭云术</strong>；必须实体化（AC 10）才能造成物理伤害。形体可以是八拟肢的无定柱体、巨蜘蛛，或美丽的人/精灵。人形时能像 6 级战士使用武器和灵能；蜘蛛形除 AC 10 和灵能外遵循巨蜘蛛；无定形以 8 条拟肢攻击，每击 5–8 点，力量等效 18/50。

气态时只有 +1 或更好的武器能命中；<strong>臭云术</strong> 反而治疗 3–12 点，<strong>造风术</strong> 造成 6–36 点伤害（除非被魔法抗性阻挡），<strong>风行术</strong> 可摧毁一个蜡融妖，牧师通常能带 2 人则可摧毁 2 个，但必须触碰目标。一个轮内可在气态、实体、蜘蛛和无定形之间改变。可能的灵能学科为细胞调整（只在人形）、支配、灵光改变、概率旅行。人形可同样使用牧师和战士能用的武器、魔法物品和护甲；穿护甲后，变为蜘蛛或无定形前必须先气化，否则护甲会伤害形体。

## 渊地蛇人 · Yuan-ti

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 4/0 |
| 移动 | 12" 或 9" |
| 生命骰 | 6–9 |
| 巢穴内 | 70% |
| 财宝 | C |
| 攻击 | 2 |
| 特殊攻击 | 法术 |
| 魔法抗性 | 20% |
| 智力 | 天才 |
| 阵营 | 混沌邪恶 |
| 体型 | M |
| 灵能 | 1560 |
| 等级/经验值 | 可变。 |

渊地蛇人居住热带丛林，是退化而腐化的昔日人类种族，崇拜恶魔并尊重各类爬虫；未知黑暗仪式污染了血液，令其产生怪物。分三类：纯血、混种和憎恶。

纯血 6 HD，外表人类但有鳞手、分叉舌或略显爬虫特征，80% 能冒充人类，通常处理对外事务并远行。混种身体某部分为蛇，可掷一次或两次或由 DM 选择：蛇头；躯干能像蛇弯曲；无腿、躯干末端为蛇尾；以蛇代替手臂；身体覆鳞；背部长蛇尾。蛇头咬 1–10，蛇臂咬 1–6，蛇尾缠绕 1–4；蛇部位 AC 0；混种 7–8 HD。憎恶 9 HD，外表常被误认作娜迦；全身蛇形或仅有一个人类特征（如头或臂），非人头咬击 1–10。

有人的腿者 MV 12"，蛇身者 MV 9"，能盘绕柱子。有人头的渊地蛇人每天各一次可施放：<strong>造成恐惧、黑暗术</strong>（半径 15 英尺）、<strong>魅惑蛇类、化杖为蛇、中和毒性、暗示术、变形他人</strong>。它们说自己的语言，也能与蛇或蛇状怪物交流；人头者还说混沌语和通用语。
