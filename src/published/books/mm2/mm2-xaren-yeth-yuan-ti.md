## 萨伦 · Xaren

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 极稀有 |
| 出现数量 | 1–4 |
| 护甲等级 | 1 |
| 移动 | 9" |
| 生命骰 | 5+5 |
| 巢穴内 | 70% |
| 攻击 | 4 |
| 伤害 | 1–3×3、4–16 |
| 特殊攻击 | 1–5 伏击 |
| 特殊防御 | 免疫火与寒冷 |
| 智力 | 平均 |
| 阵营 | 中立 |
| 体型 | M（4 英尺高） |
| 等级/经验值 | 55 + 每生命值 8（原表未列等级） |

萨伦是石鼎兽的亲族，来自土元素位面，也会到主物质位面进食，最喜欢铁、铜、银、金和电金。魔法金属物品的每一点魔法加值可使它永久增加 1 点生命值，但总生命值最多 45；它们因此渴求魔法金属。萨伦像石鼎兽一样与岩石环境融合，极易伏击；20 英尺可闻到矿石，40 英尺可闻到魔法金属。每餐 5–8 磅金属足够维持 1–4 天。

它们能说奇怪语言，心灵感应或 <strong>通晓语言</strong> 可帮助交流；会接近索取金属，闻到没有交给它的魔法金属时 80% 攻击，不给普通金属时 40% 攻击。火和寒冷无效，闪电造成半伤或无伤；<strong>移土术、化肉为石、挖掘术</strong> 可立即杀死，<strong>化石为泥</strong> 使护甲等级变为 10，持续 1–4 轮；利刃半伤，钝器全伤。它可能咬魔法武器（将武器视为护甲等级 −2），咬中会彻底摧毁武器，但持有者可作粉碎打击豁免。它可随意回土元素位面，以 9" 穿过固体岩石，调整分子需完整 1 轮。

主物质位面的萨伦常靠近矿脉或财宝。巢穴财宝概率为 40% 的 2–200 枚金币（每种硬币 2 枚，白金除外）、20% 的 1–8 颗宝石（基准 10 gp）、10% 的 1–2 件非金属魔法物品且价值低于 10,000 gp；70% 在岩石内约 10 英尺处。战斗失利会逃回巢穴，进入后再逃往土元素位面。
