朱朱僵尸 由魔法使用者用 <strong>能量吸取</strong> 抽尽人类或人形生物的全部生命等级创造。它像普通 Zombie 一样被“编程”，但各方面更强：护甲更好、移动更快，甚至可在水下活动而无需呼吸，能像 6 级盗贼攀爬，并以 6 HD 怪物的力量攻击。它能投掷武器，也能使用弓或弩。

由于部分存在于负能量位面，只能被 +1 或更好魔法武器命中；穿刺和钝击武器只造成半伤，斩击武器（斧、宽刃剑、双手剑、bardiche、halberd、voulge 等）造成正常伤害。免疫心智、幻觉、魅惑、束缚、毒、电、魔法飞弹、死亡和寒冷；火半伤，酸和圣水正常。牧师驱散时按 幽魂 对待。外表似普通 Zombie，但肉较少腐烂、灰色、革质且坚硬，眼中燃烧着憎恨生命的光。

怪物僵尸 是巨大类人生物怪物（如 熊地精、巨人等）的动画尸体，通常由邪恶牧师或魔法使用者创造和控制。它们能执行简单命令或短句指示。移动迟缓，在近战中最后攻击，并会战斗至毁灭；钝器只造成半伤。免疫魅惑、寒冷、死亡魔法、束缚和睡眠；牧师驱散时按 妖鬼 对待；圣水每瓶造成 2–8 点伤害。

佐博怪 以人类和类人生物肉为食。初遇时 AC 10，经过一轮即可吸收周围自然护甲：土 AC 7、木 AC 5、金属 AC 3、石 AC 0。新 AC 持续 10 轮，并获得等于 10 减新 AC 的伤害加值。它攻击对手时也能吸收对方护甲、盾牌、戒指或护符等魔法保护，使物品化为尘埃且无豁免；若新物品会使当前 AC 变差，则物品毁坏但不改变 佐博怪 的 AC。例如它先吸收石头成为 AC 0，再击中 +2 盾牌后成为 AC -2、伤害加值 +12，随后击中 AC 3 的板甲时板甲化尘，但 AC 与伤害不变。

## 接合菌 · Zygom

| 项目 | 数值 |
| --- | --- |
| 出现频率 | 稀有 |
| 出现数量 | 1–3 |
| 护甲等级 | 8 |
| 移动 | 1"（或宿主移动） |
| 生命骰 | 3（宿主见下文） |
| 巢穴内 | 50% |
| 财宝 | 按宿主及偶然物 |
| 攻击/伤害 | 按宿主 |
| 特殊攻击 | 乳胶 |
| 特殊防御 | 见下文 |
| 智力 | 无法评定 |
| 阵营 | 中立邪恶 |
| 体型 | 按宿主（每个生长体 1/6–1/4 英尺） |
| 等级/经验值 | III/86 + 每生命值 4，另加宿主经验值。 |

接合菌 是短细茎和卵形菌盖组成的小型单独真菌；一到两打个体由根茎结构相连，形成一个共同生物。它虽能存在于土中，却偏好寄生在活体肉内，以宿主血液和组织为食，并通过脑和神经连接控制宿主。感染后依宿主体型与体质在 1–8 周内死亡；接合菌 留在尸体上，直到整个尸体被吃尽，再移动寻找新的宿主。宿主会依真菌意志行动、攻击和防御。常见宿主为巨蚁、巨鼠、奥斯奎普，偶尔为小型人形。

菌落与生物粗略接触时，有 1/6 机会让菌盖破裂的淡蓝色“乳液”黏上对方；乳液极黏，可将材料粘合 2–5 天，随后干燥碎裂。粘在肉上会感染 接合菌 孢子，胶粉化时孢子已开始成长并控制宿主；只有 <strong>治疗疾病</strong> 能清除感染。乳胶也能把武器粘在目标上、生物粘在生物上等。

接合菌 的真菌智力完全异于人类，任何影响心智的魔法（诱惑、魅惑、支配、束缚、催眠等）都无效。
