内层位面生物以元素环境为家。地下城主可以把《怪物图鉴》《怪物图鉴 II》和《恶魔宝典》中的普通生物改造成元素对应体；它们的频率、数量、护甲、伤害、魔法抗性、智力、阵营和体型通常保持不变，主要改变外观、移动方式、免疫和脆弱性。

## 通用能力 General Abilities

元素生物通常可以穿越自己的位面以及相邻的副元素、准元素位面；它们能看见边界以太位面，也能感知进入内层位面的其他生物，但若没有额外能力，不能离开内层位面进入原初世界。水、空气、烟和蒸汽生物能在相应介质中移动；土、矿物、泥和冰生物则可在固体中穿行。

常见免疫与弱点如下：

| 类型 | 免疫或抗性 | 常见弱点 |
| --- | --- | --- |
| 空气 | 风、天气、云法术 | 土、火或相反元素攻击 |
| 火焰 | 普通火焰与热量 | 寒冷、水、冰 |
| 土 | 土和岩石塑形、部分物理攻击 | 风、水、泥 |
| 水 | 水流操纵、水环境 | 火、雷电 |
| 烟 | 空气与火焰攻击、窒息 | 水、风 |
| 岩浆 | 火焰与土 | 水、寒冷 |
| 泥 | 土与水 | 火、干燥 |
| 冰 | 寒冷与水 | 火、热 |
| 闪电 | 空气、天气、雷电 | 土、绝缘与非金属 |
| 辐射 | 火、热和光 | 黑暗、水、寒冷 |
| 矿物 | 影响固体的法术 | 改变形态、酸、震动 |
| 蒸汽 | 热、冷、空气与水法术 | 水、风 |
| 真空 | 真空、负能量、窒息 | 空气、生命能量 |
| 灰烬 | 寒冷、负能量 | 温暖、风、空气 |
| 尘土 | 火焰、负能量 | 水、风、湿气 |
| 盐 | 寒冷、负能量 | 水、治疗、湿气 |

若元素对应体在自己的免疫环境中遇到原本会造成弱点的攻击，它仍保留该免疫；位面相邻关系不会自动抹去生物的核心能力。

## 外观与体型 Appearance and Size

元素对应体不必与原始生物外貌相同。空气对应体可能由云、鸟形或箭头状气流组成；火焰对应体可能是几何火块、火焰人或火焰兽；土对应体可能是巨石、晶体、矿物雕像或带有岩石附肢的动物；水对应体则会与水流融合，边界模糊。

元素位面会改变生物体型。d100 可决定对应体比原始生物小 2 级、小 1 级、相同、大 1 级或大 2 级；小型生物的改变受限制，大型生物可能被扩大到原体型的两倍或更多。体型变化会影响护甲、命中、伤害、移动和负重。

## 准元素生物 Para-Elemental Creatures

副元素生物通常分为元素类人和元素怪物。烟、岩浆、泥和冰的元素类人可按 d20 分别决定出现几率；烟与火、岩浆与火、泥与水、冰与水的相邻关系决定它们的外观与能力。准元素生物是原初生物的元素版本，通常保留原始智能与职业能力，但获得对应准元素的免疫和弱点。

## 宝藏 Treasure of Elemental Creatures

元素生物的宝藏依照怪物书中的对应生物处理，但宝藏内容会受位面影响。空气位面的宝藏常是药剂、香水和轻质魔法物品；火焰位面有金币、宝石、金属和熔炉制品；土位面有矿石、宝石与金属；水位面有珍珠、珊瑚、沉船货物和双倍数量的金币。副元素位面的宝藏按相邻主要元素中更接近的一方处理。
