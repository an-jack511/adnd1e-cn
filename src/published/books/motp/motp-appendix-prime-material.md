原初位面也称众多原初世界，是最接近普通冒险世界的位面集合。每个原初世界都有自己的物理、魔法和时间条件；它们之间可能相似，也可能完全不同。以本位面为基准，地下城主可以为另一个原初世界指定三个参数：物理因素（PF）、魔法因素（MF）和时间因素（TF）。

## 到达原初位面 Reaching the Prime Material Planes

以太位面包围每个原初世界，内层位面可以从以太边界抵达原初世界；星界则连接原初世界与外层位面。位面转移可以把旅行者送往其他原初世界，但必须知道准确目标并承受施法误差。原初世界之间不存在普通法术可以直接跨越的稳定“公路”，旅行者通常要先进入以太或星界。

魔法物品、位面护符和某些伟大力量的领域可以打开原初世界之间的通道。每个原初世界还可能有自己的以太边界、星界颜色池、传送门和半位面；这些入口往往只被当地居民或守护者知晓。

## 三项位面因素 Three Planar Factors

### 物理因素 Physical Factor, PF

PF 表示当地科学和物理规律与本位面的差异。数值越高，世界越接近普通世界；数值越低，飞行、燃烧、体型、重力和物质反应越不寻常。

| PF | 典型效果 |
| ---: | --- |
| 10 | 科学解释失效；物质会以爆炸方式互相反应。 |
| 8 | 液体可能燃烧或爆炸，电击和闪电效果异常。 |
| 6 | 超过 10 英尺的生物罕见；部分液体和气体惰性。 |
| 5 | 大型飞行生物的飞行受限；气体和液体变化明显。 |
| 3 | 多数有翼生物可飞行；火焰和爆炸接近正常。 |
| 1 | 大多数有翼生物可飞行；智慧、体型和火焰正常。 |
| 0 | 与本位面大致相同。 |
| −1 | 飞行可由思想或超常力量实现；可出现巨型生物。 |
| −3 | 智慧和巨型生物常见，生物学不再遵循普通规律。 |
| −5 | 重力可能局部改变；火焰不需要燃料。 |
| −7 | 纪念碑、精灵建筑和古老机器可能具有生命。 |
| −10 | 整个位面可以移动；元素和生物会互相转换。 |

### 魔法因素 Magical Factor, MF

MF 表示魔法能量的密度和强度。MF 越高，普通生物越可能施法，法术等级和持续时间越强；MF 越低，法术等级受到限制，魔法物品也可能失效。施法者进入异位面时，其可用法术上限通常取本位面与目标位面之间较低的一方。

### 时间因素 Temporal Factor, TF

TF 表示世界的时间流逝与本位面的差异。正值可能使旅行者未来数年后才返回，负值则可能让旅行者回到过去；时间旅行造成的后果由地下城主裁定。绝大多数容易到达的原初世界的三项因素接近 0，变化只用于制造特殊战役环境。

## 在其他原初世界生存 Survival in Alternate Primes

本位面居民在 PF 接近 0 的原初世界通常能够生存。若物理因素差异超过 2，旅行者的体型、移动、呼吸、飞行和装备可能受到影响；魔法因素差异会限制法术等级与施法数量。时间因素差异通常不会立刻伤害角色，却可能使返回本位面后错过数年或数百年。

遭遇、战斗和魔法依照当地参数处理。盗贼能力通常不受影响；战士能力通常正常；游侠在物理条件接近本位面的世界保留追踪；野蛮人只有在 PF 接近本位面时才能正常使用其特殊技能；骑士和武僧通常正常；圣武士的魔法能力受 MF 限制，但坐骑在其他位面通常仍能存在。

## 原初世界示例 Examples

标准 AD&D 战役可以视为 PF、MF、TF 均为 0 的原初世界。地下城主可以把 PF 设为 1–2，让飞行、体型和火焰略有变化；把 MF 设为 4–5，让高等级魔法普遍存在；把 TF 设为正值或负值，让一次位面旅程改变战役年代。异世界冒险的关键不是把每项规则都改写，而是给玩家一个明确、可预测的异质环境。
