<A NAME="alignment"></A>

<p>确定属性、选择种族和职业之后，还必须决定角色的阵营。有时职业已经限定了阵营：德鲁伊必须中立，圣武士必须守序善良，盗贼可以中立或邪恶，刺客则必定邪恶。不过，除德鲁伊和圣武士外，这些限制仍留下不少余地。盗贼可以是守序中立、守序邪恶、中立邪恶、混乱邪恶、混乱中立、绝对中立，甚至中立善良；刺客的选择也几乎同样多。角色可选阵营如下。</p>
<DL><DT>混乱邪恶</DT><DD>崇尚自由、无常与苦难；蔑视法律秩序、善意和善行，认为生命毫无价值。此阵营者推动混乱与邪恶，希望在由个人任性与自身欲望支配的体系中取得权力、荣耀与威望。</DD><DT>混乱善良</DT><DD>把自由与行动的不受拘束视为终极真理，同时珍视生命和每个个体的福祉，也极为尊重个人主义。他们宣扬混乱善良诸神，力求把这些价值传播到全世界。</DD><DT>混乱中立</DT><DD>比起尊重生命、行善，或轻视生命、助长邪恶，混乱中立者更看重无常和失序。善与恶是彼此配衡的两臂；两者都不应受到偏爱，也都不该占据上风，否则终极混乱本身便会受损。</DD><DT>守序邪恶</DT><DD>极为尊重法律和严格秩序，却视生命、美、真理、自由等毫无价值，至少也对它们嗤之以鼻。他们凭借严酷纪律，企图把自己的枷锁套在整个世界之上。</DD><DT>守序善良</DT><DD>同样严守法律与秩序，但目的在于改善公共福祉。为了建立秩序，当然必须牺牲某些自由；然而真理具有最高价值，生命与美也极为重要。这种社会的利益应当惠及所有人。</DD><DT>守序中立</DT><DD>把规制视为至高要务，在善恶之间取中道。他们认为，世界乃至整个宇宙若想达到终极和谐，唯一希望就在法律与秩序。与使万物变得可预测、受规制这一坚定目标相比，善恶都无关紧要。</DD><DT>中立邪恶</DT><DD>认为法律与混乱都只是无谓的顾虑，纯粹的邪恶才是一切。两者都可利用，却同样是愚蠢的累赘，对把最大程度的邪恶带给世界毫无用处。</DD><DT>中立善良</DT><DD>与正相反的中立邪恶不同，他们相信，要为世界带来最佳状态——尤其是让一切生物、特别是智慧生物获得最有利的生存条件——就必须让一定规制与自由结合。</DD><DT>绝对中立</DT><DD>把其他所有阵营都视为万物体系的不同侧面。善与恶、混乱与秩序都必须保持平衡，现状才能维持；因为事物本来已不可能真正改善，即便偶有改善也只是短暂而肤浅。只要围绕自然核心的“轮子”不因人类等智慧生物这种非自然力量的干预而失衡，自然终会占上风，使万物保持其应有面貌。</DD></DL>
<p>自然，每种阵营之内都有程度不一的倾向与变化；以上描述只是概括。即使属于“绝对”中立，角色也可能基本偏善，或逐渐趋向邪恶。你的战役裁判很可能会用图表记录角色在阵营图上的偏移。每次冒险中角色的行为（以及意图）都会影响这项记录；有些行为可能使角色声明的阵营逐渐移向、甚至真正变成另一个阵营。</p>
<h2>改变阵营 Changing Alignment</h2>
<p>角色完全可能在非自愿的情况下改变阵营；主动改换阵营则极为困难，只有有限范围内的变化稍易实现。邪恶阵营可以沿同一轴线变动，中立角色也可选择一个更明确的阵营。除此之外，裁判很可能要求角色作出严厉牺牲并完成相应行为，甚至还须执行一项使命；事实上，即便只在善或恶的同一轴线上变动，或由中立向外偏移，也可能需要提出有力证明。此后若再主动改变阵营，难度会更高；想主动回到曾经背弃的阵营几乎不可能。即使是非自愿的偏移，也必须付出重大的赎罪代价。</p>
<A NAME="hit-points"></A>
<H1>角色生命值 Character Hit Points</H1>
<p>角色和怪物一样，各自拥有数量不同的生命值。生命值表示角色在被杀死之前能承受多少实际或潜在伤害。其中一部分确实代表肉体所能承受的创伤；但在高等级时，相当大的一部分其实代表技巧、运气和魔法因素。普通武装人员大约承受5点伤害便会死亡。假设一名10级战士有55点生命值，又因体质获得30点加值，总计85点；这大致相当于生物的18枚生命骰，足以杀死四匹大型战马。即使是幻想世界里的战士，真能用肉身承受如此伤害也荒谬可笑。牧师、盗贼及其他职业虽程度稍轻，道理仍然相同。因此，生命值的大部分象征战斗技巧、运气（由超自然力量赐予）与魔法力量。</p>
<p>生命值由生命骰决定。1级角色通常只有一枚生命骰（游侠和武僧例外，起始各有两枚）；此后每升一级再获得一枚生命骰，即掷骰决定新增生命值。治疗药水、疗伤法术、再生戒指乃至祈愿术都能以魔法恢复生命值，但角色的生命值绝不能超过生命骰初始结果、体质加值（或减值）与魔法装置共同确定的上限。例如，一名角色在冒险开始时有26点生命值，就不能靠喝药水或接受法术使生命值高于26。</p>
<DIV>例：上述26点生命值的角色踏上冒险。探索地下城之初，他跌入陷阱，承受一枚六面骰（1d6）的伤害，结果为4点，生命值降至22。随后在战斗中又受15点伤害，降至7点。牧师对他施放重伤治疗术，恢复10点（实际数值取决于掷骰），生命值回到17。之后的行动又把他降至3点，但队伍使用祈愿术让所有成员恢复至满值，于是他再次回到26点。</DIV>
<p>休息也能恢复生命值，因为身体得以愈合，并重新积蓄构成技巧、运气与魔法生命值的体力或力量。角色职业决定其生命骰种类。有些战役中，裁判会把生命值总数保密，只告诉玩家自己感觉“强健”“疲惫”或“十分虚弱”，借此表示生命值正在减少；另一些战役则由玩家记录并追踪角色的生命值变化。两种方法都可以，采用哪一种由你所在战役的地下城主决定。</p>
<A NAME="establishing"></A>
<H1>确定角色 Establishing the Character</H1>
<h2>让角色立足于世 Establishing The Character</h2>
<p>属性、种族、职业、阵营和生命值确定之后，角色便已创造完成。接下来要为其命名，也可以补充一些家世背景；若角色不幸早逝，还可指定一名近亲继承遗物，使人物更为具体。完成这些工作后，地下城主会把角色带入战役世界。无论起点是村庄、城镇还是城市，角色多半都得先熟悉周围环境。</p>
<p>第一步往往是设法进城——例如门卫会追问你来此有何贵干。进去以后，必须找到安全而价格合理的住处，通常是某家旅店，也可能只是租来的小床、阁楼，或客栈中的房间。这里将充当据点和补给站，所以必须尽量避免闯入和盗窃。安顿好总部后，角色便可摸清当地情况，寻找购买冒险装备所需的商家；也许还得查明其他玩家角色住在何处，以便共同远征。</p>
<p>总之，角色经过创造、塑造并在当地立足后，只要买好装备、处理好与其他玩家角色的关系，就可以开始冒险。如果一时找不到其他玩家角色，或他们不愿合作，最好雇用武装人员。这类受雇者与随从详见“受雇者”和“随从”两节。</p>
<A NAME="languages"></A>
<H1>角色语言 Character Languages</H1>
<p>所有人类，以及与人类交往密切的亚人和非人种族，都说“通用语”。战役中央区域内的各国都使用这种语言；不过，裁判完全可能设定某些地区所说的通用语与角色掌握的不同。</p>
<p>除通用语外，所有能够言语交流的智慧生物还会使用各自阵营的特殊语言：混乱邪恶、混乱善良、混乱中立、守序邪恶、守序善良、守序中立、中立邪恶、中立善良与绝对中立语。角色会说哪一种由阵营决定，而且每个角色只能使用一种阵营方言（参见“角色职业：刺客”）。角色若改变阵营，便再也不能说原先掌握的阵营语言。</p>
<p>除此之外，德鲁伊有自己的特殊语言，盗贼则有秘密黑话“盗贼暗语”。因此，角色至少会说两种语言：通用语和阵营语；还可能会说德鲁伊或盗贼的特殊行话。亚人和非人角色还会各自的种族语言（见“角色种族”）。在大多数战役中，公开说阵营语很可能被视为严重失礼。</p>
<p>角色可以学习额外语言。即使思维相当迟缓（智商80）的人也能多学一种，不过词汇量、运用与翻译能力必然有限；非常聪慧的人则能学习五、六乃至七种。（可学习语言数量详见“角色属性：智力”。）新语言的学习方法如下。</p>
<p>角色必须找到一名会说目标语言的人类、亚人、非人或会说话的生物，并与这位老师近距离相处最多一年。智力每高于12一点，学习时间便比一年少一个月：智力13需11个月，智力14需10个月，依此类推，智力18只需6个月。同一时间只能学习一种新语言。</p>
<UL><LI>战役中究竟可以学习哪些语言，完全由地下城主决定。常见语言包括：矮人语、精灵语、地精语、半身人语、大地精语、狗头人语、蜥蜴人语、食人魔语、兽人语。</LI></UL>
<p>受战役环境限制，上述语言未必都能学到；反过来，表中未列的语言也可能十分常见。请咨询地下城主。举例来说，若你捉到一名半人马或某种会说话的龙，就有可能学习相应生物的语言。</p>
