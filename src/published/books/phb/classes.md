<h2>角色职业（说明、职能与等级） CHARACTER CLASSES (Descriptions, Functions, Levels)</h2>
<p>角色职业就是玩家角色所从事的行当。你打算怎样参与游戏、认为怎样最能应对其中的挑战，以及希望扮演什么角色，都由职业（或多职业）决定。牧师主要提供支援，但也有一些攻击法术，并能有效使用护甲与武器。德鲁伊是牧师的子职业，行事方式与其他牧师相近，却较不擅长战斗，在荒野环境中则更有本领。战士通常投身近身肉搏，因为他们一般比其他职业拥有更多生命值和更好的武器。圣武士是守序善良的战士（见“阵营”），达到较高等级后还能获得有限的牧师能力。游侠是另一种战士子职业；他们战力强大，高等级时还会得到少量德鲁伊与魔法法术。魔法师不应指望自己擅长近战，但拥有大量攻击、防御和获取信息的法术，几乎全靠魔法解决游戏提出的难题。幻术师是魔法师的子职业，主要差别在于所用法术的种类。盗贼依靠机智、灵巧和隐秘行动。刺客是盗贼的子职业，是邪恶而悄无声息的杀手。武僧则是修习锻体与徒手战斗的苦行弟子。后文将逐一详述各职业。你要自行决定角色的职业，但选择会受已生成的属性值限制，也可能受角色种族限制。</p>
<p>以下各表可让你迅速看出职业之间的主要差异。若要作具体比较，仍须结合各职业条目中的详细规则。请注意，多职业的非人及半人种族通常只会受到盗贼职业的限制。也就是说，战士／魔法师可以同时运用护甲、武器与法术的优势；战士／盗贼则受盗贼职业的限制。</p>

<h3>角色职业表 I 注释 Notes Regarding Character Classes Table I</h3>
<p>“角色职业”不言自明。表中省略了多职业，但下文会说明与其有关的若干规则。</p>
<p>生命骰类型表示相应职业的角色每获得一个经验等级时，应掷哪种骰子来决定自己的生命值。多职业角色按以下步骤确定生命值：</p>
<OL><LI>分别掷出角色各职业对应的生命骰。</LI><LI>将所有骰子的结果相加，再应用体质调整。</LI><LI>用总数除以角色的职业数（两个或三个）；小于 &#189; 的小数舍去，达到或超过 &#189; 的小数进位到下一个整数。</LI><LI>所得商数，就是多职业角色在该经验等级提升时获得的生命值。</LI></OL>
<p>请注意，多职业角色若已不能继续提升某个职业，便不再从该职业获得生命骰。（见“角色生命值”。）</p>
<p>生命骰数量上限假定角色没有种族等级限制，能够升到取得相应生命骰数量所需的等级。还须注意：若职业（或种族）没有等级上限，即使角色已不能再获得生命骰，升级时仍会继续获得额外生命值。（见“角色生命值”。）</p>
<p>施法能力只表示该职业能否使用法术。（法术详情见“角色法术”。）</p>
<p>职业等级上限表示角色在相应职业中最多能升到多高。由表可见，多数职业本身没有上限，但非人或半人种族可能受到种族等级限制。</p>
