# 每近战轮攻击次数表 Attacks Per Melee Round Table

本表适用于<strong>战士、骑士及其子职业</strong>使用刺击或劈砍武器时的一般每轮攻击次数。使用<strong>专精武器</strong>的战士与游侠应改用前文的武器专精表。

| 职业 | 等级 | 每近战轮攻击次数 |
|:---|:---:|:---:|
| 战士 | 1–6 | 1/1 |
| 野蛮人 | 1–5 | 1/1 |
| 游侠 | 1–7 | 1/1 |
| 骑士 | 1–5 | 1/1 |
| 圣武士 | 1–6 | 1/1 |
| 战士 | 7–12 | 3/2 |
| 野蛮人 | 6–10 | 2/3* |
| 游侠 | 8–14 | 3/2 |
| 骑士 | 6–10 | 3/2 |
| 圣武士 | 7–12 | 3/2 |
| 战士 | 13 以上 | 2/1 |
| 野蛮人 | 11 以上 | 2/1 |
| 游侠 | 15 以上 | 2/1 |
| 骑士 | 11–15 | 2/1 |
| 圣武士 | 12–18 | 2/1 |
| 骑士 | 16 以上 | 5/2 |
| 圣武士 | 19 以上 | 5/2 |

*原书扫描中野蛮人 6–10 级确实印为 `2/3 rounds`，与前后等级的递增趋势矛盾。此处照录，待人工校勘原书勘误。*

<strong>原书注：</strong>此表不适用于与<strong>少于一枚 d8 生命骰</strong>的怪物，以及非例外的人类与半人类交战；上述对象可按<strong>每等级每轮攻击一次</strong>处理。战士与游侠使用专精武器时，本表也不适用。
