容貌反映角色的外表吸引力、社交仪态与个人美貌。它决定他人对角色的初次反应；容貌很高的角色甚至可能影响他人的意志和行动。魅力专门涉及领导力和角色之间的交往，容貌则关系到外貌吸引力与第一印象。两者并不相同，不过魅力会影响容貌。

确定角色原有的六项属性后，还须确定其长相：丑陋、寒碜、平凡，还是漂亮？掷 3d6 并相加，取得 3 至 18 的容貌基础值，再作以下调整。

| 魅力 | 容貌调整 |
|:---:|:---:|
| 低于 3 | -8 |
| 3 | -5 |
| 4–5 | -3 |
| 6–8 | -1 |
| 9–12 | 0 |
| 13–15 | +1 |
| 16–17 | +2 |
| 18 | +3 |
| 高于 18 | +5 |

魅力低于 3 时，调整后的容貌可能落在 -5 至 +10 之间。疾病、毁容、衰老或神器使魅力升降时，容貌也应逐点同幅变化：魅力减少 1 点，容貌同样减少 1 点。

某些种族还须作额外的容貌调整。这项种族调整只用于判断<strong>其他种族</strong>的反应，和魅力的种族调整一样；同族彼此看待时不应用它。

| 种族 | 对其他种族的容貌调整 |
|:---|:---:|
| 半兽人 | -3 |
| 矮人、侏儒 | -1 |
| 半身人、人类 | 0 |
| 半精灵、木精灵 | +1 |
| 灰精灵、高等精灵 | +2 |

在计算有效容貌时，把表中列于同一格的成对种族视为同一种族。例如，半身人在人的眼里，与人类彼此看待一样有吸引力或令人反感；反过来亦然。

容貌对人形生物有以下效果。这里包括人类、亚人类、类人生物、巨人类，以及外形和动机近似人类的双足生物；并不限于这些类别。

<strong>-16 或更低。</strong> 见到角色的人会厌恶、惊骇，以致转身离开，或试图消灭这个令人不忍直视的生物。如果低容貌者十分强大，反应往往变成逃跑，或者加深先前已经形成的敬畏（恐惧）。若观看者与此生物同属邪恶阵营，则按同等数值的正容貌处理。

<strong>-15 至 -9。</strong> 他人会显露反感，倾向于移开目光、辱骂此人，并普遍怀有敌意。除非观看者全都属于邪恶阵营，因而可将负容貌视为正容貌，否则他们绝不会接纳此人。

<strong>-8 至 0。</strong> 所有观看者都会厌弃此人，希望远离这般丑陋的生物。若有借口，身边的人会公然敌视甚至攻击；否则，他们通常只是排斥此人。

<strong>+1 至 +6。</strong> 角色显然丑陋，旁人会不自在，希望尽快离开。若有机会充分交谈与来往，角色的魅力可以抵消外貌造成的不利印象。

<strong>+7 至 +9。</strong> 角色相貌寒碜，初次接触会给人负面印象，但反感并不强烈。若有交谈与人际互动，高魅力很快就能克服它。例如，一名魅力 16、容貌基础值 9 的矮人，面对矮人以外的生物时，容貌为 8；在其他矮人眼中，其容貌只受魅力 +2 调整。

<strong>+10 至 +13。</strong> 长相平凡或普通，对观看者没有效果。

<strong>+14 至 +17。</strong> 相貌出众，接触者会对观看此人产生兴趣。反应调整增加的百分数等于角色的容貌数值。异性会主动接近；除非其感知超过角色容貌的 50%，否则会如同受到*迷醉术 Fascinate*影响。

<strong>+18 至 +21。</strong> 角色的美貌令人侧目、心跳加速。初次接触时，反应调整的百分数等于容貌数值的 150%。异性若感知不超过角色容貌的三分之二，会如同受到*迷醉术*影响；同性若感知低于对方容貌的 50%，也会如此。若角色严厉地拒绝他人，被拒绝者可能改按角色实际正容貌数值之半、但取负值，作出反应。

<strong>+22 至 +25。</strong> 这般惊人的美貌与 17–21 的效果相近，但旁人会聚集过来、尾随角色，甚至做出种种傻事，只为引起注意。反应调整的百分数为容貌数值的两倍，例如容貌 22 就是 +44%。感知低于容貌数值三分之二的人都会受到类似*迷醉术*的力量影响。若容貌 22–25 的角色有意追求某位异性，除非对方感知达到 18 或更高，否则对方会受到迷醉。遭到拒绝时，按前述方式处理。

<strong>+26 至 +30。</strong> 这种超凡美貌只可能属于异位面生物，例如半神、女半神，以及特别的神祇。反应调整的百分数仍为容貌数值的两倍。感知未达到容貌数值 75% 的人都会受类似*迷醉术*的力量影响；但感知达到 19 或更高者总能对此作法术豁免。若这种美貌的拥有者有意追求某位异性，只要对方感知低于 20，就必然受到此人“魅力”的控制。

高容貌产生的类迷醉效果，与幻术师二环同名法术相似。受影响者会为角色倾倒，把对方当作可信赖的朋友、导师与伙伴。成功通过对法术豁免即可免受影响；但若容貌并非魔法造成，*解除魔法 Dispel Magic*、反魔法法术及类似法术都不能消除这种迷醉。

受迷醉者会服从高容貌角色的命令，前提是一次 3d6 掷骰结果不超过该角色的容貌。若请求不符合受迷醉者自身利益，掷骰结果加 1；若请求有危险，则加值最高可达 +6，甚至更高。掷骰结果超过角色容貌时，迷醉效果即告解除。

受迷醉者若曾遭恶待，摆脱迷醉后会按该角色具有负容貌作出反应。若得到善待，即使迷醉消退，仍可能保持友好。

容貌对他人的影响是暂时的。一旦别人熟悉了角色，容貌效果便消失，改由魅力决定反应与追随者。因此，高容貌、低魅力的角色可以吸引目光，却难以长期留住追随者和盟友；美貌终究只是表象。

迷醉力量不会妨碍受影响者战斗、施法等能力，也绝不会把人变成行尸走肉般的傀儡。受迷醉期间的行为可能影响阵营，不过判定时应为容貌检定给予较大的有利调整，例如 +3 或 +4。

魔法能轻微、暂时地改变生物容貌。以幻术为基础的*改变自身 Change Self*与*变形自我 Alter Self*，无论最终外形如何，至多使容貌增减 1 点。高容貌人物或生物的幻象只在一轮内有效：迷醉效果会使受影响者格外专注地观察幻象，从而削弱其效果。*变形术 Polymorph*使容貌相对原值增减 2 点，因为观察者还能察觉到视觉之外的细微社交线索；*变化形体 Shapechange*则赋予最终形态的全部容貌效果。
