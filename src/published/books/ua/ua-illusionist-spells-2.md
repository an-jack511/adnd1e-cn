# 幻术师二环法术 Second Level Spells

以下四项依原书印刷第 67–68 页详述顺序排列。

## 改变自身 Alter Self（变化／幻术系 Alteration/Illusion）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 2 | 法术成分 | 言语、姿势 |
| 距离 | 0 | 施法时间 | 2 段 |
| 持续时间 | <strong>3–12 轮＋每级 2 轮</strong> | 豁免 | 无 |
| 影响范围 | 幻术师本人 | | |

类似*改变自身外貌 Change Self*，但改变具有<strong>半真实</strong>性质，身材可较原本增减 <strong>50%</strong>。所选形态若有翅膀，幻术师确能飞行，但速度仅为该生物真实飞行速度的 <strong>1/4</strong>，机动等级降低两档，最低到 <strong>E</strong>。若有鳃，可在法术持续期间水下呼吸。变成更大的生物并不会自动得到额外攻击或伤害，除非幻术师本就习惯该形态。

## 着迷术 Fascinate（幻术／幻影系 Illusion/Phantasm）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 2 | 法术成分 | 言语、姿势 |
| 距离 | 3″ | 施法时间 | 2 段 |
| 持续时间 | 特殊 | 豁免 | 成功则无效 |
| 影响范围 | 一个生物 | | |

幻术师试图吸引目标的注意，赢得其喜爱、友谊或服从。此术使施法者在目标眼中成了可信赖或渴望亲近的伙伴。若目标对法术豁免失败，便会尽可能跟随幻术师，只要不必过分危及自己的性命或安全。

若能与着迷目标交谈，幻术师每提出一次要求便掷 <strong>3d6</strong>；结果不超过幻术师的<strong>容貌值 Comeliness</strong>时，目标照办。显然违背目标利益的要求使掷骰 <strong>＋1</strong>；更危险、更不合理的要求使掷骰 <strong>＋2 至 ＋6</strong>。一旦掷骰结果超过容貌值，法术立刻破裂，目标会充满愤怒和憎恨。

一般具有动物智力的生物仅着迷 <strong>1–4 天</strong>；若幻术师谨慎善待、照顾并喂养它，法术结束时，它有<strong>每点施法者容貌值 2%</strong>的几率自愿继续友善并跟随。否则，未受照顾者会攻击，受过照顾者则会离开。<strong>无智力生物</strong>不受此术作用。

## 紫外视觉 Ultravision（变化系 Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 2 | 法术成分 | 言语、姿势、材料 |
| 距离 | 接触 | 施法时间 | 2 段 |
| 持续时间 | <strong>6 回合＋每级 1 回合</strong> | 豁免 | 无 |
| 影响范围 | 接触的生物 | | |

除上述等级、施法时间与持续时间等差别外，作用与[魔法师四环紫外视觉](/books/ua/ua-magic-user-spells-4/)相同。原书另指出，智力高的生物可能凭天生或魔法赋予的紫外视觉察觉隐形生物。此幻术师版本的材料成分为<strong>胡萝卜精质粉末</strong>。

## 低语之风 Whispering Wind（变化／幻影系 Alteration/Phantasm）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 2 | 法术成分 | 言语、姿势 |
| 距离 | 特殊 | 施法时间 | 2 段 |
| 持续时间 | 特殊 | 豁免 | 无 |
| 影响范围 | 半径 <strong>2″</strong> | | |

可传递讯息或制造指定声响。地下传送距离以施法者等级乘 <strong>10 尺</strong>计算，地表以上则以等级乘<strong>英里</strong>计算；例如三级幻术师可在地下传 <strong>30 尺</strong>，户外传 <strong>3 英里</strong>。风在抵达指定目标前，轻柔得仿佛无人注意的微风；抵达后以低语声传讯，或发出别的声音，至多持续 <strong>2 段</strong>，随后消失。目标超出射程、施法后超过 <strong>2 小时</strong>，或法术被魔法解除时，它也会消失。

风可携带最多 <strong>12 个词</strong>的讯息，或发出长达 <strong>12 秒</strong>的其他声音；也可以只发出轻微的簌簌气流声。施法者可设定其速度为每轮 <strong>1″–20″</strong>间任一数值；抵达后不论此前速度如何，都会盘旋整整 <strong>2 段</strong>。如*魔嘴术*，不能通过低语之风施展法术。
