## 物品术 Item（变化系 Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 3 | 法术成分 | 言语、姿势、材料 |
| 距离 | 接触 | 施法时间 | 3 段 |
| 持续时间 | 每级 6 回合；用于非活体时增为 4 倍 | 豁免 | 特殊 |
| 影响范围 | 每级 2 立方尺 | | |

触碰体积未超上限的普通、非魔法物品，使其缩至原尺寸的 <strong>1/12</strong>；还可任选使缩小后的材质变得像布。活物也能作为目标，且只有活物可<strong>对法术豁免</strong>，其豁免获得 <strong>＋4</strong>。已经变成布状的物体或生物再遭攻击时，仍按原本状态进行相应豁免。

受术物品只要被掷向坚实表面，或由原施法者说出命令词，就能恢复原本尺寸与材质。火及其燃料也可一并受术。

## 材料术 Material（塑能／咒法系 Evocation-Conjuration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 3 | 法术成分 | 言语、姿势 |
| 距离 | 1″ | 施法时间 | 1 轮 |
| 持续时间 | 永久 | 豁免 | 无 |
| 影响范围 | 每级 1 立方尺 | | |

造出寻常的<strong>原始、未经加工材料</strong>，如石、土、木；水、空气、粪、稻草等其他无生命物质也可造出。尝试造出草地之类简单植物时，基础失败率为 <strong>100%</strong>，每施法者等级降低 <strong>1 个百分点</strong>。绝不能造出动物生命，也不能造出加工、精炼、制造完成的物品，或高价值宝石、贵金属。本术只创造普通而基本的事物。

## 梅尔夫的微型流星 Melf's Minute Meteors（塑能／变化系 Evocation/Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 3 | 法术成分 | 言语、姿势、材料 |
| 距离 | 每级 1″ | 施法时间 | 5 段 |
| 持续时间 | 特殊 | 豁免 | 无 |
| 影响范围 | 每枚飞弹一个目标 | | |

施法者能投掷与自身等级相同数量的小火球。每枚作为<strong>投掷飞弹武器</strong>判定，未命中时按类似手榴弹的飞溅武器处理；命中时爆成直径 <strong>1 尺</strong>的火球，使目标受 <strong>1–4 点伤害</strong>，或点燃可燃物，甚至实木板。剩余飞弹持续可用，直到全部发出、施法者放弃，或对其施放的*解除魔法*成功。

施法后须从下列两种发射速度选定一种，<strong>不可再改</strong>：

- <strong>每 2 段一枚：</strong>在施法完成后的第 2 段，施法者指向目标发出第一枚，之后每隔 2 段再发一枚；这通常跨越到下一轮。
- <strong>每轮一枚：</strong>从施法当轮开始，每轮须放出一枚；施法者可选择该轮何时发射，也可在同一轮施展另一法术，但新法术不能要求持续专注，否则剩余流星会不由自主地放弃。

若施法者不能准确记住尚余几枚流星，也表示其已不由自主地放弃剩余部分。材料成分是用松焦油将硝石、硫黄调成的小珠，以及一支精制的微型中空金管。金管因精细工艺和魔法刻纹，制作费至少 <strong>1,000 金币</strong>，但只要不受损，便可反复施展此术。

## 密页术 Secret Page（变化系 Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 3 | 法术成分 | 言语、姿势、材料 |
| 距离 | 接触 | 施法时间 | 1 回合 |
| 持续时间 | 直到被解除 | 豁免 | 无 |
| 影响范围 | 一页，最大 2 尺见方 | | |

使一页的真实内容看起来完全不同：地图可装成研究黑檀手杖抛光的论文，法术文字可装成账本或另一种法术。可在密页上施放*语言混淆*和*爆炸符文*；*通晓语言*却不能揭示真实内容。

原施法者只须说出命令词便能暂时显示真页、阅读后再恢复伪装；连续说出命令词两遍则永久移除此术。别人若察觉页面上的微弱魔法，可尝试*解除魔法*，但若解除失败，页面会被毁坏。若不使用*解除魔法*，除*改变现实*、*祈愿术*外，只有鬼火或恶作剧精的精华能揭示真页。材料成分是磨碎的鲱鱼鳞片。

## 褐蛇符印 Sepia Snake Sigil（咒法／召唤系 Conjuration/Summoning）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 3 | 法术成分 | 言语、姿势、材料 |
| 距离 | 1/2″ | 施法时间 | 3 段 |
| 持续时间 | 特殊 | 豁免 | 无 |
| 影响范围 | 一个符印 | | |

符印有三种形式，最终都召出一条深褐色蛇形力量，扑向最近的活物，但<strong>不会攻击施法者</strong>。其攻击如同生命骰等于施法者等级的怪物。若命中，目标被闪烁的琥珀色力场包围并冻结，直到施法者主动释放，或*解除魔法*解除。在此之前，外物无法触及或移动力场及受困者；受困者不衰老、不饥饿、不睡眠、不恢复法术，也不察觉周围环境。

若蛇形力量未命中，便在棕光、巨响和一团直径 <strong>1″</strong>、持续 <strong>1 轮</strong>的土褐色烟雾中消散。三种施法用途是：

1. 施法者在空中画发光符印，并将它指向预定目标。
2. 在某个表面刻褐色符文，触碰或注视它的人会触发。
3. 在魔法著作中写一个小符号，用于保护该书。

材料成分是价值 <strong>100 金币</strong>的琥珀粉、一片任意蛇鳞及一撮蘑菇孢子。

召出一面强劲的无形风幕，足以吹起乌鸦大小的鸟，或扯走不提防者手中的纸张等轻物；是否握住物品有疑义时，可作<strong>对法术豁免</strong>。普通昆虫不能穿越。松散物，包括衣服等布料，碰到风墙便向上飞起。材料成分是一把微型扇子和一根来自异域的羽毛。
