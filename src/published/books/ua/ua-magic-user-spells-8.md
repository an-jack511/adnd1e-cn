# 魔法师八环法术 Eighth Level Spells

以下四项按原书印刷第 63–64 页顺序译录。原书在*强求术*的数值栏只列言语、姿势，正文却又规定材料成分；两处均照录。

## 束缚术 Binding（附魔／塑能系 Enchantment-Evocation）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 8 | 法术成分 | 言语、姿势、材料 |
| 距离 | 1″ | 施法时间 | 特殊 |
| 持续时间 | 特殊 | 豁免 | 特殊 |
| 影响范围 | 一个生物 | | |

捕获一名来自下层位面的生物。目标必须<strong>先被某种拘束阵图困住</strong>。束缚能持续多久，取决于束缚形式、施法者的有效等级，以及实际诵念的时间。施法者须从卷轴或书页连续诵读咒文，并做出对应形式的手势；材料视形式而异，例如以特殊金属制作的小锁链（恶魔用铁、魔鬼用银、冥界属下用镍等）、罕见的催眠草药、每目标生命骰价值 <strong>1,000 金币</strong>的大钻石或刚玉，以及绘有目标的羊皮纸或雕刻小像。

若施法者的<strong>有效等级至少为目标生命骰的两倍</strong>，目标不得豁免。否则，它可对法术豁免，修正由束缚形式与双方等级／生命骰的比例决定。有效等级按主持施法者的等级，加上每名 <strong>9 级以上</strong>助手等级的三分之一，再加上每名 <strong>4–8 级</strong>助手贡献的 <strong>1 级</strong>计算；最多可有 <strong>6 名</strong>魔法师助手。

| 束缚形式 | 效果与期限 | 可豁免时的修正 |
|:---|:---|:---:|
| 锁链 Chaining | 使目标受带有厌斥作用的束具拘禁；除施法者外，所有接近它的生物都受厌斥影响。最长每有效等级 <strong>1 年</strong>。目标仍留在拘束阵图内。 | 正常 |
| 昏睡 Slumber | 使目标陷入昏迷，最长每有效等级 <strong>1 年</strong>；仍留在阵图内。 | ＋1 |
| 缚眠 Bound Slumber | 结合锁链与昏睡，最长每有效等级 <strong>1 个月</strong>；仍留在阵图内。 | ＋2 |
| 围禁 Hedged Prison | 将目标移入或带入一片封闭区域，任何方法都无法使其自行离开；直到魔法边界遭破坏。 | ＋3 |
| 变形 Metamorphosis | 除头或脸外，将目标变为无实体形态；直到完成预定的解放行为。 | ＋4 |
| 极小收容 Minimus Containment | 将目标缩至 <strong>1 英寸或更矮</strong>，囚禁于宝石或类似物体的魔法围禁中。 | ＋5 |

围禁、变形与极小收容只有<strong>极微弱魔法灵光</strong>。若目标事先被*痛楚术*削弱，上述豁免掷骰再受 <strong>−1</strong>；被*折磨术*削弱则 <strong>−2</strong>；两术先后合用则 <strong>−4</strong>。豁免成功时，目标挣脱束缚，可自行行动。

前三种束缚可重新施展以延续，因为目标在其间无法自行挣脱；但满 <strong>1 年</strong>后，目标获得一次正常的对法术豁免，成功即解除并获自由。若接触目标或以魔法触及它等行为削弱了锁链或昏睡，续施时也适用正常豁免。

## 强求术 Demand（塑能／附魔与魅惑系 Evocation-Enchantment/Charm）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 8 | 法术成分 | 言语、姿势（原书数值栏） |
| 距离 | 特殊 | 施法时间 | 1 回合 |
| 持续时间 | 特殊 | 豁免 | 特殊 |
| 影响范围 | 一个生物 | | |

基本作用与*传讯术*相同，但施法者可在讯息中加入相当于*暗示术*的要求。目标若对法术豁免失败，便会尽力照办。若该要求按目标收到讯息时的处境来看相对不可能或不合情理，它仍能理解讯息，但无需豁免，暗示也不起效。

<strong>原书正文</strong>另列材料成分：两根各有一端开口、用细铜线相连的圆筒，以及目标身上的少量部分，如头发或指甲。数值栏与正文不一致，游戏时由地下城主裁定。

## 奥提路克的念动球 Otiluke's Telekinetic Sphere（塑能／变化系 Evocation-Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 8 | 法术成分 | 言语、姿势、材料 |
| 距离 | 2″ | 施法时间 | 4 段 |
| 持续时间 | 每级 1 轮 | 豁免 | 成功则无效 |
| 影响范围 | 每施法者等级直径增加 <strong>1 尺</strong>的球体 | | |

作用与四环*奥提路克的韧性球*相同，另使球内物体的有效重量仅为实际的 <strong>1/16</strong>。施法者可用念动力托举球内实际重量<strong>不超过 5,000 磅</strong>的目标；包住目标后，操控距离最长为每施法者等级 <strong>1″</strong>。即使球内总重超过 5,000 磅，有效重量仍是十六分之一，因此可以不费特别力气地滚动球体。

由于重量降低，球内物体的快速运动或坠落相对无害；若球体在高空硬质地面上方消失，则可能酿成灾难。除*韧性球*的材料成分外，还需一对小条形磁铁。

## 沉陷术 Sink（附魔／变化系 Enchantment-Alteration）

| 项目 | 数值 | 项目 | 数值 |
|:---|:---|:---|:---|
| 等级 | 8 | 法术成分 | 言语、姿势 |
| 距离 | 每级 1″ | 施法时间 | 8 段 |
| 持续时间 | 特殊 | 豁免 | 特殊 |
| 影响范围 | 一个生物，或每施法者等级 <strong>1 立方英尺</strong>的物体 | | |

施法者须不受打断地诵念前 <strong>4 段</strong>。此时目标被固定在原地，并取得脚下表面的密度，除非生物对法术豁免成功，或有魔法性质的物体对解离豁免成功。普通非魔法物体无权豁免。这里的“魔法性质”包括魔法物品、受附魔或具有魔法来源的物品，以及受防护法术、永久魔法或类似法术作用的物品。

施法者此时可停止施法，让目标维持现状；法术在 <strong>4 回合</strong>后消散，目标恢复正常。若继续诵念，目标在第 <strong>5 段</strong>沉入自身高度的四分之一，第 <strong>6、7 段</strong>各再沉入四分之一，第 <strong>8 段</strong>完全没入地面。

活物因此处于类似*停滞*的状态，除此以外不会受伤。无论生物或物体，沉入后都完整无损，且其最高处位于地表以下、深度等于自身高度：例如 <strong>6 尺</strong>高的目标，其最高处在地下 <strong>6 尺</strong>。移走目标周围的地面便会破除法术，目标恢复正常，但不会自动升上来。*挖掘术*、*化石为泥*、*自由术*（*囚禁术*的逆向法术）等可以协助救出目标，不会伤害它。

对施过此术的区域使用*侦测魔法*，即使目标已在侦测范围之外，也会显示一股难以辨明的微弱魔法；若目标在范围内，则能辨明其为附魔／变化性质。
