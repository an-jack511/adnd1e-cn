# 侏儒 Gnomes

*地底侏儒 Deep Gnomes*又称斯维夫尼布林（svirfneblin），是栖居地底深处的侏儒亚种族。他们可选择地表侏儒获准选择的任意职业或多职业组合。不是幻术师的地底侏儒，在较高等级还会获得特殊能力。地底侏儒比地表亲族更健壮，粗糙的皮肤从中棕色到灰棕色不等，眼睛呈灰色。

地底侏儒保有侏儒侦测坡度、不稳固墙壁，以及判断地下深度与方向的标准能力。此外，他们在地下深处的天然岩石之间，有 <strong>60%</strong> 的概率把自己伪装得与环境融为一体；在移动、攻击或做出其他会解除隐形的行动之前，效果等同隐形。

玩家角色地底侏儒必须是男性，因为从未听说这个亚种族的女性踏上冒险生涯。玩家角色没有非玩家角色斯维夫尼布林天生的魔法抗力，但对抗毒素的豁免骰 <strong>+2</strong>，所有其他豁免骰 <strong>+3</strong>。他们和同族一样免疫幻象与幻觉的效果。与非玩家角色地底侏儒不同，玩家角色的天然护甲等级不会随等级提高而自动改善。玩家角色为何失去某些能力，原因可能与前述卓尔的情况相近。

地底侏儒会说自己的语言，它与地表侏儒语有亲缘关系。依智力值，他们还可以学习其他语言，尤其是地下使用的语言。除非特意学会土元素位面生物的语言，否则玩家角色地底侏儒不能与这些生物交谈；土元素位面的生物攻击他们的可能性，也与攻击其他种族成员一样。

地底侏儒成为玩家角色时，会失去一些原本来自与土元素位面密切联系的好处。不过，<strong>不是幻术师</strong>的地底侏儒仍保有每天召唤一次土元素生物的天赋。他们在任一职业达到 <strong>6 级</strong>后，即可用类似魔法师法术*召唤元素生物 Conjure Elemental*的方式运用此能力。掷 <strong>d20</strong> 决定召来的生物；若召唤失败，当天不得再试。

| d20 | 召唤结果 |
|:---:|:---|
| 1 | 24 生命骰土元素生物 |
| 2–6 | 16 生命骰土元素生物 |
| 7–10 | 12 生命骰土元素生物 |
| 11–15 | 8 生命骰土元素生物 |
| 16–18 | 岩石兽 Xorn |
| 19–20 | 召唤失败，当天不能再试 |

玩家角色地底侏儒每天可各使用一次下列类法术能力：*目盲术 Blindness*、*朦胧术 Blur*和*改变自身 Change Self*；效果等同由与角色最高职业等级相同等级的幻术师施展。地底侏儒还持续散发相当于*防侦测术 Non-detection*的效果，但只作用于本人，不影响一片区域。

斯维夫尼布林的红外视觉范围为 <strong>12″</strong>，超视觉范围却只有 <strong>3″</strong>。在强光下，他们各类视觉的范围都缩至 <strong>3″</strong>；在这种照明条件下对敌作战，命中骰 <strong>-1</strong>。玩家角色地底侏儒遭到突袭的概率只有 <strong>1/12</strong>；若单独行动，或只与其他地底侏儒结伴，且未穿笨重护甲，则有 <strong>9/10</strong> 的概率突袭他人。玩家角色地底侏儒没有灵能能力。

近战攻击卓尔或寇涛鱼人时，地底侏儒的命中骰与伤害骰均 <strong>+1</strong>。这两个种族是他们的敌人，正如地精和狗头人是地表侏儒的敌人一样。遭到巨人、熊地精、食人魔法师、食人魔、巨魔或泰坦攻击时，他们也享有地表侏儒同样的好处。
