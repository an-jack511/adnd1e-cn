战士子职业<strong>游侠</strong>可以使用前述战士的<strong>武器专精</strong>规则。此外，下列追踪、“巨人类”对手及武器使用资料，应取代或补充《玩家手册》中对应的职业描述。

## 追踪 Tracking

追踪主要用于户外；在特定地下或“室内”环境中，游侠也能追踪生物。

<strong>户外追踪。</strong> 基础成功率为<strong>游侠每级 10%，另加 10%</strong>，如 1 级为 20%、6 级为 70%；10 级及以上最高可达 <strong>110%</strong>。即使如此，调整后的几率仍可能因负面修正降至 100% 以下。超过 100% 的最终几率按 <strong>100%</strong> 对待：在地形、追踪人数等当前条件不变时，可以一直沿踪迹追踪。

| 户外地形 | 修正 |
|:---|:---:|
| 地面足以留下足迹、爪印等压痕 | +20% |
| 偶尔留下折断树枝、弯草等明显痕迹 | +10% |
| 因岩石、水、风或其他生物交错／盖过踪迹，只留下零星痕迹 | 0% |
| 除最细微痕迹外几乎不留下经过的迹象 | −50% |

除被追踪群体中的<strong>第一只</strong>生物外，每多一只生物 <strong>+2%</strong>。足迹留下后，每经过 <strong>12 小时 −5%</strong>；游侠与目标之间的足迹每遭受 <strong>1 小时降水 −25%</strong>。若目标有意识地掩盖行踪，应把地形修正降到下一较低类别，例如从 +20% 降到 +10%；本已为 −50% 时便无法追踪。

<strong>室内追踪。</strong> 基础成功率与户外相同。根据经过的表面调整：

| 室内表面 | 修正 |
|:---|:---:|
| 泥土地面，或无人使用且积灰的区域 | +20% |
| 木地板，或偶尔会留下通行痕迹的区域 | 0% |
| 仅可能留下极细微痕迹的石地板 | −50% |

除第一只外，每多一只被追踪生物 <strong>+2%</strong>；经过其他生物穿越或盖过踪迹的区域 <strong>−50%</strong>。若目标刻意掩盖行踪，包括穿越暗门，把表面修正降到下一较低类别；本已为 −50% 时便无法追踪。

若游侠从未观察到目标足迹的任何明显特征，或者目标留下足迹后游侠未在合理时间内（通常 <strong>10–30 分钟</strong>）注意到目标留下踪迹的过程，则无法在室内追踪。地下城主应按常识判断：蠕虫、软泥和凝胶等留下明显踪迹的生物几乎总能追踪；飞行生物、幽灵、怨魂和蜘蛛等通常不留下痕迹，几乎无法追踪。不过追踪结合了视觉、听觉和嗅觉，有时仍可凭飞行扰动物品、行进声或残留气味等特别线索追踪。

<strong>光照与移动。</strong> 以下以日光或同等良好照明为正常条件。即使条件最佳，追踪中的游侠移动仍较慢；光线或踪迹质量更差时，速度还会降低。

| 踪迹与光照 | 追踪时移动率 |
|:---|:---:|
| 明显踪迹、良好光照 | 正常的 3/4 |
| 明显踪迹、昏暗光照 | 正常的 2/3 |
| 偶见踪迹、良好光照 | 正常的 2/3 |
| 偶见踪迹、昏暗光照 | 正常的 1/2 |
| 微弱踪迹、良好光照 | 正常的 1/2 |
| 微弱踪迹、昏暗光照 | 正常的 1/4 |

“明显”指追踪机会 <strong>71% 或以上</strong>，“偶见”为 <strong>31%–70%</strong>，“微弱”为 <strong>30% 或以下</strong>。“昏暗”指低于日光但尚非全黑；在<strong>完全黑暗</strong>中，若无前述非视觉线索，便无法追踪。

<strong>辨认足迹。</strong> 无论室内或户外，游侠可能判断留下踪迹的生物种类、行进方向、群体人数及速度；户外还可能估计留下踪迹的大致时间。只有<strong>追踪检定成功</strong>时才能辨认，辨认再以同样成功率<strong>另掷一次骰</strong>。各级能力累积：例如 4 级游侠兼具 3 级能力；“林地生物”指依 AD&D 遭遇表可在妖精／森林环境或荒野森林中出现的生物。

| 游侠等级 | 可辨认的事项 |
|:---:|:---|
| 1 | 常见林地生物的足迹与行进方向。 |
| 2 | 常见林地生物的数量及步速。 |
| 3 | 常见林地生物留下踪迹的时间，<strong>仅户外</strong>。 |
| 4 | 对不常见林地生物，可达到 3 级辨认能力。 |
| 5 | 对稀有林地生物，可达到 3 级辨认能力。 |
| 6 | 对极稀有林地生物，可达到 3 级辨认能力。 |
| 7 | 对 <strong>100 英里</strong>半径内的任何生物（林地或其他），可达到 3 级辨认能力。 |
| 8 | 具备 7 级能力，并可判断人类的大致体型与体重。 |
| 9 | 具备 8 级能力，并可判断骑乘生物的体型和数量，例如一匹马是否载有超过一名骑手。 |
| 10 | 对曾观察过的任何生物，不论是在升到 10 级前还是之后，均可达到 9 级辨认能力。 |

## 游侠的武器

游侠最初熟练的 <strong>3 种</strong>武器中，必须有一种是<strong>任意种类的弓</strong>或<strong>轻弩</strong>。但在至少 <strong>7 级</strong>、取得第五个武器熟练项之前，游侠不能同时熟练弓与轻弩。达到 <strong>4 级</strong>、取得第四个熟练项时，已掌握的武器必须包括：

1. 弓或轻弩；
2. 匕首或小刀；
3. 矛或斧；
4. 任意种类的剑。

选择初始武器时即须考虑上述要求。如果游侠专精其中一种武器，对应条件仍视为满足；若专精导致角色到 4 级时尚未拥有四种熟练武器，则取得的前四种熟练武器最终仍须分别覆盖上述四类。
