# AD&D 1E 规则术语覆盖审查

## 当前判断

规则术语表现有 **754 个英文词形条目**，是已收录词条数，不是覆盖完成度。不能据此称规则名词已齐全。当前主表状态为 484 项 `verified-exact`、270 项 `adapted-variant`（含已标注范围的自译），无待核项；主表、生成目录与父目录副本已同步。出处字段涵盖 DMG、PHB、DSG、WSG、UA、OA、MM、MM2 及若干设定书；这些粗略分布只反映已登记的证据范围，并不代表任何一本书已经系统审完，也不适合用来估算规则术语总量。MM 的怪物数据字段此前是显著空白，现已补齐 12 项字段名；`Size` 采用可核译名“体型”，另 11 项依 1E 栏位语境自译并逐项记录检索范围。

特别是 MM 中大量承载怪物数据的规则字段（护甲等级、移动率、生命骰、攻击、伤害、特殊攻击／防御、魔法抗性、豁免、智力、士气等）不应因为怪物名称表很大就视为已经进入规则术语表。相同地，PHB 的职业、属性、时间、战斗、施法、装备、熟练项、灵能等规则分散在正文、表格和附录，单靠 DMG 术语表也无法覆盖。

本轮从跨书候选中核验 `XP VALUE`：DL16 p.8、DLA p.76、OA p.119 的怪物记录均将其作为经验奖励字段；依 DMG 术语表已核译的 `Experience Points`＝“经验值”，收录为同一数值概念的字段变体。精确英文标签在现有 3R／5E／5R 词条快照中无匹配，因此标作 AD&D 1E 变体，而非误称为后续版精确核译。

此外，OA p.119 将 `LEVEL/XP VALUE` 合并显示为怪物等级与经验奖励字段；现以“等级／经验值”登记为组合字段，分别沿用已核的 Level 与 XP Value 译名，不冒称后续版存在该组合标签。

为使规则术语查询能直接识别时间层级的原词，本表另收 Turn、Round、Segment 三个未带消歧括注的检索别名，严格限定为 AD&D 1E 的 10 分钟回合、1 分钟轮、6 秒段；后续版单位时长不同，不能因译名相同而视为机制相同。

历史排查中的三项熟练项合成“表名”已在批次 1125 移出正式主表（不再 pending）：OA 原文为 Proficiency Tables 与表 58–61，WSG 原文为 Table 2: Wilderness Proficiencies，DSG 则分别列角色、工匠、冒险熟练项表；未找到 Nonweapon／Wilderness／Dungeon Proficiency Table 这些精确原文标题，因此不能把中文整理性标题反向当成原书术语。原书真实表名另作后续扫描入口，不把这三个合成标题当作原书词项。

另从父目录历史文件发现两条仅供排查的旧译线索：`Frequency` 曾作“出现频率”；`Treasure Types` 曾作“宝藏类型”，与本表单数 `Treasure Type` 的暂定“财宝类型”有用词差异。该旧档不具核译权威，已在两项待核证据中记录为待查冲突，未据此定译。

以 5R XPHB 结构化整书数据（`https://5e.kiwee.top/data/book/book-xphb.json`，2026-11-25）提取 `ENG_name`／中文 `name` 标题与字段配对，去重后为 1,358 组；与 59 条待核规则词做精确英文匹配，结构化标题中命中 0 项。此结果仅覆盖该数据中的结构化标题／字段配对，不代表对所有正文词句的穷尽检索；无命中项继续待核。

## 多义词与语境标注

DMG 术语表明确指出 `Level` 至少涉及地下城深度／难度、法术环阶、角色／职业／经验等级、施法者等级及怪物强度尺度；网站的泛称主译“等级”不能机械替换所有语境。`Turn`、`Round`、`Segment` 按 AD&D 1E 时间层级固定为回合、轮、段；BATTLESYSTEM `Game Round` 是七阶段的大规模战斗轮次，另列“游戏轮”，不并入一分钟近战轮。`Mob` 和 `Rout` 也已注明为 BATTLESYSTEM 专门部队类别与士气／撤退状态。以上义项及出处写入 `sense-notes.json`，开放 API 和术语查询页按义项提供筛选、查找与展示；后续扫描继续扩展同形异义词的来源和语境标注。

## 每项新增或修订的记录要求

1. 先确定 AD&D 1E 原词及原书版本／页码；在原书上下文中判断它是规则术语、普通叙述、字段标签、专名，还是某一规则机制的特定用法。
2. 按用户指定次序核查 3R → 5E → 5R 的可靠中英术语来源；若某版本存在英文精确对应且语义相符的可定位中译名，按 3R→5E→5R 顺序采用为主译；采用名称不等于移植该版本机制，概念有差异时必须分列适用范围。查不到的版本要如实标注，不能用近似词条补证。
3. 建立概念区分：同一机制的不同叫法可作别名；相似词若机制不同则拆分。保留单复数、派生词和缩写作为搜索异体时，不为其重复制造伪条目。
4. 每个原文术语都必须有中文主译：先按 3R→5E→5R 查可用译法；未找到时按既有术语、D&D 翻译惯例、词素及 1E 语境自译，记入 `rule-terms.tsv` 并标 `adapted-variant`／`self-translated-after-3R-5E-5R-search`。只有原文词项或语境本身不能确认时才保留 pending；当前站内译文只作待改目标，不作译名正确性的证据。
5. 待原书页段覆盖完成后，再逐词按术语主表回查正文、标题、表格和跨书引用，找出同概念多译、同译多义及英文副标题只译一半等问题；在此前阶段专注补齐术语库。

后续补全顺序按用户要求先处理规则重灾区，再处理法术、怪物与装备引用；核心规则书优先于零散设定材料。术语表达到“详尽”的条件是各子系统和来源页段均有盘点记录、候选均有去向，不能预设 500、1000 或其他任意数量为完成线。

本轮按 5E 中文站 `Parser.ITM_RARITY_TO_SHORT` 精确映射补入 Common／Uncommon／Rare／Very Rare 四个稀有度词项（常见／不常见／珍稀／非常珍稀）。将后两级译名用于 1E 怪物频率字段值时，只借用等级词义，不移植 5E 魔法物品稀有度机制。OCR 证实 1E MM 与 MM2 的 Frequency 字段使用这些英文值；字段名 `Frequency` 的既有中文候选“出现频率”尚未按新流程完成译名定稿。下一步先查找 3R／5E／5R 精确字段译名；若无可用对应译法，按 1E 字段语境自译并记录依据，不因未找到版本对照继续保留 pending。


MM2 怪物栏盘点补入三个真实词形变体：`Special Attack`／`Special Defense`（单数栏名）与 `Psionic Abilities`（复数栏名）。各词形分别回到 MM2 OCR 页核对，映射到既有中文字段；没有将拼版 OCR 中的无空格或斜线空格误读另立为术语。当前 3R／5E／5R 快照无这些栏名的精确对照，故记录为 1E 词形变体，不冒称后续版已核译。

`LEVEL/X.P. VALUE` 是 MM2 与 Fiend Folio 怪物记录中可见的原书标注，与 `LEVEL/XP VALUE` 是同一等级／经验值组合栏。本词形以 OCR 原页为依据记录为拼写缩写变体；没有扩展到正文所有 `X.P.` 语境。
